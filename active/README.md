# active/

Work in progress for the channel and the site — not built into the site.

| Folder | What goes in it |
| --- | --- |
| `scripts/` | Video scripts. One file per video; record from these. |
| `concepts/` | Ideas, outlines and storyboards before they become scripts. |
| `art/icons/` | SVG icons in the site style (24 px grid, 2 px stroke). |
| `art/scenes/` | Illustration scenes (16:9 SVG) for videos, slides and lesson heroes. |
| `pixelmator/` | Thumbnail, profile picture and channel cover templates — open in Pixelmator Pro. |
| `finalcut/` | The CRMA Final Cut Pro kit (titles, transitions, backgrounds). |

Script cues in `[Brackets]` name a Final Cut title from the kit, e.g. `[Key Point]`.
`(B-roll: …)` is what is on screen while I talk.
