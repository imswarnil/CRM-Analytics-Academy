# Contributing

Thanks for helping. Most help needs no code at all:

- **A resource, a lesson fix, a translation fix** — send it from
  [crmanalytics.imswarnil.com/submit](https://crmanalytics.imswarnil.com/submit).
  A person reviews every submission.
- **Code** — read on.

## Run it locally

```bash
pnpm install        # Node 22, pnpm 11
pnpm dev            # http://localhost:3000
pnpm lint           # run before every commit
pnpm typecheck
```

The site works without a database. Accounts, progress and comments need a
Neon database in `.env` — copy `.env.example`.

If the docs sidebar is empty or you see `no such table: _content_docs`, the
local content cache is stale: `rm -rf .data && pnpm dev`.

## Lessons

Lessons are Markdown in `content/en/<NN.section>/<NN.lesson>.md`. Numbers are
always two digits. Start a new one with `pnpm new-lesson`, check it with
`pnpm lesson:check`.

**Write English only.** Every other language is generated by `pnpm translate`
— never edit `content/<other language>/` or `i18n/locales/<other>.json` by hand.
If a translation reads wrong, fix the English sentence or suggest wording on
the site.

## Pull requests

1. Fork, branch from `main`.
2. Keep the change small and focused; `pnpm lint` and `pnpm typecheck` pass.
3. Describe what changed and why. Screenshots for anything visual.

Questions: [open an issue](https://github.com/imswarnil/CRM-Analytics-Academy/issues).
