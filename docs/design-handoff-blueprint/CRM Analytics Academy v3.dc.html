§1The pattern

Load the dataset, group by the dimension you care about, then project only the measures you'll chart. Keep the stream narrow early — every column you carry costs query time.

pipeline.saql
q = load "opportunities";
q = group q by 'StageName';
q = foreach q generate 'StageName', sum('Amount') as 'Pipeline';
q = order q by 'Pipeline' desc;
Tip: In Lens mode, open the SAQL editor to see the query behind any click-built chart.
