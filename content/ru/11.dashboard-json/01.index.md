# Когда открывать JSON

А. CRM Analytics приборная панель - это JSON документ: виджеты, макеты, запросы и привязки, все как текст. Создатель пишет его для вас, и иногда текст является лучшим инструментом.

::note{icon="i-lucide-file-json"}
**Это не продвинутый уровень приборной панели.** Большинство приборных панелей никогда не должны иметь своих JSON Открытый, и стремление к тому, чтобы он сделал что-то, что строитель делает идеально, - это способ создать приборную панель, которую никто другой не может поддерживать. Он зарабатывает свое место для объемной работы, для обзора и для нескольких вещей, которые интерфейс не раскрывает.
::

## Две плохие причины

::warning{icon="i-lucide-hand"}
**Не использовать JSON Делать обычную работу быстрее и не использовать ее, чтобы быть умным.** Панель приборов, отредактированная вручную в конфигурацию, которую конструктор не может перевернуть, является панелью приборов, которую вы можете изменить, что является той же ошибкой, что и перебор. Если строитель может выразить это, пусть строитель выражает это. JSON Это то, чего не может сделать строитель, и то, что он сделал.
::
