# Обсуждение Graded Quiz: Setup and Access

Десять вопросов. Как всегда, оценивается в вашем браузере, с ответами обязательно внутри страницы.

::tip{icon="i-lucide-target"}
**Вес является преднамеренным.** Четыре из десяти – это неудачи, которые *молчать* — отсутствующее поле пользователя интеграции, нуль, который не закрывается, админ, заблокированный собственным предикатом, обратный результат наследования. Молчаливые неудачи — это те, которые достигают производства, поэтому их стоит перепроверить.
::
