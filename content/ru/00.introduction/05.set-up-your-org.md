# Создайте свою организацию

Вам нужна организация для создания. Этот урок за полчаса перенесет вас из ничего в рабочий набор данных и пропустит все объяснения, которые могут подождать — раздел доступа охватывает лицензии, пользователя интеграции и безопасность на уровне строк.

::warning{icon="i-lucide-alert-triangle"}
**Не используйте обычную подписку Developer Edition.** Бесплатный разработчик Org **не** включать CRM Analytics, и вы не можете включить его из настройки — лицензии нет в организации. Используйте CRM Analytics Подписка на промоверсию Developer Edition ниже. Это самый распространенный способ пропустить первый вечер.
::

## Эти два разрешения устанавливаются в одном абзаце.

CRM Analytics Доступ предоставляется по установленному разрешению, а не по профилю и не будучи администратором. **CRM Analytics Плюс админ** несет разрешения на создание и управление: приложения, наборы данных, рецепты, панели инструментов и возможность видеть все данные через платформу. **CRM Analytics Плюс пользователь** Разрешение на ежедневное использование. В реальной организации они обращаются к разным людям, и различие является предметом раздела доступа; в вашей собственной практике вы хотите и то, и другое, а затем вы хотите забыть об этом, пока раздел доступа не объяснит, почему существует разделение.

::tip{icon="i-lucide-log-out"}
**Если Analytics Studio плитка отсутствует** После назначения наборов разрешений выйдите и войдите обратно. Задания для набора разрешений иногда требуют нового сеанса, прежде чем запускать приложение. Это решает его гораздо чаще, чем любое другое исправление.
::

## Что означает «приложение», потому что оно сбивает с толку

Ан **приложение** в CRM Analytics контейнер с общими настройками — ближе к папке, чем к приложению. Наборы данных, линзы и приборные панели живут внутри одного. Совместное использование приложения делится тем, что в нем есть, поэтому раздел исследования о сотрудничестве в значительной степени является уроком о дизайне приложения, а не о кнопках.

Ваша организация уже содержит образцы приложений из Salesforce. Оставьте их в покое; они являются полезным справочным материалом и иногда на них указывает урок. Все *ты* Строить входит в **Академия Аналитики**.

Загрузить a CSV Это займет десять секунд. Проверка занимает две минуты и экономит сборку. Три вещи идут не так, в этом порядке частоты:

fields:
  - name: "Date fields read as text"
    type: "most common"
    role: "date"
    note: "Дата, набранная в виде текста, не может быть отфильтрована по дате, сгруппирована по месяцу или использована в переключателе дат. Он прекрасно смотрится в таблице, поэтому выживает до того момента, когда вам нужна линия тренда. Фиксация означает редактирование атрибутов поля и перезагрузку файла."
  - name: "IDs typed as measures"
    type: "common"
    role: "key"
    note: "Цифровой идентификатор выводится как мера, поэтому CRM Analytics Будет весело предлагать суммировать — и кто-то, в конце концов, предложит. Принудить его к измерению при загрузке. Это имеет наибольшее значение для AccountId и CampaignId, к которым вы будете постоянно присоединяться."
  - name: "Currency scale"
    type: "expensive when wrong"
    role: "measure"
    note: "Проверьте десятичную шкалу на любую сумму. Значение, сохраненное в центах, но прочитанное как целое число, выпадает на 100 ×, каждое последующее число наследует его, и ничто не предупреждает вас. Сравните один ряд с CSV глазами, прежде чем двигаться дальше."
  - name: "Row count"
    type: "always"
    role: "measure"
    note: "Набор данных README перечисляет истинное количество строк для каждого файла. Если ваш выключен одним, у вас есть проблема с заголовком; если он равен нулю, нагрузка вышла из строя и Data Manager Монитор объясняет причину."
