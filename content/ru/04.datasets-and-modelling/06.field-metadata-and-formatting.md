# Метаданные поля и форматирование

Каждый набор данных несет метаданные о своих полях: метка отображения, формат, агрегация по умолчанию, видимость. Установка его один раз - это разница между набором данных, который люди могут использовать, и тем, который нуждается в переводчике.

## этикетки

`Sum of Amount__c` Вот что говорят данные. "Выручка" - это то, что говорит бизнес. Ярлык принадлежит набору данных, где каждый объектив и каждый виджет наследуют его.

::tip{icon="i-lucide-users"}
**Маркировка для читателя, а не для строителя.** Техническое название поля полезно для вас около недели; этикетка читается всеми, кто когда-либо открывает приборную панель, в течение многих лет. Если бы можно было спутать два поля — `Amount` о возможности и `LineAmount` на продуктовой линейке — сделать этикетки однозначными, а не короткими: «Сделка» и «Линия» предотвратят настоящую ошибку.
::

## Форматы

Валютные символы, тысячи разделителей, десятичные знаки, проценты. Фиксация их в наборе данных устраняет наиболее распространенный косметический дефект. CRM Analytics Приборные панели — одна и та же мера отформатировала три разных способа на одном экране, потому что три человека построили три виджета.

::note{icon="i-lucide-coins"}
**Децимал - это решение, которое можно прочитать, а не точное.** Никто не принимает решение о центах в 58 миллионов долларов, и шесть десятичных знаков на коэффициенте конверсии означают уверенность, которую данные не могут поддерживать. Вокруг того, что нужно для решения: вся валюта для итогов, одна десятичная для ставок, и пусть точная стоимость живет в режиме таблицы для тех, кто этого хочет.
::

## Агрегация по умолчанию

Мера может нести разумный дефолт — обычно сумма, иногда средняя, иногда максимальная. Это мелочь, которая незаметно предотвращает реальную ошибку:

::warning{icon="i-lucide-triangle-alert"}
**Поле ставок с дефолтом `sum` Это заряженный пистолет.** Данные об использовании Namilio содержат процент использования на счет в месяц. В течение двенадцати месяцев учетная запись с 80% использованием составляет 960%. Ничего не ошибается, диаграмма отображает, а число - чепуха. Установите средний показатель по умолчанию — и, что лучше, следуйте советам раздела подготовки данных и вычислите ставку из агрегированных сумм вместо того, чтобы вообще хранить ставку на один оборот.
::

## Скрытые поля

Набор данных с шестьюдесятью колонками, из которых пятнадцать являются ключами и внутренними флагами, враждебен любому, кто его исследует. Скрыть то, что никто не должен группировать: суррогатные ключи, внутренние булевы, постановочные колонки.

Это имеет наибольшее значение для **самообслуживание**, который является предметом исследования раздела. Полевой список, состоящий из пятнадцати значимых элементов, приглашает к исследованию; один, который состоит из шестидесяти элементов, половина из которых названа. `X__c`Научите людей, что этот инструмент предназначен для специалистов.

**Делайте это до обмена набором данных, а не после.** Как только существует десять виджетов, изменение метки безопасно, но изменение агрегации по умолчанию означает аудит каждого из них. Пять минут на старте стоит пять минут; те же пять минут позже стоит день проверки.
