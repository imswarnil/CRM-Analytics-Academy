# Создайте базовый набор данных с Dataset Builder

Теперь мы строим настоящий Salesforce набор данных. **Dataset Builder** Оригинальный управляемый инструмент: он ходит по объектным отношениям *для тебя*, вычисляет ключи соединения автоматически и записывает его инструкции в **поток данных**. Это самый дружелюбный способ поднять базовый набор данных, именно поэтому я все еще передаю его людям, изучающим платформу.

Помните план из зернового урока: этот набор данных **О возможностях**Начнем с возможностей и посмотрим *вверх* для аккаунта и пользователя.

::tip{icon="i-lucide-plug"}
Dataset Builder Читать дальше → **Соединение/синхронизация**не от Salesforce напрямую. В отличие от CSV Загрузите, синхронизация должна быть на месте. Если объект не синхронизирован, вы не сможете его выбрать.
::

## Снимите это.

из Analytics Studio: **Создание → Dataset Salesforce Данные**. Это средний вариант — вы не загружаете CSVИ вы не строите поверх существующего набора данных (этот путь приводит к рецептам).

Вас спросят, какой поток данных использовать. Каждое судно с **по умолчанию Salesforce поток данных**Вы можете добавить его или создать свой собственный. В производстве у вас обычно будет небольшое количество названных, запланированных потоков данных, и вы будете точно знать, что каждый из них населяет. Теперь используйте дефолт. щелкнуть **Следующий** и Dataset Builder открывается в Data Manager вкладка.

## Начните с самого низкого объекта

Dataset Builder Теперь он показывает все объекты, до которых может добраться. Наши трое **Возможность**, **Счет**и **Пользователь**.

::lesson-steps
---
items:
  - title: "Выберите возможность первым"
    description: "Это основной объект и зерно. Начнем с того, что позволяет вам связаться с учетной записью и пользователем. Начните с Аккаунта вместо этого, и вы застрянете — ему негде искать."
  - title: "Добавление аккаунта через отношения"
    description: "Наведите узел Opportunity, нажмите плюс, откройте Отношения и выберите Аккаунт. Это поиск — он прикрепляет поля учетных записей к каждой возможности."
  - title: "Добавить пользователя (владельца)"
    description: "Из отношений Opportunity добавьте таблицу пользователей, чтобы привлечь владельца возможности. Теперь у вас есть три подключенных узла."
---
::

Зерно держит: **Каждый шаг – это уникальная возможность**, обогащенный учетной записью, которой он принадлежит, и пользователем, который им владеет. Возможность не учитывается дважды.

::tip{icon="i-lucide-wand-2"}
Заметьте, что вы *не* Вы никогда не говорили, что возможности `AccountId` равный счету `Id`. Dataset Builder Прочитайте отношения прямо из Salesforce Схема и проводные ключи для вас. Это автоматическое обнаружение ключей - вся причина, по которой оно удобно для начинающих.
::

При наличии отношений добавьте поля, необходимые для каждого объекта. В прохождении это примерно:

::tip{icon="i-lucide-triangle-alert"}
**Как только вы нажмете «Далее», вы не сможете вернуться на этот экран.** Забудьте поле, и вам придется редактировать узел дайджеста потока данных (подробнее об этом следующем уроке). Поэтому, прежде чем двигаться дальше, дважды проверьте каждое поле, которое вам нужно. Дважды промерь, один раз щелкни.
::

Когда ваши поля установлены, выберите приложение (приватное приложение отлично, пока вы учитесь) и нажмите **Создать Dataset**. Dataset Builder Вкладывает все это в поток данных и запускает его. В следующем уроке мы будем смотреть, как он работает, и справляться с ошибками, которые новые учебные организации любят бросать с первого раза.
