## Версия

Конечные точки несут версию на пути. Пин.

::note{icon="i-lucide-pin"}
**Прикрепленная версия — это сценарий, который продолжает работать при обновлении платформы, а неподкрепленная версия — это сценарий, который меняет поведение на свидании, которое выбрал кто-то другой.** Обновляйте намеренно: меняйте версию, бегите против песочницы, подтвердите форму ответа, что вы ожидаете, а затем отправляйте. Это двухминутная привычка, которая предотвращает класс неудач, когда в вашем хранилище ничего не изменилось, и работа все равно сломалась.
::

## Ограничения для проектирования вокруг

Каждая платформа имеет их, и конкретные цифры движутся, поэтому совет заключается в форме, а не в цифрах.

::compare-cols
---
items:
  - title: "Формы, которые масштабируют"
    subtitle: "Work with the limits"
    icon: "i-lucide-check"
    pros:
      - "Batch — one call with many rows rather than many calls with one"
      - "Incremental — send what changed, not everything, every night"
      - "Back off and retry on a rate-limit response rather than hammering"
      - "Check the current limits for your edition before sizing anything"
    cons:
      - "More code than the naive version"
    verdict: "Write it this way from the start."
  - title: "Формы, которые проваливаются в масштабе"
    subtitle: "Fine in a test, not in production"
    icon: "i-lucide-x"
    pros:
      - "Simple, and works beautifully against 100 rows"
    cons:
      - "A call per row exhausts the daily allowance and starves everything else in the org"
      - "A full reload every night when 2% of rows changed"
      - "No retry, so one transient error loses the whole run"
    verdict: "This is how an analytics job takes down an org's API budget."
---
::

::warning{icon="i-lucide-gauge"}
**API Пределы оргширокие.** Жадная аналитическая работа не только замедляет себя — она потребляет довольствие, на которое также опираются интеграции, мобильные клиенты и другие команды. Это делает погрузчик неправильной формы операционной проблемой для людей, которые никогда не слышали о вашей приборной панели, и это причина для партии, прежде чем кто-либо попросит вас.
::
