## Скелет

```python
import os, csv, json, math, requests

BASE   = os.environ["SF_INSTANCE_URL"]        # from the secret store
TOKEN  = get_access_token()                    # refreshable
HEAD   = {"Authorization": f"Bearer {TOKEN}"}
CHUNK  = 10_000                                # rows per part

def declare(dataset, operation, metadata):
    """Create the upload job. Nothing is sent yet."""
    body = {"Format": "Csv", "EdgemartAlias": dataset,
            "Operation": operation, "Action": "None",
            "MetadataJson": metadata}
    r = requests.post(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData",
                      headers=HEAD, json=body, timeout=60)
    r.raise_for_status()
    return r.json()["id"]

def upload_parts(job_id, rows, header):
    """Send the rows as numbered parts. Part numbers start at 1."""
    for i in range(0, len(rows), CHUNK):
        part = i // CHUNK + 1
        payload = encode_csv(header, rows[i:i + CHUNK])
        post_part(job_id, part, payload)

def complete(job_id):
    """The step that is forgotten. Until this runs, nothing is processed."""
    requests.patch(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData/{job_id}",
                   headers=HEAD, json={"Action": "Process"}, timeout=60).raise_for_status()
```

::note{icon="i-lucide-code"}
**Пути конечных точек и точное изменение схемы метаданных между выпусками** Проверьте текущую документацию для вашего API Вместо того, чтобы копировать путь из любого сообщения в блоге, включая этот. Что не меняется, так это последовательность: декларировать, части, завершать, проверять. Изучите форму и посмотрите на детали.
::

## Проверка — это та часть, которая зарабатывает себе на жизнь

```python
expected = len(rows)
actual   = dataset_row_count(dataset)          # read back from metadata
if actual != expected:
    raise SystemExit(f"load mismatch: sent {expected}, dataset holds {actual}")
```

::tip{icon="i-lucide-shield-check"}
**Потерпите громкую неудачу в несоответствии, вместо того, чтобы записывать предупреждение.** Работа, которая выходит из нуля после загрузки 80% строк, создает приборную панель, которая тихо ошибается до тех пор, пока кто-то заметит, что на номере, который никто не имеет априор, может занять месяцы. Код выхода читается планировщиком; предупреждение в журнале никто не читает.
::

## Запросить результат обратно

Один и тот же сеанс может SAQL, что делает шаг сверки естественным в конце нагрузки: вытащите общий набор данных, который теперь сообщает, и сравните его с собственной цифрой исходной системы. Это привычка к ключу ответа из автоматизированного раздела API, и это самая ценная вещь, которую погрузчик может сделать за пределами загрузки.

## Запускаю.

Что бы ни запускало его - крон, график CI, оркестратор - нужно три вещи: расписание, учетные данные из секретного магазина, и где-то неудача. *замеченный*. Работа, которая проваливается в каталог журнала, который никто не открывает, — это работа, которая не работает, и вы узнаете об этом через несколько недель.
