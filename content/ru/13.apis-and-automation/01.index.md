## Что этот раздел будет охватывать

Во всём CRM Analytics достижимо над одной API Что это делает возможным, четыре работы, которые стоит автоматизировать, и те, которые должны оставаться ручными.

## Планируемые уроки

- **Зачем автоматизировать** Все в ней CRM Analytics достижимо над одной API Что это делает возможным, четыре работы, которые стоит автоматизировать, и те, которые должны оставаться ручными.
- **The REST API** Аутентификация, семейства конечных точек, которые важны для аналитики, версионного анализа и ограничений, которые стоит разработать, прежде чем что-либо писать.
- **SAQL из кода** Отправить запрос по The API и чтение того, что возвращается — плюс четыре законных причины, по которым число из сценария отличается от того же числа на приборной панели.
- **Загрузка данных** Внешние данные APIЗаявляйте, загружайте по частям, завершайте сигнал — трехэтапный шаблон, файл метаданных, который определяет типы ваших полей, и сбой, который каждый поражает один раз.
- **Python заканчивается** Проработанный путь в Python: аутентифицировать, объявить нагрузку, нажать данные Академии по частям, завершить сигнал, проверить счет строк и запросить результат обратно.
- **автоматизация & развертывание** Расписание, учетные данные, обработка отказов и использование экспорта метаданных для предоставления панели мониторинга истории изменений, которую продукт не предоставляет.
- **Вопросы для интервью** - API и вопросы автоматизации, с модельными ответами и оперативным суждением, которое они действительно исследуют.
- **Сортированная викторина** Восемь вопросов по аутентификации, запросу и внешним API данных, операциям загрузки, планированию и изменению истории.
