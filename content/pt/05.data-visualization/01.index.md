# Gráficos são argumentos

Um gráfico não é um recipiente neutro para números. Antes que alguém leia um valor, *Forma* Já fez uma afirmação: estas coisas são comparáveis, esta é maior, esta subiu, esta é parte disso.

::note{icon="i-lucide-message-square-quote"}
**Escolha o gráfico da comparação, não do tipo de dados.** "Eu tenho uma medida e uma dimensão, então - gráfico de barras" é como a maioria dos gráficos são escolhidos, e é por isso que tantos painéis são uma parede de barras. A questão é que comparação o leitor deve fazer: *Rank*, *tendência*, *composição*, *Distribuição*, *Relacionamento*, ou *Um único valor contra um alvo.*. Cada um tem uma resposta certa e várias erradas.
::

## Como um número verdadeiro mente

Nada nesta seção é sobre fazer gráficos mais bonitos. É sobre as maneiras específicas de um número correto ser mal interpretado:

::field-table
---
dataset: "common misreadings"
grain: "one row per failure"
fields:
  - name: "A bar chart sorted alphabetically"
    type: "hides the ranking"
    role: "dimension"
    note: "Leitores assumem que as barras são encomendadas pelo tamanho. Quando não estão, o olho lê o primeiro bar como o maior de qualquer maneira, e ninguém verifica novamente."
  - name: "A line chart with a non-zero baseline"
    type: "exaggerates change"
    role: "measure"
    note: "Legítimo para uma tendência onde pequenos movimentos importam, e desonesto quando o leitor assume zero. Diga o que fez na etiqueta do eixo."
  - name: "A donut with nine slices"
    type: "shows nothing"
    role: "dimension"
    note: "Humanos comparam ângulos mal passados em quatro fatias. Nove fatias é uma mesa com um círculo."
  - name: "An average with no distribution"
    type: "hides the shape"
    role: "measure"
    note: "A utilização da empresa de Namilio de 78% é a média das contas em 30% e as contas em 130%. Ambos precisam de ação, em direções opostas, e a média não mostra nenhuma."
  - name: "A dual axis"
    type: "invents a relationship"
    role: "key"
    note: "Duas medidas em duas escalas cruzam onde você escolher para colocar os eixos. O ponto de passagem é uma decisão de formatação que os leitores interpretam como um achado."

::tip{icon="i-lucide-eye"}
**Um hábito para toda a seção.** Depois de construir qualquer gráfico, pergunte: *O que alguém concluiria disso em quatro segundos, e isso é verdade?* Não "é o número certo" - o número está quase sempre certo. A conclusão é o que dá errado.
