# Escolhendo um mapa

Comece a partir da frase que o leitor poderá dizer depois de quatro segundos. O tipo de gráfico vem dele quase mecanicamente.

## O caminho da decisão

::lesson-steps
---
items:
  - title: "É hora do eixo X?"
    description: "Se sim, você está mostrando uma tendência: linha para uma medida contínua, coluna para períodos discretos as pessoas contam (acordos fechados por mês). Mantenha o tempo na ordem do tempo - este é o único eixo que você nunca classificar por valor."
  - title: "É um número contra uma referência?"
    description: "A KPI Tile com uma comparação, ou um medidor se a referência é um alvo difícil. Nunca um gráfico de uma barra: um bar sem nada além se comunica menos do que o número escrito claramente."
  - title: "Você está classificando categorias?"
    description: "Barras horizontais, ordenadas por valor, limitadas ao topo N com o limite no título. Este é o cavalo de trabalho e é muito mais certo do que as alternativas que as pessoas alcançam."
  - title: "É composição, partes de um todo?"
    description: "Duas ou três partes: uma barra empilhada. Quatro ou mais, ou quando os valores exatos importam: uma tabela com uma coluna de ações. Um donut só quando há genuinamente duas ou três fatias e a forma em si é a mensagem."
  - title: "São duas medidas uma contra a outra?"
    description: "Espalhem-se. Uma medida por eixo, um ponto por entidade. Esta é a única família que responde 'fazer estes se movem juntos', e é muito pouco usado."
  - title: "É um espalhamento em vez de um total?"
    description: "Uma visão de distribuição: bandas, uma tabela de colunas estilo histograma. Quando estiver prestes a relatar uma média, pergunte se a forma é a descoberta."
  - title: "É um processo com etapas?"
    description: "Um funil se os estágios forem sequenciais e encolhendo, uma cachoeira se as coisas forem adicionadas e subtraídas para atingir um valor final."
---
::

## O padrão que está certo muitas vezes

**Um gráfico de barras horizontal, ordenado descendo, limitado ao top 10, com o limite no título.**

::tip{icon="i-lucide-bar-chart-3"}
**Se você não pode decidir, construa isso e siga em frente.** Ele responde à pergunta mais comum (que é maior), é legível em qualquer tamanho, sobrevive a escala de cinza e um projetor, e é muito difícil de interpretar mal. Procure outra coisa quando você tem uma razão - uma tendência, um relacionamento, uma composição - não porque o painel tem muitas barras nele. Um painel de barras que cada um responde uma pergunta real bate uma variada onde existem três widgets para interesse visual.
::

## O quê? CRM Analytics te dá

A lista de gráficos é longa, e o subconjunto útil é curto. Na prática, as famílias desta seção cobrem essencialmente todos os painéis de produção:

dataset: "the working set"
grain: "one row per family"
fields:
  - name: "Bar / column"
    type: "rank, and discrete time"
    role: "dimension"
    note: "O mais usado, e aquele cujo tipo de ordem é mais frequentemente errado."
  - name: "Line / area"
    type: "trend"
    role: "date"
    note: "Mudança contínua ao longo do tempo. Área apenas quando a quantidade preenchida é significativa - uma área empilhada de séries não relacionadas é decoração."
  - name: "Donut / stacked / treemap"
    type: "composition"
    role: "dimension"
    note: "Pequenos números de peças. Passados quatro, use uma mesa ou uma barra ordenada."
  - name: "Scatter / bubble"
    type: "relationship"
    role: "measure"
    note: "Duas medidas, e uma terceira como tamanho para bolha. Pouco usado em relação ao quanto revela."
  - name: "Number / gauge"
    type: "against a target"
    role: "measure"
    note: "A manchete da maioria dos painéis. Precisa de uma comparação para significar qualquer coisa."
  - name: "Table / pivot"
    type: "identity and exact values"
    role: "key"
    note: "A resposta certa mais frequentemente do que o pensamento centrado em gráficos sugere."
  - name: "Map"
    type: "geography, when geography matters"
    role: "dimension"

  - name: "Funnel / waterfall"
    type: "process and bridge"
    role: "measure"
    note: "Etapas sequenciais, ou adições e subtrações atingindo um total."
