# Números, Gauges e Sparklines

A maioria dos painéis abrem com um único valor. A maioria dos valores simples não são acionáveis, e a correção não custa nada.

## Um número só significa muito pouco.

"Rede nova ARR: $1.42M" - isso é bom? O leitor não pode saber, então eles perguntam ou assumem. Três ingredientes consertam:

::lesson-kpis
---
columns: 3
items:
  - label: "Número nu."
    value: "$1.42M"
    hint: "Cannot be acted on — no scale, no direction"
  - label: "Com uma comparação"
    value: "$1.42M"
    delta: "+8.3% vs plan"
    trend: "up"
    good: true
    hint: "Now it has a verdict attached"
  - label: "Com um brilho também"
    value: "$1.42M"
    delta: "+8.3% vs plan"
    trend: "up"
    good: true
    hint: "And now the reader knows whether it is normal"
    spark:
      - 820
      - 910
      - 1040
      - 980
      - 1180
      - 1310
      - 1420
---
::

::note{icon="i-lucide-gauge"}
**Número, comparação, direção.** A comparação dá escala contra o plano, contra o último período, contra o mesmo período do ano passado. A direção dá um veredicto. Diga qual comparação é, no rótulo: "Acima de 8%" contra três referências diferentes dá três respostas diferentes, e eles frequentemente discordam em sinal.
::

## A bondade pertence à métrica.

::warning{icon="i-lucide-arrow-down"}
**Descer nem sempre é ruim.** Churn caindo, CAC revanche encurtando, queda do tempo para fechar, casos passados SLA declinando, taxa de desconto caindo - todas as boas notícias. Uma paleta padrão que pinta cada diminuição de vermelho transforma um quarto forte em uma parede de alarme e ensina o leitor a ignorar a cor. Definir a direção da bondade por medida, e verificar a sanidade, perguntando: *Se este número fosse metade, eu ficaria satisfeito?*
::

## Sparklines

Um pequeno gráfico dentro do azulejo, mostrando os últimos períodos. Ele responde "isso é normal?", que é a pergunta que um único número sempre provoca e nunca pode responder.

::tip{icon="i-lucide-activity"}
**Adicione brilhos antes de adicionar outro gráfico.** Eles custam quase nenhum espaço e nenhuma atenção, e eles convertem cada KPI de uma foto para uma tendência. 112% NRR significa pouco, 112% no final de uma linha que subiu por sete meses seguidos significa algo específico, e o mesmo 112% no final de uma linha que caiu de 121% significa algo urgente.
::

## Manômetros

Um medidor mostra um valor contra uma escala, geralmente com faixas coloridas. Ganha seu espaço em exatamente uma situação: **Um verdadeiro alvo fixo onde "o quão perto estamos" é a questão**.

::compare-cols
---
items:
  - title: "Bom medidor."
    subtitle: "A real target exists"
    icon: "i-lucide-target"
    pros:
      - "Pipeline coverage against 3x — the target is the point"
      - "SLA attainment against a contractual 95%"
      - "Bands come from the business, not from thirds of the range"
    cons:
      - "Uses much more space than the number plus a delta"
    verdict: "One per dashboard at most."
  - title: "Manômetro ruim."
    subtitle: "A number wearing a dial"
    icon: "i-lucide-circle-slash"
    pros:
      - "Looks like a cockpit"
    cons:
      - "No meaningful maximum, so the scale is invented"
      - "Bands split evenly into thirds, which is arithmetic pretending to be judgement"
      - "Occupies four times the space of the KPI tile it replaced"
    verdict: "Use a number with a comparison."
---
::

## Formatando o próprio número.

::field-table
---
dataset: "number formatting"
grain: "one row per rule"
fields:
  - name: "Abbreviate on tiles"
    type: "$1.42M not $1,420,000"
    role: "measure"
    note: "Ninguém decide sobre os últimos quatro dígitos de uma manchete. Mantenha toda a precisão na mesa para quem precisar."
  - name: "Round to the decision"
    type: "one decimal on rates"
    role: "measure"
    note: "Seis casas decimais em uma taxa de conversão implica uma confiança que os dados não têm. Moeda inteira para os totais, um decimal para as taxas."
  - name: "Tabular figures"
    type: "in any column"
    role: "dimension"
    note: "dígitos monoespaçados, então uma coluna de números se alinha no ponto decimal e magnitudes são comparáveis em um relance."
  - name: "State the period"
    type: "in the label"
    role: "date"
    note: "'Net New ARR - Aug FY26, vs plano'. A leitura errada mais comum de um painel é sobre qual período uma capa de manchete, e é livre para evitar."
---
::
