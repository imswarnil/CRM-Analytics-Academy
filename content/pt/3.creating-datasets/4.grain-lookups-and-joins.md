# O Modelo Mental

Esta lição não tem vídeo de propósito. É o conceito de desacelerar. *internalizar* Antes de construir algo. Cada problema de dataset que eu tenho depurado ao longo dos anos remonta a uma de duas coisas: o errado **grão**, ou um **Junte-se** que silenciosamente multiplicam filas. Faça isso direito e as ferramentas nas próximas aulas se tornam óbvias.

## O que é grão?

**Grão** A questão é: *O que uma fileira representa?*

Quando você constrói um conjunto de dados sobre oportunidades, o grão é uma linha por **Oportunidade**. Esse é o seu **objeto central** - Seu nível mais baixo e detalhado. Tudo o mais que você traz (a conta, o proprietário) é *Informações de apoio* Apegado a essa fila de oportunidades. O grão nunca muda: uma oportunidade, uma fila.

::tip{icon="i-lucide-ruler"}
Diga em voz alta antes de construir: **"uma linha deste conjunto de dados é uma \_\_\_\_\_. "** Oportunidade. Case. Conta. Atividade. Se não consegue terminar essa frase de forma limpa, ainda não está pronto para construir o conjunto de dados. *Sobre*.
::

## Comece do objeto mais baixo.

Aqui está a regra que te salva toda vez:*Comece com seu objeto mais baixo e olhe. *Para cima.* A hierarquia.**

In Salesforce, uma oportunidade **Olhe para cima.** Para uma Conta. `AccountId`) e para um usuário proprietário (via `OwnerId`). Uma Conta se senta *Mais alto.* - Uma conta tem *muitos* oportunidades. Então...

É por isso que o objeto que você começa com é um *Decisão de design*, não um pensamento posterior. Se seu painel é sobre oportunidades, comece com Oportunidade. Se você realmente precisa de uma linha por conta, **Conjunto de dados diferente** Com um grão diferente, e tudo bem, apenas seja deliberado.

## Procuras vs juntas

Você verá a palavra **Junte-se** Nas ferramentas, mas para os conjuntos de dados de base, o que você quase sempre quer é **Procure.**.

- A **Procure.** Liga campos de um objeto "pai" de nível superior em cada fileira de crianças. Traga o nome e a indústria da conta para todas as oportunidades. **sem mudar o grão**. Uma oportunidade permanece uma fila.
- A **Junte-se** (no sentido relacional mais completo) pode combinar linhas muitos-para-muitos e **multiplicar** Eles. Junte-se às oportunidades de seus itens de linha e de repente uma oportunidade se torna cinco linhas - uma por item de linha. Às vezes é o que você quer, muitas vezes é um inseto que infla suas somas.

::tip{icon="i-lucide-triangle-alert"}
O erro clássico: você se junta a um pai para uma criança esperando uma fila e obter muitos, então cada `sum(Amount)` Agora é duas ou três contas. Quando um total parece muito grande, **Cheque seu grão primeiro.** Nove em cada dez vezes um olhar foi tratado como um fã.
::
