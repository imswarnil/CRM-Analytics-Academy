# Carregar dados de um CSV Arquivo

A maneira mais rápida de obter dados CRM Analytics é um **CSV upload**. É uma carga manual, única - sem sincronização, sem fluxo de dados, sem receita - e é perfeito para dados que vivem *Fora.* Salesforce Ou que você só precisa entrar rapidamente.

Nosso arquivo de exemplo, `Opportunity External Amounts`, navios nos arquivos de treinamento da EA (o zip do primeiro vídeo). Ele imita os dados que chegam de um sistema separado: **Nome**, um **Quantidade original**, e um **Quantidade de fatura externa**. Imagine que finanças rastreiam uma fatura externa que Salesforce Não tem, e você exportou para CSV.

Os dados estão lá, prontos para você.

## O esquema de metadados (um pouco avançado)

Quando você carrega, o motor de dados lê o seu CSV e **Adivinhe.** O tipo de cada campo: o texto se torna um **Dimensão**, os números se tornam **Medidas**. Você pode anular esses palpites na UI.

O exemplo clássico é **Código postal.**. São dígitos, então o motor lê como um *Medir.* (algo para somar ou média) — mas você nunca adicionaria códigos postais. Você corta e se agrupa por eles. Então mude de **Medir.** para **Dimensão** No local.

Na maioria das vezes, a UI é tudo que você precisa. Mas algumas coisas... **Campos multivalores** - não pode ser definido na UI. Para esses, baixe o gerado **Arquivo de esquema de metadados**, editá-lo à mão (por exemplo, definir `isMultiValue: true` Em um campo), recarregar e terminar o upload.

::tip{icon="i-lucide-info"}
Alcance o arquivo de esquema apenas quando a UI não pode expressar o que você precisa: campos multi-valores, formatação precisa de números, ou forçando um tipo que o motor errou. Para 90% dos uploads, a dimensão na tela/medida/revisão de data é suficiente. Nós cobrimos o arquivo do esquema totalmente no Data Manager Aulas.
::
