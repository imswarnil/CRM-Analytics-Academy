# Funções da Família

Você não precisa de toda a referência. Você precisa de cinco famílias e cerca de quinze funções.

## Agregação

As funções que colapsam muitas linhas em um valor, usado dentro `foreach … generate` depois de um `group`.

::field-table

grain: "one row per function"

    type: "the workhorse"
    role: "measure"
    note: "Ignora nulos silenciosamente. Uma soma sobre uma coluna que é 40% nula é uma soma de 60% dos dados, reportados sem comentários - verifique densidade nula antes de confiar em qualquer total."
  - name: "count()"
    type: "rows, not things"
    role: "measure"

    type: "distinct count"

::warning{icon="i-lucide-divide"}
**Razões: agregar ambas as partes, em seguida, dividir.** `sum('Discount') / sum('ListTotal')` é a taxa de desconto ponderada que o negócio significa. `avg('DiscountPct')` Pesa US$ 5 mil igual a US$ 1 e produz um número que ninguém reconhece. E guarde o denominador, uma divisão por zero em um mês envenena toda a série.
::

## Datas

Datas em SAQL são estruturados em vez de valores simples, com partes que você pode agrupar diretamente: ano, quarto, mês, semana, dia.

- **`date('Field_Year', 'Field_Month', 'Field_Day')`** - Construir uma data das partes para comparações.
- **`daysBetween(a, b)`** - a base da velocidade para liderar, dias em estágio, idade e tempo de ciclo.
- **`toDate()` / `now()`** - para qualquer coisa medida contra hoje.
- **Intervalos relativos** - "Quarter atual", "últimos 90 dias". Conveniente, e eles fazem uma consulta *não-determinalista*A mesma consulta retorna números diferentes amanhã, o que é correto para um painel ao vivo e uma armadilha quando você está se reconciliando com um relatório fixo.

::note{icon="i-lucide-calendar"}
**Sempre diga qual data você agrupou.** Uma oportunidade criou, perto, última modificação e datas de entrada no palco. O mesmo conjunto de dados agrupado por um diferente conta uma história genuinamente diferente, e nenhuma chamada de função na consulta dirá ao leitor o que você escolheu - apenas o título widget pode.
::

## Cordas

`lower()` e `upper()` Para comparações que não devem se importar com o caso, `trim()` para os dados que chegam de um CSV, `substr()` para extrair um prefixo, e concatenação para construir uma etiqueta composta.

::tip{icon="i-lucide-spell-check"}
**Normalizar antes de comparar, não depois.** `EMEA`, `emea` e `EMEA ` são três grupos diferentes, e um agrupamento que divide uma região em três parece um problema de dados ao invés de um de formatação. Se importa em uma consulta, geralmente importa na receita também. Conserte-a a montante para que cada painel herde a correção.
::

## Matemática e condicional

Aritmética funciona como esperado. A condicional que vale a pena saber é **`case`**, que é como você balde dentro de uma consulta:

```
q = foreach q generate 'Account' as 'Account',
      (case when 'UtilizationPct' < 55 then "At risk"
            when 'UtilizationPct' > 105 then "Overage"
            else "Healthy" end) as 'Band',
      sum('ARR') as 'ARR';
```

::warning{icon="i-lucide-repeat"}
**Se um `case` Aparece em mais de uma consulta, pertence à receita.** Regras de Bucketing duplicadas através de widgets derivam: "em risco" vem a significar menos de 55 em um painel e menos de 60 em outro, ambos defensáveis, e o desacordo aparece em uma reunião. Balde uma vez em um nó transformado e cada tela herda as mesmas bandas.
::

## Manuseio nulo

Nulls são a fonte silenciosa de respostas erradas:

- **`coalesce(a, b)`** - Substitua um padrão. Use deliberadamente: substituir nulo por zero vira "desconhecido" em "nenhum", que é uma reivindicação.
- **`is null` / `is not null`** - o teste explícito.
- **A armadilha da desigualdade** - O quê? `'Stage' != "Closed Lost"` Também remove todas as filas onde Stage é nulo. Quase nunca pretendeu, nunca anunciou.
