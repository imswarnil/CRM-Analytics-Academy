# Quando não usá-lo

Ser capaz de dizer "esta é a ferramenta errada, aqui está o porquê, aqui está o que usar em vez" é o que separa alguém que conhece um produto de alguém que pode ser confiável com uma decisão. Cinco caixas.

## 1. A exigência é em tempo real.

CRM Analytics É uma atualização de horário. Noite é típico, hora é comum, a cada poucos minutos é possível e caro, subminuto não é o que o produto é.

::warning{icon="i-lucide-timer"}
**A conversa a ter, em uma pergunta.** "Que decisão isso conduz, e quão velha pode ser antes de ser inútil?" Perguntado na primeira semana leva dez minutos. Perguntado no terceiro mês, após os conjuntos de dados e painéis existirem, é uma falha de projeto. A maioria dos pedidos "em tempo real" voltam como "esta manhã está bem" - e os que realmente significam segundos são telas operacionais, que pertencem a um Salesforce Página, um evento de plataforma, ou ferramentas feitas de propósito.
::

## 2. A tela é sobre um registro.

Armazenamento colunar é otimizado para agregar muitas linhas, não para recuperar uma inteira. "Tudo sobre esta conta em uma tela" Salesforce Página de registro, possivelmente com um componente de painel incorporado para as peças agregadas.

## 3. A maioria dos dados não está em Salesforce

CRM Analytics Pode ler absolutamente Snowflake, Redshift, S3 e bancos de dados. A questão é proporção e centro de gravidade.

## 4. A saída é um documento, não uma decisão.

Faturas, declarações, contratos, arquivamentos regulatórios paginados - qualquer coisa onde o layout é a entrega e cada linha deve aparecer. Isso é um problema de geração de documentos. CRM Analytics widgets são construídos para agregar e ser explorado, não para paginar fielmente.

## Cinco. Uma pergunta, uma vez.

Se alguém precisa de um número esta semana e ninguém vai perguntar de novo, construir um Salesforce Relatório. É livre, instantâneo, vivo e adequado. CRM Analytics Ganha seu custo quando *Muitas pessoas.* Necessidade *muitas respostas* Câmbio. *Junte-se* Dados, repetidamente.

::tip{icon="i-lucide-repeat"}
**O custo que surpreende as pessoas não é a licença, é a propriedade.** Um conjunto de dados tem um cronograma que pode derivar, um grão que tem que ser explicado a cada novo construtor, uma receita que alguém deve manter, e uma definição que alguém deve defender em uma reunião. Vale a pena pagar por um treino. É absurdo para uma única pergunta.
::

## O resumo honesto

Use CRM Analytics Quando o CRM é o centro de gravidade, quando o modelo de segurança importa, quando muitas pessoas precisam de auto-serviço sobre dados ligados, e quando os dados de horas estão bem. Isso descreve um grande número de problemas reais de análise de mercado, incluindo todos neste curso.

Use outra coisa quando a exigência for segundos, um único registro, um documento, um único, ou uma empresa cujos dados vivem principalmente em outro lugar.
