## Enviar a ordem importa (um pouco)

Não por correção, por sanidade. Carregar as dimensões primeiro para que quando você construir uma receita, os alvos de busca já existam.

::lesson-steps
---
items:
  - title: "Dimensões primeiro."
    description: "Contas, contatos, produtos, representantes, centros, campanhas. Seis pequenos arquivos. Dois minutos cada, e agora cada receita posterior pode olhar para cima contra eles."
  - title: "Então os fatos do oleoduto"
    description: "leads, oportunidades, produtos de oportunidade, citações. Isto é o que a seção de oleoduto funciona."
  - title: "Então pós-venda"
    description: "uso*mensal, arr*fotos, casos, CSAT*pesquisas, plataforma*Saudável, então o par de sala de aula, lotes e inscrições."
  - title: "Exigência por último."
    description: "Web*sessões, seo*Palavras-chave, llm*Visibilidade, marketing*Gastar. Eles não se juntam a nada, então nada os espera."
---
::

::tip{icon="i-lucide-upload"}
Use **Criar → Dataset → CSV Arquivo**, não uma receita, para o upload cru. Uma receita é para moldar. Enviar através de um significa re-executar um trabalho toda vez que quiser uma mesa crua de volta.
::

## Conserte os metadados do campo agora, não depois.

Este é o passo que todos pulam e todos se arrependem. Quando CRM Analytics Deduz um esquema que comete três erros previsíveis neste conjunto de dados.

::lesson-cards
---
columns: 3
items:
  - title: "Booleanos se tornam texto."
    icon: "i-lucide-toggle-left"
    description: "IsWon, SLABached, DefletedByAI chegam como as cordas 'verdadeira' / 'falso'. Filtrado, mas você não pode somar - e contar vitórias é uma soma."
  - title: "Números se tornam dimensões."
    icon: "i-lucide-hash"
    description: "LeadScore, Posição, Menção A classificação é lida como texto porque são números inteiros pequenos. Então você não pode média-los."
  - title: "A moeda não tem formato."
    icon: "i-lucide-dollar-sign"
    description: "Quantidade e ARR render em 120000. Defina o formato uma vez no conjunto de dados e cada gráfico herda $120K."
---
::

A correção é um conjunto de dados. **metadados de campo**, coberto pelos conjuntos de dados e seção de modelagem - editar o campo, definir o tipo, definir o formato, salvar. Faça uma vez por conjunto de dados e cada lente, painel e SAQL A consulta herda.

::metric-spec
---
items:
  - name: "Counting won deals"
    formula: "count() filtered to IsWon = true"
    grain: "Per opportunity"
    watchout: "Do NOT sum IsWon as text. If it uploaded as a string, either convert the field or count with a filter — a text 'true' summed gives you zero and no error."
---
::

## Três receitas, construídas uma vez.

Ao invés de entrar em 20 painéis, junte-se uma vez e registre o resultado. Três conjuntos de dados juntos carregam tudo nesta seção.

### Receita 1 - `opp_enriched`

O oleoduto. Oportunidades, além do contexto da conta e do representante.

::lesson-steps
---
items:
  - title: "Entrada: oportunidades"
    description: "608 fileiras. Este é o grão da saída - uma fileira por oportunidade, e deve continuar assim."
  - title: "Junte-se às contas na Contabilidade."
    description: "Olhe, não acrescente. Traz Segmento, Indústria, Região, HealthScore, SupportTier. Um-para-um, então sem fãs."
  - title: "Junte-se aos representantes do proprietário. Id"
    description: "Traz Papel, RampStatus, Anual Quota, Gerente. Olhe para o proprietário em branco em acordos de Self-Serve - eles não têm representante, e uma associação padrão vai deixá-los silenciosamente."
  - title: "Agregar os produtos de oportunidade primeiro, em seguida, juntar"
    description: "Grupo por oportunidade Id, conte os produtos e uma lista de produtos. Juntando-se aos itens de linha crua, em vez disso multiplica cada oportunidade pela sua contagem de produto."
  - title: "Junte-se à citação final."
    description: "Filtrar aspas para ISFinalVersion = verdadeiro antes de entrar, ou uma oportunidade se torna até cinco linhas."
  - title: "Saída: enriquecida"
    description: "Ainda 608 fileiras. Verifique a contagem antes de usá-la. Se crescesse, você se espalharia."
---
::

::tip{icon="i-lucide-shield-alert"}
**A única afirmação a sempre correr.** Depois de cada entrada, verifique a contagem da linha contra a entrada. `opp_enriched` Devem ser 608 fileiras. Se for 1.192 você juntou itens de linha crus; se for 818 você juntou todas as versões de citação. Contagem de linha é o teste de correção mais barato em análise.
::

### Receita 2 - `lead_funnel`

Com a campanha e o resultado.

::lesson-steps
---
items:
  - title: "Entrada: leads"
    description: "2.800 linhas, e a saída fica 2.800. Leads desqualificados ficam aqui, deixando-os inflar cada taxa de conversão."
  - title: "Junte-se às campanhas na Campanha. Id"
    description: "Traz Canal, Tipo, Gasto, Região. Lidera com uma campanha em branco Id são reais (auto-servir inscrições) - mantê-los com a esquerda juntar."

    description: "Na oportunidade convertida Id, traga de volta Stage, Quantity, IsWon. Agora um conjunto de dados responde \"qual canal produziu receita\", não apenas \"que produziu leads\"."

::note{icon="i-lucide-repeat-2"}
**Agende-os, então esqueça-os.** Defina cada receita para correr à noite. Cada painel a jusante lê um conjunto de dados, não uma junção, o que significa que um painel não pode estar errado de uma forma que uma receita não é - um único lugar para consertar, e um único lugar para auditar.
::

## O erro que vale a pena nomear

Uma tentadora quarta receita: juntar tudo em um conjunto de dados e construir cada painel sobre ele. Parece eficiente. É uma armadilha.

::compare-cols
---
items:
  - title: "Três conjuntos de dados propositais."
    icon: "i-lucide-layers-3"
    pros:
      - "Each has one obvious grain"
      - "Row-count assertions are meaningful"
      - "A fan-out is caught at build time"
    verdict: "What this section uses."
  - title: "Um amplo conjunto de dados \"tudo\""
    icon: "i-lucide-package"
    pros:
      - "Only one thing to schedule"
    cons:
      - "No single grain, so every sum is suspect"
      - "Slow, and re-runs for any change"
      - "Fan-out is invisible until a number is absurd"
    verdict: "Avoid. The convenience is real and it costs you correctness."
---
::
