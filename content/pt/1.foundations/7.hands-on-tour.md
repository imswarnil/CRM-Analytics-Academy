# Tour das Mãos: Analytics Studio, Data Manager & Histórias

Chega de teoria, vamos clicar. Esta lição é uma visita guiada do CRM Analytics Interface: **Analytics Studio**, o **Data Manager**E um verdadeiro **Einstein Discovery História**. Siga em sua organização de desenvolvedores grátis (da Lição 1) para que os conceitos das últimas lições se tornem memória muscular. O clipe acima é mais longo do que o normal porque há muito para ver.

## Entrando: Analytics Studio

CRM Analytics é alcançado através do **Lançador de aplicativos.** (o ícone da grade no topo esquerdo de Salesforce). Procure e abra **Analytics Studio** - o espaço de trabalho dedicado onde todo o seu trabalho de análise acontece.

O Estúdio **Casa** é o seu centro de comando. Espere para encontrar:

- **Favoritos** - painéis, lentes e conjuntos de dados que você usa com frequência.
- **Notificações** - Alertas disparados pelas condições de dados.
- **Assinaturas** - fotos agendadas de widgets enviados para você.
- **Watchlist** métricas rápidas que você quer ficar de olho.
- **Navegar** - Tudo organizado por **apps** e **Activos** (caixas, lentes, conjuntos de dados, histórias).

Daqui você pode abrir um **Painel** para ver curadoria, análise interativa, ou abrir um **Lente** para explorar um único conjunto de dados ad hoc, exatamente os conceitos de camada de design da Lição 5.

## O Data Manager

Mude para o **Data Manager** E você está olhando para a sala de máquinas - a camada de dados da Lição 4, tornada visível. Suas áreas-chave:

- **Monitor** - o diário de cada **trabalho de dados** (sincronia, fluxo de dados, receitas). Verifique o estado, duração e erros aqui. Esta é sua primeira parada quando um painel parece velho.
- **Fluxos de dados & Receitas** - Construir e editar suas transformações (legado fluxo de dados vs. receitas modernas de arrastar e soltar).
- **Dados / Datasets** - procurar os dados otimizados que alimentam tudo.
- **Conectar** - as conexões de Data Sync que estão nos dados de origem.
- **Conexões ao vivo. & conexões de saída** - Fontes de dados diretas (como Snowflake) e os alvos para os quais você empurra os resultados.

::tip{icon="i-lucide-activity"}
Faça o **Monitor** Tem um hábito. A maneira mais rápida de explicar "por que meu número está errado?" é verificar se o trabalho de ontem realmente funcionou.
::

## Abrindo uma história

Agora a parte emocionante - abrir um **Einstein Discovery História** e ver a camada de inteligência ganhar vida. Uma história lê seus dados e apresenta:

- **Correlações e insights** - os principais preditores e influenciadores que conduzem seu resultado, em linguagem simples.
- **E se a análise?** - mudar um valor de entrada em um registro e assistir o resultado previsto mover. É assim que um usuário constrói intuição para qual alavanca importa: "Se reduzirmos o ciclo de vendas em uma semana, a probabilidade de vitória aumenta tanto assim."

## Avaliando o modelo

Uma história responsável não é apenas uma boa visão. Ela mostra como é confiável o que está por trás disso. **Modelo** É. Procure as métricas de avaliação do modelo:

- **R2 (R-quadrado)** - quanto da variação o modelo explica.
- **MAE (Erro Absoluto)** - o tamanho médio do erro de previsão.
- **RMSE** - erro que penaliza grandes erros mais pesadamente.
- **Validação cruzada** - Testando o modelo com dados para confirmar. **generaliza** em vez de memorizar o conjunto de treinamento.

::note{icon="i-lucide-gauge"}
Métricas dizem se deve confiar em um modelo. *Antes* Você implante. Uma história que parece perspicaz mas tem métricas fracas não está pronta para a produção.
::

## Colocando o modelo

Quando as idéias da história são úteis e suas métricas se sustentam, o passo final é **implante o modelo.**. Como vimos na Lição 6, a implantação começa a marcar registros reais. Surge uma pontuação, uma explicação e uma ação recomendada onde os usuários trabalham, enquanto escondem a complexidade da ciência dos dados.
