## Onde os dados chegam: conjuntos de dados

No entanto os dados chegam, ele finalmente pousa em **Datasets**. Um conjunto de dados é CRM AnalyticsOtimizado, formato de armazenamento colunar, projetado para consultas rápidas sobre grandes volumes. Uma vez que você tem datasets no lugar, a verdadeira diversão começa:

- **Combinar conjuntos de dados** - Junte ou misture várias fontes para que uma única análise possa abranger, digamos, oportunidades. *e* Dados de receita externa.
- **Crie campos derivados.** — calcular novos valores (ratios, baldes, bandeiras) que não existiam na fonte.

Aqui é onde os dados brutos se tornam um modelo em forma, pronto para análise.

## Dados ao vivo vs. replicados.

Nem toda fonte precisa ser copiada. CRM Analytics Apoia duas filosofias:

::note{icon="i-lucide-git-compare"}
**Dados replicados** é copiado em um conjunto de dados - rápido para consultar, mas um instantâneo ponto-em-tempo. **Conexões ao vivo (Dados Diretos)** Consultar o sistema fonte em tempo real - por exemplo, correndo contra **Floco de neve** diretamente para que você sempre veja dados atuais sem duplicá-los.
::

A replicação dá a você velocidade de bolhas e a habilidade de se misturar e se transformar livremente. Live/Direct Data lhe dá frescura e evita armazenar outra cópia. Arquiteturas do mundo real costumam usar ambos, escolhendo por fonte baseado em volume, necessidades de frescura e governança.

## Obtendo dados de volta

O fluxo é **Bidirecional**. CRM Analytics Não é um beco sem saída onde os dados são vistos e esquecidos. Através **conexões de saída**, pode levar os resultados de volta para outros sistemas - por exemplo para **AWS S3**, **Floco de neve**, ou **Tabuleiro Hyper.** Extratos. Isso significa que os dados em forma, enriquecidos ou pontuados que você constrói aqui podem alimentar armazéns a jusante, outras ferramentas de BI, ou lagos de dados.

## Computação dedicada e virtualizada

Aqui está o detalhe arquitetônico que liga tudo, e ecoa a lição anterior. CRM Analytics Continua. **Computação dedicada e virtualizada** - separado do banco de dados transacional que alimenta sua vida Salesforce App.

Por que isso importa? Análise é... *Pesado.*. Escanear milhões de linhas, juntar conjuntos de dados e modelos de treinamento parariam um banco de dados operacional e prejudicariam cada usuário tentando salvar um registro. Ao executar análises em sua própria camada de computação contra conjuntos de dados otimizados, CRM Analytics mantém o seu CRM do dia-a-dia rápido enquanto ainda aperta o volume sério nos bastidores.
