# O que é CRM Analytics? A experiência inteligente

**CRM Analytics** - Anteriormente **Tableau CRM**, **Einstein Analytics**, e originalmente **Onda** Quando ele lançou em **2015** — é SalesforceÉ a plataforma de análise nativa. Sua única razão para existir é trazer **inteligente, análise preditiva para os usuários finais de CRM**Não analistas trancados em uma ferramenta separada, mas os vendedores, agentes de serviço, e gerentes que vivem dentro Salesforce Todos os dias. Esta lição define o que o produto realmente é e, tão importante, o que é *Não.*.

## Dos dados à inteligência

Cada Salesforce Org já tem uma grande quantidade de informações: contas, oportunidades, casos, contatos. Padrão Salesforce Relatórios permitem cortar esses dados, mas eles respondem apenas um tipo de pergunta: *O que está acontecendo agora?* CRM Analytics estende essa história em duas direções:

- **Para trás**, com rápida análise histórica através de grandes volumes de dados de muitas fontes.
- **Em frente.**, com visão aumentada, preditiva que antecipa o que é provável que aconteça a seguir.

Essa combinação é o que Salesforce Chama o *Experiência inteligente*.

## Vivo contra histórico: dois mundos complementares.

Um equívoco frequente é que CRM Analytics *Substitui* padrão Salesforce Relatórios e painéis. Não. Os dois são construídos para trabalhos diferentes:

| Relatórios padrão & Painéis | CRM Analytics |
| --- | --- |
| Operacional, **Viva.** Vista | Histórico & **analítico** Vista |
| O transacional **sistema de registro** | Dados misturados de muitas fontes. |
| "O que é verdade agora?" | "Quais são as tendências, e o que vem depois?" |
| Ótimo para operações diárias. | Ótimo para exploração em grande escala. & Previsão |

Relatórios padrão lidos diretamente do banco de dados transacional, o sistema de registro ao vivo, que é perfeito para visualização operacional, até o segundo ponto. Mas esse mesmo banco de dados não foi projetado para atravessar milhões de fileiras através de vários objetos e fontes externas sem atrasar o negócio.

CRM Analytics resolve isso trabalhando em cópias otimizadas de seus dados, dando-lhe velocidade em escala e espaço para adicionar previsões de aprendizado de máquina em cima. Mantenha seus relatórios para operações ao vivo. *e* ganhar uma camada analítica dedicada para perguntas mais profundas.

## Por que isso importa?

Trazer inteligência para o usuário final muda de comportamento. Em vez de um gerente exportar dados para uma planilha uma vez por semana, um representante vê uma pontuação, recomendação explicada no momento em que abre uma conta. Em vez de adivinhar qual é a prioridade, o sistema os classifica e diz por quê. Essa é a promessa de CRM AnalyticsTransformando os dados que você já possui em orientação as pessoas confiam e usam.

Por enquanto, segure a grande ideia: **CRM Analytics Complementos Salesforce reportando adicionando uma camada rápida, histórica e preditiva de inteligência para usuários de CRM.**
