# Metadados de campo e formatação

Cada conjunto de dados carrega metadados sobre seus campos: etiqueta de exibição, formato, agregação padrão, visibilidade. Defini-lo uma vez é a diferença entre um conjunto de dados que as pessoas podem usar e um que precisa de um tradutor.

## Etiquetas

`Sum of Amount__c` é o que os dados dizem. "Revenue" é o que o negócio diz. O rótulo pertence ao conjunto de dados, onde cada lente e cada widget herda.

::tip{icon="i-lucide-users"}
**Rótulo para o leitor, não para o construtor.** O nome técnico do campo é útil para você por cerca de uma semana, o rótulo é lido por todos que abrem o painel, por anos. Se dois campos pudessem ser confusos... `Amount` na oportunidade e `LineAmount` Na linha de produtos, tornar os rótulos inequívocos em vez de curtos: "Quantidade de acordo" e "Quantidade de linha" evitam um erro real.
::

## Formatos

Símbolos de moeda, milhares de separadores, casas decimais, porcentagens. Consertar isso no conjunto de dados remove o defeito cosmético mais comum em CRM Analytics painéis - a mesma medida formatado três maneiras diferentes em uma tela porque três pessoas construíram três widgets.

::note{icon="i-lucide-coins"}
**Decimais são uma decisão de legibilidade, não precisa.** Ninguém toma uma decisão sobre os centavos de um valor de $13,4M, e seis casas decimais em uma taxa de conversão implica uma confiança que os dados não podem suportar. Redondo ao que a decisão precisa: moeda inteira para os totais, uma decimal para as taxas, e deixe o valor exato viver em modo de mesa para quem quiser.
::

## Agregação padrão

Uma medida pode ter um padrão sensível, geralmente soma, às vezes média, ocasionalmente máxima. É uma pequena coisa que silenciosamente evita um erro real:

::warning{icon="i-lucide-triangle-alert"}
**Um campo de taxa com um padrão de `sum` É uma arma carregada.** Os dados de uso da Academia carregam uma porcentagem de utilização por conta por mês. Somado em 12 meses, uma conta de 80% de utilização é de 960%. Nada de erros, o gráfico renderiza, e o número é absurdo. Defina o padrão em média - e melhor, siga o conselho da seção de preparação de dados e computar a taxa de totais agregados em vez de armazenar uma taxa por linha em tudo.
::

## Campos escondidos.

Um conjunto de dados com sessenta colunas, das quais quinze são chaves e bandeiras internas, é hostil a qualquer um explorá-lo. Escondam o que ninguém deve agrupar: chaves substitutas, booleanos internos, colunas de encenação.

Isso importa mais para **Auto-serviço**, que é assunto da seção de exploração. Uma lista de campo que tem quinze itens significativos convida a exploração, uma que tem sessenta itens de comprimento, metade deles nomeado `X__c`, ensina as pessoas que esta ferramenta é para especialistas.
