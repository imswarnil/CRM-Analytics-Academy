# Valores Tabelas, Imagens e Temas de Widget

Os gráficos respondem "quanto" e "o que é maior". Cedo ou tarde alguém pergunta **"Que registros exatamente?"** - e esse é o **tabela de valores**Uma lista direta de linhas, um registro por linha, colunas de sua escolha.

Parece o widget menos projetado na tela. Tem mais configurações de design do que qualquer outra.

## Colunas padrão vêm do conjunto de dados

Coloque uma tabela de valores no painel e ela não aparece em branco. Chega pré-povoada com um conjunto de colunas. Isso não é um palpite. Eles são os **campos padrão** configurado no próprio conjunto de dados, no **Campos** Painel de edição do conjunto de dados.

Esta é uma peça realmente útil de higiene de dataset. Definir padrões sensatos uma vez - dizer *Nome da oportunidade*, *Conta.*, *Estágio*, *Data de encerramento*, *Quantidade* - e cada tabela de valores que qualquer um constrói sobre esse conjunto de dados começa de um lugar razoável em vez de despejar noventa colunas ou nenhuma.

## Adicionando um campo à mesa

Adicionar uma coluna é feito da consulta do widget, não arrastando para a mesa. Abra o passo atrás da mesa, encontre a lista de campos, e adicione o campo que você quer - ele aparece como uma nova coluna imediatamente.

Ordem para leitura. Coloque o **Identificando** colunas primeiro (nome, conta), o **categórico** próximo (estágio, proprietário, região) e o **Números** O último à direita, onde o olho espera escaneá-los. Leitores analisam uma mesa da esquerda para a direita exatamente uma vez; façam aquele passe fazer o trabalho.

::tip{icon="i-lucide-triangle-alert"}
O **Campos** Editor você vê dentro de um painel de passo é **Não.** A mesma coisa que o editor Fields em uma lente. O dashboard só controla quais campos esta consulta retorna e como esse widget os exibe. Metadados de campo reais — a etiqueta de exibição, formatação de números, colunas padrão, se um campo está escondido dos usuários — devem ser editados em **Modo de lente**, no próprio conjunto de dados. Se você está mudando algo e ele teimosiamente não fica entre widgets, você está no editor errado.
::

## Espaçamento: ajusta dados ao widget

O espaçamento padrão da mesa é generoso, o que significa que uma tabela de tamanho para caber no seu layout geralmente mostra quatro linhas e uma barra de rolagem. Nas propriedades do widget, encontre a opção de espaçamento e escolha **Ajustar dados ao widget**.

Isso muda a mesa de uma linha fixa para uma que comprime para usar o espaço que foi dado - mais linhas visíveis, colunas dimensionadas para o seu conteúdo, muito menos espaço branco morto. Em um painel onde a mesa é um detalhe de apoio em vez do evento principal, é a diferença entre uma lista útil e um teaser.

## Temas em widgets individuais

Um painel tem um tema geral, mas **Cada widget pode substituí-lo.**. Nas propriedades do widget você encontrará uma definição de tema - virar uma única tabela ou gráfico para o **escuro** Tema e transforma com um fundo escuro e texto claro enquanto tudo ao seu redor permanece claro.

Isso parece caótico. Usado deliberadamente é uma das ferramentas de layout mais eficazes disponíveis:

- Dê-me o **KPI strip** Em todo o topo um tema escuro para que ele leia como uma faixa de cabeçalho distinta.
- Escurecer um único **Chamada** widget — a liderança de um número se importa — então o olho pousa lá primeiro.
- Use um fundo escuro atrás de uma mesa de **imagens** Ou logotipos, que quase sempre ficam melhor contra o escuro do que contra o branco.

A disciplina é usá-lo para **Agrupando**, não decoração. Se dois widgets compartilham um tema, um leitor assume que eles pertencem um ao outro, certifique-se de que realmente o façam.

## Renderizando URLs como imagens

Esta é a propriedade que a maioria das pessoas nunca descobre, e muda o que uma mesa pode ser.

Salesforce Os dados estão cheios de URL campos - URLs de fotos do usuário, links de imagem do produto, campos de logotipo, miniaturas de documentos. Por padrão, uma tabela de valores mostra aqueles como o que eles são: longas, feias e inclicáveis cordas de texto que explodem a largura da coluna.

Nas propriedades da coluna há um **mostrar dados como imagem** Opção. Ligue-o e CRM Analytics Vai buscar o URL e mostra a imagem na cela.

O uso clássico é um **foto do proprietário** coluna em uma mesa de top-performers - rostos em vez de nomes faz uma tabela de classificação se sentir pessoal e instantaneamente escaneável. O mesmo truque funciona para imagens de produtos em uma tabela de catálogo, logos de contas em uma lista de clientes, ou ícones de status armazenados como URLs de imagem.

::tip{icon="i-lucide-info"}
A imagem tem que ser acessível pelo navegador vendo o painel. URLs de fotos hospedadas pela Salesforce se comportam bem porque o usuário já está autenticado; um link para um sistema interno que requer um login separado renderizará como uma imagem quebrada para todos, menos você. Teste com o login de um colega antes de enviá-lo.
::
