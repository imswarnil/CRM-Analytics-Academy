# Ligando painéis Juntos.

Um painel não pode responder tudo. Tente pegar um monstro que ninguém lê. O melhor padrão é **Preparar.** de painéis focados, um resumo, um detalhe do oleoduto, uma visão de atividade, conectados para que o usuário se mova entre eles sem nunca tocar no menu de navegação.

O **link** widget é como você constrói isso, e ele faz consideravelmente mais do que abrir um URL.

## O que uma ligação pode apontar para

Arraste um widget de link para a tela e suas propriedades pedem um destino. Você tem três opções:

Você também controla se o alvo abre na mesma guia ou uma nova. A mesma conta de uma broca que faz parte do fluxo, nova guia de material de referência que o usuário voltará.

## Carregando filtros através

Este é o cenário que torna os links genuinamente poderosos, e o que a maioria das pessoas deixa desligado porque eles nunca notaram.

Activar **aplicar seleções / aplicar filtros** no link, e do usuário **O estado atual do painel viaja com eles.**. Se eles filtraram para EMEA, Q3, e fecharam, eles pousaram no painel alvo já filtraram para EMEA, Q3, e fecharam.

Sem ele, a jornada é: filtrar cuidadosamente, clicar através, reaplicar todos os mesmos filtros, perder sua linha de pensamento. Com ele, os dois painéis parecem uma aplicação com duas visualizações.

::tip{icon="i-lucide-triangle-alert"}
Os filtros só atravessam quando o **Painel alvo tem filtros compatíveis** em um conjunto de dados com os mesmos nomes de campo. Ligar um painel de pipeline a um painel de suporte em um conjunto de dados completamente diferente e as seleções não têm nada para ligar. Design de painéis conectados como uma família desde o início, em conjuntos de dados compartilhados e nomes de campo compartilhados, e isso só funciona.
::

## Estimulando um link como uma aba

Um widget de link aceita o mesmo estilo que qualquer outro widget - cor de fundo, fonte, raio de borda, enchimento. Coloque uma linha deles no topo do painel, dê-lhes um fundo cheio e uma borda superior arredondada, e você tem algo que o usuário lê inequivocamente como **tabs**.

Realce o atual (um fundo mais forte, ou a cor da marca) e cinza os outros, e um conjunto de quatro painéis se comporta como uma aplicação de quatro tab. É totalmente cosmético, não há nenhum componente de tabulação por baixo, mas os usuários não sabem disso e não precisam. É uma das peças de maior impacto de estilo disponíveis, porque a navegação é onde a maioria dos painéis cai.

## A ligação transparente sobre um recipiente

Agora o truque que vale a pena roubar. Um widget de link renderiza como texto, e às vezes você quer um **Imagem clicável** Em vez disso, uma telha de produto, uma foto de equipe, um cartão de marca que abre o painel relevante.

Não tem nenhum botão de imagem. Você finge convincentemente:

::lesson-steps
---
items:
  - title: "Largue um widget de contêiner."
    description: "Coloque um recipiente na tela e dimensione para o azulejo que quiser."
  - title: "Dê-lhe uma imagem de fundo"
    description: "Nas propriedades do contêiner, defina uma imagem de fundo e escolha como ele se encaixa - a cobertura geralmente fica melhor."
  - title: "Sobreponha um widget de links"
    description: "Arraste um widget em cima do contêiner para cobrir exatamente a mesma área."
  - title: "Faça a ligação invisível."
    description: "Ajuste a cor de fundo do link para totalmente transparente e sua cor de fonte para totalmente transparente também."
  - title: "Aponte para o destino."
    description: "Defina o painel de destino e habilite as seleções, e então teste que toda a telha clica."
---
::

O resultado é uma imagem que o usuário clica. O link ainda está lá, fazendo seu trabalho, carregando seus filtros - ele não tem nada visível para renderizar. Ambos o fundo *e* A cor da fonte precisa ser transparente, deixar o texto opaco e você tem uma palavra perdida flutuando sobre sua foto.

::tip{icon="i-lucide-lightbulb"}
Porque o elo invisível não dá feedback, adicione o dinheiro você mesmo: uma borda sutil no contêiner, uma legenda por baixo, ou uma dica na ligação explicando para onde vai. Uma imagem que acaba por ser clicável é uma agradável surpresa. *Olha.* clicável e é um bom design.
::

Use isso para uma landing page, uma grade de imagens, cada uma abrindo uma área diferente do negócio. É preciso dois widgets por azulejo e faz um aplicativo de análise parecer um produto ao invés de uma pasta de relatórios.
