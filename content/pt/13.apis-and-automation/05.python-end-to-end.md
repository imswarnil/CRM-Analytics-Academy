# Python Fim a Fim

A forma de um carregador de verdade, na ordem que você escreveria. A biblioteca específica importa menos do que a sequência - as mesmas cinco etapas aplicam-se se você usa um Salesforce SDK, um cliente REST, ou simples pedidos.

## Os cinco estágios

::lesson-steps
---
items:
  - title: "Autenticar como usuário de integração"
    description: "Credenciais de variáveis de ambiente, nunca do arquivo. Consiga uma ficha, e embrulhe a chamada para que uma expiração no meio da corrida refresque em vez de morrer."
  - title: "Leia e prepare os dados."
    description: "Carregue a fonte, a web_sessions.csv de Namilio, ou uma consulta de armazém, e moldá-la para combinar com os metadados que você está prestes a declarar. Nomes de colunas, tipos e ordem estabelecidos aqui, não improvisados durante o upload."
  - title: "Declare o trabalho."
    description: "Nome, operação e metadados de campo. Este é o arquivo que decide se suas datas são datas; mantenha-o no repositório ao lado do script para que ele seja revisionável."
  - title: "Envio em partes numeradas e completação do sinal"
    description: "Enrole as fileiras, envie cada parte com seu número, e depois defina o trabalho para completar. O sinal de conclusão é o passo que é esquecido, e esquecer que não produz nenhum erro e nenhum conjunto de dados."
  - title: "Verifique, então informe."
    description: "Leia de volta a contagem do conjunto de dados e compare com o que você enviou. Registre os dois. Um carregador que não verifica é um carregador que falha silenciosamente."

## O esqueleto

```python
import os, csv, json, math, requests

BASE   = os.environ["SF_INSTANCE_URL"]        # from the secret store
TOKEN  = get_access_token()                    # refreshable
HEAD   = {"Authorization": f"Bearer {TOKEN}"}
CHUNK  = 10_000                                # rows per part

def declare(dataset, operation, metadata):
    """Create the upload job. Nothing is sent yet."""
    body = {"Format": "Csv", "EdgemartAlias": dataset,
            "Operation": operation, "Action": "None",
            "MetadataJson": metadata}
    r = requests.post(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData",
                      headers=HEAD, json=body, timeout=60)
    r.raise_for_status()
    return r.json()["id"]

def upload_parts(job_id, rows, header):
    """Send the rows as numbered parts. Part numbers start at 1."""
    for i in range(0, len(rows), CHUNK):
        part = i // CHUNK + 1
        payload = encode_csv(header, rows[i:i + CHUNK])
        post_part(job_id, part, payload)

def complete(job_id):
    """The step that is forgotten. Until this runs, nothing is processed."""
    requests.patch(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData/{job_id}",
                   headers=HEAD, json={"Action": "Process"}, timeout=60).raise_for_status()
```

::note{icon="i-lucide-code"}
**Os caminhos finais e o esquema exato de metadados mudam entre os lançamentos.** - Verifique a documentação atual para o seu API versão em vez de copiar um caminho de qualquer blog, incluindo este. O que não muda é a sequência: declarar, partes, completar, verificar. Aprenda a forma e veja os detalhes.
::

## A verificação é a parte que ganha seu sustento.

```python
expected = len(rows)
actual   = dataset_row_count(dataset)          # read back from metadata
if actual != expected:
    raise SystemExit(f"load mismatch: sent {expected}, dataset holds {actual}")
```

::tip{icon="i-lucide-shield-check"}
**Falhe alto em um desencontro ao invés de registrar um aviso.** Um trabalho que sai zero depois de carregar 80% das fileiras produz um painel que está silenciosamente errado desde que alguém note que, em um número que ninguém tem um antecedente, pode ser meses. Um código de saída é lido pelo programador, um aviso em um registro é lido por ninguém.
::

## Perguntando o resultado de volta

A mesma sessão pode ser executada SAQL, o que torna um passo de reconciliação natural no final de uma carga: puxar o total do conjunto de dados agora reporta e compará-lo com a própria figura do sistema fonte. Esse é o hábito da chave de resposta da seção de APIs automatizada - e é a única coisa mais valiosa que um carregador pode fazer além de carregar.

## Executando.

O que quer que seja, Cron, uma agenda de informantes, um orquestrador, precisa de três coisas: a agenda, as credenciais de uma loja secreta, e em algum lugar o fracasso é *Viu?*. Um trabalho que falha em um diretório de registros que ninguém abre é um trabalho que não está funcionando, e você descobre semanas depois.
