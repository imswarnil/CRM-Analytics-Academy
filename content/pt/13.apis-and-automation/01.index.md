## O que esta secção abrangerá

Tudo dentro CRM Analytics é alcançável sobre uma API — o que isso torna possível, os quatro empregos que valem a pena automatizar, e os que devem permanecer manuais.

## Aulas planejadas

- **Por que automatizar** — Tudo em CRM Analytics é alcançável sobre uma API — o que isso torna possível, os quatro empregos que valem a pena automatizar, e os que devem permanecer manuais.
- **A REST API** — Autenticação, as famílias de endpoint que importam para análise, versionamento e os limites que valem a pena projetar antes de escrever qualquer coisa.
- **SAQL do código** — Envio de uma consulta sobre o API e lendo o que volta — mais as quatro razões legítimas de um número de um script difere do mesmo número no painel.
- **Carregando dados** — Dados externos API: declarar, carregar em partes, completar o sinal — o padrão de três passos, o arquivo de metadados que decide seus tipos de campo, e a falha que todos batem uma vez.
- **Fim do fim do Python** — Um caminho trabalhado em Python: autenticar, declarar uma carga, empurrar os dados da Academia em partes, completar o sinal, verificar a contagem de linhas e consultar o resultado de volta.
- **Automação & implantação** — Scheduling, credenciais, manipulação de falhas, e usando a exportação de metadados para dar aos painéis o histórico de mudanças que o produto não fornece.
- **Perguntas de entrevista** — A API e questões de automação, com respostas de modelo — e o julgamento operacional que eles estão realmente procurando.
- **Questionário de classificação** — Oito perguntas sobre autenticação, a consulta e APIs de dados externos, operações de carga, agendamento e histórico de mudanças.
