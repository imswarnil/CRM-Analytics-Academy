# Salesforce Fundações

Cada CRM Analytics painel é uma imagem de Salesforce dados. Se você sabe como esses dados são moldados — quais objetos existem, como eles apontam uns para os outros, onde os números realmente vivem — os painéis são fáceis. Caso contrário, cada gráfico é um palpite que acontece renderizar.

Esta secção é o piso térreo. É curto, prático, e nada mais tarde funciona sem ele.

## O que esta secção abrange

1. **Objetos, campos e relacionamentos**: o modelo de dados por trás de cada painel
2. **Sua org e um aplicativo pequeno**: uma org livre, os dados da Academia, um objeto personalizado
3. **Obtendo dados em**Importações, Carregador de Dados, APIs e IDs externos

## Como lidar com isso

Leia uma lição, então abra uma org Developer Edition e clique nos mesmos objetos. Cada lição termina com um curto questionário e as perguntas de entrevista que você provavelmente será questionado sobre o tópico. Quando a lição tem um vídeo, ela fica no topo da página.
