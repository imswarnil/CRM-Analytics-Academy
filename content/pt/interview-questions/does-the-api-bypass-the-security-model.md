Não. Solicita autenticar como usuário e as permissões do usuário, compartilhamento e segurança de nível de linha se aplicam exatamente como na interface. Vale a pena dizer claramente porque 'use o API' ocasionalmente é oferecido como uma solução para um problema de acesso, e não é um. É também a primeira coisa que eu verifico quando o número de um script difere do de um painel: geralmente eles estão rodando como usuários diferentes e ambos os números estão certos.
