# O que é um Dataset em CRM Analytics?

Criar conjuntos de dados é o **Primeiro passo real** em qualquer CRM Analytics (Tableau CRM) projeto. Antes que você possa construir um único painel, contar uma história, ou treinar um Einstein Discovery Modelo, você tem que obter dados *em* A plataforma e moldá-la em algo que você possa questionar. Esse "algo" é um **Conjunto de dados**E toda esta seção é sobre construí-los bem.

Depois de sete anos de construção nesta plataforma, aqui está a versão honesta: nove em cada dez vezes, seu trabalho começa criando um conjunto de dados. Há exceções - consultas diretas e conexões ao vivo - mas essas resolvem problemas estreitos dentro de um painel específico. O pão e a manteiga são os dados.

## Então o que é um conjunto de dados?

Um conjunto de dados é um **formato de armazenamento**. Você pega objetos ou tabelas que se relacionam uns com os outros, combina-os, e armazena o resultado em uma forma que é construída de propósito para uma necessidade analítica.

Diga que quer analisar oportunidades. Você puxaria o objeto Oportunidade, mas também traria o **Conta.** Cada oportunidade pertence a **Usuário** Quem é o dono, e talvez, no final da estrada, atividades relacionadas. Tudo isso se combina em um amplo e auto-suficiente conjunto de dados sobre oportunidades. Esse é o exercício que faremos à mão mais tarde nesta seção.

## Por que é tão rápido?

Você não precisa disso diariamente, mas ajuda saber o que está debaixo do capô. Um conjunto de dados usa **Aplainado, índice invertido, sistema de armazenamento de valor chave** - uma maneira chique de dizer que é uma loja de arquivos colunares com um algoritmo de compressão e indexação proprietário.

O pagamento é o ponto: você pode armazenar **Grandes volumes.** de dados em um conjunto de dados e ainda questioná-lo rápido o suficiente para alimentar um painel interativo. Essa combinação, Big Data. *e* Sub-segunda resposta — é por isso que a plataforma se incomoda com um formato de armazenamento dedicado em vez de apenas consultar Salesforce diretamente.

::tip{icon="i-lucide-lightbulb"}
Porque um conjunto de dados é... **instantâneo armazenado**Os dados são tão recentes quanto da última vez que os refrescou. Manter os conjuntos de dados atuais é um problema de agendamento. Um que voltaremos quando falarmos sobre sincronização, fluxo de dados e receitas.
::

## Quando *Não.* para construir um conjunto de dados

Datasets são o padrão, mas não são a única opção. CRM Analytics Também apoia:

- **Consultas diretas.** - Consultar um pequeno conjunto de Salesforce dados na mosca, sem materializar um conjunto de dados.
- **Conexões ao vivo.** - Leia diretamente de uma fonte externa (como Snowflake) na hora da consulta.

Ambos são reais e úteis, mas se encaixam em *Específico* Componente do painel ou requisito, não o caso geral. Se está apenas começando, assuma que está construindo um conjunto de dados e trate ao vivo/direto como a exceção que procura deliberadamente.
