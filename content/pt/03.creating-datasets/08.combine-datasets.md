# Combine Datasets em um Dataset Final

Você agora construiu as mesmas oportunidades de dataset de duas maneiras, e você enviou um externo CSV Mais cedo. Hora de agir constantemente em projetos reais: **Misturar dois conjuntos de dados em um.** - O quê? Salesforce Dados enriquecidos com dados externos e um conjunto de dados final pronto para o painel.

Aqui é onde a distinção "base de dados contra dados finais" compensa. Seu conjunto de dados oportunidades e seu CSV são **linha de base** Blocos de construção. Agora vamos combiná-los em um **final** Dataset um painel realmente lê.

::tip{icon="i-lucide-recycle"}
Você nem sempre precisa de uma receita nova. Se você já tem uma receita produzindo as oportunidades de dataset, você pode muitas vezes adicionar outro nó nele em vez de manter uma receita separada. À medida que você escala, ativamente procurar maneiras de **Reduzir o número de receitas** Você se mantém vivo, menos partes móveis, menos coisas para agendar e depurar.
::

## Saída do conjunto de dados final

A mesma regra de antes: as uniões não fazem nada até que você **adicionar um nó de saída**.

- Clique no plus após a união e adicione um **Saída** Node - este é o conjunto de dados terminado (por exemplo. *Oportunidades com Quantidade Externa*).
- **Aplicar**, então **Salve e corra**. A receita executa e materializa o conjunto de dados combinados.

É isso. Você se juntou a interna Salesforce dados com externa CSV Dados em um conjunto de dados enriquecido. A partir daqui, você poderia cobrir transformações — colunas computadas, agregações, filtros — mas mesmo esta simples mistura é suficiente para alimentar um painel ou uma história.

::tip{icon="i-lucide-clock"}
Fique com o... **ordem de operações** Em mente de agendamento: a sincronização atualiza os objetos de base → a receita de base/fluxo de dados reconstrói as oportunidades de dataset → esta combinação de receita reconstrói o conjunto de dados final. Agende-os nessa sequência, ou seu conjunto de dados "final" servirá silenciosamente os dados de ontem.
::

## O que você pode fazer agora

Você pode criar conjuntos de dados de três maneiras: CSV, Dataset Builder, e receitas - e combiná-los em conjuntos de dados prontos para análise. Essa é a fundação em tudo o mais CRM Analytics Fique de pé.
