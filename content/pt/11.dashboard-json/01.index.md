# Quando abrir o JSON

A CRM Analytics painel é um JSON Documento: widgets, layouts, consultas e ligações, tudo como texto. O construtor escreve para você, e ocasionalmente o texto é a melhor ferramenta.

::note{icon="i-lucide-file-json"}
**Este não é o nível avançado de construção do painel.** A maioria dos painéis nunca deveriam ter seus JSON abrir, e tentar fazer algo que o construtor faz perfeitamente bem é uma maneira de produzir um painel que ninguém mais pode manter. Ele ganha seu lugar para trabalho a granel, para revisão, e para o punhado de coisas que a interface não expõe.
::

## As quatro boas razões.

## As duas más razões

::warning{icon="i-lucide-hand"}
**Não use JSON para fazer um trabalho comum mais rápido, e não usá-lo para ser inteligente.** Um painel feito à mão em uma configuração que o construtor não pode percorrer é um painel que só você pode mudar, o que é a mesma falha que um painel sobrecarregado. Se o construtor pode expressá-lo, deixe o construtor expressá-lo — o JSON é para o que o construtor não pode fazer, e para ver o que ele fez.
::
