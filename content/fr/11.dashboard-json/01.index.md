# Quand ouvrir JSON

A CRM Analytics tableau de bord est un JSON document: widgets, mises en page, requêtes et reliures, tous en texte. Le constructeur l'écrit pour vous, et parfois le texte est le meilleur outil.

::note{icon="i-lucide-file-json"}
**Ce n'est pas le niveau avancé du tableau de bord.** La plupart des tableaux de bord ne devraient jamais avoir leur JSON ouvert, et l'atteindre pour faire quelque chose que le constructeur fait parfaitement bien est un moyen de produire un tableau de bord que personne d'autre ne peut maintenir. Il gagne sa place pour le travail en vrac, pour l'examen, et pour la poignée de choses que l'interface ne expose pas.
::

## Les quatre bonnes raisons

    type: "the main one"
    role: "key"

  - name: "Review and diff"
    type: "underrated"
    role: "dimension"
    note: "JSON est un texte, donc un changement diffs. Cela convertit 'J'ai ajusté le tableau de bord' en une liste revisible de ce qui bougeait exactement -- le seul contrôle de changement réaliste disponible pour les tableaux de bord."
  - name: "Reuse and templating"
    type: "scaling"
    role: "measure"
    note: "Quatre tableaux de bord régionaux qui ne diffèrent que par une valeur de filtre. Construisez un, copiez le JSON, changez la valeur. Mieux encore, les générer -- qui est la section API."
  - name: "Reaching something the UI does not expose"
    type: "occasional"
    role: "measure"
    note: "Propriétés qui existent dans le format mais n'ont aucun contrôle dans le constructeur. Véritable, rare, et la raison pour laquelle les gens ouvrent d'abord le fichier -- puis ils découvrent les trois autres et restent."
---
::

## Les deux mauvaises raisons

::warning{icon="i-lucide-hand"}
**Ne pas utiliser JSON faire le travail ordinaire plus rapidement, et ne pas l'utiliser pour être intelligent.** Un tableau de bord édité à la main dans une configuration que le constructeur ne peut pas aller-retour est un tableau de bord seulement vous pouvez changer, ce qui est la même défaillance qu'un bordé. Si le constructeur peut l'exprimer, qu'il l'exprime: JSON est pour ce que le constructeur ne peut pas faire, et pour voir ce qu'il a fait.
::
