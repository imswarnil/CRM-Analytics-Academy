# Salesforce Fondations

Chaque CRM Analytics tableau de bord est une image de Salesforce données. Si vous savez comment ces données sont façonnées — quels objets existent, comment ils se pointent l'un l'autre, où les chiffres vivent réellement — les tableaux de bord sont faciles. Si vous ne le faites pas, chaque graphique est une hypothèse qui se produit à rendre.

Cette section est au rez-de-chaussée. Elle est courte, pratique, et rien ne fonctionne plus tard sans elle.

## Ce que couvre cette section

1. **Objets, champs et relations**: le modèle de données derrière chaque tableau de bord
2. **Votre org et une petite application**: un org gratuit, les données de l'Académie, un objet personnalisé
3. **Obtenir des données**: importations, Data Loader, API et ID externes

## Comment y arriver

Lire une leçon, puis ouvrir un org Developer Edition et cliquer sur les mêmes objets. Chaque leçon se termine par un court quiz et les questions d'entrevue que vous êtes le plus susceptible d'être posées sur le sujet. Lorsque la leçon a une vidéo, elle se trouve en haut de la page.
