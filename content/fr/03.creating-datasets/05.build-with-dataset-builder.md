# Construire un ensemble de données de base avec Dataset Builder

Maintenant nous construisons un vrai Salesforce ensemble de données. **Dataset Builder** est l'outil d'origine: il marche les relations objet *pour toi*, calcule automatiquement les touches de jointure, et écrit ses instructions dans un **flux de données**. C'est la façon la plus amicale de soutenir un ensemble de données de base, c'est exactement pourquoi je le donne encore aux gens apprenant la plateforme.

Rappelez-vous le plan de la leçon de grain: cet ensemble de données est **sur les possibilités**, donc nous commençons par Opportunity et regarder *en haut* à Compte et Utilisateur.

::tip{icon="i-lucide-plug"}
Dataset Builder lit de la **Couche Connect/Sync**, pas de Salesforce directement. Donc, contrairement à un CSV upload, la synchronisation doit être en place en premier. Si un objet n'est pas synchronisé, vous ne pourrez pas le sélectionner.
::

## Démarre.

De Analytics Studio: **Créer → Dataset → Salesforce Données**. C'est l'option du milieu — vous ne téléchargez pas un CSV, et vous ne construisez pas sur un ensemble de données existant (ce chemin mène à des recettes).

On vous demandera quel flux de données utiliser. Tous les navires **par défaut Salesforce flux de données**, et vous pouvez y ajouter ou créer votre propre. En production, vous aurez généralement un petit nombre de flux de données nommés, programmés et vous saurez exactement ce que chacun peuple. Pour l'instant, utilisez la valeur par défaut. Cliquez sur **Suivant** et Dataset Builder ouvre dans le Data Manager onglet.

## Démarrer à partir de l'objet le plus bas

Dataset Builder maintenant montre chaque objet qu'il peut atteindre. Nos trois sont **Possibilités**, **Compte**et **Utilisateur**.

::lesson-steps
---
items:
  - title: "Sélectionner d'abord Opportunité"
    description: "C'est l'objet central et le grain. À partir de ce qui vous permet de rejoindre Compte et Utilisateur. Commencez par Compte à la place et vous seriez coincé — il n'a nulle part où chercher."
  - title: "Ajouter un compte via les relations"
    description: "Passez le nœud Opportunity, cliquez sur le plus, ouvrez Relations et choisissez Compte. C'est une recherche — elle attache des champs de compte à chaque opportunité."
  - title: "Ajouter User (le propriétaire)"
    description: "À partir des relations de Opportunity, ajoutez la table Utilisateur pour amener le propriétaire de l'occasion. Maintenant vous avez trois nœuds connectés."
---
::

Le grain contient: **chaque rangée est une opportunité unique**, enrichi avec le compte auquel il appartient et l'utilisateur qui le possède. Aucune opportunité n'est comptée deux fois.

::tip{icon="i-lucide-wand-2"}
Remarquez ce que vous *n'a pas* vous ne lui avez jamais dit que `AccountId` égal à Compte `Id`. Dataset Builder lire les relations directement de la Salesforce schéma et filé les clés pour vous. Cette détection automatique des clés est la raison pour laquelle elle est conviviale pour les débutants.
::

## Choisissez vos champs

Avec les relations en place, ajoutez les champs dont vous avez besoin de chaque objet. Dans le passage qui est à peu près:

::lesson-cards
---
columns: 3
items:
  - title: "De l'occasion"
    icon: "i-lucide-target"
    description: "Montant, date de clôture, date de création, nom, étape, won, Type — mesures et dimensions du noyau, plus les deux ID qu'il porte automatiquement."
  - title: "Compte"
    icon: "i-lucide-building-2"
    description: "Nom du compte, type, industrie et état de facturation (ou zip) — les firmographies que vous couperez les opportunités par."
  - title: "De l'utilisateur"
    icon: "i-lucide-user"
    description: "Nom complet et photo du propriétaire — de sorte que les tableaux de bord peuvent attribuer et personnaliser."
---
::

::tip{icon="i-lucide-triangle-alert"}
**Une fois que vous cliquez sur Suivant, vous ne pouvez pas revenir à cet écran.** Oubliez un champ et vous devrez modifier le noeud de digest du flux de données à la place (plus sur cette prochaine leçon). Donc, avant de passer à autre chose, revérifiez chaque champ dont vous avez besoin est sélectionné. Mesurez deux fois, cliquez sur Suivant une fois.
::

Lorsque vos champs sont définis, choisissez une application (l'application privée est très bien pendant que vous apprenez) et cliquez sur **Créer un ensemble de données**. Dataset Builder Il pousse tout ça dans le flux de données et le déclenche. Dans la prochaine leçon, nous allons la regarder courir — et gérer les erreurs que les nouveaux entraînements aiment lancer la première fois.
