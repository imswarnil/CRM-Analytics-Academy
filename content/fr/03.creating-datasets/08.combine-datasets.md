# Combiner les ensembles de données en un ensemble de données final

Vous avez maintenant construit les mêmes opportunités dataset deux façons, et vous avez téléchargé un externe CSV plus tôt. Le temps pour le déménagement que vous ferez constamment sur des projets réels: **mélanger deux ensembles de données en une seule** — Salesforce les données enrichies de données externes — et la sortie d'un ensemble de données final, prêt au tableau de bord.

C'est là que la distinction « base de données par rapport à l'ensemble final » est payante. Vos opportunités dataset et votre CSV sont **référence** les blocs de construction. Maintenant nous les combinons en **finale** dataset un tableau de bord lit réellement.

::tip{icon="i-lucide-recycle"}
Tu n'as pas toujours besoin d'une recette toute neuve. Si vous avez déjà une recette produisant l'ensemble de données des opportunités, vous pouvez souvent y ajouter un autre nœud au lieu de maintenir une recette séparée. À mesure que vous vous étendez, cherchez activement des façons de **réduire le nombre de recettes** vous restez en vie — moins de pièces mobiles, moins de choses à programmer et à déboguer.
::

## Produit l'ensemble de données final

Même règle qu'avant : les jointures ne font rien jusqu'à ce que vous **ajouter un noeud de sortie**.

- Cliquez sur le plus après la jointure et ajoutez un **Produit** noeud — c'est l'ensemble de données terminé (par exemple: *Possibilités avec montant externe*) .
- **Appliquer**Alors **Enregistrer et exécuter**. La recette exécute et matérialise l'ensemble de données combiné.

C'est ça. Vous avez rejoint l'intérieur Salesforce données avec données externes CSV données dans un ensemble de données enrichi. De là, vous pouvez calquer sur les transformations — colonnes calculées, agrégations, filtres — mais même ce mélange simple est suffisant pour alimenter un tableau de bord ou une histoire.

Gardez **ordre des opérations** à l'esprit pour la programmation : sync rafraîchit les objets de base → la recette de base / flux de données reconstruise l'ensemble de données d'opportunités → cette recette combinant reconstruise l'ensemble de données final. Prévoyez-les dans cette séquence, ou votre ensemble de données « finales » servira discrètement les données d'hier.
::

## Ce que tu peux faire maintenant

Vous pouvez créer des ensembles de données de trois façons — CSV, Dataset Builder, et les recettes — et les combiner en ensembles de données finis, prêts à l'analyse. C'est la base de tout le reste. CRM Analytics debout.
