Rechercher JSON pour la syntaxe de liaison. Les liens sont invisibles dans l'interface — ils vivent dans des panneaux de configuration individuels — donc dans le constructeur les trouver tous signifie ouvrir chaque widget. Dans le fichier ils sont greppables, et dix secondes vous donne la carte de dépendance qui autrement prendrait un après-midi. Ensuite, j'écris cette carte dans la description du tableau de bord de sorte que la personne suivante ne répète pas l'exercice.
