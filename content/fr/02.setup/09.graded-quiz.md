# Quiz classé: Configuration et accès

Dix questions. Comme toujours, noté dans votre navigateur, avec les réponses nécessairement à l'intérieur de la page.

::tip{icon="i-lucide-target"}
**La pondération est délibérée.** Quatre des dix sont sur les échecs qui sont *silencieux* — le champ manquant de l'utilisateur d'intégration, le null qui échoue fermé, l'administrateur verrouillé par son propre prédicat, le retour en héritage. Les échecs silencieux sont ceux qui atteignent la production, ils sont donc ceux qui valent la peine de sur-test.
::
