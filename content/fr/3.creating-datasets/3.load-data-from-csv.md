# Charger les données d'un CSV Fichier

Le moyen le plus rapide pour obtenir des données dans CRM Analytics est **CSV Téléchargement**. C'est une charge manuelle, unique — pas de synchronisation, pas de flux de données, pas de recette — et c'est parfait pour les données qui vivent *extérieur* Salesforce ou que vous avez juste besoin d'entrer rapidement.

Notre fichier exemple, `Opportunity External Amounts`, expédie dans les fichiers de formation EA (le zip de la première vidéo). Il imite les données arrivant d'un système séparé: **Dénomination**, un **Montant initial**, et un **Montant de la facture externe**. Imagine finance suit un chiffre de facture externe qui Salesforce n'a pas, et vous l'avez exporté vers CSV.

## Le flux de téléchargement

De Analytics Studio, le chemin est court et mérite d'être mémorisé:

::lesson-steps
---
items:
  - title: "Ouvrir Analytics Studio"
    description: "Lanceur d'application → faire défiler vers Analytics Studio → ouvrir. Vous atterrirez sur la maison du Studio."
  - title: "Créer un ensemble de données →"
    description: "Cliquez sur Créer, puis sur Dataset. Choisissez la première option : CSV fichier."
  - title: "Choisissez votre fichier"
    description: "Sélectionnez votre CSV (ici, le fichier des montants externes occasion) et cliquez sur Suivant."
  - title: "Nom de l'ensemble de données"
    description: "Donnez-lui un nom clair, et ajoutez un suffixe si vous voulez, il atterrit dans votre application privée à moins que vous ne choisissiez un autre."
  - title: "Examiner les types de champs, puis télécharger"
    description: "Vérifiez les dimensions, les mesures et les dates du moteur détecté, ajustez si nécessaire et cliquez sur Télécharger le fichier."
---
::

Lorsque vous atterrissez dans le Studio, l'ensemble de données est prêt à être utilisé. Remarquez quelque chose d'important sur le diagramme de la dernière leçon : CSV l'ensemble de données est **de son propre chef** - c'est *pas* câblé dans un flux de données ou de synchronisation, parce que c'était une charge manuelle, une fois. Les données sont simplement là, prêtes pour vous.

## Le schéma des métadonnées (un peu avancé)

Lorsque vous téléchargez, le moteur de données lit votre CSV et **devine** chaque type de champ : le texte devient un **dimension**, les chiffres deviennent **mesures**. Vous pouvez outrepasser ces devinettes droit dans l'assurance-chômage.

L'exemple classique est **Code postal**. C'est des chiffres, donc le moteur le lit comme un *mesure* (quelque chose en somme ou en moyenne) — mais vous n'avez jamais additionné des codes zip. Vous coupez et vous groupez par eux. Alors changez-le **mesure** à **dimension** sur place.

::lesson-cards
---
columns: 2
items:
  - title: "Dimension"
    icon: "i-lucide-tags"
    description: "Un champ que vous regroupez ou filtrez par — nom de compte, étape, région, code postal. Le truc catégorique."
  - title: "Mesure"
    icon: "i-lucide-calculator"
    description: "Un champ numérique que vous agrégeez — quantité, nombre, nombre. Ce que vous additionnez et que vous avez en moyenne."
---
::

La plupart du temps, l'assurance-chômage est tout ce dont vous avez besoin. Mais certaines choses — comme **champs multi-valeurs** — ne peut être défini dans l'assurance-chômage. Pour ceux-ci, télécharger le produit **Fichier schéma de métadonnées**, l'éditer à la main (par exemple, `isMultiValue: true` sur un champ), rechargez-le et terminez le chargement.

::tip{icon="i-lucide-info"}
N'accédez au fichier schéma que lorsque l'interface utilisateur ne peut pas exprimer ce dont vous avez besoin — champs multi-valeurs, formatage précis des nombres, ou forcer un type le moteur a mal tourné. Pour 90 % des téléchargements, l'examen de la dimension/mesure/date à l'écran est suffisant. Nous couvrons le fichier schéma entièrement dans le Data Manager des leçons.
::
