## الهيكل العظمي

```python
import os, csv, json, math, requests

BASE   = os.environ["SF_INSTANCE_URL"]        # from the secret store
TOKEN  = get_access_token()                    # refreshable
HEAD   = {"Authorization": f"Bearer {TOKEN}"}
CHUNK  = 10_000                                # rows per part

def declare(dataset, operation, metadata):
    """Create the upload job. Nothing is sent yet."""
    body = {"Format": "Csv", "EdgemartAlias": dataset,
            "Operation": operation, "Action": "None",
            "MetadataJson": metadata}
    r = requests.post(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData",
                      headers=HEAD, json=body, timeout=60)
    r.raise_for_status()
    return r.json()["id"]

def upload_parts(job_id, rows, header):
    """Send the rows as numbered parts. Part numbers start at 1."""
    for i in range(0, len(rows), CHUNK):
        part = i // CHUNK + 1
        payload = encode_csv(header, rows[i:i + CHUNK])
        post_part(job_id, part, payload)

def complete(job_id):
    """The step that is forgotten. Until this runs, nothing is processed."""
    requests.patch(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData/{job_id}",
                   headers=HEAD, json={"Action": "Process"}, timeout=60).raise_for_status()
```

::note{icon="i-lucide-code"}
**The endpoint paths and the exact metadata schema change between releases** - التحقق من الوثائق الحالية الخاصة بك API نسخة بدلاً من نسخ مسار من أي مدون، بما في ذلك هذه وما لا يتغير هو التسلسل: إعلان، أجزاء، استكمال، والتحقق. تعلم الشكل وتبحث عن التفاصيل
::

## التحقق هو الجزء الذي يكسب نفقته

```python
expected = len(rows)
actual   = dataset_row_count(dataset)          # read back from metadata
if actual != expected:
    raise SystemExit(f"load mismatch: sent {expected}, dataset holds {actual}")
```

::tip{icon="i-lucide-shield-check"}
**فشلاً عالياً على خطأ بدلاً من تسجيل تحذير** والوظيفة التي تخرج صفرا بعد تحميل 80 في المائة من الصفوف تنتج لوحة للدبابات تكون خاطئة هدوءا ما دامت تتطلب من شخص ما أن يلاحظ - وهو ما لا يوجد فيه أحد قبله، يمكن أن يكون أشهرا. ويقرأ الجدول الزمني رمز الخروج؛ ولا يقرأ أحد تحذيرا في السجل.
::

## استرجاع النتيجة

ويمكن أن تدار الدورة نفسها. SAQLالذي يجعل خطوة المصالحة طبيعية في نهاية تحميل: سحب مجموع مجموعة البيانات الآن تقارير ومقارنة ذلك على الرقم الخاص بنظام المصدر. وهذا هو عادة الرد الرئيسي من القسم الآلي - وهو الشيء الوحيد الأثمن الذي يمكن أن يفعله المُحمّل إلى ما بعد التحميل.

## تشغيله

أياً كان ما يُديره - كرونة، والجدول الزمني للمخابرات، وجهاز تنسيق - يحتاج إلى ثلاثة أشياء: الجدول الزمني، وثائق التفويض من متجر سري، وفي مكان ما يكون الفشل *شوهد*. العمل الذي يفشل في دليل السجل لا أحد يفتح هو وظيفة لا تعمل، وتعرف بعد أسابيع.
