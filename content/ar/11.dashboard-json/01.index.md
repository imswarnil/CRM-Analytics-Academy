# متى يفتح JSON

ألف CRM Analytics اللوحة هي JSON الوثيقة: نماذج، مخططات، استفسارات وملزمات، كلها نص. البنّاء يكتبها لك، وفي بعض الأحيان النص هو الأداة الأفضل.

::note{icon="i-lucide-file-json"}
**هذا ليس المستوى المتقدم من بناء لوحة التحكم** معظم لوحات السحب لا يجب أن يكون لها JSON تم فتحه و الوصول إليه ليفعل شيئاً يقوم به البنّاء بشكل جيد جداً هو طريقة لإنتاج لوح مظلة لا أحد يستطيع الحفاظ عليه وهي تكسب مكانها للعمل بالجملة، وللاستعراض، ولحفافة الأشياء التي لا تكشفها الوصلة البينية.
::

## السببان السيئان

::warning{icon="i-lucide-hand"}
**لا تستخدم JSON للقيام بعمل عادي أسرع ولا تستخدمه ليكون ذكياً** لوح مدوّن يدويّ إلى تشكيلة لا يمكن للبنّاء أن يُطلقوا النار عليه هو لوح مُدبّ فقط يمكنك تغييره إذا استطاع البناء أن يعبر عن ذلك، دع البناء يعبر عنه - JSON هو ما لا يستطيع البنّاء القيام به، ولرؤية ما فعله.
::
