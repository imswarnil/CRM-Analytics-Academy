# جب کھولیں JSON

جواب CRM Analytics کرس اینڈرسن ایک علامت ہے۔ JSON دستاویز : تمام متن کے طور پر ، لکڑیوں ، برتنوں ، برتنوں اور بندھنوں کو محفوظ رکھا جاتا ہے ۔ معمار اسے آپ کے لیے لکھتے ہیں اور کبھی کبھار متن بہترین ذریعہ ہے۔

::note{icon="i-lucide-file-json"}
**یہ فن تعمیر کا ترقی یافتہ بندھن نہیں ہے ۔** زیادہ تر کنجروں کو ان کے پاس نہیں ہونا چاہئے JSON اِس کے علاوہ اُس نے اُس کام کو بھی شروع کِیا جو اُس نے تعمیر کِیا تھا ۔ اِس کی وجہ یہ ہے کہ اِس میں بہت سی چیزیں ہیں ۔
::

## دو خراب وجوہات

::warning{icon="i-lucide-hand"}
**استعمال نہ کرو JSON عام کام کو تیز کرنے کے لئے اور اسے مہارت سے استعمال نہ کریں ۔** آپ صرف تبدیل کر سکتے ہیں اگر معمار اس کا اظہار کر سکتا ہے تو معمار اس کا اظہار کر سکتا ہے — JSON یقیناً ایسا نہیں ہے جس نے ایسا کِیا ہو اور جو کچھ اُس نے کِیا ہو ۔
