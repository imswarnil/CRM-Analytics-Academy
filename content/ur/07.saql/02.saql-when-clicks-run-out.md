# SAQL جب حملہ شروع ہوتا ہے

SAQL نہیں SQL مختلف کلیدی الفاظ کے ساتھ. یہ ایک ہے **داخلي زبان تبدیل کريں**: ہر بیان میں پہلے بیان کے نتائج کو لے کر اسے تبدیل کر دیتا ہے۔ یہی وجہ ہے کہ *ترتیب* اِس کے بارے میں بتاتے ہیں کہ اِس منصوبے کے بارے میں کیا کہا جاتا ہے ۔ SQL لوگ.

## ایک سوراخ کی شکل

ایک تخلیق شدہ اور نمونے کو فوراً دیکھا جاتا ہے:

```
q = load "Namilio_Opportunities";
q = filter q by 'StageName' == "Closed Won";
q = group q by 'Segment';
q = foreach q generate 'Segment' as 'Segment', sum('Amount') as 'Revenue';
q = order q by 'Revenue' desc;
q = limit q 10;
```

چھ بیانات، ہر رد عمل `q`. . بوجھ، تنگ، گروپ، حساب، ترتیب، حدیث۔

::note{icon="i-lucide-arrow-down"}
**معاملات کو ایسے انداز میں ترتیب دیں کہ اس میں نہ ہو۔ SQL. .** جواب SQL انجن آپ کے لئے دوبارہ ترتیب دیتا ہے. یہاں آپ ایک پائپ لائن کی حقیقت بیان کر رہے ہیں: گروپنگ کے بعد فیلڈنگ کا مطلب یہ ہے کہ آپ ٹیمیں بند کرنے جا رہے تھے. اِس کی کیا وجہ ہے ؟
::

## تین نمونے

### 1۔ گر تے ہوئے گن

ایک غلہ میں قطاروں کو شمار کرتے ہوئے غلط بات شمار کرتے ہیں:

```
q = foreach q generate 'Segment' as 'Segment',
      unique('OpportunityId') as 'Deals',
      sum('LineAmount') as 'Revenue';
```

نیمیلیو کا لکیری دانہ یہ ضروری بناتا ہے: 1,378 قطاروں، 677 حسابات۔

### ۲ ۔ کُل ملا دو

ہر گروپ نے پوری جماعت کے مقابلے میں — کلک کرنے سے ، براہِ‌راست یہاں سے مقابلہ کِیا ۔ گروپ `all` مجموعی حاصل کرنے کے لئے، پھر اس کے مقابلے میں ہر گروپ کا موازنہ. یہ ہر " آمدنی کی شرح" کے پیچھے کا نمونہ ہے اور یہ سب سے عام وجہ ہے۔ SAQL بالکل.

### 3۔ عام موازنہ

اِس کے بعد اِس چوتھائی کے قریب ، ڈیلٹا اور اُن کے درمیان واقع دو دریا بہہ رہے تھے ۔ سیکشن 9 کی رفتار بنانے میں یہ انداز بالکل استعمال ہوتا ہے۔

::tip{icon="i-lucide-lightbulb"}
**اِس سے آپ کو بہت فائدہ ہوگا ۔** کلک کر کے سب سے قریبي چیز بنا ئيں SAQL، اور وہاں سے ترمیم. آپ کو صحیح میدانی حوالوں، درست حوالہ جات اور آزاد کے لیے کام کرنے والا نصاب حاصل ہے — اور حوالہ جات جہاں دست یاب تحریر ہے۔ SAQL عام طور پر غلط ہوتا ہے: میدانی ناموں کے لیے یک رجوع کریں، تار کی قدروں کے لیے دہرااؤ، بالکل اسی طرح جیسے حفاظتی پریڈ میں۔
::
