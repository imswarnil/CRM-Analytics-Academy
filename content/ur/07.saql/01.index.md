# کیوں ؟ SAQL ترک

ہر لینس، ہری ہری ہری ہری اور ہری ہری ہری ہری ہری ہری ہری ہری۔ SAQL نیچے. اسے دوباره بنا نے کے ليے ، آپ اسے صرف تب ہی لکھ سکتے ہیں جب کلک کا رابطہ ختم ہو جائے

::note{icon="i-lucide-waves"}
**SAQL یہ ایک بہت بڑی تبدیلی ہے ۔** ہر بیان میں پہلے بیان کے نتیجے کو لیا جاتا ہے اور اسے تبدیل کر کے اسی سوراخ کی تبدیلی کی نشان دہی کرتا ہے۔ آپ کے کام کو دوبارہ ترتیب دینے والا کوئی نہیں ہے، **ترتیب آپ بیانات میں لکھتے ہیں وہ منصوبہ ہے جو چلتا ہے۔** — گروہ بنانے کے بعد فیلڈنگ کرنے کے بعد آپ کو قطاروں میں کھڑا کرنا تھا ۔ یہ واحد ذرہ فرق ہے جو جاننے والے لوگوں کو شکار کرتا ہے۔ SQL ٹھیک ہے.
::

## شکل

```
q = load "Namilio_Opportunities";
q = filter q by 'StageName' == "Closed Won";
q = group q by 'Segment';
q = foreach q generate 'Segment' as 'Segment', sum('Amount') as 'Revenue';
q = order q by 'Revenue' desc;
q = limit q 10;
```

بوجھ، تنگ، گروپ، حساب، ترتیب، حدیث۔ چھ بیانات، ہر رد عمل `q`'' ہر وہ چیز کھا لیتی ہے جو پچھلی پیداوار ہوتی ہے۔
