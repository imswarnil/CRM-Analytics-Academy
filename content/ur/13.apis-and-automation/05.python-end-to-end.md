## جواب

```python
import os, csv, json, math, requests

BASE   = os.environ["SF_INSTANCE_URL"]        # from the secret store
TOKEN  = get_access_token()                    # refreshable
HEAD   = {"Authorization": f"Bearer {TOKEN}"}
CHUNK  = 10_000                                # rows per part

def declare(dataset, operation, metadata):
    """Create the upload job. Nothing is sent yet."""
    body = {"Format": "Csv", "EdgemartAlias": dataset,
            "Operation": operation, "Action": "None",
            "MetadataJson": metadata}
    r = requests.post(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData",
                      headers=HEAD, json=body, timeout=60)
    r.raise_for_status()
    return r.json()["id"]

def upload_parts(job_id, rows, header):
    """Send the rows as numbered parts. Part numbers start at 1."""
    for i in range(0, len(rows), CHUNK):
        part = i // CHUNK + 1
        payload = encode_csv(header, rows[i:i + CHUNK])
        post_part(job_id, part, payload)

def complete(job_id):
    """The step that is forgotten. Until this runs, nothing is processed."""
    requests.patch(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData/{job_id}",
                   headers=HEAD, json={"Action": "Process"}, timeout=60).raise_for_status()
```

::note{icon="i-lucide-code"}
**خارج‌شُدہ برقی راستے اور درست metadata scription کے درمیان تبدیلی** — اپنے لئے موجودہ دستاویزات چیک کریں API ورژن کسی بھی بلاگ پوسٹ سے کسی بھی راستے کی نقل کرنے کی بجائے، اس ایک سمیت. اِس میں کیا تبدیلی نہیں کی گئی ہے ؟ شکل و صورت کا مطالعہ کريں اور تفصیل دیکھیں ۔
::

## نتیجہ اخذ کرنا

ایک ہی سیشن چلا سکتے ہیں SAQL. ، جس کی وجہ سے ایک چارج کے آخر میں مصالحت کا مرحلہ قدرتی قرار دیا جاتا ہے : اب کل ڈیٹا سیٹ کی رپورٹوں کو کھینچ کر سرسید نظام کے اعداد و شمار کے مقابلے میں اس کا موازنہ کریں۔ یعنی اے پی آئی ایس کے سیکشن کی طرف سے جواب دہ عادت ہے — اور یہ واحد قابل قدر چیز ہے جو لوڈ کرنے سے آگے بڑھ سکتی ہے۔

## اسے چلاتے ہیں۔

جو بھی چیز اسے چلاتا ہے — کرن ، سی آئی شیڈول ، آرکسٹرار — تین چیزوں کی ضرورت ہے : شیڈول ، خفیہ دکان سے مطابقت اور کسی بھی جگہ ناکامی *طےشدہ*. . ایک ایسی ملازمت جو کسی لاج ڈائریکٹر میں ناکام ہو جائے، کوئی نہیں کھول رہا ہے ایک کام ہے جو چلا نہیں رہا ہے، اور آپ کو کچھ ہفتوں بعد پتہ چلتا ہے.
