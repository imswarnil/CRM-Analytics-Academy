## جو درست ہے اکثر ہے

**اِس کے بعد اُس نے اُس سے پوچھا : ” کیا مَیں اِس بات کا اندازہ لگا سکتا ہوں کہ مَیں اِس میں کیا کچھ کر سکتا ہوں ؟ “**

::tip{icon="i-lucide-bar-chart-3"}
**اگر آپ فیصلہ نہیں کر سکتے تو اس پر عمل کریں ۔** یہ سب سے زیادہ عام سوال (جو سب سے بڑا ہے) کا جواب دیتا ہے، کسی بھی حجم میں اسے پڑھا جاتا ہے، یہ زہریلی اور پروجیکٹر کو محفوظ رکھتا ہے اور اسے پڑھنا بہت مشکل ہوتا ہے۔ اگر آپ کے پاس کوئی وجہ ہے — ایک رُجحان ، رشتہ‌دار ، ایک ترکیب — ہے تو اس کی بجائے اُس پر بہت سی مصیبتیں آتی ہیں ۔ ہر ایک کا جواب مختلف قسم کے سوالات سے ملتا ہے جہاں تین گول نظر آتے ہیں ۔
::

## کیا؟ CRM Analytics آپ دے رہے ہیں

چارٹ فہرست طویل ہے اور مفید صوبے مختصر ہیں۔ عملی طور پر، اس حصے کے خاندان بنیادی طور پر تمام پیداواری اشیاء پر مشتمل ہیں:

::field-table
---
dataset: "the working set"
grain: "one row per family"
fields:
  - name: "Bar / column"
    type: "rank, and discrete time"
    role: "dimension"
    note: "سب سے زیادہ استعمال کِیا جاتا ہے ۔"
  - name: "Line / area"
    type: "trend"
    role: "date"
    note: "وقت کے ساتھ ساتھ معمولی تبدیلیاں. صرف اُس وقت ہی علاقہ کا مطلب ہے جب یہ مقدار پوری ہو جاتی ہے ۔"
  - name: "Donut / stacked / treemap"
    type: "composition"
    role: "dimension"
    note: "چھوٹے چھوٹے حصے صرف۔ چاروں ہاتھ، میز یا جزوی بار استعمال کریں۔"
  - name: "Scatter / bubble"
    type: "relationship"
    role: "measure"
    note: "دو اقدامات، اور بلبلے کے لئے تیسرا سائز زیر استعمال رشتہ دار اس بات کو ظاہر کرتے ہیں۔"
  - name: "Number / gauge"
    type: "against a target"
    role: "measure"
    note: "زیادہ‌تر لوگوں کا خیال ہے ۔ کسی بات کا موازنہ کریں ۔"
  - name: "Table / pivot"
    type: "identity and exact values"
    role: "key"
    note: "صحیح جواب چارٹ سے بہت زیادہ لگتا ہے"
  - name: "Map"
    type: "geography, when geography matters"
    role: "dimension"
    note: "صرف اس وقت جب زمین پر جگہ ہونے کی بجائے لیبل کی بجائے نقطہ ہوتا ہے۔"
  - name: "Funnel / waterfall"
    type: "process and bridge"
    role: "measure"
    note: "( ب ) اِس مضمون میں ہم کن سوالوں پر غور کریں گے ؟"
