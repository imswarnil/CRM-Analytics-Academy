# سُرخ دُنیا کا نظارہ کریں

چلو تعمیر کرتے ہیں **درست** مواقع اعداد و شمار — موقع + اکاؤنٹ + صارف — مگر ساتھ **پرنٹ** اس بار. ریکیپ جدید ڈیٹا پریپ انجن ہیں: ڈرافٹ-اور ریڈ، نظریاتی، اور دور دراز سے زیادہ لطیف۔ تجارتی اعتبار سے یہ ہے کہ *آپ* تعلقات خود کریں۔ Dataset Builder اگلی چیز اور آپ کے لئے کُل‌وقتی کُتب ۔

## نیا دوبارہ شروع کریں

از Analytics Studio: **ڈی بگ ڈیٹا سیٹ بنائیں** اور آپ کے ڈیٹا سیٹ یا سنک چیزوں سے چن لیں — یہ ایک کھلا ہے **پرنٹ** میں Data Manager (ڈاٹا پھول & دوبارہ شروع **ریسپس** نیا ربط قائم کریں.

(جو) برصغیر میں ہے۔ **ڈیٹا منتخب کریں** سب کچھ آپ تک دستیاب دکھائی دیتا ہے: ڈیٹا سیٹ جو آپ نے بنایا ہے، بیرونی ماخذ اور متصلہ/سنس چیز۔ Salesforce. . ایک ہی تین — **موقع**: **اکاؤنٹ**: **صا لح**. .

::tip{icon="i-lucide-list-checks"}
پہلا حقیقی فرق Dataset Builder: **تمام منتخب کريں** ایک طرف سے ان پر کلک کرنے کی بجائے میدانوں میں ہر چیز استعمال کرنے کی بجائے، وسیع پیمانے پر چیزوں پر ایک بہت بڑا وقت بچانے والا. لیکن ایسا نہیں ہے. اگر کسی چیز کے 150+ شعبے ہیں آپ سب کو ان سب کی ضرورت نہیں ہے؛ صرف وہی چیز لاؤ جو ضرورت ہے.
::

کلک کرو **اگلے حصے** اور تم تین جماعتوں میں ہو۔ **متصل نہیں**. . یہ بنیادی فرق ہے: کسی کوائل میں، ان کو جوڑنے کا کام ہے.

::tip{icon="i-lucide-triangle-alert"}
یہ کرنسی ٹیکس ہے، اور یہ اندرونی طور پر قابل قدر ہے: **یہ ایک مشترکہ کلید کو استعمال کرتا ہے اور غلط کو چن سکتا ہے۔** آپ کو ضرورت کے مالک کے لئے `OwnerId → User.Id`... نہیں `Opportunity.Id → User.Id`. . آپ کو کرنا ہوگا *آپ کی چیزوں کو جانتے ہیں* اسے پکڑنے کے لئے کافی ہے. Dataset Builder اگر آپ اس غلطی کی اجازت نہ دیتے — کہ آپ کنٹرول کے لئے تجارت کو دور کرنے کے لئے تحفظ ہے.
::

## اپنے ستونوں پر

ریپرز آپ کو پیداواری ستونوں پر حقیقی کنٹرول دیتے ہیں:

- **قسم** — کسی کو منتخب کرنے کے لئے شمولیت کے حساب کو وسیع کریں **طےشدہ** ایک بھرپور تعاون. ( اِس مضمون کی پہلی تصویر کو دیکھیں ۔ )
- **رنگ** — اکاؤنٹ سے حاصل ہونے والے میدان `Account.Name`: `Account.Industry`، اور اسی طرح. آپ اِن جملوں کا نام بدل کر رکھ سکتے ہیں تاکہ آخری کالم جو آپ چاہتے ہیں پڑھ سکتے ہیں ۔
- **رہو یا گرا دو** — آنے والے ستونوں اور آنے والے ستونوں کو دیکھیں **بند** جن کی آپ کو ضرورت نہیں ہے تو وہ کبھی برآمد تک نہیں پہنچ سکتے۔ ترم `User.` مثال کے طور پر ، صرف مالک کے نام اور تصویر کے میدانوں تک اُس کے مالک کی طرف اشارہ کرتے ہیں ۔
