# بس لائن ڈیٹا سیٹ بنانا Dataset Builder

اب ہم ایک حقیقت بنا رہے ہیں Salesforce اعداد و شمار **Dataset Builder** اصل ہدایت شدہ اوزار ہے: یہ چیز تعلقات کو چلاتی ہے۔ *آپ کے لئے*، ساتھی کلیدوں کو خودبخود باہر کر دیتے ہیں اور اس کی ہدایات ایک میں درج کرتے ہیں۔ **اعداد و شمار**. . یہ ایک بیس لائن ڈیٹا سیٹ قائم کرنے کا دوست سب سے بڑا طریقہ ہے، جس کی وجہ سے میں اب بھی پلیٹ فارم سیکھنے والوں کو ہاتھ لگاتا ہوں۔

اناج کے سبق سے منصوبے کو یاد رکھیں: یہ ڈیٹا سیٹ ہے۔ **مواقع کے بارے میں**، تو ہم موقعے سے شروع کرتے ہیں اور دیکھتے ہیں۔ *اٹھو* اکاؤنٹ اور صارف کے لئے.

::tip{icon="i-lucide-plug"}
Dataset Builder پڑھتا ہے۔ **گرب/س**... سے نہیں Salesforce براہ راست. تو ایک کے برعکس CSV اپلوڈ، سنسکرت کو پہلے پہل میں ہونا چاہیے۔ اگر کسی چیز کو سنسکرت نہیں کیا جائے تو اس کا انتخاب نہیں ہو سکتا۔
::

## اسے بند کر دو

از Analytics Studio: **ڈی بگ ڈیٹا سیٹ بنائیں Salesforce ڈیٹا**. . یہ درمیانی طریقہ ہے — آپ ایک اپ لوڈ نہیں کر رہے ہیں CSV... اور آپ ایک موجود ڈیٹا سیٹ کے اوپر تعمیر نہیں کر رہے ہیں (یعنی یہ راستہ انفلیشن تک لے جاتا ہے).

آپ سے پوچھا جائے گا کہ کس ڈیٹا بیس کو استعمال کرنے کے لئے. ہر یانگ جہاز ایک ساتھ ہوتے ہیں۔ **طے شدہ Salesforce اعداد و شمار**''اور آپ اس میں اضافہ کر سکتے ہیں یا خود پیدا کر سکتے ہیں۔ پروڈکشن میں آپ کے پاس ایک چھوٹا سا نام ہو گا، شیڈول ڈیٹا کے حساب سے اور آپ کو پتہ چل جائے گا کہ ہر ایک کے بارے میں کیا ہے. اب، ڈیٹنگ استعمال. کلک کرو **اگلے حصے** اور Dataset Builder بند Data Manager تب

## ذیلی چیز سے شروع کریں

Dataset Builder اب ہر چیز ظاہر کرتی ہے کہ اسے حاصل کیا جا سکتا ہے۔ ہمارے تین بچے ہیں۔ **موقع**: **اکاؤنٹ**، اور **صا لح**. .

غلہ وصول کرتا ہے: **ہر قطار ایک منفرد موقع ہے۔**، حساب سے مالا مال کیا جاتا ہے اور صارف جو اس کے مالک ہوتے ہیں۔ کوئی موقع دو مرتبہ شمار نہیں کیا جاتا۔

::tip{icon="i-lucide-wand-2"}
غور کریں کہ آپ کیا کرتے ہیں *نہیں* یہ کرنا ہوگا: آپ نے کبھی نہیں بتایا کہ موقع `AccountId` اکاؤنٹ کے برابر ہے `Id`. . Dataset Builder براہ راست تعلقات پڑھاتے ہیں۔ Salesforce آپ کے لئے کلیدیں اتار دیں اور. یہی وجہ ہے کہ خودکار کلیدی طور پر اس کی پوری وجہ ہے.
::

**اگلے پر کلک کرنے کے بعد آپ اس پردے میں واپس نہیں آ سکتے۔** آپ کو ایک میدان بھول جانا ہوگا اور آپ کو اعداد و شمار کے فضلے کو تبدیل کرنا ہوگا اس کی جگہ (اور اس کے اگلے سبق پر بھی)۔ لہٰذا آگے بڑھنے سے پہلے، آپ کو ضرورت کے ہر میدان میں ڈبل چیک کیا جاتا ہے۔ پیمائش دو بار، پھر کلک کریں۔
::

جب آپ کے کھیت کھل جاتے ہیں تو کسی ایپ کا انتخاب کریں (کسی نجی ایپ کو اچھی طرح جانتے ہوئے) اور کلک کریں۔ **ڈیٹا سیٹ بنائیں**. . Dataset Builder یہ سب کچھ ڈیٹا کے ڈبوں میں ڈال کر اسے ختم کر دیتا ہے. اگلے سبق میں ہم اسے دیکھتے ہیں — اور ان غلطیوں کو حل کریں گے جو نئی تربیتی یا گرلز پہلی بار پھینکنے کو پسند کرتے ہیں۔
