# تعمیر : فن‌لینڈ اور سلیس ویلو شہر

موقعی انتظامیہ "جو متعلقہ ہے" پوچھتا ہے۔ یہ سوال کرتا ہے کہ مشین کتنی اچھی طرح کام کرتی ہے اور کہاں رکاوٹ ہے۔

::note{icon="i-lucide-gauge"}
**آپ کو توقع کرنی چاہئے** سب سے زیادہ آمدنی حاصل کرنے کے لئے آپ کو اِس کی قیمت صرف کرنی پڑتی ہے ۔ مہنگا مرحلہ بد ترین تبدیلی لانے والا ہے۔ *اور* اس کے ذریعے سے سب سے زیادہ مقدار گزر جاتی ہے اور صرف ایک قدرے وزنی فن ظاہر کرتا ہے۔
::

## رفتار مساوات

::metric-spec
---
items:
  - name: "Sales Velocity"
    formula: "(qualified opportunities × avg deal size × win rate) / avg cycle length in days"
    grain: "Per segment, per quarter"
    source: "opp_enriched"
    watchout: "Revenue per day. Its value is not the number — it is that it has exactly four levers, so 'we need more pipeline' becomes a choice between four measurable actions. Never compute it blended across segments: dividing Strategic's deal size by Self-Serve's cycle produces a number describing nothing."
---
::
