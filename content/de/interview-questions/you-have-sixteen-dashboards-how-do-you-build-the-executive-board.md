Indem wir entscheiden, was los ist. Ungefähr 130 Widgets existieren und neun Dinge überleben, und die Arbeit ist nicht die Auswahl der neun - die meisten Leute wählen eine ähnliche neun - es verteidigt die Ablehnungen gegenüber den Leuten, die sie gebaut haben. Mein Test pro Zahl ist, ob eine zwanzigprozentige Bewegung eine Entscheidung in diesem Quartal ändern würde, und jedes Diagramm auf dem Board muss eine der Kacheln darüber erklären. Alles, was einen Absatz zur Interpretation benötigt, wird auf einen Blick falsch gelesen, so dass es mit einem Link auf sein eigenes Dashboard gehört.
