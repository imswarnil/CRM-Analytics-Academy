# Grain, Joins und Fan-Out

Das ist die wichtigste Lektion im Kurs. Bauen Sie es, anstatt es zu lesen - der Punkt ist, eine falsche Zahl auf Ihrem eigenen Bildschirm zu sehen, ohne Warnung irgendwo, und fühlen, wie gewöhnlich es aussieht.

## Was Fan-Out ist

Ein one-to-many join multipliziert Zeilen auf der "one" Seite. Jede Maßnahme, die zur "einen" Seite gehört, wird nun über jedes ihrer Kinder wiederholt, so dass die Summe sie mehrmals zählt.

::warning{icon="i-lucide-alert-triangle"}
**Nichts an diesem Versagen ist exotisch**Und genau deshalb ist es gefährlich. Der Join ist korrekt. Jede Zeile ist korrekt. Der Datensatz baut, das Dashboard rendert, das Diagramm ist gutaussehend und die Zahl ist fast dreimal zu groß. Es wird überprüft, weil Überprüfung bedeutet, auf einen Bildschirm zu schauen, und der Bildschirm sieht richtig aus.
::

## Die beiden Fixes und wenn jeder richtig ist

::compare-cols
---
items:
  - title: "Aggregation vor dem Beitritt"
    subtitle: "Collapse the many side first"
    icon: "i-lucide-combine"
    pros:
      - "Output stays at one row per deal — the grain you probably want"
      - "Parent measures stay safe to sum"
      - "You choose exactly what the lines contribute: a count, a sum, a max"
    cons:
      - "Product-level detail is gone from this dataset"
    verdict: "Right when the dataset is about DEALS."
  - title: "Halten Sie das feine Korn, lassen Sie das Elternmaß fallen"
    subtitle: "Stay at line level, deliberately"
    icon: "i-lucide-scissors"
    pros:
      - "Product-level analysis stays possible"
      - "Line amounts are genuinely per-line, so they sum correctly"
    cons:
      - "Anyone using this dataset must know the grain, or they will sum the wrong thing"
      - "Deal counts need distinct counts, not row counts"
    verdict: "Right when the dataset is about PRODUCTS."
---
::

::note{icon="i-lucide-file-text"}
**Was auch immer Sie wählen, schreiben Sie das Korn in die Beschreibung des Datensatzes.** "Eine Zeile pro Gelegenheit" oder "eine Zeile pro Gelegenheit pro Produkt" dauert fünf Sekunden und es ist der einzige nützlichste Satz, den jeder Downstream lesen wird. Ein Datensatz, dessen Korn nicht dokumentiert ist, ist eine Falle, die Sie einem Kollegen stellen.
::

## Deutliche Zählungen

Sobald ein Datensatz ein feines Korn hat, **Anzahl der Zeilen stoppt die Bedeutung Anzahl der Deals**. Bei Linienkorn sind 1.192 Reihen 608 Möglichkeiten. Verwenden Sie eine eindeutige Zählung auf dem Gelegenheitsschlüssel anstelle einer Zeilenzählung und überprüfen Sie sie mit einer Zahl, die Sie kennen.

::tip{icon="i-lucide-bug"}
**Debug durch Verengung, nicht durch Starren.** Filtern Sie zu einer einzigen Gelegenheit, schalten Sie das Objektiv in den Tischmodus und zählen Sie die Zeilen von Hand. Dreißig Sekunden, und es sagt Ihnen genau, welche Seite multipliziert wurde - wo eine Stunde des Betrachtens einer Gesamtsumme Ihnen überhaupt nichts sagt.
::
