# Feldmetadaten und Formatierung

Jeder Datensatz enthält Metadaten über seine Felder: Display-Beschriftung, Format, Standard-Aggregation, Sichtbarkeit. Es einmal einzustellen ist der Unterschied zwischen einem Datensatz, den Menschen verwenden können, und einem, der einen Übersetzer benötigt.

## Etiketten

`Sum of Amount__c` Das sagen die Daten. "Einnahmen" ist das, was das Geschäft sagt. Das Label gehört in den Datensatz, wo jedes Objektiv und jedes Widget es erbt.

::tip{icon="i-lucide-users"}
**Label für den Leser, nicht für den Builder.** Der technische Name des Feldes ist für Sie ungefähr eine Woche lang nützlich; Das Etikett wird von jedem gelesen, der jemals das Dashboard öffnet, jahrelang. Wenn zwei Felder verwechselt werden könnten - `Amount` über die Gelegenheit und `LineAmount` auf der Produktlinie — machen Sie die Etiketten eindeutig und nicht kurz: "Deal Amount" und "Line Amount" verhindern einen echten Fehler.
::

## Formate

Währungssymbole, Tausende Trennzeichen, Dezimalstellen, Prozentsätze. Beheben Sie diese im Datensatz entfernt den häufigsten kosmetischen Defekt in CRM Analytics Dashboards - das gleiche maß formatierte drei verschiedene arten auf einem bildschirm, weil drei personen drei widgets bauten.

::note{icon="i-lucide-coins"}
**Dezimale sind eine Lesbarkeitsentscheidung, keine Präzisionsentscheidung.** Niemand trifft eine Entscheidung über die Cent eines $ 13.4M Zahl, und sechs Dezimalstellen auf einer Conversion-Rate impliziert ein Vertrauen, das die Daten nicht unterstützen können. Runden Sie auf das, was die Entscheidung braucht: ganze Währung für Summen, eine Dezimalzahl für Preise, und lassen Sie den genauen Wert im Tabellenmodus für jeden, der es will.
::

## Standard-Aggregation

Ein maß kann einen vernünftigen standard tragen - normalerweise summe, manchmal durchschnittlich, gelegentlich max. Es ist eine kleine Sache, die leise einen echten Fehler verhindert:

::warning{icon="i-lucide-triangle-alert"}
**Ein Kursfeld mit einem Default von `sum` Es ist eine geladene Waffe.** Die Nutzungsdaten der Akademie tragen einen Nutzungsprozentsatz pro Konto und Monat. Insgesamt über zwölf Monate, ein Konto bei 80% Auslastung liest sich als 960%. Nichts fehler, das diagramm macht, und die zahl ist unsinn. Setzen Sie den Standard auf Durchschnitt - und besser, folgen Sie dem Rat des Datenvorbereitungsabschnitts und berechnen Sie die Rate aus aggregierten Summen, anstatt überhaupt eine Pro-Zeilen-Rate zu speichern.
::

## Versteckfelder

Ein Datensatz mit sechzig Spalten, von denen fünfzehn Schlüssel und interne Flaggen sind, ist feindselig gegenüber jedem, der ihn erforscht. Verstecken Sie, was niemand gruppieren sollte: Ersatzschlüssel, interne Booleen, Staging-Spalten.

Das ist am wichtigsten für **Selbstbedienung**, was das Thema des Explorationsabschnitts ist. Eine Feldliste, die fünfzehn bedeutungsvolle Gegenstände lang ist, lädt zur Erkundung ein; eine, die sechzig Gegenstände lang ist, die Hälfte von ihnen benannt `X__c`, lehrt die Menschen, dass dieses Tool für Spezialisten ist.

## Der Fünf-Minuten-Pass, der sich für jeden Datensatz lohnt

  - title: "Format der Maßnahmen"

    description: "„ Eine Zeile pro Chance und Produkt. Der einzige nützlichste Satz, den jemand nach unten lesen wird, und der am häufigsten fehlende."

::tip{icon="i-lucide-clock"}
**Tun Sie dies, bevor Sie einen Datensatz freigeben, nicht danach.** Sobald zehn Widgets vorhanden sind, ist das Ändern eines Labels sicher, aber das Ändern einer Standardaggregation bedeutet, jedes einzelne von ihnen zu auditieren. Fünf Minuten am Start kostet fünf Minuten; die gleichen fünf Minuten später kostet einen Nachmittag der Überprüfung.
::
