# Benutzerdefinierte Tooltips und Chartmarker

Ein Diagramm hat zwei Informationsebenen: was Sie sehen und was Sie bekommen, wenn Sie genauer hinsehen. Die sichtbare Schicht sollte rücksichtslos einfach bleiben. Die **Tooltip** ist, wo all die Details, die Sie nicht wollten, die Leinwand zu überladen, zum Leben erweckt werden.

Die meisten Dashboards werden mit dem Standard-Tooltip ausgeliefert. Zehn Minuten Konfiguration machen es zum informationsreichsten Teil der gesamten Seite.

## Auswählen, was auf dem Hover erscheint

Öffnen Sie die Eigenschaften eines Charts und finden Sie die **Tooltip** Schnitt. Sie erhalten direkte Kontrolle über den Inhalt:

Der entscheidende Schritt ist **Verstecken der Standardwerte, die Sie nicht brauchen**. Ein Tooltip, der das Achsenlabel wiederholt, auf das der Benutzer bereits zeigt, verschwendet eine Linie. Schalten Sie alles aus, was sich seinen Platz nicht verdient, und was bleibt, liest sich als absichtliche Nachricht und nicht als Datenabwurf.

## Benutzerdefinierter Text, der Schrittfelder interpoliert

Dies ist der Teil, den es wert ist, richtig gelernt zu werden. Das benutzerdefinierte Textfeld ist nicht statisch - Sie können auf **Felder aus der Stufe**, und der Tooltip ersetzt den Istwert für den bewegten Datenpunkt.

Das bedeutet, dass Sie anstelle eines nackten Stapels von Label-Wert-Paaren einen Satz schreiben können:

> **{Account Name}** geschlossen **{Amount}** quer **{Count}** Deals in diesem Quartal.

Bewegen Sie eine Bar und Sie erhalten eine lesbare Aussage über diese bestimmte Bar. Es kostet ein paar Minuten und es verändert, wie Nicht-Analysten das Diagramm erleben - sie lesen eine Tatsache, nicht eine Datenstruktur zu entschlüsseln.

Es gibt auch eine **Nullwerte zeigen** Option. Schalten Sie es ein, wenn ein fehlender Wert selbst sinnvoll ist ("keine Aktivität protokolliert"), und aus, wenn Leerzeichen nur Rauschen sind, das den Tooltip kaputt aussehen lässt.

## Tooltips als Inline-Hilfe

Hier ist eine Verwendung, die die meisten Leute vermissen: Ein Tooltip muss die Daten überhaupt nicht beschreiben. Es kann **Erläuterung des Charts**.

Dashboards sammeln Metriken, deren Definitionen im Kopf von jemandem leben. *Pipeline-Abdeckung*, *gewichtete Prognose*, *bereinigtes Erreichen* Jede Organisation hat drei davon und keine zwei Menschen definieren sie auf die gleiche Weise. Setzen Sie diese Definition in den benutzerdefinierten Tooltip-Text und die Antwort sitzt genau dort, wo die Frage gestellt wird: auf dem Diagramm, im Moment der Verwirrung.

::tip{icon="i-lucide-lightbulb"}
Verwenden Sie einen Tooltip, um die Frage zu beantworten, über die Ihre Benutzer Ihnen eine E-Mail senden. "Beinhaltet dies Closed-Lost?" "Ist das in lokaler Währung?" Eine Zeile benutzerdefinierten Textes tötet diesen Thread dauerhaft und macht das Dashboard selbstdokumentierend für jeden, der ihn erbt.
::

Halten Sie es jedoch kurz. Ein Tooltip ist ein Blick, keine Seite. Wenn Ihre Erklärung drei Absätze benötigt, gehört sie in ein Text-Widget oder eine verlinkte Seite - und es ist wahrscheinlich ein Zeichen, dass die Metrik selbst vereinfacht werden muss.

## Kartenmarkierungen

Tooltips sind On-Demand. Manchmal braucht man das Gegenteil: etwas **dauerhaft sichtbar**, an einem bestimmten Punkt auf dem Diagramm angebracht, der "Hier schauen" sagt.

Das ist ein **Kartenmarkierung** Eine Anmerkung, die Sie an einen einzelnen Balken, eine Spalte oder einen Datenpunkt anheften. In den Eigenschaften des Diagramms wählen Sie den zu markierenden Punkt aus und konfigurieren dann drei Dinge:

Marker sind für die Geschichte hinter der Zahl, die Sache, die die Daten nicht selbst sagen können:

- Der Monat Einnahmen getaucht **Weil ein großes Konto abgestoßen ist** - Markieren Sie es, also untersucht niemand es jedes Quartal neu.
- Das Quartal Sie **Änderung der Methodik**, so dass der Leser weiß, dass ein Schrittwechsel kein echter Trend ist.
- Die Rekordwoche wert **Aufrufen** Anstatt zu verlassen, um bemerkt zu werden.

::tip{icon="i-lucide-triangle-alert"}
Marker werden an eine **Spezifischer Datenpunkt**. Wenn Ihr Diagramm nach einer Benutzerauswahl gefiltert, neu sortiert oder anders gruppiert wird, kann ein Marker neben etwas sitzen, um das es nie ging. Verwenden Sie sie in stabilen, verankerten Charts - eine feste Zeitreihe ist ideal - und überprüfen Sie sie erneut, wenn Sie den zugrunde liegenden Schritt ändern.
::

Sparsam verwendet - ein oder zwei pro Armaturenbrett - Marker sind die nächste Sache CRM Analytics hat eine fußnote, und sie stoppen die gleiche frage, die jeden monat gestellt wird.
