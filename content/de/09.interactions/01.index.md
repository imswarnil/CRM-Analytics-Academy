# Interaktion ist eine Design-Entscheidung

Ein statisches Dashboard beantwortet die Fragen, an die Sie gedacht haben. Eine interaktive beantwortet die Follow-ups - und die Follow-ups sind dort, wo der Wert ist.

::note{icon="i-lucide-mouse-pointer-click"}
**Fast niemand wird eine Linse bauen. Fast jeder wird auf eine Bar klicken.** Diese Asymmetrie ist das ganze Argument, um Interaktion ernst zu nehmen: Es ist der einzige Self-Service, den die meisten Ihrer Zuhörer jemals nutzen werden. Wenn ein Klick auf etwas auf Ihrem Dashboard zu einer sinnvollen Verengung führt, beantwortet das Dashboard hundert Fragen, die Sie nie erwartet hätten. Wenn das Klicken nichts oder etwas Überraschendes bewirkt, beantwortet es die sechs, die Sie erstellt haben.
::

## Die vier Mechanismen

::field-table
---
dataset: "how a dashboard responds"
grain: "one row per mechanism"
fields:
  - name: "Faceting"
    type: "automatic, same dataset"
    role: "key"
    note: "Widgets, die auf einem Datensatz aufgebaut sind, filtern sich standardmäßig gegenseitig. Der Mechanismus, mit dem sich ein Dashboard lebendig anfühlt, und derjenige, der am häufigsten vollständig auf Standardeinstellungen bleibt."
  - name: "Filter widgets"
    type: "explicit controls"
    role: "dimension"
    note: "Monat, Segment, Region an der Spitze. Absichtlich, auffindbar und das, wonach die Leute suchen, wenn sie nicht erkennen, dass sie auf das Diagramm klicken können."
  - name: "Selection state"
    type: "what is chosen at open"
    role: "dimension"
    note: "Die Erstauswahl entscheidet, was jeder zuerst sieht. Ein Dashboard, das sich ungefiltert und enorm öffnet, lässt jeden Zuschauer jeden Morgen die gleichen drei Klicks machen."
  - name: "Navigation"
    type: "between screens"
    role: "measure"
    note: "Links von einer Zusammenfassung zu einem Detail-Dashboard oder zu einem Salesforce Aufzeichnungen. Die Fluchtluke, die ein Armaturenbrett klein bleiben lässt."
---
::

## Die beiden Misserfolge

::compare-cols
---
items:
  - title: "Alles Facetten alles"
    subtitle: "The default, unexamined"
    icon: "i-lucide-shuffle"
    pros:
      - "Feels responsive"
      - "No configuration"
    cons:
      - "The reference widget moves, so the comparison it exists for disappears"
      - "Widgets at a different grain narrow in ways the data cannot support"
      - "A stray click leaves the whole screen filtered with no obvious way back"
    verdict: "Decide per widget, not per dashboard."
  - title: "Nichts facettiert irgendetwas"
    subtitle: "Widgets on separate datasets, unwired"
    icon: "i-lucide-unlink"
    pros:
      - "Predictable"
    cons:
      - "It is a page of pictures — the reader must re-ask every question with the filters"
      - "Half-wired is worse: four widgets narrow, three keep showing the global figure, and every number is individually correct"
    verdict: "Check every widget against a filter before shipping."
---
::

::warning{icon="i-lucide-alert-triangle"}
**Half-wired ist der gefährliche Zustand.** Ein Viewer filtert nach EMEA, vier Widgets schmal und drei nicht, und der Bildschirm als Ganzes sagt jetzt etwas Falsches, während jedes einzelne Widget Recht hat. Niemand berichtet das, weil nichts kaputt aussieht. Das Testen dauert dreißig Sekunden: Wenden Sie einen Filter an und überprüfen Sie, ob sich jedes Widget geändert hat oder einen absichtlichen Grund hat, dies nicht zu tun.
::

## Was dieser Abschnitt abdeckt

Faceting und Filter im Detail, Auswahlzustand und was ein Dashboard beim Öffnen anzeigen soll, und Navigation zwischen Dashboards und in Salesforce Aufzeichnungen. Bindungen - ein Widget, das die Abfrage eines anderen füttert - sind der nächste Abschnitt, weil sie ein anderer Mechanismus mit unterschiedlichen Kosten sind.
