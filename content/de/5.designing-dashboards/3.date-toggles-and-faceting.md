# Date Toggles und Controlling Faceting

Ein Datumsfilter im Standardfilterfeld funktioniert, aber es lässt den Benutzer arbeiten: Öffnen Sie das Panel, finden Sie das Feld, wählen Sie einen Bereich, wenden Sie an. A **:** Zeile über der Oberseite des Dashboards macht den gleichen Job mit einem Klick - *2024 | 2025 | 2026* Da sitzen, offensichtlich, immer sichtbar.

Diese Lektion baut diese Zeile auf und deckt auf dem Weg die einzige missverstandene Einstellung im Dashboard-Design ab: **Aufbringen von Filtern von Faceting**.

## Jedes Filter-Widget braucht einen Schritt

Hier ist die Regel, die fast jeden beim ersten Mal stolpert: ein Umschalter, eine Liste oder ein Datums-Widget **Erfindet keine eigenen Werte**. Es liest sie von einem **Schritt** Eine gespeicherte Abfrage. Wenn kein Schritt das Feld zurückgibt, nach dem Sie filtern möchten, hat das Widget nichts anzuzeigen.

Die Reihenfolge der Operationen ist also immer die gleiche: Bauen Sie zuerst den Schritt, ziehen Sie dann das Widget und binden Sie es.

## Gruppe nach einem date bucket, kein rohes date.

Sie können nicht auf ein rohes Datumsfeld umschalten - es hat Tausende von unterschiedlichen Werten und Sie erhalten Tausende von Schaltflächen. Was Sie wollen, ist ein **Datumsteil**: Jahr, Quartal, Monatsname.

CRM Analytics Datumsfelder legen ihre Bestandteile automatisch frei, und in einem gut erstellten Datensatz haben Sie oft auch ein benutzerdefiniertes Bucket-Feld (etwas wie) *Steuerzeitraum* oder *Abschlussjahr*) im Rezept genau zu diesem Zweck erstellt. Gruppieren Sie den Schritt mit diesem Feld und Sie erhalten eine Handvoll sauberer Werte - genau eine Schaltfläche.

::tip{icon="i-lucide-lightbulb"}
Wenn Sie die Datumsteile im Dashboard bekämpfen, gehört der Fix normalerweise dazu **Upstream im Rezept**. Ein dediziertes Bucket-Feld mit genau den gewünschten Labels ("FY25 Q1") ist billiger zu pflegen als ein Stapel von Workarounds auf Dashboard-Ebene, und jedes Dashboard im Datensatz erhält es kostenlos.
::

## Filtern Sie den Schritt, damit nur relevante Werte angezeigt werden

Ihr datensatz enthält wahrscheinlich daten, die weiter zurückreichen, als sich jemand darum kümmert, plus ein paar nachzügler von schlechter dateneingabe. Links in Ruhe, Ihre Toggle-Reihe macht jeden von ihnen und wickelt sich auf drei Linien.

Hinzufügen a **Filter auf dem Schritt selbst** — auf die letzten drei Jahre oder auf eine bestimmte Liste von Zeiträumen beschränken. Der Umschalter zeigt immer nur, was der Schritt zurückgibt, also filtern Sie den Schritt, wie Sie die Schaltflächen kuratieren. Dies ist eine Entscheidung auf Abfrageebene, keine Anzeige, weshalb sie auf den Schritt gehört.

## Klonen Sie einen Schritt, um den zweiten zu machen

Sobald du deine **Jahr** Toggle arbeiten, Sie wollen fast immer eine **Quartal** Daneben schalten. Es von Grund auf neu zu bauen bedeutet, jede Einstellung zu wiederholen.

Stattdessen **Klonen Sie den Schritt**. Finden Sie es in der Schrittliste, wählen Sie Klon, und Sie erhalten eine genaue Kopie mit den Filtern und der Gruppierung - ändern Sie dann nur das Gruppierungsfeld in Viertel, benennen Sie es um und binden Sie es an ein zweites Umschalt-Widget. Dreißig Sekunden statt fünf Minuten, und die beiden Schritte bleiben strukturell identisch, was sie später leichter zu pflegen macht.

::tip{icon="i-lucide-info"}
Klonierte Schritte sofort umbenennen. Ein Dashboard mit `Step_1`, `Step_1_copy`, und `Step_1_copy_copy` ist ein Wartungsalbtraum sechs Monate später - und Sie werden derjenige sein, der es beibehält.
::

## Die facettierende Gotcha

Nun zum wichtigen Teil. Drop your two toggles on, klicken Sie **2025** auf das Jahr umschalten, und beobachten Sie das Viertel umschalten verlieren die meisten seiner Optionen. Klicken Sie auf ein Viertel und das Jahr Umschalten kann auf einen einzigen Wert zusammenbrechen. Es fühlt sich kaputt an.

Das ist es nicht. Es ist **Facettieren** Genau das zu tun, was Faceting tut.

Faceting bedeutet, dass Widgets auf einem Dashboard sich automatisch gegenseitig filtern. Wählen Sie einen Wert in einem, und jeder andere Schritt fragt mit dieser Auswahl erneut ab. Für Charts ist das wunderbar - das ist das ganze interaktive Dashboard-Erlebnis. für *Filter Widgets* es ist oft falsch, weil ein Filter-Widget Sie zeigen sollte **Alle verfügbaren Optionen**Nicht nur diejenigen, die Ihre aktuelle Auswahl überleben.

Der Fix ist eine Checkbox auf dem Widget: **Aufbringen von Filtern von Faceting**. Deaktivieren sie es, und der schritt dieses widgets hört auf, auswahlen zu hören, die anderswo gemacht wurden. Seine Tasten bleiben gesetzt, egal was der Benutzer klickt.

Tun Sie dies für beide Umschalter. Jetzt behalten die Jahrreihe und die Viertelreihe ihre Form, der Benutzer kombiniert sie frei und die Diagramme unten reagieren auf beide. Das ist das Verhalten, das die Leute von einer Filterleiste erwarten.

## Räumung des Abstands

Zwei Toggle-Widgets nebeneinander hinterlassen normalerweise eine unangenehme Lücke, da das Dashboard-Raster standardmäßig Platz zwischen den Zellen schafft. In den Layout-Eigenschaften des Dashboards finden Sie **Zellabstand** Lassen Sie es gegen Null fallen und die Widgets sitzen bündig gegeneinander und lesen Sie als einen kontinuierlichen Kontrollstreifen anstelle von zwei separaten Boxen.

Es ist eine kleine Einstellung mit einem unverhältnismäßigen Einfluss darauf, wie "fertig" ein Dashboard aussieht. Es lohnt sich, jedes Dashboard, das Sie erstellen, neben den umliegenden Seitenrändern zu überprüfen.

Mit Filterung unter Kontrolle, das nächste, was zu schärfen ist, wie rohe Datensätze angezeigt werden. Als nächstes: **Tabellen, Bilder und Widget-Themen**.
