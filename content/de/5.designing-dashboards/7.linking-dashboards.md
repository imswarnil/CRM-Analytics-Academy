# Verknüpfung von Dashboards Gemeinsam

Ein Dashboard kann nicht alles beantworten. Versuche es und du bekommst ein scrollendes monster, das niemand liest. Das bessere Muster ist ein **Satz** von fokussierten Dashboards - eine Zusammenfassung, ein Pipeline-Detail, eine Aktivitätsansicht - verbunden, so dass sich der Benutzer zwischen ihnen bewegt, ohne jemals das Navigationsmenü zu berühren.

Die **Verbindung** Widget ist, wie Sie das bauen, und es tut wesentlich mehr als ein Öffnen URL.

## Was ein Link auf

Ziehen Sie ein Link-Widget auf die Canvas und seine Eigenschaften fragen nach einem Ziel. Sie haben drei Möglichkeiten:

Sie steuern auch, ob sich das Ziel in demselben oder einem neuen Tab öffnet. Gleiche Registerkarte für einen Drilldown, der Teil des Flusses ist; neue Registerkarte für Referenzmaterial, von dem der Benutzer zurückkommen wird.

## Tragefilter über

Dies ist die Einstellung, die Links wirklich mächtig macht, und die, die die meisten Leute verlassen, weil sie es nie bemerkt haben.

Ermöglicht **Auswahl anwenden / Filter anwenden** über den Link und die **Der aktuelle Dashboard-Zustand reist mit ihnen**. Wenn sie nach EMEA, Q3 gefiltert und gewonnen haben, landen sie auf dem Ziel-Dashboard, das bereits nach EMEA, Q3 gefiltert und gewonnen wurde.

Ohne sie ist die Reise: Filtern Sie sorgfältig, klicken Sie sich durch, wenden Sie alle die gleichen Filter erneut an, verlieren Sie Ihren Gedankengang. Damit fühlen sich die beiden Dashboards wie eine Anwendung mit zwei Ansichten an.

::tip{icon="i-lucide-triangle-alert"}
Filter tragen nur sauber durch, wenn die **Target Dashboard verfügt über kompatible Filter** in einem Datensatz mit den gleichen Feldnamen. Verknüpfen Sie ein Pipeline-Dashboard mit einem Support-Dashboard in einem völlig anderen Datensatz und die Auswahl hat nichts zu binden. Entwerfen Sie verknüpfte Dashboards von Anfang an als Familie, auf gemeinsamen Datensätzen und gemeinsamen Feldnamen, und das funktioniert einfach.
::

## Styling eines Links wie ein Tab

Ein Link-Widget akzeptiert das gleiche Styling wie jedes andere Widget - Hintergrundfarbe, Schriftart, Randradius, Padding. Setzen Sie eine Reihe von ihnen über die Oberseite des Dashboards, geben Sie ihnen einen gefüllten Hintergrund und eine abgerundete obere Kante, und Sie haben etwas, das der Benutzer unverkennbar liest als **Laschen**.

Markieren Sie die aktuelle (einen stärkeren Hintergrund oder die Markenfarbe) und grau die anderen, und ein Satz von vier Dashboards verhält sich wie eine Vier-Tab-Anwendung. Es ist völlig kosmetisch - es gibt keine echte Tab-Komponente darunter - aber die Benutzer wissen das nicht und müssen es nicht. Es ist eines der wichtigsten Styling-Bits, denn bei der Navigation fallen die meisten Dashboard-Sets herunter.

## Der transparente Link über einem Container

Jetzt der Trick, der es wert ist, gestohlen zu werden. Ein Link-Widget wird als Text dargestellt, und manchmal möchten Sie eine **anklickbares Bild** Stattdessen — eine Produktkachel, ein Teamfoto, eine Markenkarte, die das entsprechende Dashboard öffnet.

Es gibt kein Image-Button-Widget. Sie fälschen einen überzeugend:

::lesson-steps
---
items:
  - title: "Ein Container-Widget löschen"
    description: "Legen Sie einen Behälter auf die Leinwand und Größe es auf die Kachel, die Sie wollen."
  - title: "Geben Sie ihm ein Hintergrundbild"
    description: "Legen Sie in den Eigenschaften des Containers ein Hintergrundbild fest und wählen Sie, wie es passt - die Abdeckung sieht normalerweise am besten aus."
  - title: "Überlagern eines Link-Widgets"
    description: "Ziehen Sie ein Link-Widget auf den Container, so dass es den gleichen Bereich genau abdeckt."
  - title: "Machen Sie den Link unsichtbar"
    description: "Stellen Sie die Hintergrundfarbe des Links auf vollständig transparent und die Schriftfarbe auf vollständig transparent."
  - title: "Richten Sie es am Bestimmungsort"
    description: "Legen Sie das Ziel-Dashboard fest und aktivieren Sie die Anwendungsauswahl und testen Sie dann, ob die gesamte Kachel durchklickt."
---
::

Das Ergebnis ist ein Bild, auf das der Benutzer klickt. Der Link ist immer noch da, macht seine Arbeit, trägt seine Filter - er hat einfach nichts sichtbares zu rendern. Sowohl der Hintergrund *und* die Schriftfarbe muss transparent sein; lassen Sie den Text undurchsichtig und Sie erhalten ein verirrtes Wort, das über Ihrem Bild schwebt.

::tip{icon="i-lucide-lightbulb"}
Da der unsichtbare Link kein Hover-Feedback gibt, fügen Sie die Affordanz selbst hinzu: einen subtilen Rahmen auf dem Container, eine Beschriftung darunter oder einen Tooltip auf dem Link, der erklärt, wohin es geht. Ein Bild, das sich als anklickbar herausstellt, ist eine schöne Überraschung; ein Bild, das *Blicke* Klickbar und ist einer ist gutes Design.
::

Verwenden Sie dies für eine Zielseite - ein Raster aus Bildkacheln, die jeweils einen anderen Geschäftsbereich öffnen. Es dauert zwei Widgets pro Kachel und es macht eine Analyse-App eher wie ein Produkt als ein Ordner von Berichten.

## Wo das dich verlässt

Sie haben jetzt das komplette Design-Toolkit: Farbe, die Bedeutung trägt, Filter, die nur einen Klick entfernt sind, Tabellen, die Gesichter zeigen, Diagramme, die sich selbst erklären, ein KPI Band, das die Headline-Frage beantwortet, und Navigation, die eine Reihe von Dashboards zusammenhält.
