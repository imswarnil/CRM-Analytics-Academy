# Werte Tabellen, Bilder und Widget-Themen

Charts antworten "wie viel" und "was ist am größten". Früher oder später fragt jemand **"Welche Aufzeichnungen genau?"** - und das ist die **Wertetabelle**: eine gerade Liste von Zeilen, ein Datensatz pro Zeile, Spalten Ihrer Wahl.

Es sieht aus wie das am wenigsten gestaltete Widget auf der Leinwand. Es hat mehr Design-Einstellungen als fast jede andere.

## Standardspalten stammen aus dem Dataset

Lassen Sie eine Wertetabelle auf ein Dashboard fallen und es wird nicht leer angezeigt - es wird mit einer Reihe von Spalten vorbefüllt. Das ist keine Vermutung. Sie sind die **Standardfelder** auf dem Datensatz selbst konfiguriert, im **Felder** Panel des Bearbeitungsbildschirms des Datensatzes.

Dies ist ein wirklich nützliches Stück Datensatzhygiene. Sensible defaults einmal — sagen *Name der Gelegenheit*, *Konto*, *Phase*, *Schlussdatum*, *Betrag* - und jede Wertetabelle, die jemand auf diesem Datensatz aufbaut, beginnt an einem vernünftigen Ort, anstatt neunzig oder keine Spalten zu werfen.

## Hinzufügen eines Feldes zur Tabelle

Das Hinzufügen einer Spalte erfolgt aus der Abfrage des Widgets, nicht durch Ziehen auf die Tabelle. Öffnen Sie den Schritt hinter der Tabelle, suchen Sie die Feldliste und fügen Sie das gewünschte Feld hinzu – es wird sofort als neue Spalte angezeigt.

Ordnung ist wichtig für die Lesbarkeit. Put **Identifizierung** zuerst (Name, Konto), die **kategorisch** die nächsten (Stufe, Eigentümer, Region) und die **Zahlen** zuletzt rechts, wo das Auge erwartet, sie zu scannen. Leser analysieren einen Tisch von links nach rechts genau einmal; Machen Sie diesen Pass die Arbeit.

::tip{icon="i-lucide-triangle-alert"}
Die **Felder** Editor, den Sie in einem Dashboard sehen Schritt ist **nicht** Das gleiche wie der Fields Editor in einem Objektiv. Das In-Dashboard steuert nur, welche Felder diese Abfrage zurückgibt und wie dieses Widget sie anzeigt. Realfeld-Metadaten – das Display-Label, die Zahlenformatierung, Standardspalten, ob ein Feld vor Benutzern verborgen ist – müssen in **Linsenmode**auf dem Dataset selbst. Wenn Sie etwas ändern und es hartnäckig nicht über Widgets hinweg bleibt, sind Sie im falschen Editor.
::

## Spacing: Fit Daten zum Widget

Der Standardtabellenabstand ist großzügig, was bedeutet, dass eine Tabelle, die nach Ihrem Layout bemessen ist, oft vier Zeilen und eine Scrollleiste anzeigt. In den Eigenschaften des Widgets finden Sie die Abstandsoption und wählen **Daten passen zu Widget**.

Das schaltet den Tisch von einer festen Zeilenhöhe auf eine, die komprimiert wird, um den Raum zu nutzen, den er erhalten hat - mehr Zeilen sichtbar, Spalten nach ihrem Inhalt, weit weniger toter Weißraum. Auf einem Dashboard, bei dem der Tisch eher ein unterstützendes Detail als das Hauptereignis ist, ist es der Unterschied zwischen einer nützlichen Liste und einem Teaser.

## Themen zu einzelnen Widgets

Ein Dashboard hat ein Gesamtthema, aber **Jedes Widget kann es überschreiben**. In den Widget-Eigenschaften finden Sie eine Theme-Einstellung - drehen Sie eine einzelne Tabelle oder ein Diagramm in die **dunkel** Thema und es rendert mit einem dunklen hintergrund und hellem text, während alles um ihn herum hell bleibt.

Schlecht benutzt sieht das chaotisch aus. Bewusst verwendet, ist es eines der effektivsten verfügbaren Layout-Tools:

- Geben Sie **KPI Streifen** Oben ein dunkles thema, so dass es sich als eigenständiges headerband liest.
- Darken a Single **Callout** Widget - die One-Nummer-Führung kümmert sich darum - also landet das Auge zuerst dort.
- Verwenden Sie einen dunklen Hintergrund hinter einem Tisch von **Bilder** oder Logos, die fast immer besser gegen Dunkel als gegen Weiß aussehen.

Die Disziplin besteht darin, es für **Gruppe**Nicht Dekoration. Wenn zwei Widgets ein Thema teilen, nimmt ein Leser an, dass sie zusammengehören; Stellen Sie sicher, dass sie es tatsächlich tun.

## URLs als Bilder darstellen

Dies ist die Eigenschaft, die die meisten Menschen nie entdecken, und es ändert sich, was ein Tisch sein kann.

Salesforce Daten sind voll von URL Felder — URLs von Benutzerfotos, Produktbildlinks, Logofelder, Miniaturansichten von Dokumenten. Standardmäßig zeigt eine Wertetabelle diese als das an, was sie sind: lange, hässliche, nicht klickbare Textfolgen, die die Spaltenbreite ausblasen.

Auf den Eigenschaften der Säule gibt es eine **Daten als Bild zeigen** Option. Schalten Sie es ein und CRM Analytics fetzt die URL und stellt stattdessen das Bild in der Zelle dar.

Die klassische Nutzung ist eine **Besitzerfoto** Spalte auf einem Top-Performer-Tisch - Gesichter statt Namen machen eine Rangliste fühlen sich persönlich und sofort scannbar. Der gleiche Trick funktioniert für Produktbilder in einer Katalogtabelle, Kontologos in einer Clientliste oder Statussymbole, die als Bild-URLs gespeichert sind.

::tip{icon="i-lucide-info"}
Das Bild muss durch den Browser erreichbar sein, der das Dashboard betrachtet. Von Salesforce gehostete Foto-URLs verhalten sich gut, weil der Benutzer bereits authentifiziert ist; Ein Link zu einem internen System, der eine separate Anmeldung erfordert, wird als defektes Bild für alle außer Ihnen dargestellt. Testen Sie mit dem Login eines Kollegen, bevor Sie es versenden.
::
