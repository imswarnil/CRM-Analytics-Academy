# Onboarding Videos und die Learn Action

Wir haben diesen abschnitt mit funktionen verbracht, die daten an die nutzer weitergeben. Der Letzte drückt *Verständnis* Ihnen gegenüber - und es spricht den häufigsten Grund an, warum ein Armaturenbrett leise stirbt: Niemand war sich jemals sicher, was sie anschauten.

## Die Onboarding-Eigenschaft

Jedes Widget hat eine **Onboarding** Eigenschaft im Dashboard Editor. Setzen Sie es, und das Widget erhält eine **Lernen** Aktion in seinem Menü. Ein Benutzer, der darauf klickt, erhält ein Video, in dem dieses Widget erklärt wird.

## Das gotcha: es muss ein Embed sein URL

::tip{icon="i-lucide-triangle-alert"}
Die URL Sie müssen ein YouTube sein **Einbettung** URL, nicht der gewöhnliche Watch-Link aus der Adressleiste Ihres Browsers.

Holen Sie es sich aus dem Video **Share → Embed** Option - das gibt Ihnen die `youtube.com/embed/...` Form. Einfügen der normalen `youtube.com/watch?v=...` Link (oder der Link) `youtu.be/...` Kurzer Link) führt zu einer Lernaktion, die sich für nichts öffnet, ohne dass ein offensichtlicher Fehler erklärt, warum.
::

Dies lohnt sich jedes Mal zu überprüfen, weil der Fehler still ist. Die Eigenschaft speichert glücklich, die Aktion Lernen erscheint im Menü und das Ganze sieht konfiguriert aus - bis ein Benutzer darauf klickt und ein leeres Panel erhält. Testen Sie die Aktion immer nach dem Speichern aus der Perspektive eines Betrachters und nicht aus der des Editors.

## Warum dies in einen Bereich der Zusammenarbeit gehört

Onboarding Videos sind Dokumentation, die lebt **Wo die Frage gestellt wird**. Eine wiki-seite, die ihr dashboard erklärt, wird von niemandem gelesen; eine learn-aktion auf dem widget, von dem jemand verwirrt ist, wird von genau der person gelesen, die es braucht.

Reservieren Sie es für die Widgets, die es verdienen - die berechneten Metriken, die mit nicht offensichtlichen Geschäftsregeln, die Sie bereits zweimal erklären mussten. Das Anfügen eines Videos an eine einfache Anzahl offener Fälle ist eine Anstrengung, bei der niemand verwirrt war.

::tip{icon="i-lucide-graduation-cap"}
Ein praktisches Muster: Aufnahme eines Videos pro *Armatur* Sie decken die zwei oder drei wirklich kniffligen Widgets ab, befestigen sie an jedem von ihnen und Sie haben in etwa einer halben Stunde eine Selbstbedienungs-Hilfeschicht aufgebaut. Es muss nicht ein Video pro Widget sein, um nützlich zu sein.
::
