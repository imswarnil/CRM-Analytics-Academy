# Daten von einem Widget herunterladen

Wie gut Ihr Dashboard auch ist, jemand möchte die Daten in Excel. Der Kampf gegen diesen Instinkt ist ein verlorener Kampf - der bessere Schritt ist, genau zu verstehen, was der Export ihnen gibt, und dafür zu entwerfen.

Jedes Widget hat einen **Anteil** Seine eigene Handlung, und in ihm eine **Download** Option. Sie wählen ein Format:

## Was Sie tatsächlich bekommen: die Abfrage, nicht der Datensatz

Dies ist das Konzept, das den Nutzern eine enorme Verwirrung erspart.

Download Export **Das Ergebnis der Widget-Abfrage** Nicht der Datensatz dahinter. Was also in Ihrer Tabelle landet, hängt ganz davon ab, von welcher Art von Widget Sie exportiert haben.

::lesson-cards
---
columns: 2
items:
  - title: "Download aus einem gruppierten Chart"
    icon: "i-lucide-bar-chart-3"
    description: "Ein nach Stufen gruppiertes Balkendiagramm, das die Summe des Betrags zeigt, gibt genau das zurück: eine Zeile pro Stufe und eine Betragsspalte. Die Gruppierung ist die Abfrage - es gibt keine zugrunde liegenden Details im Ergebnis zu exportieren."
  - title: "Download aus einer Wertetabelle"
    icon: "i-lucide-table-2"
    description: "Eine Wertetabelle ist eine nicht gruppierte Ausgabe auf Zeilenebene. Exportieren Sie es und Sie erhalten jede Spalte, die Sie auf den Tisch legen, eine Zeile pro Datensatz - die Details, nach denen Benutzer tatsächlich fragen."
---
::

Wenn ein Benutzer also sagt: "Der Export hat mir nur vier Zeilen gegeben", hat er keinen Fehler getroffen - er hat ein Diagramm mit vier Balken exportiert. Der Fix ist, ihnen etwas zum Export zu geben *von*: eine Wertetabelle mit den wichtigen Spalten.

::tip{icon="i-lucide-lightbulb"}
Design-Gewohnheit: Wenn Sie wissen, dass das Publikum eines Dashboards exportieren wird, setzen Sie eine **Wertetabelle** absichtlich darauf, mit den Säulen, die sie brauchen. Lassen Sie sie nicht ein Diagramm exportieren und entdecken, dass es aggregiert ist.
::

## Das 100-Zeilen-Limit

Eine Wertetabelle stellt nicht jede Zeile standardmäßig dar - sie ist begrenzt auf **100 Reihen**. Diese Obergrenze gilt für das, was das Widget abgefragt hat, und daher für das, was Sie exportieren können. Niemandes Tabellenkalkulation stoppt zufällig bei genau 100 Zeilen.

Sie können es erhöhen. In den Abfrageeinstellungen des Widgets gibt es eine **Grenze** Sie können erhöhen.

::lesson-steps
---
items:
  - title: "Öffnen Sie die Abfrage der Wertetabelle"
    description: "Bearbeiten Sie das Dashboard, wählen Sie das Widget aus und öffnen Sie die Abfrage, an die es gebunden ist."
  - title: "Finden Sie das Zeilenlimit"
    description: "Das Limit der Wertetabelle wird standardmäßig auf die Abfrage gesetzt - 100."
  - title: "Heben Sie es bewusst"
    description: "10.000 ist die unterstützte Obergrenze für diese Art von Export. Setzen Sie es auf das, was der Anwendungsfall wirklich braucht, nicht auf das Maximum durch Reflex."
---
::

Können Sie über 10.000 hinausgehen? Technisch gesehen, ja - das Limit akzeptiert eine größere Zahl. Aber hinter diesem Punkt bist du außerhalb dessen, was unterstützt wird, und die eigentliche Einschränkung hört auf, die Plattform zu sein und beginnt zu sein **Der Browser**. Die Ergebnismenge muss gerendert und clientseitig gehalten werden, so dass sehr große Tische langsam, unzuverlässig und anfällig dafür werden, einfach auf jemandes Laptop zu versagen. Bauen Sie keinen Geschäftsprozess darauf auf.

::tip{icon="i-lucide-triangle-alert"}
**Erhöhen Sie nicht das Limit auf Ihrem Haupt-Dashboard.** Die höhere Grenze gilt für jeden, der sie öffnet, jedes Mal - so dass der gelegentliche 10.000-Reihen-Export einer Person das Armaturenbrett für die hundert Leute, die nur das Diagramm wollten, dauerhaft verlangsamt.

Bau A **separates Download-Only-Dashboard oder Objektiv** Stattdessen: eine einzelne Wertetabelle, die Spalten, die die Finanzierung tatsächlich benötigt, die höhere Grenze und ein Filterfeld. Link zum Haupt-Dashboard. Exporteure erhalten ihre Daten, alle anderen behalten ihr schnelles Dashboard und Sie erhalten einen offensichtlichen Ort, an dem Sie nachsehen können, wenn der Export unterbrochen wird.
::

## Download benötigt eine Berechtigung

Exportieren ist nicht automatisch für jeden Benutzer verfügbar – es wird durch eine Berechtigung im Berechtigungssatz des Benutzers geregelt. Wenn ein Benutzer Ihnen sagt, dass die Download-Option fehlt oder ausgegraut ist, ist dies das erste, was Sie überprüfen müssen, nicht die Dashboard-Konfiguration.

Das ist auch der Hebel, um in die andere Richtung zu ziehen: In Organisationen, in denen Daten, die die Plattform verlassen, ein Compliance-Problem darstellen, kontrollieren Sie sie zentral, indem Sie einfach die Erlaubnis nicht erteilen, anstatt zu versuchen, Exporte aus Ihren Dashboards zu entwerfen.

Exporte antworten "gib mir die Daten". Die nächste Lektion beantwortet eine verwandte, aber andere Anfrage - "Ich brauche einen Schnitt, den du nicht gebaut hast" - mit **Self-Service Exploration**.
