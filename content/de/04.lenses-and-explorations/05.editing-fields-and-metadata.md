# Bearbeiten von Feldern und Dataset Metadaten

Öffnen Sie eine Linse auf einem frisch gebauten Datensatz und es sieht ... rau aus. Dimensionen werden aufgerufen `AccountId.Name` und `StageName`. Beträge werden als nackte Zahlen ohne Währungssymbol und acht Dezimalstellen angezeigt. Jedes Diagramm Ihrer Stufen wählt andere Farben als das letzte.

All das ist **Metadaten des Datensatzes**, und Sie reparieren es aus dem Inneren einer Linse - über die **Felder** Panel.

::tip{icon="i-lucide-triangle-alert"}
Lesen Sie dies sorgfältig: Das Fields Panel tut **nicht** Bearbeiten der Linse. Es bearbeitet die **Datensatz**. Jede Änderung, die Sie hier speichern, gilt für diesen Datensatz **überall** - jedes vorhandene Objektiv, jedes Dashboard, jede Geschichte, für jeden Benutzer. Das ist es, was es macht, und es ist auch, warum Sie es als eine absichtliche Handlung und nicht als kosmetische Optimierung behandeln sollten.
::

Sie brauchen die **Verwalten von Analytics** oder **Datenflüsse bearbeiten** Erlaubnis, diese Änderungen vorzunehmen. Ohne sie ist das Feldfeld schreibgeschützt.

## Öffnen des Fields Panels

Aus einer offenen Linse, suchen Sie nach **Felder** Option (normalerweise im Objektivmenü oder neben der Feldliste). Es listet jedes Feld im Datensatz auf, aufgeteilt in **Abmessungen**, **Maßnahmen**, und **Daten**. Wählen Sie ein Feld und seine Einstellungen erscheinen rechts.

Vier Dinge sind deine Zeit wert.

## 1. Standardfelder für die Wertetabelle

Wenn jemand diesen Datensatz öffnet und zu einem **Wertetabelle**Welche Spalten sollten sie zuerst sehen?

Allein gelassen, erhalten Sie jede Reihenfolge, in der der Datensatz eingebaut wurde - oft IDs und Systemfelder an der Vorderseite. Im Feldfeld können Sie die **Standardfelder**: Wählen Sie die Handvoll Spalten, die die Geschichte tatsächlich erzählen (Kontoname, Bühne, Abschlussdatum, Betrag, Eigentümer) und legen Sie ihre Reihenfolge fest.

Es ist eine kleine Veränderung mit einem übergroßen Effekt. Jeder Kollege, der diesen Datensatz öffnet, beginnt jetzt mit etwas Lesbarem anstelle einer Wand mit achtzehnstelligen IDs.

## 2. Umetikettierungsmaße

Wählen Sie eine Dimension und bearbeiten Sie ihre **Kennzeichnung**. `AccountId.Name` wird **Kontoname**. `StageName` wird **Phase**. `Owner.UserRole.Name` wird **Verkaufsrolle**.

Dies ist die höchste Wert, niedrigste Anstrengung Sache in dieser Lektion. Das Label ist das, was in Feldpickern, Diagrammachsen, Legenden, Tooltips und Tischüberschriften erscheint - überall, wo ein Geschäftsanwender liest. Niemand sollte Ihr Objektmodell kennen müssen, um Ihr Dashboard zu verwenden.

::tip{icon="i-lucide-info"}
Relabeling verändert die **Nur Etiketten**. Die **API Name unverändert** — fortgeschritten/SAQL Modus, den du immer noch schreibst `'AccountId.Name'`, nicht `'Account Name'`. Gleiches gilt für Bindungen und Filterdefinitionen. Wenn a SAQL Die Abfrage bricht nach einem Relabel, das Relabel ist nicht die Ursache; schauen Sie woanders hin.
::

## 3. Bearbeiten von Werten und Zuweisen von Farben

Erweitern Sie eine Dimension und Sie können sehen, seine **Werte**und gegen jeden Satz eine **Farbe**.

So bekommst du **konsistente, aussagekräftige Farbe in jedem Diagramm Ihrer Organisation**. Wählen Sie eine Farbe für jede Etappe einmal - Geschlossenes Grün, Geschlossenes Verlorenes Rot, alles dazwischen auf einer vernünftigen Rampe - und von da an *alle* Ein nach Stage gruppiertes Diagramm verwendet in jedem Dashboard diese Farben automatisch. Keine Neuauswahl von Farben pro Chart mehr und kein "Warten Sie, ist Grün gewonnen oder verloren auf diesem?"

Tun Sie es für die Dimensionen, die überall erscheinen: Bühne, Typ, Industrie, Priorität, Status. Rot / Bernstein / Grün für alles mit einer inhärenten Gut-zu-Schlecht-Bestellung zahlt sich sofort aus.

Sie können auch die **angezeigter Wert** sich selbst - aber hier müssen Sie vorsichtig sein.

::tip{icon="i-lucide-triangle-alert"}
**Ändern Sie die Etiketten hier; Ändern Sie die tatsächlichen Werte auf der Datenschicht.** Das Umbenennen eines Werts in diesem Panel ändert nur, was *ausgestellt*. Der zugrunde liegende Wert ist unberührt, so SAQL Abfragen, Filterdefinitionen, Bindungen und Exporte zeigen immer noch das Original. Jemand, der "Enterprise" in einem Chart sieht und dann schreibt `filter q by 'Segment' == "Enterprise"` wird Null Zeilen erhalten, wenn der gespeicherte Wert wirklich `ENT`. Wenn ein Wert wirklich falsch ist, beheben Sie ihn in der **Rezeptur oder Datenfluss** mit einem Bucket oder einer Transformation - so stimmen der gespeicherte Wert und der angezeigte Wert überein, und niemand wird in sechs Monaten verwirrt.
::

## 4. Formate für die Anzahl der Messwerte

Wählen Sie ein Measure aus und Sie können festlegen, wie seine Zahlen auf der gesamten Plattform dargestellt werden:

::lesson-cards
---
columns: 3
items:
  - title: "Dezimalstellen"
    icon: "i-lucide-hash"
    description: "Beträge benötigen fast nie mehr als zwei und oft null. Das Trimmen von Dezimalzahlen macht Charts dramatisch einfacher zu scannen."
  - title: "Währung"
    icon: "i-lucide-banknote"
    description: "Wählen Sie das Währungsformat und fügen Sie das Symbol ein, das Sie benötigen - $, €, £, ❤. Es erscheint dann auf Äxten, Etiketten, Tabellen und Tooltips."
  - title: "Kundenspezifisches Format"
    icon: "i-lucide-settings-2"
    description: "Erstellen Sie Ihr eigenes Muster für Präfixe, Suffixe, Tausende Separatoren oder Einheiten - Prozentsätze, Stunden oder \"K-Einheiten\"."
---
::

Der Währungsschritt fängt die Leute auf: Anstatt eine lange Dropdown der Weltwährungen, wählen Sie in der Regel die Währung oder benutzerdefinierte Formatoption und dann **Einfügen des Symbols** in das Formatfeld. Kopieren Sie das gewünschte Zeichen, fügen Sie es in das Präfix ein, fertig. Ein Rupie- oder Euro-Symbol verhält sich genau wie der Dollar-Default, sobald er dort ist.

## Sparen

Save, und die Änderungen sind live. Nicht "leben in diesem Objektiv" - leben im Datensatz. Öffnen Sie alle vorhandenen Dashboards, die darauf aufgebaut sind, und die Etiketten, Farben und Währungsformate werden bereits angewendet, ohne dass etwas neu erstellt werden muss.
