# Wählen eines Charts

Beginnen Sie mit dem Satz, den der Leser nach vier Sekunden sagen kann. Der Charttyp folgt daraus fast mechanisch.

## Der Entscheidungspfad

::lesson-steps
---
items:
  - title: "Ist die x-Achse Zeit?"
    description: "Wenn ja, zeigen Sie einen Trend: Zeile für ein kontinuierliches Maß, Spalte für diskrete Perioden, die Menschen zählen (Deals pro Monat geschlossen). Halten Sie die Zeit in der Reihenfolge - dies ist die eine Achse, die Sie nie nach Wert sortieren."
  - title: "Ist es eine Zahl gegen eine Referenz?"
    description: "A KPI Kachel mit einem Vergleich oder einem Messgerät, wenn die Referenz ein hartes Ziel ist. Niemals ein Single-Bar-Diagramm: Ein Balken mit nichts daneben kommuniziert weniger als die Zahl, die deutlich geschrieben ist."
  - title: "Sind Sie Ranking-Kategorien?"
    description: "Horizontale Balken, sortiert nach Wert, begrenzt auf das obere N mit dem Limit im Titel. Dies ist das Arbeitspferd und es ist viel häufiger richtig als die Alternativen, nach denen Menschen greifen."
  - title: "Ist es Zusammensetzung - Teile eines Ganzen?"
    description: "Zwei oder drei Teile: eine gestapelte Stange. Vier oder mehr, oder wenn die genauen Werte wichtig sind: eine Tabelle mit einer Freigabespalte. Ein Donut nur, wenn es wirklich zwei oder drei Scheiben gibt und die Form selbst die Botschaft ist."
  - title: "Sind es zwei Maßnahmen gegeneinander?"
    description: "Streuen. Ein Maß pro Achse, ein Punkt pro Einheit. Dies ist die einzige Familie, die antwortet: \"Mach diese Schritte gemeinsam\", und sie wird schlecht unterbenutzt."
  - title: "Ist es eher ein Spread als ein Total?"
    description: "Eine Verteilungsansicht — Bänder, ein Spaltendiagramm im Histogrammstil. Jedes Mal, wenn Sie einen Durchschnitt melden, fragen Sie, ob die Form der Befund ist."
  - title: "Ist es ein Prozess mit Etappen?"
    description: "Ein Trichter, wenn die Stufen sequentiell sind und schrumpfen, ein Wasserfall, wenn Dinge addiert und subtrahiert werden, um einen Endwert zu erreichen."
---
::

## Der Standard, der zu oft richtig ist

**Ein horizontales Balkendiagramm, sortiert absteigend, begrenzt auf die Top Ten, mit dem Limit im Titel.**

::tip{icon="i-lucide-bar-chart-3"}
**Wenn Sie sich nicht entscheiden können, bauen Sie das auf und machen Sie weiter.** Es beantwortet die häufigste Frage (die am größten ist), es ist lesbar in jeder Größe, es überlebt Graustufen und einen Projektor, und es ist sehr schwer falsch zu lesen. Erreichen Sie etwas anderes, wenn Sie einen Grund haben - einen Trend, eine Beziehung, eine Komposition - nicht weil das Dashboard zu viele Balken hat. Ein Dashboard mit Balken, die jeweils eine echte Frage beantworten, schlägt eine abwechslungsreiche, bei der drei Widgets für visuelles Interesse existieren.
::

## Was CRM Analytics gibt dir

Die Chartliste ist lang und die nützliche Untermenge ist kurz. In der Praxis decken die Familien in diesem Abschnitt im Wesentlichen alle Produktions-Dashboards ab:

::field-table
---
dataset: "the working set"
grain: "one row per family"
fields:
  - name: "Bar / column"
    type: "rank, and discrete time"
    role: "dimension"
    note: "Der am häufigsten verwendete und derjenige, dessen Sortierreihenfolge am häufigsten falsch ist."
  - name: "Line / area"
    type: "trend"
    role: "date"
    note: "Kontinuierliche Veränderung im Laufe der Zeit. Bereich nur, wenn die gefüllte Menge sinnvoll ist - ein gestapelter Bereich von nicht verwandten Serien ist Dekoration."
  - name: "Donut / stacked / treemap"
    type: "composition"
    role: "dimension"
    note: "Nur eine kleine Anzahl von Teilen. Nach vier, verwenden Sie einen Tisch oder eine sortierte Bar."
  - name: "Scatter / bubble"
    type: "relationship"
    role: "measure"
    note: "Zwei Maßnahmen, und eine dritte als Größe für Blase. Unterbenutzung im Verhältnis dazu, wie viel es offenbart."
  - name: "Number / gauge"
    type: "against a target"
    role: "measure"
    note: "Die Überschrift der meisten Dashboards. Braucht einen Vergleich, um etwas zu bedeuten."
  - name: "Table / pivot"
    type: "identity and exact values"
    role: "key"
    note: "Die richtige Antwort weit häufiger als Chart-zentriertes Denken suggeriert."
  - name: "Map"
    type: "geography, when geography matters"
    role: "dimension"
    note: "Nur wenn die Position auf der Erde eher der Punkt als das Etikett ist."
  - name: "Funnel / waterfall"
    type: "process and bridge"
    role: "measure"
    note: "Sequenzielle Stufen oder Additionen und Subtraktionen, die eine Summe erreichen."
---
::
