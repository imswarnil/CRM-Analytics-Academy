# Karten

Eine Karte ist das richtige Diagramm, wenn **Die Stellung auf der Erde ist Teil der Botschaft**. Es ist die falsche - und es wird trotzdem gewählt - wenn die Geographie nur ein Etikett ist.

## Der Test

::note{icon="i-lucide-map-pin"}
**Würde sich die Schlussfolgerung des Lesers ändern, wenn die Regionen mit A, B, C umbenannt würden?** Wenn ja, leistet die Geographie echte Arbeit: Nachbarschaft, Entfernung, Gebietsgrenzen, Reisen, Deckungslücken. Wenn nein, ist Geographie nur ein Kategoriename, und ein sortiertes Balkendiagramm ordnet diese Kategorien viel genauer ein als eine Farbskala jemals.
::

Die Akademie hat vier Regionen: AMER, EMEA, APAC, LATAM. Vier Kategorien. Ein sortiertes Balkendiagramm antwortet "welche Region ist am größten und um wie viel" genau. Eine Karte lässt den Leser zwei Blautöne auf Formen von wild unterschiedlicher Größe vergleichen, und es dauert viermal so viel Platz, um es schlechter zu machen.

## Das Bevölkerungsproblem

::warning{icon="i-lucide-users"}
**Ein Choropleth jeder rohen Gesamtmenge ist meist eine Bevölkerungskarte.** Färben Sie die Vereinigten Staaten, Deutschland und Indien nach Einnahmen und die größten Volkswirtschaften leuchten auf, was Sie vor dem Öffnen des Dashboards kannten. Fast jeder Geschäftsplan muss sich normalisieren: Umsatz pro Konto, Penetration gegen adressierbare Märkte, Wachstumsrate statt Niveau. Die unnormalisierte Version ist nicht falsch - sie beantwortet nur eine Frage, die niemand gestellt hat.
::

Es gibt eine zweite, ruhigere Version des gleichen Problems: **Fläche ist nicht wert**. Eine große dünn besiedelte Region nimmt weit mehr Pixel ein als eine kleine dichte, so dass das Auge sie stärker belastet, egal welche Farbe sie hat.

::tip{icon="i-lucide-bar-chart-3"}
**Der ehrliche Standard für regionale Geschäftsdaten ist ein sortiertes Balkendiagramm.** Erreichen Sie eine Karte, wenn jemand sehen muss *wo*, nicht wenn die Dimension Ortsnamen darin hat. Dies ist eine der wenigen Chart-Entscheidungen, bei denen die beeindruckendere Option normalerweise die schlechtere ist.
::
