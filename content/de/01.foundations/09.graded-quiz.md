# Bewertetes Quiz: Grundlagen

Zehn Fragen über den gesamten Abschnitt. In Ihrem Browser bewertet - die Antworten werden notwendigerweise auf dieser Seite gesendet, da es sich um einen öffentlichen Open-Source-Markdown handelt, so dass das Quiz nur so viel wert ist wie Ihre Ehrlichkeit damit.

::tip{icon="i-lucide-target"}
**Verwenden Sie es als Diagnose, nicht als Punktzahl.** Beantworten Sie alles und lesen Sie dann nur die Lektion hinter jedem, den Sie verpasst haben. Vier von zehn mit zwei Lektionen, die neu gelesen werden, schlagen zehn von zehn, ohne dass etwas gelernt wurde - und die Fragen werden absichtlich auf Getreide, Erlaubnisse und Abgestandenheit ausgerichtet, weil diese drei die meisten wirklichen Fehler ausmachen.
::
