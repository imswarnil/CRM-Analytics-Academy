# Einbettung

Der billigste Weg, Analysen zu verwenden, besteht darin, die Entscheidung zu entfernen, sie sich anzusehen.

## Der Analytics Tab

Der gleiche Inhalt im Inneren Lightning ExperienceNeben den tabs, die die leute bereits benutzen. Gleiche Daten, gleiche Berechtigungen, unterschiedliche Türen - und für ein Publikum, das eher verbraucht als baut, ist es die richtige Tür.

::note{icon="i-lucide-door-open"}
**Design für den Tab, nicht für Studio.** Du wirst einbauen Analytics Studio, die Vollbild und geräumig ist. Ihre Zielgruppe öffnet das gleiche Dashboard im Analytics-Tab, innerhalb der Lightning-Shell, mit weniger Platz und einer Navigationsleiste darüber. Überprüfen Sie es dort vor dem Versand - ein Layout, das in Studio bequem ist, kann an dem Ort eng sein, an dem es tatsächlich verwendet wird.
::

## Auf einer Rekordseite

Eine Dashboard-Komponente auf einer Konto- oder Gelegenheitsseite, die auf diesen Datensatz gefiltert wird. Dies ist die stärkste verfügbare Platzierung, da die Person bereits aus einem anderen Grund da ist.

## Filtern Sie es in den Datensatz

Ein eingebettetes Dashboard, das unternehmensweite Zahlen auf einer Kontoseite anzeigt, ist schlimmer als kein Dashboard: Es sieht so aus, als ob es sich um dieses Konto handelt und nicht. Geben Sie die ID des Datensatzes in das Dashboard, damit er sich selbst erfasst, und legen Sie den Umfang in den Titel - die gleiche Screenshot-Disziplin aus dem Kollaborationsabschnitt aus dem gleichen Grund.

## Die Disziplin Einbettungsbedürfnisse

::lesson-steps
---
items:
  - title: "Halten Sie es auf zwei oder drei Widgets"
    description: "Eine Komponente wird angeschaut, nicht erforscht. Die Überschrift, ein Trend und höchstens eine kurze Liste - alles konkurriert mehr mit der Rekordseite selbst."
  - title: "Beobachten Sie das Ladebudget"
    description: "Die Datensatzseite hat eine eigene Leistungsobergrenze und die Benutzer geben der Seite die Schuld, nicht der Komponente. Ein eingebettetes Dashboard, das jeder Kontoseite drei Sekunden hinzufügt, wird von jemandem entfernt, der Ihnen nie sagt, warum."
  - title: "Respektieren Sie das Sicherheitsmodell"
    description: "Row-Level-Sicherheit gilt weiterhin, so dass ein Benutzer eine Komponente ohne Daten sehen kann. Geben Sie ihm einen leeren Zustand - auf einer Rekordseite liest sich ein leeres Panel als defekte Seite und nicht als ehrliche Abwesenheit."
  - title: "Entscheiden Sie, wer die Seite besitzt"
    description: "Die Datensatzseite gehört demjenigen, der Lightning verwaltet, und das Dashboard gehört Ihnen. Stimmen Sie vor dem Versand zu, oder die Komponente verschwindet leise in der Neugestaltung der Seite einer anderen Person."
---
::

::tip{icon="i-lucide-target"}
**Einbetten ist, wo die Adoption tatsächlich herkommt.** Ein Standalone-Dashboard konkurriert mit jeder anderen Sache an einem Tag und verliert die meisten Tage. Eine Komponente auf einer Seite, die sie öffnen, kostet sie sowieso nichts - und das ist der Grund CRM AnalyticsDie Position innerhalb des CRM ist eher ein echter Vorteil als eine Marketinglinie.
::
