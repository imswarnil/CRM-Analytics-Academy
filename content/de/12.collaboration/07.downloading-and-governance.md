# Download und Governance

Zwei unglamouröse Themen, die darüber entscheiden, ob die Arbeit ein Jahr überlebt.

## Downloads

Menschen exportieren. Sie exportieren, um etwas zu tun, was das Dashboard nicht tut, und der Export ist normalerweise eher ein Signal als ein Problem.

::lesson-steps
---
items:
  - title: "Fragen Sie, was Sie damit machen"
    description: "Normalerweise eines von drei Dingen: eine Berechnung, die das Dashboard nicht anbietet, eine Liste zum Durcharbeiten oder ein Format, das jemand anderes verlangt. Jeder hat einen anderen Fix, und zwei der drei sind Dinge, die Sie bauen können."
  - title: "Bauen Sie das, was sie neu erschaffen"
    description: "Ein wöchentlicher Export, bei dem immer der gleiche Pivot angewendet wird, ist ein Widget, das Sie noch nicht erstellt haben. Dies ist die zuverlässigste Quelle für wirklich gewünschte Funktionen."
  - title: "Geben Sie ihnen die Liste richtig"
    description: "Wenn die Notwendigkeit besteht, durch Reihen zu arbeiten, ist das legitim. Halten Sie das Dashboard in den Top Ten und stellen Sie den vollständigen Download daneben bereit, anstatt 140 scrollende Zeilen auf den Bildschirm zu stellen."
  - title: "Akzeptieren Sie den Rest"
    description: "Einige Exporte existieren, weil eine Bank, ein Auditor oder ein Board Pack eine Datei benötigt. Das ist in Ordnung - das Ziel ist nicht Null-Exporte, es sind Null-Exporte, die das Dashboard neu erstellen."
---
::

::warning{icon="i-lucide-file-spreadsheet"}
**Das Problem der konkurrierenden Wahrheit ist das eigentliche Risiko.** Eine exportierte Tabellenkalkulation ist eine Momentaufnahme, die niemals aktualisiert wird, bearbeitet wird, geteilt wird und sechs Wochen später gegen ein Dashboard zitiert wird, das seitdem korrigiert wurde. Niemand handelt in böser Absicht und beide Zahlen haben eine Herkunft - was die Meinungsverschiedenheit viel schwieriger macht als einen einfachen Fehler. Downloads sind nicht der Feind; Downloads, die jemandes permanente Arbeitskopie werden.
::

Row-Level-Sicherheit gilt für Exporte wie für Abfragen: Menschen laden herunter, was sie sehen können. Das ist richtig, und es bedeutet, dass zwei Personen, die das gleiche Widget exportieren, legitimerweise verschiedene Dateien produzieren können.

## Governance, in der kleinsten nützlichen Form

Governance in einer kleinen Organisation braucht keinen Ausschuss. Es braucht vier Dinge aufgeschrieben und eine Person verantwortlich:

::field-table
---
dataset: "the minimum that actually works"
grain: "one row per artefact"
fields:
  - name: "An owner per dashboard"
    type: "a name"
    role: "key"
    note: "Jemand, der Fragen beantwortet, die Definitionen beibehält und über Änderungen entscheidet. Ohne dies verschlechtert sich das Dashboard lautlos - der Zeitplan driftet, ein Feld ändert die Bedeutung stromaufwärts und das Vertrauen geht lange bevor jemand ein Ticket einreicht."
  - name: "Metric definitions"
    type: "one page"
    role: "key"
    note: "Formel, Korn, Quelle, bekannte Falle - die metrische Form, die während dieses Kurses verwendet wird. Es antwortet \"warum ist das anders als meine nummer\", was die erste frage ist, die jemand stellt."
  - name: "The security note"
    type: "four lines"
    role: "dimension"
    note: "Welche Datensätze Prädikate tragen, was jeder auf Englisch sagt, wer ausgenommen ist, was der Fallback ist. Sicherheitskonfiguration ist als Konfiguration unlesbar."
  - name: "A deprecation habit"
    type: "quarterly"
    role: "measure"
    note: "Löschen oder Archivieren von Dashboards öffnet niemand. Vier Pipeline-Dashboards mit leicht unterschiedlichen Definitionen sind schlechter als eines, weil es ein Argument garantiert, das keine Menge an Korrektheit löst."
---
::

::tip{icon="i-lucide-trash-2"}
**Löschen ist eine Governance-Aktivität.** Jedes unbenutzte Dashboard ist ein zukünftiges Argument, eine Wartungskosten und eine Sache, die jemand im falschen Moment finden und vertrauen wird. Zu überprüfen, was niemand öffnet und es zu entfernen, ist unglamourös und es ist die höchste Hebelwirkung, die jeder tut - weit mehr als Genehmigungsprozesse für neue Arbeit.
::

## Die Eigentumsstrafe

::note{icon="i-lucide-user-check"}
**"Dieses Dashboard gehört X, die Definitionen sind hier und es aktualisiert sich nachts um 03:00 Uhr."** Dieser Satz, der an das Dashboard angehängt ist, ist der größte Teil der Governance. Es beantwortet, wer zu fragen ist, was die Zahlen bedeuten und wie aktuell sie sind - was die einzigen drei Fragen sind, die jemand tatsächlich hat.
::
