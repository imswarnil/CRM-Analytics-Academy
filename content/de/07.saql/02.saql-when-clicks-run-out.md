# SAQL Wenn Klicks ausgehen

SAQL ist nicht SQL Mit unterschiedlichen Keywords. Es ist ein **Stream Transformationssprache**: jede Anweisung nimmt das Ergebnis der vorherigen Anweisung und transformiert es. Das macht die *Bestellung* der Aussagen der Abfrageplan, der der einzige strukturelle Unterschied ist, der erlebt wird SQL Menschen.

## Die Form einer Abfrage

Lesen Sie ein generiertes und das Muster ist sofort sichtbar:

```
q = load "Namilio_Opportunities";
q = filter q by 'StageName' == "Closed Won";
q = group q by 'Segment';
q = foreach q generate 'Segment' as 'Segment', sum('Amount') as 'Revenue';
q = order q by 'Revenue' desc;
q = limit q 10;
```

Sechs Aussagen, jede Neuzuweisung `q`. Load, narrow, group, compute, order, limit.

::note{icon="i-lucide-arrow-down"}
**Ordnung zählt in einer Weise, die es nicht in SQL.** A SQL Engine ordnet Ihre Abfrage für Sie neu an. Hier beschreiben Sie eine Pipeline wörtlich: Filtern nach dem Gruppieren bedeutet, Zeilen zu aggregieren, die Sie verwerfen würden. Filtern Sie früh, immer - es ist sowohl schneller als auch näher an dem, was Sie gemeint haben.
::

## Drei Muster, die es wert sind, auswendig zu lernen

### 1. Deutliche Anzahl

Bei einem feinen Korn zählt das Zählen von Reihen das Falsche:

```
q = foreach q generate 'Segment' as 'Segment',
      unique('OpportunityId') as 'Deals',
      sum('LineAmount') as 'Revenue';
```

Namilios Zeilenkorn macht dies unerlässlich: 1.378 Zeilen, 677 Angebote.

### 2. Gesamtanteil

Jede Gruppe im Vergleich mit dem Ganzen - unangenehm durch Klicken, unkompliziert hier. Gruppe nach `all` Um die Gesamtsumme zu erhalten, vergleichen Sie dann jede Gruppe mit ihr. Dies ist das Muster hinter jedem "Prozentsatz des Umsatzes" Widget, und es ist der häufigste Grund zu öffnen SAQL überhaupt.

### 3. Periodenvergleich

Zwei gefilterte Ströme, die jeweils aggregiert wurden, schlossen sich dann der Gruppierung an - in diesem Quartal neben dem letzten Quartal, wobei das Delta zwischen ihnen berechnet wurde. Der Geschwindigkeitsaufbau von Abschnitt 9 verwendet genau diese Form.

::tip{icon="i-lucide-lightbulb"}
**Merken Sie sich keine Syntax, die Sie generieren können.** Bauen Sie das nächstgelegene, was Sie können, indem Sie klicken, wechseln Sie zu SAQLund editiere von dort. Sie erhalten korrekte Feldreferenzen, korrektes Zitat und ein Arbeitsskelett kostenlos - und das Zitat ist, wo handgeschrieben SAQL geht in der Regel schief: einzelne Anführungszeichen für Feldnamen, doppelte Anführungszeichen für Zeichenkettenwerte, genau wie in einem Sicherheitsprädikat.
::

::warning{icon="i-lucide-eye-off"}
**Die Wartungsfalle.** Eine Metrik, die in Handschrift definiert ist SAQL Innerhalb eines Widgets ist für jeden unsichtbar, der den Datensatz, das Rezept oder die Dokumentation betrachtet. Es wird Monate später von jemandem wiederentdeckt, der versucht herauszufinden, warum zwei Dashboards nicht übereinstimmen. Verwendung SAQL zum Formen einer Abfrage; Verwenden Sie das Rezept zum Definieren einer Metrik.
