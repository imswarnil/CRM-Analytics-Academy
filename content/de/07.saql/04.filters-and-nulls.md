# Filter und Nullen

Zwei Themen, die wie Housekeeping aussehen und einen überraschenden Anteil an falschen Zahlen ausmachen.

## Filtern Sie früh

Weil SAQL ist ein stream, ein filter, der platziert wird, nachdem eine gruppe bereits für Aggregatreihen bezahlt hat, die sie dann wegwirft.

## Die Ungleichheitsfalle

::warning{icon="i-lucide-ban"}
**A `!=` Vergleich fällt Nullen zusammen mit den Werten, die Sie ausgeschlossen haben.** `'Stage' != "Closed Lost"` Entfernen von Closed-Lost-Deals *und* Jeder deal, dessen phase leer ist - diejenigen, die am ehesten datenqualitätsprobleme sind, die es wert sind, gesehen zu werden. Die Zahl fällt, nichts Fehler, und die fehlenden Zeilen sind genau die, die niemand beobachtet. Wenn Sie "alles außer X, einschließlich Unbekannte" meinen, schreiben Sie es explizit: `'Stage' != "Closed Lost" || 'Stage' is null`.
::

Dies ist die SAQL Version der Rezeptfilterwarnung aus dem Abschnitt Datenvorbereitung, und es ist der gleiche Fehler an einer anderen Stelle.

## Null ist nicht unbekannt

Eine Null bedeutet "Wir wissen es nicht". Eine Null bedeutet "Wir wissen, und es ist keine". Sie verhalten sich in jeder Aggregation anders und werden häufig verwirrt:

::field-table
---
dataset: "null behaviour"
grain: "one row per function"
fields:
  - name: "sum"
    type: "skips nulls"
    role: "measure"
    note: "Gibt die Summe der Zeilen zurück, die einen Wert hatten. Über eine spärliche Spalte ist dies insgesamt eine Teilmenge, die als Gesamtmenge dargestellt wird."
  - name: "avg"
    type: "skips nulls in both parts"
    role: "measure"
    note: "Der Mittelwert der Zeilen, die einen Wert hatten. Normalerweise richtig, selten überprüft - und wesentlich anders als der Mittelwert über alle Zeilen, wenn Sie Nullen als Null zählen wollten."
  - name: "count vs unique"
    type: "rows vs values"
    role: "key"
    note: "count() zählt Zeilen am Grain; unique() zählt verschiedene Nichtnullwerte. Auf einer spärlichen Säule ist der Unterschied groß und beides ist nicht falsch."
  - name: "Grouping by a nullable field"
    type: "produces a null bucket"
    role: "dimension"
    note: "Was ehrlich und oft der interessanteste Eimer auf dem Chart ist - \"nicht zugewiesen\" ist eine echte Kategorie. Beschriften Sie es, anstatt es zu verbergen."
---
::

::note{icon="i-lucide-search"}
**Überprüfen Sie die Nulldichte, bevor Sie einer Spalte vertrauen.** Eine Abfrage — Anzahl der Zeilen gegen `unique` oder eine Anzahl von Nicht-Null-Werten - sagt Ihnen, ob ein Feld 5% leer oder 60% leer ist. Namilios CSAT ist das ständige Beispiel: Nur etwa 42% der geschlossenen Fälle führen eine Umfrage durch, so dass jede Zufriedenheitszahl die Befragten und nicht die Kunden beschreibt. Die Zahl ist nicht falsch; sie beantwortet eine engere Frage als ihr Etikett behauptet.
::

## Filter in Dashboards versus Filter in Queries

Drei verschiedene Dinge, und verwirrend sie erzeugt Dashboards, wo die Hälfte der Widgets auf eine Steuerung reagieren und die Hälfte leise nicht:

- **Ein Abfragefilter** ist Teil des Widgets SAQL - immer angewendet, unsichtbar für den Betrachter.
- **Ein Dashboardfilter oder Facette** wird oben, pro Interaktion angewendet und erreicht nur Widgets, die mit ihm verdrahtet sind.
- **Ein Sicherheitsprädikat** wird von der Plattform pro Viewer angewendet und kann von beiden nicht umgangen werden.

::tip{icon="i-lucide-list-checks"}
**Ein Widget, das immer etwas ausschließen muss, sollte es in der Abfrage ausschließen, nicht in einem Filter, den der Betrachter löschen kann.** "Offene Pipeline" sollte niemals geschlossene verlorene Geschäfte anzeigen können, weil jemand einen Filter zurücksetzt. Alles Strukturelle gehört in die Abfrage; alles Sondierende gehört in den Filter.
::
