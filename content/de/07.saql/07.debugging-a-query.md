# Debuggen einer Abfrage

Eine Abfrage, die Fehler sagt Ihnen, wo Sie suchen. Eine Abfrage, die die falsche Antwort zurückgibt, sagt Ihnen nichts, und das ist es wert, eine Methode für.

## Die Methode

::lesson-steps
---
items:
  - title: "Zurückschneiden auf die Last"
    description: "Alles löschen nach `load` und überprüfen Sie die Zeilenzählung gegen das, was der Datensatz enthalten soll. Wenn das bereits falsch ist, liegt das Problem vorgelagert und keine Menge an Abfragebearbeitung wird es beheben."
  - title: "Hinzufügen einer Anweisung zu einer Zeit"
    description: "Fügen Sie den Filter erneut hinzu, dann gruppieren, dann foreach, überprüfen Sie den Zählerstand und einen Abtastwert nach jedem. Die Aussage, bei der die Zahl keinen Sinn mehr macht, ist die Aussage mit dem Bug. Dies dauert etwa zwei Minuten und ersetzt eine Stunde des Starrens."
  - title: "Eng an ein Unternehmen"
    description: "Filtern Sie auf ein einzelnes Konto oder eine Gelegenheit, bei der Sie von Hand zählen können. Ein Aggregat kann Ihnen nicht sagen, welche Seite multipliziert wurde; sechs Zeilen auf dem Bildschirm können."
  - title: "Lesen Sie es als Pipeline, laut"
    description: "\"Alles laden, geschlossen bleiben, Gruppe für Segment, Summenbetrag.\" Laut gesagt, ein Filter an der falschen Stelle oder eine fehlende eindeutige Zählung wird normalerweise offensichtlich, bevor Sie den Satz beendet haben."
---
::

## Performance, kurz

Die meisten langsamen Abfragen sind aus einem von drei Gründen in dieser Reihenfolge langsam:

1. **Filtern spät.** Reihen zusammengefasst und dann verworfen. Bewegen Sie den Filter nach oben.
2. **Ein sehr feines Korn bei jeder Ladung aggregieren.** Wenn viele Leute dies täglich öffnen, aggregieren Sie sich im Rezept.
3. **In der Abfrage tun, was in das Rezept gehört.** Verknüpfungen und abgeleitete Felder neu berechnet pro Ansicht, pro Viewer.

::tip{icon="i-lucide-gauge"}
**Messen Sie als normaler Benutzer, nicht als Sie selbst.** Ein Administrator kann die Sicherheitsbewertung überspringen, für die ein echter Viewer bei jeder Abfrage bezahlt, so dass ein Dashboard, das sich schnell anfühlt, für die Personen, die es tatsächlich verwenden, spürbar langsamer sein kann.
::

## Hinterlasse einen Kommentar

Eine handgeschriebene Abfrage, die in einem versendeten Dashboard überlebt, sollte sagen, was sie berechnet und warum sie nicht im Rezept enthalten ist. Eine Linie. Es ist der Unterschied zwischen der nächsten Person, die es versteht, und der nächsten Person, die das Armaturenbrett daneben umbaut.
