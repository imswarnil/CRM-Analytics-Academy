# Arbeiten über Datasets hinweg

SAQL kann mehr als einen stream in einer abfrage tragen und kombinieren. Die Mechanik ist einfach; das Urteil ist nicht.

## Das Urteil zuerst

::warning{icon="i-lucide-git-branch"}
**Wenn zwei Datensätze für etwas mehr als ein Widget kombiniert werden müssen, sollte das Rezept dies tun.** Eine Verknüpfung, die in eine Widget-Abfrage geschrieben wurde, wird für jeden Benutzer berechnet und ist für jeden, der den Datensatz oder seine Dokumentation liest, unsichtbar. Zwei Dashboards werden es schließlich etwas anders implementieren, beide werden vertretbar sein, und die Meinungsverschiedenheiten treten in einem Meeting statt in einer Überprüfung auf. Query-Time Kombination ist für *Vergleiche*, nicht für *Modelle*.
::

## Die Kornfalle folgt Ihnen hier

Alles, was die Datensätze und Modellierung Abschnitt sagt über Getreide gilt innerhalb einer Abfrage. Das Kombinieren eines Streams mit einer Zeile pro Gelegenheit mit einer Zeile pro Zeile multipliziert Zeilen genau so, wie ein Rezept beitreten würde, und das Addieren des Elternmaßes verdoppelt sich anschließend auf genau die gleiche Weise.

::note{icon="i-lucide-ruler"}
**Geben Sie beide Körner an, bevor Sie sie kombinieren, im Abfrageeditor genauso viel wie in einem Rezept.** Der Abfrageeditor fühlt sich leichter an als ein Rezept - es ist nur Text, nichts wird neu aufgebaut - und diese Leichtigkeit ist genau der Grund, warum die Leute hier den Scheck überspringen. Der Arithmetik ist es egal, wo Sie es geschrieben haben.
::

## Praktische Form

Das muster ist: laden und formen sie jeden stream separat, dann kombinieren sie auf einem gemeinsamen schlüssel, dann berechnen.

```
-- actuals by segment
act = load "Namilio_Opportunities";
act = filter act by 'StageName' == "Closed Won";
act = group act by 'Segment';
act = foreach act generate 'Segment' as 'Segment', sum('Amount') as 'Actual';

-- targets by segment (a small, separate dataset)
tgt = load "Namilio_Targets";
tgt = group tgt by 'Segment';
tgt = foreach tgt generate 'Segment' as 'Segment', sum('Target') as 'Target';
```

Beide Ströme befinden sich bereits in einer Reihe pro Segment, so dass die Kombination von ihnen nichts multiplizieren kann - was die Eigenschaft ist, absichtlich zu arrangieren, anstatt danach zu entdecken.

::tip{icon="i-lucide-check"}
**Aggregieren Sie jeden Strom zu dem gemeinsamen Getreide, bevor Sie kombinieren.** Wenn beide Seiten eine Reihe pro Schlüssel sind, ist die Kombination durch Konstruktion sicher. Dies ist die Abfrage-Editor-Version von "Aggregate the many side before the join", und es ist die gleiche Korrektur aus dem gleichen Grund.
::

## Ein Hinweis auf fehlende Matches

Ein Segment, das in Istwerten vorhanden ist, aber von Zielen abwesend ist, oder umgekehrt, erzeugt Nullen auf einer Seite. Entscheiden Sie, was das bedeutet: Ein Segment ohne Ziel ist wahrscheinlich eine Datenlücke, die es wert ist, aufgetaucht zu werden, während ein Ziel ohne tatsächliche Werte ein Segment ist, das nichts verkauft hat - was ein Fund ist, keine Lücke. Das stillschweigende Füllen beider mit Null ist die einfache Option und verbirgt den Unterschied.
