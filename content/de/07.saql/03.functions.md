# Funktionen nach Familie

Sie brauchen nicht die ganze Referenz. Sie brauchen fünf Familien und etwa fünfzehn Funktionen.

## Aggregation

Die Funktionen, die viele Zeilen in einen Wert einteilen, werden im Inneren verwendet `foreach … generate` nach a `group`.

::field-table
---
dataset: "aggregation"
grain: "one row per function"
fields:
  - name: "sum('Field')"
    type: "the workhorse"
    role: "measure"
    note: "Ignoriert Nullen schweigend. Eine Summe über eine Spalte, die 40% Null ist, ist eine Summe von 60% der Daten, die ohne Kommentar gemeldet wird - überprüfen Sie die Nulldichte, bevor Sie einer Gesamtmenge vertrauen."
  - name: "count()"
    type: "rows, not things"
    role: "measure"
    note: "Zählt ROWS beim aktuellen Getreide. Bei Namilios Line-Item sind das 1.378 Linien, nicht 677 Deals. Dies ist das Kornproblem, das die Kleidung einer Funktion trägt."
  - name: "unique('Field')"
    type: "distinct count"
    role: "key"
    note: "Was Sie fast immer wollen, wenn ein Datensatz mit etwas verbunden wurde. unique('Chance) Id' gibt Deals; count() gibt Linien."
  - name: "avg('Field')"
    type: "use carefully"
    role: "measure"
    note: "Durchschnittet die Nicht-Null-Zeilen, was normalerweise richtig und selten überprüft ist. Verwenden Sie es niemals mit einer Rate pro Zeile, die Sie gewichtet haben möchten - das ist Summe ÷ Summe, berechnet aus den Teilen."
  - name: "min() / max()"
    type: "extremes and dates"
    role: "date"
    note: "max an einem datum gibt das letzte ereignis pro gruppe an, was der standardweg ist, um \"letzte aktivität\" ohne separate abfrage zu erhalten."
  - name: "median() / percentile_cont()"
    type: "when the mean lies"
    role: "measure"
    note: "Die Deal-Größen von Namilio werden durch eine flache Plattformgebühr von 48.000 US-Dollar neben Tausenden von Kleinnutzungsverträgen stark verzerrt, so dass der Median den typischen Deal beschreibt und der Mittelwert nicht."
---
::

::warning{icon="i-lucide-divide"}
**Verhältnis: aggregieren beide Teile, dann teilen.** `sum('Discount') / sum('ListTotal')` ist der gewichtete Abzinsungssatz, den das Unternehmen meint. `avg('DiscountPct')` gewichtet einen $ 5.000 Deal genauso wie einen $ 2 Millionen und produziert eine Zahl, die niemand erkennt. Und bewache den Nenner - eine Division durch Null in einem Monat vergiftet die ganze Serie.
::

## Daten

Daten in SAQL sind eher strukturiert als einfache Werte, mit Teilen, die Sie direkt gruppieren können: Jahr, Quartal, Monat, Woche, Tag.

- **`date('Field_Year', 'Field_Month', 'Field_Day')`** Konstruieren Sie ein Datum aus den Teilen für Vergleiche.
- **`daysBetween(a, b)`** — die Grundlage für Speed-to-Lead, Day-in-Stage, Alter und Zykluszeit.
- **`toDate()` / `now()`** Für alles, was heute gemessen wird.
- **Relative Bereiche** - "aktuelles Quartal", "letzte 90 Tage". Bequem, und sie machen eine Abfrage *Nicht-deterministisch*Die gleiche Abfrage gibt morgen unterschiedliche Zahlen zurück, was für ein Live-Dashboard und eine Falle korrekt ist, wenn Sie sich mit einem festen Bericht abgleichen.

::note{icon="i-lucide-calendar"}
**Sagen Sie immer, nach welchem Datum Sie gruppiert sind.** Eine Gelegenheit hat enge, zuletzt modifizierte und Bühneneintrittsdaten geschaffen. Derselbe Datensatz, der durch einen anderen gruppiert ist, erzählt eine wirklich andere Geschichte, und kein Funktionsaufruf in der Abfrage wird dem Leser mitteilen, welchen Sie ausgewählt haben - nur der Widget-Titel kann.
::

## Strings

`lower()` und `upper()` für Vergleiche, die sich nicht um den Fall kümmern müssen, `trim()` für Daten, die von einem CSV, `substr()` zum Extrahieren eines Präfixes und Verkettung zum Aufbau eines Verbundetiketts.

::tip{icon="i-lucide-spell-check"}
**Normalisieren Sie, bevor Sie vergleichen, nicht danach.** `EMEA`, `emea` und `EMEA ` Es gibt drei verschiedene Gruppen, und eine Gruppierung, die eine Region in drei teilt, sieht eher wie ein Datenproblem als ein Formatierungsproblem aus. Wenn es in einer Abfrage wichtig ist, ist es normalerweise auch im Rezept wichtig - beheben Sie es stromaufwärts, so dass jedes Dashboard den Fix erbt.
::

## Mathematik und Konditionale

Arithmetik funktioniert wie erwartet. Das bedingte Wissen ist **`case`**, was ist, wie Sie Bucket innerhalb einer Abfrage:

```
q = foreach q generate 'Account' as 'Account',
      (case when 'UtilizationPct' < 55 then "At risk"
            when 'UtilizationPct' > 105 then "Overage"
            else "Healthy" end) as 'Band',
      sum('ARR') as 'ARR';
```

::warning{icon="i-lucide-repeat"}
**Wenn a `case` erscheint in mehr als einer Abfrage, es gehört in das Rezept.** Bucketing-regeln, die über widgets drift dupliziert werden: "gefährdet" bedeutet unter 55 auf einem dashboard und unter 60 auf einem anderen, beide vertretbar, und die uneinigkeit oberflächen in einer besprechung. Bucket einmal in einem Transformationsknoten und jeder Bildschirm erbt die gleichen Bänder.
::

## Nullumschlag

Nullen sind die stille Quelle falscher Antworten:

- **`coalesce(a, b)`** Ersetzen Sie einen Standard. Verwenden Sie absichtlich: Ersetzen von Null mit Null wird "unbekannt" in "none", was ein Anspruch ist.
- **`is null` / `is not null`** Der explizite Test.
- **Die Ungleichheitsfalle** — `'Stage' != "Closed Lost"` Entfernt auch jede Zeile, in der Stage null ist. Fast nie beabsichtigt, nie angekündigt.
