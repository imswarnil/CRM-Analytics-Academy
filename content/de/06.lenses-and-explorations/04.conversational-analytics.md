# Conversational Analytics

## Der Ausfallmodus

::warning{icon="i-lucide-message-square-warning"}
**Es antwortet fließend, auch wenn es eine andere Frage beantwortet hat.** Bitten Sie um "Einnahmen nach Vertreter im letzten Quartal" und Sie erhalten möglicherweise die richtige Maßnahme, die vom Eigentümer gruppiert wird, aber am Schlussdatum, wenn Sie das erstellte Datum gemeint haben, oder zum Kalenderquartal gefiltert, wenn das Unternehmen ein anderes Steuerquartal betreibt. Der Chart ist korrekt für *einige* Frage. Nichts auf dem Bildschirm zeigt an, dass es nicht deins ist. Fließend ist keine Genauigkeit, und eine fließend falsche Antwort ist gefährlicher als eine offensichtlich gebrochene.
::

Die Verteidigung ist die von früher in diesem Abschnitt: **Überprüfen Sie es im Tabellenmodus oder lesen Sie die generierte Abfrage.** Ein Ergebnis in natürlicher Sprache ist ein Ausgangspunkt zur Überprüfung, keine Antwort auf ein Zitat. Das ist eine vernünftige Arbeitshaltung und es ist keine Kritik an dem Feature - das gleiche gilt für ein Diagramm, das jemand anderes gebaut hat.

## Warum Feldmetadaten über die Qualität entscheiden

Natürliche Sprache muss Ihre Wörter auf Felder abbilden. Dieses Mapping ist nur so gut wie die Labels:

- Ein Feld gekennzeichnet `Amount__c` Es ist schwer, "Einnahmen" zu erzielen. Beschriftet "Deal Amount", ist es einfach.
- Zwei ähnliche Felder mit vagen Etiketten produzieren zuversichtlich falsche Übereinstimmungen - `Amount` versus `LineAmount` Das ist genau diese Gefahr.
- Sechzig sichtbare Spalten, die Hälfte davon Schlüssel, machen den Suchraum laut und die Übereinstimmungen schlimmer.

::tip{icon="i-lucide-link"}
**Die vorherige Lektion ist die Voraussetzung dafür.** Beschriften Sie die Felder, verstecken Sie die Sanitäranlagen, legen Sie die Formate fest - und die Abfrage in natürlicher Sprache wird merklich besser, ohne dass jemand eine Einstellung namens "AI" berührt. Die meisten Beschwerden, dass es "unsere Daten nicht versteht" sind Beschwerden über Metadaten, die niemand gepflegt hat.
::
