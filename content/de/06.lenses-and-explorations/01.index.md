# Exploring ist die Arbeit

Dashboards bekommen die Aufmerksamkeit. Lenses Dort geschieht das Verständnis tatsächlich, und eine Person, die gut erforscht, produziert bessere Dashboards als eine Person, die gut gestaltet, aber schlecht erforscht.

::note{icon="i-lucide-recycle"}
**Eine Linse ist absichtlich verfügbar.** Sie sollen zwanzig in einer Stunde machen und keine von ihnen behalten. Das ist keine Verschwendung - es ist, wie eine Frage nach Daten aussieht. Die Gewohnheit zu vermeiden ist, jede Erkundung als etwas zu behandeln, das bewahrt werden muss, was ein schnelles Untersuchungswerkzeug in ein Archivierungsproblem verwandelt.
::

## Was eine Linse ist

Ein Datensatz. Eine oder mehrere Gruppen. Eine oder mehrere Maßnahmen. Ein Diagramm oder eine Tabelle oder die Abfrage hinter beiden. Nichts wird gerettet, es sei denn, Sie retten es.

::note{icon="i-lucide-arrow-right"}
**SAQL und Feldmetadaten haben eigene Abschnitte.** Die Abfragesprache ist einer einzelnen Lektion entwachsen und ist nun der nächste Abschnitt; Beschriftungen, Formate und Standardaggregationen gehören zum Dataset-Design, da sie Eigenschaften des Datasets und nicht einer einzelnen Exploration sind.
::

## Die einzige Gewohnheit aus diesem Abschnitt

::tip{icon="i-lucide-repeat-2"}
**Klicken, dann lesen Sie die SAQL. Jedes Mal, für einen Nachmittag.** Fügen Sie eine Gruppierung hinzu und lesen Sie sie. Ändern Sie das Maß und lesen Sie es. Fügen Sie einen Filter, Sortieren, Limit hinzu. Das ist die gesamte Grammatik der Sprache, die anhand von Antworten gelernt wurde, die Sie bereits mit dem Auge überprüfen können - und wenn die SAQL Abschnitt Attribution Build braucht wirklich handschriftlich SAQLEs wird eher vertraut als neu sein. Zwanzig Minuten davon schlagen jede Menge Syntax-Referenz.
::
