# Wann man das öffnet JSON

A CRM Analytics Das Dashboard ist ein JSON Dokument: Widgets, Layouts, Abfragen und Bindungen, alles als Text. Der Builder schreibt es für Sie, und gelegentlich ist der Text das bessere Werkzeug.

::note{icon="i-lucide-file-json"}
**Dies ist nicht die fortgeschrittene Ebene des Dashboard-Gebäudes.** Die meisten Dashboards sollten niemals ihre JSON geöffnet, und zu erreichen, dass es etwas tut, was der Erbauer perfekt macht, ist eine Möglichkeit, ein Armaturenbrett zu produzieren, das niemand sonst pflegen kann. Es verdient seinen Platz für Massenarbeit, für Überprüfung und für die Handvoll Dinge, die das Interface nicht ausstellt.
::

## Die vier guten Gründe

  - name: "Reuse and templating"

## Die beiden schlechten Gründe

::warning{icon="i-lucide-hand"}
**Nicht verwenden JSON gewöhnliche Arbeit schneller zu erledigen und sie nicht zu benutzen, um klug zu sein.** Ein Dashboard, das von Hand in eine Konfiguration bearbeitet wird, die der Builder nicht umrunden kann, ist ein Dashboard, das nur Sie ändern können, was der gleiche Fehler ist wie ein übergebundener. Wenn der Erbauer es ausdrücken kann, lass den Erbauer es ausdrücken - die JSON Für das, was der Erbauer nicht tun kann, und dafür, zu sehen, was er getan hat.
::
