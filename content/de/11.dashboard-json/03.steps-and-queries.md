# Schritte und Queries

Ein Schritt ist eine Abfragedefinition mit einem Namen. Alles, was ein Widget zeigt, kommt von einem.

## Was ein Schritt trägt

- **Sein Datensatz** - welche es liest.
- **Seine Form** Gruppierungen, Maßnahmen und Filter, entweder als strukturierte Eigenschaften, die der Builder bearbeiten kann, oder als Rohdaten SAQL.
- **Sein Name** Wie sich Widgets und Bindungen darauf beziehen.
- **Sein Auswahlverhalten** Was passiert, wenn ein Betrachter auf etwas klickt, das von diesem Schritt angetrieben wird, einschließlich der Frage, ob er andere und seine erste Auswahl konfrontiert.

::warning{icon="i-lucide-lock"}
**Umwandlung eines Schritts in Roh SAQL kann in der Praxis einseitig sein.** Sobald ein Schritt eine handgeschriebene Abfrage enthält, kann der visuelle Editor das strukturierte Formular möglicherweise nicht rekonstruieren, so dass die nächste Person den Text bearbeitet oder das Widget neu erstellt. Das ist ein akzeptabler Handel für etwas, das der Erbauer wirklich nicht ausdrücken kann, und ein schlechter für eine Anfrage, die Sie aus Vorliebe von Hand geschrieben haben.
::

## Statische Stufen

Nicht jeder Schritt fragt Daten ab. A **statischer Schritt** enthält eine feste Liste von Werten - die Optionen in einem Umschalter, eine Reihe von Schwellenwerten, eine Liste von Etiketten. Sie sind, wie ein maßnahmenschalter seine entscheidungen trifft, und sie sind billig: keine abfrage, keine rundreise.

::tip{icon="i-lucide-list"}
**Wenn die Werte eines statischen Schritts Geschäftsregeln sind, sind sie an der falschen Stelle.** Schwellenwerte, die in den statischen Schritt eines Dashboards eingegeben wurden, werden unsichtbar abgestanden - niemand überprüft das Dashboard JSON wenn das Unternehmen seine Definition von "gefährdet" ändert. Bänder und Schwellenwerte gehören in das Rezept, wo die Bucketing-Lektion sie setzen; ein statischer Schritt ist für Schnittstellenoptionen wie "ARR / Deal Count".
::

## Konsolidierung von Abfragen

Die Anzahl der verschiedenen Schritte ist der Hauptleistungshebel auf einem Armaturenbrett, und die JSON macht es zählbar.

## Filter leben an mehr als einem Ort

Ein Widget kann durch den stufeneigenen Filter, durch einen Dashboard-Filter, durch facettierte Auswahl und durch das Sicherheitsprädikat verengt werden. Wenn ein Widget weniger Zeilen als erwartet zeigt, JSON erzählt Ihnen direkt von dem ersten davon - und das ist oft der, an den sich niemand erinnert hat.
