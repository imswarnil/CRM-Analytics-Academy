# Widgets und Layouts

Ein Widget ist *Was* gezeichnet ist. Ein Layout ist *Wo es sitzt*. Sie auseinander zu halten, lässt ein Widget auf einem breiten Bildschirm und einem Telefon anders positioniert werden - und deshalb ist ein Positionierungsproblem nie im Widget.

## Widgets

Jeder Widget-Eintrag benennt seinen Typ, den Schritt, der ihn füttert, und seine Anzeigeparameter. Die Eigenschaften, die als Text wissenswert sind:

::tip{icon="i-lucide-replace"}
**Bulk Formatierung ist die beste alltägliche Nutzung der JSON.** Jemand entscheidet, dass Währung ohne Dezimalstellen über ein ganzes Dashboard abgekürzt werden sollte. Im Erbauer sind das zwölf Tafeln und eine gute Chance, eine zu verpassen; als Text ist es ein Find-and-Replace, der keine verpassen kann. Gleiches gilt für einen Schwellenwertwechsel in jedes bedingte Format auf dem Bildschirm.
::

## Layouts und warum sie Menschen überraschen

Layouts sind der Teil, der Sie auffängt, weil es normalerweise **mehr als 1** - eine Reihe von Haltepunkten, jeder mit seinen eigenen Positionen und Größen.

::warning{icon="i-lucide-smartphone"}
**Ein Widget kann in einem Layout existieren und nicht in einem anderen.** Fügen Sie ein Widget im Builder hinzu, während Sie einen Desktop in der Vorschau anzeigen, und ein Telefonlayout empfängt es möglicherweise nicht - so dass das Widget für jeden auf einem kleinen Bildschirm einfach abwesend ist, ohne dass es angezeigt wird. Ebenso erzeugt das Löschen eines Widgets und das Verlassen einer verwaisten Referenz in einem anderen Layout einen leeren Slot. Wenn ein Dashboard auf einem Gerät falsch und rechts auf einem anderen aussieht, sind die Layouts, wo zu suchen, und das Widget ist fast sicher in Ordnung.
::

## Container und Gruppierungen

Container gruppieren Widgets, sodass ein Set zusammen positioniert, angezeigt oder ausgeblendet werden kann. Gut genutzt, halten sie verwandte Widgets über Haltepunkte hinweg zusammen. Schwer benutzt, nisten sie mehrere Ebenen tief und werden so schwer zu argumentieren wie verkettete Bindungen - die gleiche Wartbarkeitsregel gilt.

## Der Round-Trip-Test

::note{icon="i-lucide-refresh-cw"}
**Nach jeder Handbearbeitung: Speichern, laden Sie das Dashboard im Builder neu und bestätigen Sie, dass es immer noch geöffnet und immer noch bearbeitet wird.** Einige handschriftliche Strukturen sind gültig JSON dass der Builder nicht in seine visuelle Form rekonstruieren kann, und Sie möchten das sofort und nicht drei Wochen später entdecken, wenn ein Kollege versucht, einen Titel zu ändern. Wenn die Rundreise fehlschlägt, kehren Sie zu der Kopie zurück, die Sie vor dem Start exportiert haben.
::
