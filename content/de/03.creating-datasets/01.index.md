# Was ist ein Dataset in CRM Analytics?

Die Erstellung von Datasets ist die **Erster richtiger Schritt** In jedem CRM Analytics ()Tableau CRM) Projekt. Bevor Sie ein einzelnes Dashboard erstellen, eine Geschichte erzählen oder eine Einstein Discovery Modell, du musst Daten bekommen *in* die Plattform und formen Sie es in etwas, das Sie abfragen können. Dieses "Etwas" ist ein **Datensatz**In diesem ganzen Abschnitt geht es darum, sie gut zu bauen.

Nach sieben Jahren des Aufbaus auf dieser Plattform ist hier die ehrliche Version: Neun Mal von zehn beginnt Ihre Arbeit mit der Erstellung eines Datensatzes. Es gibt Ausnahmen - direkte Abfragen und Live-Verbindungen -, aber diese lösen enge Probleme in einem bestimmten Dashboard. Brot und Butter ist der Datensatz.

## Was ist eigentlich ein Datensatz?

Ein Dataset ist ein **Speicherformat**. Sie nehmen Objekte oder Tabellen, die sich aufeinander beziehen, kombinieren sie und speichern das Ergebnis in einer Form, die speziell für einen Analysebedarf erstellt wurde.

Angenommen, Sie möchten Chancen analysieren. Sie würden das Opportunity-Objekt ziehen, aber Sie würden auch die **Konto** Jede Gelegenheit gehört dazu, **Nutzer** Wer besitzt es, und vielleicht - auf der Straße - verwandte Aktivitäten. All dies wird zu einem breiten, in sich geschlossenen Datensatz über Chancen kombiniert. Das ist die Übung, die wir später in diesem Abschnitt von Hand machen werden.

## Warum es so schnell ist

Sie brauchen das nicht täglich, aber es hilft zu wissen, was unter der Haube ist. Ein Dataset verwendet eine **abgeflachtes, invertiertes Schlüsselwert-Speichersystem** — eine ausgefallene Art zu sagen, es ist ein säulenförmiger Dateispeicher mit einem proprietären Kompressions- und Indexierungsalgorithmus.

Die Auszahlung ist der ganze Punkt: Sie können speichern **Große Mengen** Daten in einem Datensatz abfragen und dennoch schnell genug abfragen, um ein interaktives Dashboard zu betreiben. Diese Kombination - Big Data *und* Sub-Sekunden-Antwort — ist, warum die Plattform stört mit einem dedizierten Speicherformat statt nur Abfrage Salesforce direkt.

::tip{icon="i-lucide-lightbulb"}
Weil ein Dataset eine **Gespeicherter Snapshot**Ihre Daten sind nur so frisch wie das letzte Mal, als Sie sie aktualisiert haben. Datensätze aktuell zu halten ist ein Planungsproblem - auf das wir zurückkommen werden, wenn wir über Synchronisierung, Datenflüsse und Rezepte sprechen.
::

## Wann *nicht* Um einen Dataset zu erstellen

Datensätze sind der Standard, aber sie sind nicht die einzige Option. CRM Analytics unterstützt auch:

- **Direkte Anfragen** - Abfrage eines kleinen Satzes von Salesforce Daten im laufenden Betrieb, ohne einen Datensatz zu materialisieren.
- **Live-Verbindungen** - Lesen Sie direkt von einer externen Quelle (wie Snowflake) zur Abfragezeit.

Beide sind real und nützlich, aber sie passen zu einem *spezifisch* Dashboard-Komponente oder Anforderung, nicht der allgemeine Fall. Wenn Sie gerade erst anfangen, nehmen Sie an, dass Sie einen Datensatz erstellen, und behandeln Sie Live / Direct als die Ausnahme, die Sie absichtlich erreichen.
