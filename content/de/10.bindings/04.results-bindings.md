# Ergebnisse Bindungen

Eine Auswahlbindung liest, was jemand geklickt hat. A **Ergebnisse bindend** liest, was eine Abfrage zurückgegeben hat - eine Summe, ein Durchschnitt, ein Maximum, die oberste Kategorie - und speist sie in ein anderes Widget ein.

## Der Ausführungsauftrag, den Sie gerade erstellt haben

::warning{icon="i-lucide-hourglass"}
**Eine Ergebnisbindung lässt ein Widget auf ein anderes warten.** Widget B kann nicht abfragen, bis Widget A zurückgekehrt ist, so dass aus zwei parallelen Anfragen zwei sequentielle werden. Kette drei und das letzte Widget wartet auf zwei Rundfahrten. Dies ist die Ursache für die spezifische Beschwerde "das Dashboard ist langsam in einer Weise, die nicht übereinstimmt, wie wenige Widgets es hat" - und weil die Abhängigkeit in der Konfiguration lebt, deutet nichts auf dem Bildschirm darauf hin.
::

## Debugging ist wirklich schwieriger

Mit einer Auswahlbindung ist die Eingabe auf dem Bildschirm: Sie können sehen, was ausgewählt ist. Mit einer Ergebnisbindung ist die Eingabe ein Wert in einer anderen Abfrage, und wenn das abhängige Widget etwas Merkwürdiges anzeigt, müssen Sie herausfinden, was die Quelle zurückgegeben hat, bevor Sie sagen können, ob der Verbraucher falsch liegt.

## Wenn das Rezept es hätte tun sollen

::note{icon="i-lucide-database"}
**Wenn der berechnete Wert eine Unternehmensmetrik ist, gehört er vorgelagert.** Eine Ergebnisbindung, die die "durchschnittliche Deal-Größe" für jeden Betrachter bei jeder Ladung berechnet, erledigt Nachtarbeit zur Ansichtszeit - und definiert eine Metrik an einem Ort, den niemand finden kann. Berechnen Sie es im Rezept, speichern Sie es und binden Sie es an ein Feld. Reserve Ergebnisse Bindungen für Dinge, die wirklich von der *aktuelle Auswahl*die ein Rezept nicht kennt.
::

## Ein vernünftiges Limit

Ein oder zwei Ergebnisbindungen auf einem Dashboard sind normal und nützlich. Five ist ein Dashboard, das sich wie eine Anwendung verhält, sequenziell geladen wird und nur von demjenigen gepflegt werden kann, der es geschrieben hat.

::tip{icon="i-lucide-split"}
**Wenn Sie einen vierten wollen, teilen Sie das Dashboard.** Zwei Bildschirme, jeder einfach, schlagen einen cleveren - und sie können mit verschiedenen Zuschauern geteilt werden, was sowieso einfacher ist.
::
