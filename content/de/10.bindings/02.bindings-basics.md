# Bindungen

Faceting ist automatisch. A **Bindung** Es nimmt den Zustand eines Widgets - eine Auswahl, ein Ergebnis, einen Wert - und speist ihn in die Abfrage, den Titel oder die Sichtbarkeit eines anderen Widgets ein.

## Beginnen Sie mit dem dynamischen Titel

Wenn Sie eine Bindung verwenden, verwenden Sie diese. Ein Dashboard, das seine eigenen Filter in seinen Titeln angibt, verhindert den häufigsten Fehler in der Analysekommunikation: Ein Screenshot einer gefilterten Ansicht wird als das ganze Bild gelesen.

::tip{icon="i-lucide-camera"}
**Angenommen, jedes Dashboard wird gescreent und in eine Nachricht ohne Kontext eingefügt.** Ein Titel mit der Aufschrift "Pipeline - nur EMEA, erstellt in Q3" überlebt diese Reise intakt. Ein Titel mit der Aufschrift "Pipeline" wird bis Donnerstag zu einer unternehmensweiten Zahl in der Argumentation eines anderen.
::

## Wo es schief geht

::warning{icon="i-lucide-network"}
**Bindungen sind Logik, die in der Widget-Konfiguration gespeichert ist.** Sie können nicht auf einen Blick gelesen werden, sie diffen nicht, und sie sind nirgendwo dokumentiert, wo die nächste Person hinschauen wird. Ein Armaturenbrett mit zwanzig von ihnen funktioniert wunderschön und wird unantastbar - die Person, die es erbt, kann sehen, dass das Ändern von etwas etwas bricht, aber nicht was oder warum, also bauen sie stattdessen ein neues Armaturenbrett. So endet eine Organisation mit vier Pipeline-Dashboards und einem Argument darüber, was richtig ist.
::

## Die Regel, die es wert ist angenommen zu werden

::note{icon="i-lucide-file-text"}
**Wenn eine Bindung beim Betrachten des Bildschirms nicht offensichtlich ist, schreiben Sie sie auf** - in der Beschreibung des Dashboards oder in den Projektnotizen neben den metrischen Definitionen. Eine Zeile pro Bindung: Was füttert was und warum. Dies dauert eine Minute und ist der Unterschied zwischen einem Dashboard, das das Team besitzt, und einem Dashboard, das eine Person besitzt.
::

## Wenn eine Bindung die falsche Antwort ist

Zwei anerkennenswerte Fälle:

- **Sie bauen eine Metrik neu auf.** Wenn die Bindung existiert, um eine Definition zu berechnen, gehört sie in das Rezept. Widget-Level-Definitionen driften, und eine Bindung macht sie schwerer zu finden als einfach SAQL würde.
- **Du baust zwei Zuschauer auf einen Bildschirm.** Ein Armaturenbrett, das sich für den Verkauf und für Finanzen neu konfiguriert, sind normalerweise zwei Armaturenbretter, die einen Trenchcoat tragen. Zwei Bildschirme, jeder einfach, schlagen einen cleveren - und sie können für verschiedene Zielgruppen geteilt werden, was der Abschnitt Zusammenarbeit zeigt, ist die einfachere Sache zu regieren.
