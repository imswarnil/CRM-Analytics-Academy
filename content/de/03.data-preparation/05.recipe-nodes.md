# Rezeptknoten

Sieben Knotentypen machen fast alles. Der nützliche Weg, sie zu lernen, ist nicht alphabetisch - es ist durch das, was jeder mit der **Körner**, weil Grain die einzige Eigenschaft ist, die Sie vom ersten Knoten bis zum letzten verfolgen müssen.

## Gruppiert nach Wirkung auf Getreide

::field-table
---
dataset: "nodes by what they do to the grain"
grain: "one row per node type"
fields:
  - name: "Input"
    type: "sets the grain"
    role: "key"
    note: "Lies ein synchronisiertes Objekt, einen Datensatz oder eine hochgeladene Datei. Das Körnchen des Rezepts beginnt als das Körnchen seiner Eingaben, weshalb Sie beide laut sagen, bevor Sie sich etwas anschließen."
  - name: "Filter"
    type: "grain unchanged"
    role: "dimension"
    note: "Entfernt Zeilen. Weniger Zeilen, gleiche Bedeutung pro Zeile. Der sicherste Knoten in der Liste - und trotzdem lohnt es sich, die Zählung zu überprüfen, denn ein Filter, der mehr entfernt, als Sie erwartet haben, ist eine häufige Ursache für \"niedriger als erwartet\"."
  - name: "Formula"
    type: "grain unchanged"
    role: "measure"
    note: "Fügt eine pro Zeile berechnete Spalte hinzu. Nichts daran, was eine Zeile darstellt, ändert sich. Alles, was arithmetisch aus bestehenden Säulen abgeleitet wird, gehört hierher."
  - name: "Transform"
    type: "grain unchanged"
    role: "dimension"
    note: "Bucket, split, concatenate, change a type, flatten eine Hierarchie. Operationen auf Spaltenebene. Die Flatten, die für Rollenhierarchie-Sicherheit verwendet werden, leben hier."
  - name: "Join"
    type: "MAY MULTIPLY the grain"
    role: "key"
    note: "Der gefährliche. Ein lookup gegen eine one-row-per-key-tabelle ist sicher; der beitritt zu einer one-to-many-beziehung multipliziert zeilen. Zähle immer vorher und nachher."
  - name: "Aggregate"
    type: "COARSENS the grain"
    role: "measure"
    note: "Zerfällt viele Reihen in eine pro Gruppe. Dies ist der Fix für Fan-Out, wenn er vor einem Beitritt angewendet wird, und es ist auch, wie Sie vorab zusammengefasste Datensätze absichtlich erstellen."
  - name: "Output"
    type: "writes the dataset"
    role: "key"
    note: "Benennt den Datensatz, wählt seine App und ist, wo Sie das Korn in die Beschreibung schreiben sollten. Ein Rezept kann mehrere Ausgaben haben, so dass eine Pipeline einen detaillierten Datensatz und einen zusammenfassenden Datensatz speist."

## Das Muster, das Sie ständig verwenden werden

**Aggregate, dann wieder beitreten.** Fast jedes "Ich brauche eine Zählung von X auf jedem Y" ist diese Form:

  - title: "Aggregation"

**Verwenden Sie die Node Preview ständig, nicht gelegentlich.** Jeder Knoten zeigt seine Ausgabe an. Klicken Sie durch die Kette und beobachten Sie die Zeilenzahl bei jedem Schritt ist das schnellste Debugging-Tool im Produkt, und es macht einen Kornwechsel unmöglich zu verpassen - die Zahl ändert sich vor Ihnen, an der genauen Knoten verantwortlich.

## Joins: Wissen, welche Art Sie gewählt haben

- **Lookup / links** - hält jede Zeile links, fügt Spalten von rechts hinzu, wo eine Übereinstimmung existiert. Nicht übereinstimmende Zeilen behalten die linken Werte und erhalten Nullen. Dies ist die übliche Wahl.
- **Inneres** - hält nur Zeilen passend auf beiden Seiten. Legitim, und die stille Ursache für "Aufzeichnungen fehlen": eine Gelegenheit, deren Konto zuvor stillschweigend herausgefiltert wurde.
- **Äußere Varianten** — nicht übereinstimmende Zeilen von einer Seite oder beiden aufbewahren und Lücken mit Nullen füllen.

::warning{icon="i-lucide-scissors"}
**Eine innere Verbindung ist ein Filter, der die Kleidung einer Verbindung trägt.** Es entfernt Zeilen und tut dies an einem Punkt, an dem Sie darüber nachdenken, Spalten hinzuzufügen, anstatt Datensätze zu entfernen. Wenn Zeilen fehlen und Berechtigungen ausgecheckt werden, ist der nächste Verdächtige eine innere Verknüpfung stromaufwärts.
::

## Rezepte klein halten

Es gibt keine Hard Node Decke, und es gibt eine praktische. An ungefähr zwanzig Knoten vorbei hört ein Rezept auf, von jedem lesbar zu sein, der es nicht geschrieben hat, und der Fehler hört auf zu lokalisieren - man kann nicht mehr sagen, welches Drittel der Pipeline gebrochen ist.

::note{icon="i-lucide-split"}
**Split auf Bedeutung, nicht auf Größe.** Ein sauberer Basisdatensatz, der durch ein Rezept erzeugt wird, und zwei abgeleitete Datensätze, die von anderen, die es lesen, erzeugt werden, sind leichter zu begründen. *und* schneller zu beheben als eine lange Kette. Die Kosten sind ein weiterer Zeitplan, um richtig zu bestellen - was angesichts der Abhängigkeitsfalle aus der vorherigen Lektion ein Kostenwert ist, den man ernst nehmen sollte, anstatt ihn zu ignorieren.
::
