# Fehlende Werte

Eine Null bedeutet *Wir wissen nicht,*. Eine Null bedeutet *Wir wissen es, und es ist keine*. Jede Aggregation behandelt sie anders, und sie zu verwirren ist eine der leisesten Möglichkeiten, eine falsche Zahl zu produzieren.

## Füllen einer Lücke ist ein Anspruch

::warning{icon="i-lucide-pencil"}
**Jede Füllung behauptet etwas.** Null behauptet keine. Der Durchschnitt behauptet typisch. Der vorherige Wert behauptet nichts geändert. Jede ist in einigen Situationen vertretbar und jede ist eine Aussage, die Sie im Namen der Daten machen, also gehört sie in die metrische Definition und nicht in einen Formelknoten. Die Frage ist: *Wenn diese Füllung falsch ist, was bricht?* Einen fehlenden Betrag mit Null zu füllen, zieht jeden Durchschnitt nach unten; das Füllen mit dem Mittelwert erfindet einen Deal, der nie existiert hat.
::

::tip{icon="i-lucide-flag"}
**Wenn sie füllen, halten sie eine flaggenspalte, die sagt, dass sie es getan haben.** A boolean `AmountWasImputed` kostet nichts und bedeutet, dass jeder gefüllte Zeilen aus einer Analyse ausschließen kann, die sie nicht enthalten sollte - und ein Jahr später sagen kann, welche Zahlen real waren. Das Füllen ohne Flagge zerstört die Informationen, die es jemals vermisst hat.
::

## Voraussichtliche Füllung

Die Schätzung eines fehlenden Wertes aus anderen Spalten - ein Betrag, der aus Segment und Produkt abgeleitet wird, ein Schlussdatum, das aus Stadium und Alter abgeleitet wird - ist gelegentlich angemessen und immer ein größerer Anspruch als eine Konstante.

::warning{icon="i-lucide-brain"}
**Wenn Sie einen Wert vorhersagen und dann analysieren, finden Sie das Muster, mit dem Sie vorhergesagt haben.** Imputieren Sie den Betrag aus dem Segment, berichten Sie dann die Einnahmen nach Segmenten, und die Segmentunterschiede, die Sie sehen, sind teilweise Ihre eigene Imputation, die auf Sie zurückblickt. Halten Sie unterstellte Werte von jeder Analyse über die Sache, von der sie unterstellt wurden, fern und markieren Sie sie, damit auch jemand anderes dies tun kann.
::

## Fehlen als Signal

Manchmal ist der Leerwert die informativste Spalte im Datensatz.

::note{icon="i-lucide-lightbulb"}
**In Namilio, `EconomicBuyerIdentified` Leerstellen korreliert mit Verlust** - nicht, weil die leere den verlust verursacht, sondern weil ein rep, der nicht engagiert ist, keine felder ausfüllt. Das macht "ist es leer" wirklich prädiktiv und völlig unumsetzbar: einem Vertreter zu sagen, dass er das Feld ausfüllen soll, schafft keinen wirtschaftlichen Käufer. Dies ist eine der häufigsten möglichkeiten, wie ein ansonsten gutes modell ratschläge hervorbringt, die nichts ändern, und die. Einstein Discovery Der Abschnitt kehrt dazu zurück.
::

## Der Response Rate Case

Namilios CSAT deckt etwa 42% der geschlossenen Fälle ab. Der Durchschnitt ist arithmetisch korrekt und beantwortet eine engere Frage als sein Label behauptet: Er beschreibt Menschen, die sich entschieden haben zu antworten, und die Antwort verzerrt sich auf die Entzückten und Wütenden.

Der Fix ist keine Imputation. Es veröffentlicht die Antwortrate neben der Punktzahl dauerhaft - eine Zufriedenheitszahl ohne eine ist eher eine Werbung als eine Messung.
