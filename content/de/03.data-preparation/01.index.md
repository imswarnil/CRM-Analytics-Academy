# Von der Quelle zum Dataset

Alles sichtbar in CRM Analytics baut auf einem Datensatz auf, und ein Datensatz wird von jemandem erstellt, der Entscheidungen trifft. In diesem Abschnitt geht es darum, sie absichtlich zu machen.

    type: "manual, one-off"

Es wird sich niemals selbst aktualisieren, was eine Funktion ist, wenn die Datei ein fester Auszug ist und eine Haftung, wenn jemand erwartet, dass sie aktuell ist."

    type: "the normal path"
    role: "key"

  - name: "External connection → recipe"

## Die Frage, die diesen ganzen Abschnitt beherrscht

::note{icon="i-lucide-ruler"}
**Was genau repräsentiert eine Zeile des Outputs?** Sie haben dies im Abschnitt Stiftungen getroffen. Hier werden Sie es absichtlich falsch bauen, sehen, dass sich die Einnahmen der Akademie fast verdreifachen, und dann reparieren - weil die Abstraktion nur zu einem Reflex wird, nachdem Sie gesehen haben, wie sie eine plausible falsche Zahl mit Ihren eigenen Daten erzeugt hat.
::

## Die eine Gewohnheit, durch den Abschnitt zu tragen

Zählen Sie Zeilen an jedem Knoten.

::tip{icon="i-lucide-hash"}
**Vor einem Beitritt und danach.** Wenn die Reihenzahl stieg, änderte sich das Korn, und Sie müssen in der Lage sein zu sagen, warum. Manchmal sollte es - das Verbinden von Konten mit Chancen hält 608 Zeilen; Das Verbinden von Produktlinien mit Chancen erzeugt rechtmäßig 1.192. Der Misserfolg ist nicht der Anstieg. Der Fehler summiert die eines Elternteils `Amount` nach der Erhöhung, vor der nichts im Produkt Sie warnen wird, weil nichts im Produkt weiß, was Sie gemeint haben.
::
