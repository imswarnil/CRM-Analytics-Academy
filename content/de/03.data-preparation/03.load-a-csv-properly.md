# Belastung a CSV Richtig

Das Hochladen dauert zehn Sekunden. Die Überprüfung dauert zwei Minuten. In dieser lektion geht es um die zwei minuten, denn jede der drei folgenden Überprüfungen verhindert eher einen wiederaufbau als ein Ärgernis.

## Die drei Kontrollen, in der Reihenfolge der Kosten

::field-table
---
dataset: "what to verify at upload"
grain: "one row per check"
fields:
  - name: "Dates typed as dates"
    type: "most common"
    role: "date"
    note: "Ein textdatum wird perfekt in einer tabelle dargestellt, so dass es jede zufällige Überprüfung überlebt. Es kann nicht nach Bereich gefiltert, nach Monat gruppiert oder trendiert werden - und Sie stellen fest, dass Sie genau in dem Moment einen Trend benötigen. Es zu beheben bedeutet, die Attribute zu bearbeiten und die Datei neu zu laden."
  - name: "IDs typed as dimensions"
    type: "common"
    role: "key"
    note: "Kontosumme Id ist bedeutungslos und verfügbar. Erzwingen Sie jeden Identifikator auf eine Dimension beim Laden. Dies ist am wichtigsten für die Schlüssel, denen Sie beitreten werden, was im Fall der Akademie AccountId, OpportunityId und CampaignId ist."
  - name: "Currency scale"
    type: "expensive when wrong"
    role: "measure"
    note: "Heraus um 100x ist unsichtbar: jede Downstream-Figur ist konsequent falsch, so dass nichts anomal aussieht. Vergleichen Sie eine einzelne Zeile mit der Rohdatei, bevor Sie fortfahren."
  - name: "Row count"
    type: "always"
    role: "measure"
    note: "Der Datensatz README gibt die wahre Anzahl für jede Academy-Datei an. Off by one ist ein Header-Problem. Null ist eine ausgefallene Last, und Monitor hält den Grund."
---
::

## Warum der Antwortschlüssel so wichtig ist

Die Akademie `README.md` gibt die wahren Summen an - Zeilen pro Datei, geschlossene Einnahmen, ARR nach Monat, Lead Counts. Jeder Build in diesem Kurs kann daher gegen etwas überprüft werden, das unabhängig voneinander wahr ist.

::tip{icon="i-lucide-check-check"}
**Überprüfen Sie jede Ladung, auch wenn Sie zuversichtlich sind.** Der Wert fängt nicht den Fehler, den Sie erwartet haben; er baut den Reflex auf, so dass Sie, wenn Sie an Daten ohne README arbeiten, immer noch instinktiv nach etwas suchen, mit dem Sie sich in Einklang bringen können - eine Finanzzahl, eine zuvor veröffentlichte Zählung, ein Bericht, dem jemand bereits vertraut. Analysten, die dies tun, sind vertrauenswürdig; Analysten, die dies nicht tun, werden schließlich in der Öffentlichkeit überrascht.
::

## Wenn a CSV ist die richtige Antwort, und wenn es nicht

::compare-cols
---
items:
  - title: "CSV ist richtig"
    subtitle: "Fixed extracts, learning, one-offs"
    icon: "i-lucide-file-check"
    pros:
      - "No infrastructure, no connection, no schedule"
      - "Reproducible: the same file gives the same dataset"
      - "Perfect for this entire course"
    cons:
      - "Never updates itself"
      - "Somebody has to remember to re-upload"
    verdict: "Fine when the data genuinely does not change."
  - title: "CSV ist falsch"
    subtitle: "Anything anyone expects to be current"
    icon: "i-lucide-file-x"
    pros:
      - "Fast to set up, which is the trap"
    cons:
      - "It will silently age, and it looks identical to a live dataset"
      - "The re-upload becomes one person's undocumented monthly chore"
    verdict: "Use a connection and a schedule instead."
---
::

::warning{icon="i-lucide-calendar-x"}
**Die manuell hochgeladene Falle in der Produktion.** A CSV Einmal geladen wird "das Armaturenbrett" und altert ruhig. Es gibt nichts auf dem Bildschirm, um es von einem geplanten Datensatz zu unterscheiden, und die einzige Person, die es weiß, ist, wer es hochgeladen hat. Wenn Sie eines versenden müssen, geben Sie das Auszugsdatum in den Datensatznamen ein - `the Academy Accounts 2026-09` - so ist die Abgestandenheit für jeden sichtbar, anstatt sich an eine Person zu erinnern.
::
