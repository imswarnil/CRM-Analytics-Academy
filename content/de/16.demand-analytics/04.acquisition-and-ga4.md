# Build: Akquisition

Ein Besucher kommt an, liest die Dokumente, meldet sich an und ruft die API. Drei dieser vier sind in GA4 messbar und einer von ihnen ist der einzige, der Einnahmen vorhersagt.

::note{icon="i-lucide-terminal"}
**Bei einem Entwickler-First-Unternehmen ist die Qualifizierungsveranstaltung technisch, nicht kommerziell.** Eine Preisseitenansicht bedeutet, dass jemand neugierig ist. Eine erfolgreiche Premiere API Anruf bedeutet, dass jemand sie integriert hat, und die wechselkosten sind gerade gestiegen. Bauen Sie das Dashboard darum herum.
::

## Zwei für diese Daten spezifische Fallen

::lesson-cards
---
columns: 2
items:
  - title: "Die Wochenendklippe"
    icon: "i-lucide-calendar-x"
    description: "Der Entwickler-Traffic sinkt samstags um ~58%. Jeder Tagesvergleich liest sich jedes Wochenende als Krise. Verwenden Sie 7-Tage-Durchschnitte oder vergleichen Sie Dienstag mit Dienstag und sagen Sie, was Sie getan haben."
  - title: "Docs Seiten verzerren Durchschnittswerte"
    icon: "i-lucide-file-code"
    description: "Docs-Sitzungen laufen ~ 210 Sekunden und 3,4 Seiten gegenüber 74 Sekunden und 1,9 für Marketing-Seiten. Eine Site-weite \"durchschnittliche Engagement\" -Zahl ist das Verhältnis Ihrer beiden Zielgruppen, kein Maß für Qualität."
---
::

::tip{icon="i-lucide-split"}
**Segment nach Seite Tippen Sie, bevor Sie etwas abschließen.** Docs, Pricing, Product, Blog, Compare und Trust verhalten sich wie sechs verschiedene Websites. Eine einzelne Conversion-Rate über sie hinweg ist ein Durchschnitt von Dingen, die niemals gemittelt werden sollten.
::

## Wo dieses Dashboard aufhören muss

::note{icon="i-lucide-hand"}
`web_sessions.csv` hat **Kein Account oder Lead Key**. Es kann Ihnen nicht sagen, dass diese Sitzung dieser Kunde wurde. Die Brücke ist ein Anmeldeereignis, das einen Kanal in `leads.csv` - was genau das ist `FirstTouchChannel` ist, und genau, warum es eine einzelne gespeicherte Meinung ist, anstatt eine Tatsache. Die Attributionslektion behandelt dies richtig.
::
