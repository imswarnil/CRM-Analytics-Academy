# Ladedaten von a CSV Datei

Der schnellste Weg, um Daten in CRM Analytics ist eine **CSV Upload**. Es ist ein manuelles einmaliges Laden — keine Synchronisierung, kein Datenfluss, kein Rezept — und es ist perfekt für Daten, die leben *außen* Salesforce Oder dass man nur schnell rein muss.

Unsere Beispieldatei, `Opportunity External Amounts`, Schiffe in den EA-Schulungsdateien (Zip aus dem ersten Video). Es ahmt Daten nach, die aus einem separaten System stammen: a **Name**, an **Ursprünglicher Betrag**und ein **Externer Rechnungsbetrag**. Imagine Finance verfolgt eine externe Rechnungszahl, die Salesforce hat nicht, und Sie haben es exportiert, um CSV.

Wenn Sie wieder im Studio landen, ist der Datensatz einsatzbereit. Beachten Sie etwas Wichtiges im Data-Landscape-Diagramm der letzten Lektion: a CSV Datensatz sitzt **allein** — es ist *nicht* Verdrahtet in einen Datenfluss oder Synchronisation, weil es eine manuelle, einmalige Last war. Die Daten sind einfach da, bereit für Sie.

## Das Metadatenschema (ein wenig fortgeschritten)

Wenn Sie hochladen, liest die Data Engine Ihre CSV und **Vermutungen** Typ jedes Feldes: Text wird zu einem **Dimension**Zahlen werden **Maßnahmen**. Sie können diese Vermutungen direkt in der Benutzeroberfläche überschreiben.

Das klassische Beispiel ist **Postleitzahl**. Es sind Ziffern, also liest der Motor es als a *Maßnahme* (etwas zur summe oder zum durchschnitt) - aber sie würden niemals postleitzahlen addieren. Sie schneiden und gruppieren nach ihnen. Ändern Sie es von **Maßnahme** bis **Dimension** vor Ort.

::lesson-cards

    description: "Ein Feld, nach dem Sie gruppieren oder filtern – Kontoname, Stufe, Region, Postleitzahl. Das kategorische Zeug."
  - title: "Maßnahme"
    icon: "i-lucide-calculator"
    description: "Ein numerisches Feld, das Sie aggregieren - Menge, Menge, Zählung. Das Zeug, das Sie summieren und durchschnittlich."
---

Die meiste Zeit ist die UI alles, was Sie brauchen. Aber einige Dinge - wie **Felder mit mehreren Werten** - kann nicht in der Benutzeroberfläche definiert werden. Für diejenigen, laden Sie die generierte **Metadatenschemadatei**Bearbeiten Sie es von Hand (z. B. Set) `isMultiValue: true` In einem Feld, laden Sie es erneut hoch und beenden Sie den Upload.

::tip{icon="i-lucide-info"}
Erreichen Sie die Schemadatei nur, wenn die Benutzeroberfläche nicht ausdrücken kann, was Sie benötigen - mehrwertige Felder, genaue Zahlenformatierung oder Erzwingen eines Typs, den die Engine falsch gemacht hat. Für 90% der Uploads ist die On-Screen-Dimension / Maßnahme / Datumsüberprüfung ausreichend. Wir decken die Schema-Datei vollständig in der Data Manager Lektionen.
::
