# Self-Service Exploration

Hier ist eine Szene, die jeder Dashboard-Designer kennt. Sie versenden ein Dashboard. Innerhalb einer Woche erhalten Sie eine E-Mail: *"Das ist großartig - könnten Sie eine Version hinzufügen, die nach Produkten anstatt nach Regionen aufgeschlüsselt ist?"* Sie fügen es hinzu. Nächste Woche: *"...und einer vom Besitzer?"*

**Entdecken** ist das Feature, das diese Warteschlange beendet.

## Was Explore tut

Das Aktionsmenü jedes Widgets beinhaltet **Entdecken**. Die Auswahl nimmt die Abfrage des Widgets - mit den aktuellen Filtern und Auswahlen des Dashboards - und öffnet sie in einem **Objektiv**: die vollständige Explorationsschnittstelle, wobei die Steuerungen für Gruppierung, Maß und Kartentyp freigelegt werden.

Von dort aus betrachtet der Benutzer nicht mehr ein Bild, das jemand anderes entworfen hat. Sie halten die Abfrage.

::lesson-steps
---
items:
  - title: "Open Explore auf dem Widget"
    description: "Die aktuelle Abfrage des Widgets und die aktiven Filter des Dashboards sind damit verbunden, so dass der Ausgangspunkt genau das ist, was sie sich angesehen haben."
  - title: "Ändern Sie die Frage"
    description: "Tauschen Sie die Gruppierung von Region zu Produkt, fügen Sie eine zweite Gruppierung hinzu, wechseln Sie das Maß, ändern Sie den Diagrammtyp - alle zeigen und klicken Sie auf das Objektiv."
  - title: "Lesen Sie die Antwort"
    description: "Die Frage, über die sie dir eine E-Mail geschickt haben, wird jetzt von ihnen in etwa dreißig Sekunden beantwortet."
  - title: "Speichern Sie es als Ihre eigene Linse"
    description: "Wenn es ein Schnitt ist, den sie wieder wollen, speichern sie es als Objektiv in ihrer eigenen App. Es wird ihnen zu halten, ohne Ihr Dashboard zu berühren."
---
::

Der letzte Schritt ist der ruhige Sieg. Das Dashboard konzentriert sich auf die von Ihnen entworfene Geschichte; die einmaligen Variationen leben als persönliche Linsen der Menschen, die sie brauchen. Ihr Dashboard bläht sich nicht langsam in vierzig Charts auf, weil vierzig Leute jeweils nach einem gefragt haben.

::tip{icon="i-lucide-users"}
Explore ist die höchste Hebelwirkung, die in einer Benutzerschulung demonstriert werden kann. Die meisten Geschäftsanwender haben keine Ahnung, dass ihre Lizenz es ihnen ermöglicht, ihre eigene Analyse zu erstellen - sie gehen davon aus, dass jede neue Ansicht ein Anfrageticket ist. Wenn Sie ihnen diese eine Aktion zeigen, ändert sich, wie sie die Plattform nutzen.
::

## Wenn Sie es ausschalten sollten

Explore ist nicht immer der richtige Anruf. Vernünftige Gründe, sie zu deaktivieren:

::lesson-cards
---
columns: 2
items:
  - title: "Kuratierte Executive Dashboards"
    icon: "i-lucide-crown"
    description: "Ein Board-Level-Dashboard, bei dem jede Zahl bewusst eingerahmt wird. Einen Betrachter neu gruppieren zu lassen, führt zu einer Fehlinterpretation von Metriken, die nur das bedeuten, was sie im Kontext bedeuten."
  - title: "Eingebettete und mobile Oberflächen"
    icon: "i-lucide-smartphone"
    description: "Ein Dashboard, das auf einer Lightning-Aufzeichnungsseite eingebettet oder für Mobilgeräte eng gebaut ist - ein Benutzer in eine vollständige Linsenschnittstelle fallen zu lassen, ist erschütternd und oft visuell gebrochen."
---
::

Beachten Sie, dass der Trade-off wirklich ein Trade-off ist. Das Ausschalten von Explore schützt die Erzählung, bringt Sie aber auch wieder auf das Empfangsende dieser E-Mails. Standard, es zu verlassen, es sei denn, Sie haben einen Grund.

## Wie man es ausschaltet

Beide Switches sind Widget **Eigenschaften**, festgelegt im Dashboard-Editor mit dem ausgewählten Widget:

::lesson-cards
---
columns: 2
items:
  - title: "Widget-Aktionen anzeigen"
    icon: "i-lucide-list-x"
    description: "Der Hauptschalter. Deaktivieren Sie es und das gesamte Aktionsmenü des Widgets verschwindet - kein Explore, kein Share, keine Set-Benachrichtigung, kein Annotate."
  - title: "Show Explore Aktionen"
    icon: "i-lucide-search-x"
    description: "Der gezielte Switch. Belässt das Aktionsmenü an Ort und Stelle, entfernt jedoch die Explorationsoptionen, sodass Benutzer weiterhin teilen und herunterladen, ohne die Abfrage neu gruppieren zu können."
---
::

Reach für **Show Explore Aktionen** zuerst. Das vollständige Ausschalten von Widget-Aktionen ist ein stumpfes Instrument - es nimmt Benachrichtigungen, Anmerkungen und Downloads gleichzeitig weg, und Benutzer verbinden das fehlende Menü selten mit einer absichtlichen Designentscheidung. Sie gehen einfach davon aus, dass das dashboard kaputt ist.

Mit Explore kann ein Benutzer seinen eigenen Datenschnitt erstellen. Die nächste Lektion behandelt, wie sie halten und teilen einen Schnitt von *Ihr* Dashboard, ohne es zu verlassen: **Ansichten**.
