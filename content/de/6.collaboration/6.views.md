# Speichern und Teilen von Ansichten

Jeder Benutzer öffnet das gleiche Dashboard und macht sofort dasselbe: wendet die gleichen vier Filter an. Ihre Region. Ihr Team. Dieses Quartal. Nur offene Möglichkeiten. Jeden Morgen.

**Ansichten** Entfernen Sie dieses Ritual.

## Was eine Ansicht ist

Eine Ansicht ist eine **gespeicherter Satz des Dashboard-Zustands** - die Auswahlen, Filter und Entscheidungen, die Sie getroffen haben - unter einem Namen gespeichert und an das Dashboard angehängt. Es ist keine Kopie des Dashboards. Es gibt ein Dashboard; eine Ansicht ist ein Lesezeichen in eine bestimmte Position darin.

::lesson-steps
---
items:
  - title: "Stellen Sie das Dashboard so ein, wie Sie es möchten"
    description: "Wenden Sie Ihre Filter und Auswahlen an, bis auf dem Bildschirm Ihr Ausschnitt angezeigt wird - Ihre Region, Ihr Team, Ihr Datumsbereich."
  - title: "Speichern Sie die Ansicht"
    description: "Öffnen Sie das Ansichtsmenü oben im Dashboard und speichern Sie den aktuellen Status mit einem klaren Namen: \"West - Open Pipeline\", \"Mein Team in diesem Quartal\"."
  - title: "Wechsel zwischen den Ansichten jederzeit"
    description: "Die Ansichtsauswahl listet jede Ansicht auf dem Dashboard auf. Wählen Sie eine und das Dashboard springt direkt in diesen Zustand."
---
::

## Die Standardansicht

Sie können eine Ansicht als **Ausfall** - der Zustand, in den das Dashboard beim Öffnen geladen wird, anstelle der ursprünglichen Startposition des Designers.

Dies ist ein kleines Feature mit einem übergroßen Effekt auf die Adoption. Ein Dashboard, das auf "alles, alle Regionen, alle Zeit" öffnet, lässt jeden Benutzer arbeiten, bevor er etwas Wichtiges sieht. Ein Dashboard, das sich öffnet *von* Zahlen fühlen sich an, als ob sie für sie gebaut wurden.

::tip{icon="i-lucide-lightbulb"}
Es lohnt sich, im Benutzertraining explizit aufzurufen: "Setzen Sie die Filter, die Sie täglich verwenden, speichern Sie sie als Ansicht, machen Sie sie zu Ihrem Standard." Es dauert zwanzig Sekunden und es ist die einzige Änderung, die am ehesten jemanden dazu bringt, das Armaturenbrett morgen wieder zu öffnen.
::

## Eine Ansicht teilen

Views verbinden sich auf saubere Weise mit der Sharing-Lektion. Wenn Sie eine Ansicht betrachten und das Dashboard kopieren **URL**Der Link trägt die **view ID**. Ihr Kollege öffnet es und landet nicht im Standardzustand des Dashboards, sondern auf *Ihre Ansicht* - die gleichen Filter, die gleiche Auswahl, der gleiche Datenschnitt, den Sie besprochen haben.

Das macht aus einem Link eine komplette Kommunikation. Anstatt das Pipeline-Dashboard zu öffnen, nach Westen zu filtern, dann Q3, dann Closed-Won, senden Sie einen URL.

Zwei Vorbehalte, die Sie beachten sollten, beide in Bezug auf Sicherheit und nicht auf die Ansicht selbst:

::lesson-cards
---
columns: 2
items:
  - title: "Sie benötigen immer noch Dashboard-Zugriff"
    icon: "i-lucide-lock"
    description: "Eine Ansicht URL gewährt nichts. Wenn der Empfänger keinen Zugriff auf das Dashboard erhalten hat, erhält der Link einen Berechtigungsfehler und keine Vorschau."
  - title: "Sie sehen immer noch ihre eigenen Reihen"
    icon: "i-lucide-shield"
    description: "Row-Level-Sicherheit und jedes Sicherheitsprädikat gelten für sie, nicht für Sie. Sie landen auf den gleichen filtern - aber die zahlen darunter sind ihre. Zwei Personen können die identische Ansicht öffnen URL und rechtmäßig unterschiedliche Summen sehen."
---
::

Dieser zweite punkt ist der, um im gespräch vorsichtig zu sein. Wenn Sie und ein Kollege "die gleiche Ansicht" betrachten und verschiedene Zahlen aneinander zitieren, haben Sie wahrscheinlich beide Recht - Sie sehen verschiedene Daten durch die gleiche Linse. Bestätigen Sie den Sicherheitskontext, bevor Sie annehmen, dass etwas kaputt ist.

## Views vs. Objektive vs. Abonnements

Diese drei werden ständig verwirrt, so dass es eine saubere Trennung wert ist:

Das letzte ist, wo wir als nächstes gehen. Ansichten machen das Dashboard bequem zu öffnen; **Abonnements und Beobachtungslisten** Machen Sie es zeigen, ob Sie es öffnen oder nicht.
