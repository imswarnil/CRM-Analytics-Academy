# Ein Dashboard teilen

Die **Anteil** Action befindet sich in der oberen rechten Ecke jedes Dashboards, und es ist die Funktion, die die meisten Leute zuerst entdecken - normalerweise, weil sie einen Screenshot an ihren Manager senden möchten. Sie leistet wesentlich mehr.

Es gibt zwei Ebenen des Teilens in CRM Analytics, und es lohnt sich, sie sofort in deinem Kopf zu trennen:

## Gewährung des Zugangs

Der erste Tab des Share-Dialogs handelt von **Wer das Dashboard überhaupt öffnen kann**. Sie wählen einen Benutzer, eine Gruppe oder eine Rolle aus und geben ihnen eine Zugriffsebene - normalerweise **Betrachter** für ein Geschäftspublikum, **Herausgeber** oder **Betriebsleiter** Für jemanden, der es ändern oder neu teilen muss.

Es lohnt sich zu erinnern: Der Zugang zum Dashboard ist *nicht* Das gleiche wie Datenzugriff. Durch das Teilen des Dashboards kann jemand die Seite öffnen; was sie darin sehen, wird immer noch von der gemeinsamen Vererbung des Datensatzes und allen von Ihnen festgelegten Sicherheitsprädikaten bestimmt. Zwei Personen können dasselbe öffnen URL und rechtmäßig unterschiedliche Zahlen sehen.

::tip{icon="i-lucide-shield-check"}
Wenn ein Kollege meldet, dass ein freigegebenes Dashboard "leer" ist, überprüfen Sie die Sicherheit auf Zeilenebene, bevor Sie die Freigabeeinstellungen überprüfen. Ein leeres Dashboard bedeutet normalerweise Zugriff auf die Seite, aber nicht auf die Zeilen.
::

## Posting zu Chatter

Der Share-Dialog kann das Dashboard direkt in eine **Geschwätz** Feed - Ihr eigenes, eines Kollegen oder einer Gruppe. Sie geben eine Nachricht ein, wählen das Ziel aus und posten.

Das ist wirklich nützlich und wird wirklich zu wenig genutzt. Ein dashboard, das in der sales-ops-chatter-gruppe mit einem kontextsatz angekündigt wird ("neues pipeline-gesundheits-dashboard, nachts um 6 uhr aktualisiert") wird geöffnet. Eine, die als Link ohne Kontext per E-Mail gesendet wird, tut dies nicht.

## Die URL - und warum es schlauer ist, als es aussieht

Der Share-Dialog gibt Ihnen eine **URL** Sie können kopieren. Wichtiges Detail ist, dass die URL zeigt nicht nur auf das Armaturenbrett — es kodiert **Der Zustand, den Sie gerade betrachten**.

Dies löst die häufigste Reibung in analytischen Konversationen: "Schauen Sie sich die Westregion in Q3 an" und verwandeln Sie sich in drei Folgemeldungen, auf welche Filter Sie klicken sollen. Schick stattdessen den Staat.

## Download als Bild

Die **Bild** Mit der Option wird das Dashboard als Bild dargestellt, das Sie in ein Deck, ein Dokument oder eine E-Mail legen können. Es erfasst das Dashboard als aktuell gefiltert, so dass die gleiche Gewohnheit "State the State first" gilt.

Es ist jedoch eine Momentaufnahme - in dem Moment, in dem Sie es exportieren, hört es auf, live zu sein. Für alles wiederkehrende, ein **Abonnement** (später in diesem Abschnitt) ist eine viel bessere Antwort als ein manuelles Bild jeden Montag.

## Druck

**Druck** Es ist die Option, die die Leute verpassen. Es wird nicht nur der Druckdialog des Browsers auf dem Bildschirmlayout ausgelöst - CRM Analytics Legt das Dashboard zuerst in eine druckfreundliche Anordnung um, so dass Widgets nicht an Seitengrenzen abgeschnitten werden und das Ganze sinnvoll auf Papier passt.

Von dort aus wählen **Speichern als PDF** im Druckdialog Ihres Browsers und Sie haben ein gemeinsam nutzbares Dokument. Für Führungskräfte, die eine monatliche PDF in ihrem Posteingang wünschen, ist dies die manuelle Version dessen, was ein Abonnement automatisiert.

::tip{icon="i-lucide-lightbulb"}
Design mit Druck im Auge, wenn Sie wissen, dass Ihr Armaturenbrett gedruckt wird: Sehr breite Raster und hohe Scroll-Tische übersetzen schlecht. Eine Seite von Compact KPI Fliesen und ein paar Charts drucken wunderschön.
::

Sharing bekommt ein Dashboard vor Menschen. Der nächste Schritt ist, das Dashboard dazu zu bringen, *sie* - das ist wo **Mitteilungen und Anmerkungen** Kommen Sie herein.
