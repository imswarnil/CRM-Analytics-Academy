# Analytics können Sie automatisieren

Datensätze, Abfragen, Dashboards und Metadaten sind programmgesteuert erreichbar. Das verwandelt eine Reihe von manuellen Aufgaben in geplante Jobs, und es macht Dashboards zu etwas, das generiert werden kann, anstatt von Hand gebaut zu werden.

::note{icon="i-lucide-shield-check"}
**Die API ist kein Weg um das Sicherheitsmodell herum.** Anfragen authentifizieren sich als Benutzer, und die Berechtigungssätze, die Freigabe und die Sicherheit auf Zeilenebene gelten genau wie in der Benutzeroberfläche. Ein skript, das als integrationskonto ausgeführt wird, sieht, was dieses konto sehen kann - was das richtige verhalten ist und es wert ist, es klar zu sagen, denn verwenden sie einfach das. API" wird gelegentlich als Workaround für ein Zugriffsproblem angeboten. Es ist keines.
::

## Was sollte manuell bleiben

::warning{icon="i-lucide-hand"}
**Eine Sache zu automatisieren, die Sie zweimal im Jahr tun, ist eine Haftung.** Das Skript verrottet, seine Anmeldeinformationen verfallen, und die Person, die es geschrieben hat, hat es vergessen, wenn es das nächste Mal läuft - so wird die jährliche Aufgabe "ein Skript debuggen, das niemand in zwölf Monaten angeschaut hat", anstatt "eine Stunde Klicken zu verbringen". Automatisieren Sie, was wöchentlich oder häufiger passiert oder was jedes Mal identisch sein muss. Alles andere ist von Hand billiger.
::

Designarbeit ist die andere Kategorie. Das Layout eines Dashboards, seine Ablehnungen und seine Titel sind Urteile, und wenn man sie aus einer Vorlage erzeugt, entstehen vierzig Bildschirme, die konsequent mittelmäßig sind und nicht einer, der richtig ist.
