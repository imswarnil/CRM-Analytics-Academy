## Was dieser Abschnitt abdecken wird

Alles in CRM Analytics ist über eine API — was das ermöglicht, die vier Jobs, die es wert sind, automatisiert zu werden, und diejenigen, die manuell bleiben sollten.

## Geplante Lektionen

- **Warum automatisieren** - Alles in CRM Analytics ist über eine API — was das ermöglicht, die vier Jobs, die es wert sind, automatisiert zu werden, und diejenigen, die manuell bleiben sollten.
- **Die REST API** Authentifizierung, die endpunktfamilien, die für analysen, versionierung und die grenzen wichtig sind, die es wert sind, entworfen zu werden, bevor sie etwas schreiben.
- **SAQL aus dem Code** Eine Abfrage über die API und lesen, was zurückkommt - plus die vier legitimen gründe, warum sich eine zahl aus einem skript von der gleichen zahl auf dem dashboard unterscheidet.
- **Ladedaten** — Die externen Daten API: deklarieren, in Teilen hochladen, Signalvervollständigung - das dreistufige Muster, die Metadatendatei, die Ihre Feldtypen bestimmt, und den Fehler, den jeder einmal trifft.
- **Python Ende bis Ende** Ein gearbeiteter Pfad in Python: Authentifizieren, Deklarieren einer Ladung, Schieben Sie die Daten der Akademie in Teile, signalisieren Sie die Vervollständigung, überprüfen Sie die Zeilenzahl und fragen Sie das Ergebnis zurück.
- **Automatisierung & Einsatz** - Planung, Anmeldeinformationen, Fehlerbehandlung und Verwendung von Metadatenexporten, um Dashboards den Änderungsverlauf zu geben, den das Produkt nicht bietet.
- **Interviewfragen** — Die API und Automatisierungsfragen, mit Modellantworten - und dem operativen Urteil, nach dem sie wirklich suchen.
- **Bewertetes Quiz** Acht Fragen zur Authentifizierung, der Abfrage und externen Daten-APIs, Ladevorgängen, Planung und Änderungsverlauf.
