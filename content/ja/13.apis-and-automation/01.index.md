# アナリティクス 自動化できます

データセット、クエリ、ダッシュボード、メタデータは、すべての到達可能なプログラムです。 マニュアルチョイスのセットをスケジュールしたジョブに変え、手作業ではなく生成できるものへとダッシュボードをオンにします。

::note{icon="i-lucide-shield-check"}
**ザ・オブ・ザ・ API セキュリティモデルの周りのやり方ではありません。** ユーザとして認証を要求し、ユーザの権限セット、共有、および行レベルのセキュリティがインターフェイスで行うように正確に適用されます。 スクリプトはインテグレーションアカウントとして実行すると、そのアカウントが確認できるものが表示されます。これは正しい動作であり、平らに表示する価値があります。 API「アクセス問題の回避策として時々提供されます。 それだけではありません。
::

## マニュアルを維持するべきもの

::warning{icon="i-lucide-hand"}
**年に2回行うことの自動化は責任です。** スクリプトのrots、その資格情報が期限切れで、次の実行時に忘れてしまったことを書いた人は、毎年恒例のタスクが「1時間クリックを中断する」の代わりに、スクリプトを12ヶ月で見ていないデバッグします。 週単位以上の頻度で何が起こるか、または毎回同じものでなければなりません。 他はすべて手作業で安くなっています。
::

デザイン作品は他のカテゴリです。 ダッシュボードのレイアウト、そのリフューザーとそのタイトルは判断され、テンプレートから生成されると、正しいものではなく、一貫して密接な画面が生成されます。
