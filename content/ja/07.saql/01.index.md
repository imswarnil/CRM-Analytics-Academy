# なぜ? SAQL プレゼンツ

すべてのレンズ、すべてのウィジェット、すべてのダッシュボードのクエリは SAQL 下の. クリックすると生成されます。クリックインターフェイスが実行したときにのみ書き込みます。

::note{icon="i-lucide-waves"}
**SAQL 説明クエリではなくストリーム変換です。** 各ステートメントは、以前のステートメントの結果を受け取り、それを変換し、同じストリーム変数を再割り当てます。 作業をリオーダーする楽観者はありませんので、 **ステートメントを記述する順序は、実行する計画です** — グループ化後のフィルタリングは、あなたが捨てようとしていた集計行を本当に行います。 これは、知っている人々をキャッチする単一の構造の違いです SQL お問い合わせ
::

## 形状

```
q = load "Namilio_Opportunities";
q = filter q by 'StageName' == "Closed Won";
q = group q by 'Segment';
q = foreach q generate 'Segment' as 'Segment', sum('Amount') as 'Revenue';
q = order q by 'Revenue' desc;
q = limit q 10;
```

負荷、狭い、グループ、計算、順序、限界。 6つのステートメント、各再割り当て `q`最終生成物を消費する。
