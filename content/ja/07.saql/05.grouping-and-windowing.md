# グループ化と窓

フォームの質問に答える *「この行は、他の人と比較して」* — これは、アグリゲーションが他人を離れて崩壊するので、単なるアグリゲーションができないことです。

## すべてのグループ

最もシンプルな2レベルの計算。 `group q by all` 個々のグループを比較するために、会社全体を与えるすべてのものを含む1つのバケツを生成します。

```
-- revenue per segment, and each segment's share of the company total
q = load "Academy_Opportunities";
q = filter q by 'StageName' == "Closed Won";
total = group q by all;
total = foreach total generate sum('Amount') as 'Total';
seg = group q by 'Segment';
seg = foreach seg generate 'Segment' as 'Segment', sum('Amount') as 'Revenue';
```

2つのストリームが結合され、各セグメントの行が合計を見ることができます。 これは、すべての「収益の割合」ウィジェットの背後にある形状であり、誰もがクエリエディタをまったく開く最も一般的な理由です。

::note{icon="i-lucide-percent"}
**合計のシェアは、正式な2レベルのクエリです。** あなたがそれを書けたら、家族の残りの部分 - 平均に対するインデックス、成長への貢献、トップNの集中 - 異なる算術と同じ操縦者です。
::

## ウィンドウズ

ウィンドウ関数は、 *隣接する行のセット* それらを衝突することなく。 3つはカバーをほとんどすべて使用します:

::field-table
---
dataset: "window calculations"
grain: "one row per pattern"
fields:
  - name: "Running total"
    type: "accumulate in order"
    role: "measure"
    note: "月によって累積的なALR、四半期に作成された累積パイプライン。 明示的な注文が必要 — 結果は 1 つなしで意味がありません。クエリはとにかく実行されます。"
  - name: "Moving average"
    type: "smooth a noisy series"
    role: "measure"
    note: "3～7ペリオドを走る。 毎日のシリーズが読みにくいとき、正直なスムース; スパイクが発見されたとき、あなたは目からそれらを滑らかに。"
  - name: "Rank within a group"
    type: "partitioned"
    role: "dimension"
    note: "地域ごとのトップ3の担当者、セグメントごとのトップ製品。 パーティションは重要な部分です。つまり、単一のグローバルランキングと最小地域のすべての列が一番下にあります。"
  - name: "Period over period"
    type: "compare to the previous row"
    role: "date"
    note: "先月、デルタまたはパーセンテージとして、読者が目を引く必要がある2つのウィジェットではなく、1つのクエリで。"
---
::

::warning{icon="i-lucide-arrow-down-up"}
**明示的な順序のないウィンドウは、それ自体を発表しないバグです。** 実行合計、期間オーバー期間、順位はすべて行順に依存し、そのエンジンが生成された順序を一切使用していない場合は、次のデータが更新された直後に異なる、安定した今日。 クエリ内の数字が変更されず、クエリが間違っています。
::

## パーティションは、一部の人々は間違って取得します

ランキング担当者 *各地域内* つまり、地域ごとにウィンドウがリセットされます。 すべての担当者をグローバルにランキングし、1つの領域にフィルタリングすると、14、27、31が1、2、3ではなくランク付けされます。

::tip{icon="i-lucide-group"}
**書き込む前に、パーティションを大声で言う:「各地域の最高の3つの担当者」。** 「それぞれに」フレーズはパーティションです。 文が "in each" がない場合、おそらくウィンドウがまったく必要ありません。
::
