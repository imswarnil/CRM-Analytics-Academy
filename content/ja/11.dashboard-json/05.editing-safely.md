# 安全に編集する

Dashboards は、実際のバージョン履歴のない org メタデータです。 どんな懲戒律が存在するかは、あなたが持って来る規律です。

## 4つの習慣

::lesson-steps
---
items:
  - title: "編集前のエクスポート"
    description: "例外なく、いつでも。 ハンド編集のための undo のストーリーは、あらかじめ保存したコピーであり、必要な瞬間は、あなたが持っていなかった瞬間です。"
  - title: "保存前の検証"
    description: "ペースト JSON バリデータ 追跡コンマまたは不均衡な括弧は、読み込まれないファイルを生成し、あなたが戻ってくるエラーは、バリデータがあなたに与えるものと同じくらい稀です。"
  - title: "ビルダーでの往復"
    description: "再ロードして確認し、まだ開いて、視覚的に編集します。 有効期間 JSON ビルダーが再構築できないのは、問題の失敗モードであり、バリデータではなくここで表示されます。"
  - title: "制限されたユーザーとして確認"
    description: "このコースの他の場所で同じルール。 管理者のアカウントから見えない方法でステップやフィルタを変更する編集は、行レベルのセキュリティと対話できます。"
---
::

## Diffsは、実際の賞品です

::note{icon="i-lucide-git-compare"}
**JSON テキストなので、変更は差分になります。** つまり、「パイプラインダッシュボードを更新しました」 — 見解不可能で、週以内に忘れました - しきい値が動かされたか、どのフィルターが追加されたかを正確に示す14行になります。 この製品が持つ制御を変更するのは最も近いことです。そして、エクスポートされたファイルをどこかに履歴で保存するよりも費用はかかりません。
::

作業可能な低儀式バージョン:

- 各生産ダッシュボードのエクスポート JSON リポジトリ、ダッシュボードごとの1つのファイル。
- 重要な変更後に再エクスポートし、理由について文でコミットします。
- 数字が争われた場合、歴史は答えます *いつ変化するか* 直接 — 通常、調査全体です。

これは、デプロイメントの自動化ではありません。ダッシュボードはまだorgに住んでいます。 レコードであり、レコードは、誰かが3月に動いた理由を尋ねる瞬間に望むものです。

## 大量編集、慎重に行われました

::warning{icon="i-lucide-search-x"}
**ファインアンド置換は、ここにある理由であり、すべてを破壊する方法です。** 短い名前でフィールドの名前を変更する — `Amount`, `Type`, `Region` — また、タイトル、ラベル、関連のないプロパティ内でヒットします。 ベアワードよりもコンテクストにマッチし、すべての置換ではなく、各置換を見直し、差分が後読み可能であることを十分に編集しておく。
::
