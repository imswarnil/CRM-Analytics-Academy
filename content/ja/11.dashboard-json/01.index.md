# いつ開くか JSON

ツイート CRM Analytics ダッシュボードは JSON document: ウィジェット、レイアウト、クエリ、バインディング、テキストとしてすべて。 ビルダーはあなたのためにそれを書いて、時にはテキストはより良いツールです。

::note{icon="i-lucide-file-json"}
**ダッシュボードビルの高度な階層ではありません。** ほとんどのダッシュボードは決して自分のものを持っているべきではありません JSON 開いて、ビルダーが完全にうまくいくことは、他の人が維持できないダッシュボードを作り出す方法です。 これは、一括作業、レビュー、およびインターフェイスが露出しない物事の便利なために、その場所を獲得します。
::

## 2つの悪い理由

::warning{icon="i-lucide-hand"}
**使用しないでください JSON 普通の仕事をより速くし、それを賢くするために使用しません。** ビルダーが往復できない設定にハンド編集されたダッシュボードは、変更できるダッシュボードで、オーバーバウンドと同じ失敗です。 ビルダーがそれを表現できるならば、ビルダーはそれを表現してみましょう — JSON ビルダーができないこと、そしてそれが何をしたかを見るためです。
::
