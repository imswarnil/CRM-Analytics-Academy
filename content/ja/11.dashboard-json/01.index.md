## 計画レッスン

- **開くとき** — すべてのダッシュボードは JSON 下の文書。 一括編集、差分、レビュー、再使用 - およびそれを開く4つの状況は、表示するのではなく、正しい動きです。
- **アナトミー** — ダッシュボードのドキュメントの4つのトップレベルの部分 — 状態、ステップ、ウィジェット、レイアウト — 互いに参照する方法と、書きていないファイルで何かを見つける方法。
- **ステップ & お問い合わせ** — ダッシュボードのドキュメントのデータレイヤー:ステップが含まれているもの、クリックされたクエリと未加工の違い SAQL, 静的なステップ, 負荷時間のためのクエリを統合.
- **ウィジェット & レイアウト** — 分離が存在する理由、ほとんどの驚きを引き起こすレスポンシブなレイアウト、およびテキストとして編集する価値のあるウィジェットのプロパティなど、それがどこに置くかが描かれています。
- **安全に編集する** — バックアップ、検証、往復テストと差分ベースのレビュー — ダッシュボードを作成する方法は、実際のバージョン管理がない製品でリバーシブルでレビュー可能に変更します。
- **インタビュー質問** — ダッシュボードで働いたかどうかを尋ねるときに、インタビュアーが本当にチェックされていること JSON —モデルの回答で。
- **グレードのクイズ** — ドキュメント構造、ステップ、レイアウト、一括編集、安全な編集に関する8つの質問。
