# ビルド: オーガニック検索 回答がリンクの上にあるとき

アカデミーは#3をランク付け *"saql グループ例"*お問い合わせ クリックすると、とにかく40%下がります。 何も壊れていない - AIの概要は、リンクの上の質問に答えています。

::note{icon="i-lucide-trending-down"}
**古い仮定は、トラフィックを決定した順位でした。** もうありません。 ランク決定 *免責事項*; クリックが発生したかどうかは、回答が既に与えられたかどうかによって異なります。 ダッシュボードのレポート位置は、トラフィックが半分にしている間に、健康な緑色の線が表示されます。
::

## ランクを置き換えるメトリック

::metric-spec
---
items:
  - name: "Clicks per Rank Point"
    formula: "sum(Clicks) / count(keywords) at a given position band"
    grain: "Per week × position band × cluster"
    source: "seo_keywords.csv"
    watchout: "Compare like with like. Position 1 and position 8 have wildly different expected CTR, so the comparison is always WITHIN a band, over time. Falling clicks at a stable rank is the signal; it means the SERP changed around you."
  - name: "AI Overview Exposure"
    formula: "count(InAIOverview = true) / count(all keyword-weeks)"
    grain: "Per cluster"
    source: "seo_keywords.csv"
    watchout: "Informational intent is hit far harder (~56%) than commercial and transactional (~20%). Blending intents produces a company-level number that hides which content type is actually being cannibalised."
  - name: "Effective CTR"
    formula: "sum(Clicks) / sum(Impressions)"
    grain: "Per cluster × week"
    source: "seo_keywords.csv"
    watchout: "Impressions still count when an Overview takes the click, so CTR falls while rank holds. That divergence IS the finding — do not smooth it away."
---
::

## ビルドする

::lesson-steps
---
items:
  - title: "ダイバージェンスチャートを最初に"
    description: "タイムライン、Xの週。 2つの対策:平均位置(反転軸)、クリックの合計。 ラインが分離するとSERPが変更されます。 このシングルチャートは、古いSEOレポートのほとんどを置き換えます。"
  - title: "位置軸を反転"
    description: "位置1は、位置40よりも優れているので、生の軸線は落下として改善を描きます。 チャートのプロパティでそれを反転するか、ダッシュボードはすべての人に読み直します。"
  - title: "全体ではなく、意図による暴露"
    description: "Intent によるグループでは、InAIOverview = true でキーワード週間のシェアを測定します。 情報収集は、戦略的知見であり、コンテンツチームが書いた内容を変更し、他者を引き立てます。"
  - title: "アリスクテーブル"
    description: "バンドの期待を下回る高インプレッションとCTRをフィルタリングします。 印象の降下でソートします。 これらは、もはやキャプチャされていない要求のあるページです。 — 最高のリターンが書き直されます。"
  - title: "ランディングページでセッションに参加"
    description: "サイトマップ*session.csv 株式の着陸 seoでページ*キーワード.csv. 1ページあたりのセッションを1週間ごとに集計し、参加してください。それ以外の場合は、毎日セッションの行に1つのキーワードをファンクションアウトします。"
---
::

::tip{icon="i-lucide-triangle-alert"}
**最後までご参加ください。** `seo_keywords` 週単位 `web_sessions` 毎日なので、各キーワードに7つのキーワードを掛け合わせます。 週にセッションを集計し、参加 `LandingPage` + 週. 2つのウィジェットとしてそれらを保存するか、通常はより良い答えです。
::

::note{icon="i-lucide-lightbulb"}
**2つのダッシュボードは1つの質問を一緒に答えます。** 情報をクリックすると、同じクラスターでボイスの上昇共有が増加するというと、説明者のコンテンツが機能していることを意味します。サイトの代わりにアシスタント内で消費されます。 ネザーダッシュボードは、単独で表示し、サイドバイサイドを提示することは、今年はコンテンツチームにとって最も価値のあることです。
::
