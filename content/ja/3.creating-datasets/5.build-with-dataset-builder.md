# ベースラインデータセットをビルドする Dataset Builder

今、私たちは現実を構築します Salesforce データセット。 **Dataset Builder** オリジナルのガイドツールです。オブジェクトの関係を歩く *お問い合わせ*、結合キーを自動的に把握し、指示を指示をaに書きます **データフロー**お問い合わせ ベースラインのデータセットを立てるのは、私がまだプラットフォームを学ぶ人々にそれを手渡している理由です。

穀物レッスンからプランを記憶:このデータセットは **機会について**ですから、オポチュニティを始めてみる *ニュース* アカウントとユーザー。

::tip{icon="i-lucide-plug"}
Dataset Builder からの読み込み **接続/同期レイヤー**からではなく Salesforce 直接。 なので、 CSV アップロードすると、同期は最初に配置する必要があります。 オブジェクトが同期されていない場合は、選択できません。
::

## キックオフ

詳しくはこちら Analytics Studio: : : **作成 → データセット → Salesforce データデータ**お問い合わせ これはミドルオプションです。アップロードされていない CSV, 既存のデータセットの上に構築されていない (パスはレシピにつながる).

どのデータフローを使うか尋ねられます。 あらゆる船舶を装備 **デフォルト Salesforce データフロー**と、それを追加したり、自分で作成したりすることができます。 生産では、通常、名前付けされた、スケジュールされたデータフローの数が小さくなり、それぞれがポップアップしていることを正確に把握できます。 現在、デフォルトを使用します。 クリック **次へ** そして、 Dataset Builder で開く Data Manager タブ。
