# 価値の欠如

null は *私たちは知らない*お問い合わせ ゼロの手段 *我々 は知っている、それはどれも*お問い合わせ すべての集計はそれらを異なって扱い、それらを混乱させることは、誤った番号を生成するための最も静かな方法の1つです。

## ギャップを埋めることは主張です

::warning{icon="i-lucide-pencil"}
**何かを主張する。** ゼロは誰を主張しません。 平均は典型的なアサート。 前の値は何も変更されないことを主張します。 それぞれは、いくつかの状況で防御可能であり、それぞれは、データを代わって作成しているステートメントです。そのため、式ノードに埋葬されるのではなく、メトリック定義に所属しています。 質問への質問は次のとおりです。 *この塗りつぶしが間違っていると、何が壊れますか?* すべての平均ダウンをドラッグゼロで不足している量を埋めます。 決して存在しなかった取引を発明する平均を充填します。
::

**塗りつぶしをするときは、自分がしたと言ったフラグ列をキープします。** ボオリアン `AmountWasImputed` 何も費用をかけないし、誰もそれらを含まない分析から満たされた列を除外することができることを意味します。 1年後、数字が本物でした。 フラグなしの充填は、それが今まで欠落していた情報を破壊します。.

## 予測充填

他の列から欠落した値の推定 — セグメントと製品から推論される量、ステージと年齢から推論されたクローズデイトは、時折合理的であり、常に定数よりも大きなクレームです。

::warning{icon="i-lucide-brain"}
**値を予測して解析すると、予測したパターンがわかります。** セグメントからの金額を計算し、セグメント別で収益を報告し、表示されるセグメントの差分は、お客様を振り返る独自のインピーションです。 それらがインピートされたものについて、任意の分析から、値をインピートし、それらをフラグを立てて、他の人もできる。
::

## 信号として欠損

時々空白はデータセットの最も有益な列です。

::note{icon="i-lucide-lightbulb"}
**アカデミーでは、 `EconomicBuyerIdentified` ブランクは失うと相関** — 空白が損失を引き起こしているためではなく、従事していない担当者がフィールドを埋めていないためです。 つまり、「それは空白です」を正式に予測し、完全に反応不可能にします。フィールドを埋めるために担当者が経済の買い手を作成しません。 これは、他のモデルが何も変更するアドバイスを生成し、最も一般的な方法の1つです。 Einstein Discovery セクションはそれに戻ります。
::

## 応答レートケース
