# ソースからデータセットへ

すべて表示 CRM Analytics データセットに組み込まれており、一部の人が選んだデータセットが作成されます。 このセクションでは、意図的に意図的に作成することについてです。

## 4つのルート

::field-table
---
dataset: "how data becomes a dataset"
grain: "one row per route"
fields:
  - name: "CSV upload"
    type: "manual, one-off"
    role: "key"
    note: "ファイルをドラッグし、推論型を確認してください。 このコースのサンプルデータと本物のワンオフに最適です。 ファイルが固定された抽出物であり、誰かがそれを現物であると期待したときに責任であるとき、それはそれ自体を更新しません。"
  - name: "Salesforce sync → recipe"
    type: "the normal path"
    role: "key"
    note: "選択されたオブジェクトとフィールドは、スケジュールで同期され、レシピが参加し、それらを形づけます。 これは、生産のorgが実行するものであり、データの準備セクションが何を仮定するかです。"
  - name: "External connection → recipe"
    type: "warehouse, S3, database"
    role: "dimension"
    note: "同じ形、異なった起源。 アカデミーのWebセッション、支出、使用は、実際のorgでこの方法に到着します。ここでは、CSVsなので、コースは外部インフラストラクチャなしで実行されます。"
  - name: "Recipe on existing datasets"
    type: "derived"
    role: "measure"
    note: "レシピは、生成された他のレシピのデータセットを読むことができます。 いくつかの下流データセットが組み込まれている、共有された清潔な基盤のために有用であり、チェーンが長くなれば危険です。スケジュールの問題は3つのリンクが最後に見えないためです。"
---
::

## このセクション全体を管理する質問

::note{icon="i-lucide-ruler"}
**出力の1列は正確に何を表しますか?** 基礎セクションでこれを満たしました。 ここでは、目的に誤って構築します。, ほぼ3倍のアカデミーの収入を参照してください。, その後、それを修正します。 — 抽象化は、あなた自身のデータで不可分な誤った番号を生成し、見てきた後だけ反射になります。.
::

## セクションを通して運ぶための1つの習慣

すべてのノードで行をカウントします。

::tip{icon="i-lucide-hash"}
**参加前とその後** 行数が上がると、穀物が変化し、なぜか言わせなければならない。 時々、それは機会にアカウントを結合し、608行を維持します。 正当な生成する機会に製品ラインに参加 1,192. 失敗は増加しません。 失敗は親のことを要約しています `Amount` 増加した後、製品内の何もあなたが何を意味するかを知っているので、製品に警告しません。
::
