# ロードする CSV プロペラ

アップロードは10秒かかります。 チェックインは2分かかります。 このレッスンは、以下の3つのチェックの1つがニュアンスではなく再構築を防ぐため、2分程度です。

## 3つのチェック、費用の順

::field-table
---
dataset: "what to verify at upload"
grain: "one row per check"
fields:
  - name: "Dates typed as dates"
    type: "most common"
    role: "date"
    note: "テキストの日付はテーブルに完璧にレンダリングされますので、すべてのカジュアルなレビューを生き残します。 月ごとにグループ化された、またはトレンドした範囲でフィルタリングすることはできません。トレンドが必要な瞬間に発見できます。 Fix は、属性を編集し、ファイルをリロードすることを意味します。"
  - name: "IDs typed as dimensions"
    type: "common"
    role: "key"
    note: "口座の額 Idは意味がありません。 あらゆる識別子を負荷の次元に強制します。 これは、アカデミーのケースでは、あなたが参加するキーのほとんどが、AccountId、OpportunityId、キャンペーンIdです。"
  - name: "Currency scale"
    type: "expensive when wrong"
    role: "measure"
    note: "100×は見えない:すべての下流図は一貫して間違っているので、異常は見えません。 移動前の目で生ファイルに対して単一の行を比較します。"
  - name: "Row count"
    type: "always"
    role: "measure"
    note: "データセット README は、すべてのアカデミーファイルの真のカウントを述べています。 一つはヘッダーの問題です。 ゼロは失敗した負荷であり、モニターは理由を保持します。"
---
::

## 答えの鍵がそれほど重要である理由

アカデミーズ `README.md` ファイルごとの行、クローズド収益、月別ARR、リード数。 そのため、このコースの全てのビルドは、独自に真摯に向き合っているものに対してチェックすることができます。

::tip{icon="i-lucide-check-check"}
**自信がある場合でも、すべての負荷を確認してください。** 値が期待するエラーをキャッチしていない; それは、リフレックスを構築しています, あなたはまだあなたが本質的に反論する何かを探していないREADMEでデータに取り組んでいるとき — 財務数字, 以前に公開された数, 誰かが既に信頼を報告. これを行うアナリストは信頼されています。 最終的には公に驚かされないアナリスト。
::

## いつか CSV 正しい答えであり、それがないとき

::compare-cols
---
items:
  - title: "CSV 正しい"
    subtitle: "Fixed extracts, learning, one-offs"
    icon: "i-lucide-file-check"
    pros:
      - "No infrastructure, no connection, no schedule"
      - "Reproducible: the same file gives the same dataset"
      - "Perfect for this entire course"
    cons:
      - "Never updates itself"
      - "Somebody has to remember to re-upload"
    verdict: "Fine when the data genuinely does not change."
  - title: "CSV 間違っている"
    subtitle: "Anything anyone expects to be current"
    icon: "i-lucide-file-x"
    pros:
      - "Fast to set up, which is the trap"
    cons:
      - "It will silently age, and it looks identical to a live dataset"
      - "The re-upload becomes one person's undocumented monthly chore"
    verdict: "Use a connection and a schedule instead."
---
::

::warning{icon="i-lucide-calendar-x"}
**生産の手動積み込みトラップ。** ツイート CSV 一度に読み込まれると、ダッシュボードと静かに年齢になります。 スケジュールされたデータセットから区別する画面には何もないし、誰がアップロードしたかを知る唯一の人。 一つを出荷する必要がある場合は、データセット名に抽出日を置く — `the Academy Accounts 2026-09` つまり、一人の人が記憶するのではなく、だれでも視線が見えます。
::
