# 接続と同期

あらゆるダッシュボード上のすべての数値を配管して決定するような2つのステージ。

## コネクション

ツイート **アクセス** 資格情報と到達可能なエンドポイントです。 ローカル Salesforce orgはデフォルトで接続されます。他のすべてが一度設定され、参照されます。

- **その他 Salesforce ログイン** — 複数の企業で共通する。
- **倉庫** — Snowflake、BigQuery、Redshift など。
- **オブジェクトストレージとデータベース** — S3、および直接データベース接続。
- **ツイート CSV アップロード** — 本当に接続ではなく、同じ目的地。

::note{icon="i-lucide-key"}
**クレデンシャルの有効期限が切れ、これはパイプライン全体で有能な失敗です** — 実行が停止し、そう言う。 パーミッションの問題と比較し、サイレントに列をドロップします。 接続がすぐに見つけ出すと、何かを静かにデバッグしている間に鑑賞する価値があります。
::

## 実際に同期するもの

データ同期プル **選択したオブジェクト** そして、 **選択したフィールド** お問い合わせ CRM Analytics' スケジュール上の店舗。 レシピは、そのローカルコピーを読みます。

この2つの理由は、

1. **速度。** 5つのオブジェクトを結合するレシピは、それ以外の場合は、実行ごとに5回ソースをクエリします。
2. **ポリテネス。** レコードのシステムは、ライブユーザーに役立つ生産CRMです。 分析の仕事は毎時それを槌で打たれるべきではありません。

社内に価値のある結果: **2つの時計があります。** Syncにはスケジュールがあり、レシピにはスケジュールがあります。 ダッシュボード上のデータは、 *早い* 2 つは、しかし、実行が取られた長い。

## 依存性トラップ

::warning{icon="i-lucide-clock-alert"}
**同期が終わる前にスケジュールされたレシピは、昨日のデータ、毎晩、永久に正常に実行されます。** エラーなし。 モニタータブは緑色を示しています。 ダッシュボードは、誰かがレポートと比較し、調査が1週間かかるまで、誰も質問しないと、正確に1日当たりの数字を示しています。 ステークホルダーが「背後にある数字が感じている」と述べたとき、それらを信じ、他のものの前に2つのスケジュールを確認してください。
::

修正は注文しています, 実際のヘッドルームで: で同期 01:00, レシピ 03:30, ない 01:30. 通常20分かかる同期は1日は50分かかります。

## 狭く同期するが、初期同期

データの準備セクションの緊張は、ここで休むので、これはあなたがそれを行動する場所です:

**ログイン**あらゆるフィールドが毎回実行する時間とスペースを要するので、 **早割**, スナップショットは、時間に同期されたものだけを覚えることができるので. 3月に最初に同期したフィールドは、2月の値はありません。 Salesforce オブジェクトは現在の状態だけを保持し、それから履歴を再構築することはできません。

実践的なルール: 長いテキストとまれに使用した記述的な列で間隔をあけてください。 **日付、所有者、ステージ、セグメントおよび金額**, 彼らが最終的にトレンドしたいものだから.

## モニターがあなたを教えてくれるもの

Data Manager → Monitor はパイプラインのログで、ほとんどのインシデントについて説明する4つの質問に答えます。

::field-table
---
dataset: "Monitor"
grain: "one row per question"
fields:
  - name: "Did it run?"
    type: "status"
    role: "key"
    note: "失敗した実行は簡単なケースです。 スケジュールが無効になったため、リリース中に頻繁にスケジュールが無効になっているので、決して起動しないランは、人々を驚かせているものです。"
  - name: "When?"
    type: "timestamp"
    role: "date"
    note: "誰かが数字が間違っていると言うとき、最も有用な数字が1つあります。 「間違った番号」のレポートの3分の1は、ここに終了します。"
  - name: "How many rows?"
    type: "count"
    role: "measure"
    note: "ここまで時間をかけてみる。 月間〜2,800行を保有し、突然2,100行を保有するデータセットは、ダッシュボードが報告されない問題上流を持っています。"
  - name: "How long?"
    type: "duration"
    role: "measure"
    note: "クリープ期間は、依存性トラップの早期警告です。20分かかる同期は50分かかります、そして、それに従うレシピと衝突することです。"
