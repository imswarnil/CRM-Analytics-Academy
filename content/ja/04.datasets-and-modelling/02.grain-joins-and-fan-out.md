# グライン、参加、ファンアウト

コースの中で最も重要なレッスンです。 それを読むのではなく、それをビルドする - 間違った番号が自分の画面に現れているのを見て、どこでも警告しないと、それがどのように普通に見えるかを感じることです。

## ファンアウトとは

「one」側のマルチプライズ行を1対1で結合します。 "one" 側にある測定は、各子に繰り返されますので、数回カウントします。

::funnel-viz
---
stages:
  - label: "ニュース"
    value: 608
    note: "契約ごとの1列。 ここに正しい金額 — $13.4M"
  - label: "製品ラインを結合した後"
    value: 1192
    note: "各取引量は現在、1〜5列に座っています - 最も大きな取引"
  - label: "額の額"
    value: 1192
    note: "≈ $36.9M. エラーなし、警告なし、各行が個別に正しい"
caption: "アカデミーは、間違った穀物に参加しました"
scale: "linear"
---
::

::warning{icon="i-lucide-alert-triangle"}
**この失敗はエキゾチックです**、それが危険である理由は正確にです。 参加は正しいです。 すべての行が正しいです。 データセットビルド、ダッシュボードのレンダー、チャートはハンサムで、数が3倍近く大きい。 画面を見ている手段を見直し、画面が右に見えるため、レビューを通過します。
::

## 2つの修正とそれぞれが正しいとき

::compare-cols
---
items:
  - title: "入社前のアグレゲート"
    subtitle: "Collapse the many side first"
    icon: "i-lucide-combine"
    pros:
      - "Output stays at one row per deal — the grain you probably want"
      - "Parent measures stay safe to sum"
      - "You choose exactly what the lines contribute: a count, a sum, a max"
    cons:
      - "Product-level detail is gone from this dataset"
    verdict: "Right when the dataset is about DEALS."
  - title: "細かい穀物を保ち、親の測定を落として下さい"
    subtitle: "Stay at line level, deliberately"
    icon: "i-lucide-scissors"
    pros:
      - "Product-level analysis stays possible"
      - "Line amounts are genuinely per-line, so they sum correctly"
    cons:
      - "Anyone using this dataset must know the grain, or they will sum the wrong thing"
      - "Deal counts need distinct counts, not row counts"
    verdict: "Right when the dataset is about PRODUCTS."
---
::

::note{icon="i-lucide-file-text"}
**どちらを選ぶか、データセットの記述に穀物を書いて下さい。** 「チャンスごとの1列」または「製品ごとの機会ごとの1列」は5秒かかります。そして、それは単一の最も有用な文章です。 穀物がドキュメントされていないデータセットは、同僚のために設定したトラップです。
::

## 3つの症状と、それぞれの意味

::field-table
---
dataset: "diagnosing a wrong total"
grain: "one row per symptom"
fields:
  - name: "Exactly 2×, 3× or suspiciously round"
    type: "fan-out"
    role: "measure"
    note: "親は子供に重複した測定値です。 各結合ノードの前後に行をカウントして、乗算が現れます。"
  - name: "Slightly high, not a clean multiple"
    type: "partial fan-out"
    role: "measure"
    note: "SOMEの両親だけが複数の子供を持っています - 通常の現実世界の場合、数字がクリーンな複数のものではないため、正確にスポット化するのが困難です。 アカデミーは1つのラインと5つの取引を扱っています。5つのラインの取引は最大です。そのため、売上高は2.75倍に膨脹します。"
  - name: "Lower than expected"
    type: "an inner join, or permissions"
    role: "key"
    note: "内側は、他の側に一致しないで行をサイレントにドロップします。 参加していない場合は、インテグレーションユーザーまたは述語です。アクセスセクションが述べたように、アクセス権限が欠落します。"
  - name: "Right total, wrong breakdown"
    type: "grouping on a fanned column"
    role: "dimension"
    note: "微妙なもの。 測定値が適切に集計されたため、合計は正しいですが、子属性によってグループ化することで、それが意味するものではありません。"
---
::

## 分散カウント

データセットが細かい穀物を持っているら、 **行のカウントは、取引のカウントを意味します**お問い合わせ ライングレインでは、1,192行は608の機会です。 行数ではなく、機会キーの異なるカウントを使用して、知っている番号に対してチェックします。

::tip{icon="i-lucide-bug"}
**星ではなく、狭くしてデバッグします。** レンズをテーブルモードに切り替え、手作業で列をカウントします。 Thirty秒は、どのサイドが乗ったかを正確に伝えます。総計1時間で総計を調べると、まったく何も伝えません。
::
