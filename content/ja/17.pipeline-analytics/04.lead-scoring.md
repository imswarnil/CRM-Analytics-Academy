# リードスコアは何かを予測しますか?

すべてのCRMは、リードスコアを持っています. 自分の作品かどうかを調べる企業はほとんどいません。 このレッスンはチェックです。Namilioの回答は *パートリー*, 最も有用な結果です。.

::note{icon="i-lucide-gauge"}
**スコアは予測です。** 予測は結果に対して得られます。 A-band が C-band よりも材料的に優れていない場合、スコアは装飾と担当者は無視する権利です。
::

## その後、スコアが欠けているものを見つける

レッスンがその場を獲得する場所です。 個々のフィールドを変換からテストし、スコア自体に比較します。

::tip{icon="i-lucide-lightbulb"}
**期待する結果。** 行動イベントは通常、推測ではなく証拠であるため、人口統計スコアを上回っています。 「私たちを呼んだ」 API「200-500人の社員がいる会社で働く」という想いが込められています。 監査がこの結果を生成した場合、推薦はそれ自体を記述します:行動のルートは、スコアをtiebreakとして使用します。
::

## この解析における2つのトラップ

    description: "D-band リードは全くルーティングされていないため、変換率は品質ではなく無視されます。 実際に働いていたバンドが、チャートの横に言っているかに注意して下さい。"

::

::note{icon="i-lucide-scale"}
**両方のトラップは同じように押します** — 彼らはスコアの明らかな値に影響を与えます。 それらを無視する監査は、常にモデルが優れています。 それらを完全に解決することなく、それらを浪費することは、監査が信頼できるものにすることです。
::
