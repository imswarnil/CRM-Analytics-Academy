# ビルド: インバウンド対アウトバウンド

インバウンドはより多くのリードを生み出します。 アウトバウンドはより大きな取引を生み出します。 どちらの側面も右側で、cite のボリュームと、誰も正しいチャートを持っていないため、引数は解決しません。

## 比較する前にモーションを定義する

バケットが間違っていると、全体の分析は価値がありません。分類は本物的に競争可能です。

::field-table
---
dataset: "leads.csv — SourceCategory"
grain: "four motions"
fields:
  - name: "Inbound Marketing"
    type: "paid, organic, webinar, conference"
    role: "dimension"
    note: "出版されたもの、または支払ったもののために、彼らは私たちに来た。"
  - name: "Product"
    type: "free course, community, self-serve"
    role: "dimension"
    note: "目的のインバウンドから分離 — PLG は完全に異なる振る舞いをし、「インバウンド」には最も一般的な分類エラーです。"
  - name: "Outbound"
    type: "SDR sequences, cold"
    role: "dimension"
    note: "ご連絡をお待ちしております。 事前の興味は表明しません。"
  - name: "Partner / Referral"
    type: "SI partners, customer referral"
    role: "dimension"
    note: "小さい容積、高い転換。 通常はチームによって所有されていないため無視されます。"
---
::

::tip{icon="i-lucide-split"}
**インバウンドから製品を分割します。** フリーコースの3つのセクションを通して働いた学習者は、ウェビナーフォームに記入した人と同じではありません。 PLGの優れたコンバージョンは、インバウンドマーケティングのmediocreコンバージョンを非表示にし、予算の引数は、敗者を平らにブレンドされた番号で決定されます。
::

## 重要なことを見つけること

::note{icon="i-lucide-crosshair"}
**動きは全体的に勝ちます。 それぞれがセグメントを獲得します。** バンド3のヒートマップは、 セルフサーブとSMB、アウトバウンドは、エンタープライズと戦略的を支配し、インバウンドマーケティングは、ミッドマーケットで有用な仕事をしている途中に座っています。 会社の勝者として提示され、この分析は、それが与える応答が間違っています。
::

## プレエンプトへの2つの異議

::compare-cols
---
items:
  - title: "「アウトバウンドリードは既に暖かかった」"
    icon: "i-lucide-thermometer"
    pros:
      - "Often true — they'd seen content first"
      - "FirstTouchChannel proves or disproves it"
    cons:
      - "Undermines outbound's apparent efficiency"
    verdict: "Check it. Filter outbound leads by FirstTouchChannel and see how many had a prior marketing touch — this is the strongest card marketing holds."
  - title: "「ブランドを消費することなく、インバウンドを乾燥させる」"
    icon: "i-lucide-sprout"
    pros:
      - "Also probably true"
      - "Unprovable on this data"
    cons:
      - "Can justify any budget indefinitely"
    verdict: "Acknowledge it as unmeasured rather than dismissing it. Then hold the line that unmeasured is not the same as proven."
---
::

::tip{icon="i-lucide-handshake"}
**両方の異議を自分で持って来る。** 運動比較を提示すると、チームを1つ持ち歩くののように見えます。 このダッシュボードが決定を変更する唯一の位置である、彼らは、あなたが非プロンプトを上げます。
::
