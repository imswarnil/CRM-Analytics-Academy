# チャートは引数

チャートは数字のニュートラルコンテナではありません。 誰が値を読み込む前に、 *形状:* すでに主張をした: これらのことは匹敵する、これは大きくなる、これは、その一部です。

::note{icon="i-lucide-message-square-quote"}
**データ型ではなく、比較からチャートを選択します。** 「私は測定値と寸法を持っているので、バーチャート」は、ほとんどのチャートが選ばれる方法であり、そのため多くのダッシュボードはバーの壁です。 質問は、読者が作ろうとしている比較です。 *ランキング*, *トレンド*, *コンテンツ*, *コンテンツ*, *関連記事*または *ターゲットに対する単一の値*お問い合わせ それぞれに正しい答えといくつかの間違ったものがあります。
::
