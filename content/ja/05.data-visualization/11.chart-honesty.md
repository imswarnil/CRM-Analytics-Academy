# チャート Honesty

すべての番号が正しいと結論が間違っています。 このレッスンは、その決定を書式化し、それらをキャッチするチェックリストの役に立つことです。

::note{icon="i-lucide-eye"}
**このテストは「この正確ではありません」ではなく、「誰が4秒で結論づけるのか」です。** 精度は簡単な部分であり、ほぼ常に良いです。 結論はダッシュボードが失敗し、失敗がチェックするのに十分な体系的である場所です。
::

## 集計はあまりにも主張です

同じ列のSum、平均、メディアン、そして異なるカウントは4つの異なる質問に答えます。ウィジェットのタイトルは通常、それらのどれも言います。

::warning{icon="i-lucide-sigma"}
**「平均取引サイズ」はあいまいで、2つの読み物は大きく異なります。** 意味は、企業の取引の手渡しによって上向きに引き出されます。 媒体は、典型的な取引を記述します。 アカデミーは、$ 36,000フラットエンタープライズプログラムの料金と$ 240アカデミープロサブスクリプションの数百を持っているので、意味とメディアンは、本物異なる物語を伝えます - そして、両方が正しいです。 ラベルに関数を置きます。 "median deal size" ではなく "average" です。
::

## 比較が間違って行く時間です

- **どの日付ですか?** 作成, クローズド, 最終修正, ステージエントリ. 異なる日付でグループ化された同じデータは異なるストーリーを伝え、選択したチャートは表示できません。
- **どの比較ですか?** 先月比12%、前年同月、または計画値の3つの回答は、署名に頻繁に同意します。
- **パートタイム** 今月は終わらないため、常にダウンしています。 いずれかを除外します。, それをシェード, またはそれをラベル付けます。 — 完全なものに加えて、不完全な月を示すダッシュボードは、一ヶ月ごとに減少を製造します。.
