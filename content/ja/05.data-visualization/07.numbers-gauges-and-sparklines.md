# 数字、ゲージ、スパークライン

ほとんどのダッシュボードは単一の値で開きます。 ほとんどの単一の値は実行できません。固定コストは何もしません。

## 数だけしか意味しません

「Net new ARR: $1.42M」 — は良いですか? 読者は知らなかったので、お尋ねください。 3つの成分がそれを修正:

::lesson-kpis
---
columns: 3
items:
  - label: "ベア番号"
    value: "$1.42M"
    hint: "Cannot be acted on — no scale, no direction"
  - label: "比較で"
    value: "$1.42M"
    delta: "+8.3% vs plan"
    trend: "up"
    good: true
    hint: "Now it has a verdict attached"
  - label: "スパークラインも"
    value: "$1.42M"
    delta: "+8.3% vs plan"
    trend: "up"
    good: true
    hint: "And now the reader knows whether it is normal"
    spark:
      - 820
      - 910
      - 1040
      - 980
      - 1180
      - 1310
      - 1420
---
::

::note{icon="i-lucide-gauge"}
**数値、比較、方向。** 比較は、昨年の同じ期間に対して、計画に対してスケールを与えます。 方向は頂点を与えます。 どの比較であれ、ラベルに「最大8%」と3つの異なる参照が3つの異なる回答を与え、署名で頻繁に同意する。
::

## グッズはメトリックに属しています

::warning{icon="i-lucide-arrow-down"}
**ダウンはいつも悪くありません。** チュルン落下、CAC のペイバックの短縮、タイム・ツー・クローズド・ドロップ、SLA のデクライニング、割引率の低下の過去のケース — すべての良いニュース。 毎回塗装するデフォルトのパレットは、アラームの壁に強い四半期を回し、読者に色を無視するように教えます。 メトリックごとの優しさの方向を設定し、サンティチェックを要求することによって: *この番号が刻まれた場合は、喜んでもらえますか?*
::

## スパークライン

タイルの中の小さなチャート、最後の数の期間を示す。 「これは普通ですか?」と答えます。これは、単一の数字が常に証明され、決して答えられない問題です。

::tip{icon="i-lucide-activity"}
**別のチャートを追加する前にスパークラインを追加します。** 彼らはほとんどスペースを要し、注意を払わないと、彼らはすべて変換します KPI スナップショットからトレンドへ。 112% NRR は、わずかを意味します。 7 ヶ月に登ったラインの端で 112% は、特定の何かを意味します。 121% から落ちたラインの端で同じ 112% は、何か緊急を意味します。
::

## ゲージ

ゲージは、通常、色付きのバンドでスケールに対して1つの値を示します。 まさにその空間を1つの状況で得ます。 **"how close is we" が疑問である正式な固定ターゲット**お問い合わせ

::compare-cols
---
items:
  - title: "よいゲージ"
    subtitle: "A real target exists"
    icon: "i-lucide-target"
    pros:
      - "Pipeline coverage against 3x — the target is the point"
      - "SLA attainment against a contractual 95%"
      - "Bands come from the business, not from thirds of the range"
    cons:
      - "Uses much more space than the number plus a delta"
    verdict: "One per dashboard at most."
  - title: "悪いゲージ"
    subtitle: "A number wearing a dial"
    icon: "i-lucide-circle-slash"
    pros:
      - "Looks like a cockpit"
    cons:
      - "No meaningful maximum, so the scale is invented"
      - "Bands split evenly into thirds, which is arithmetic pretending to be judgement"
      - "Occupies four times the space of the KPI tile it replaced"
    verdict: "Use a number with a comparison."
---
::
