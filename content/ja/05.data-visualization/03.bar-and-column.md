# バーとコラムチャート

同じチャート、2つのオリエンテーション、および複数のダッシュボードは、このセクションの他のものよりもソート順で決定されます。

## ソートは重要な設定です

CRM Analytics 並び替え **グループ化** デフォルトでは、テキストカテゴリのアルファベット順を意味します。 それはバーチャートが何であるかほとんどではありません。

::warning{icon="i-lucide-arrow-down-wide-narrow"}
**リーダーはバーがランクされていると仮定します。** 棒グラフを提示し、目は最初のバーを最大に取り、さらにチェックしません。 順序がアルファベットであるとき、その仮定は静かに間違っており、誤読は見えない - チャートは正しい、読者はそうではありません。 任意のカテゴリーのグループ化の尺度で降下をソートし、グループ化の独自の注文を時間と本物注文された段階だけ維持します。
::

## ベースラインルール

棒のため、 **長さはエンコーディングです**お問い合わせ 値が2倍に及ぶバーで、読者は考えずにそれに依存します。

::note{icon="i-lucide-ruler"}
**なので、バーチャートの軸線はゼロから始めなければなりません。** 40と60のすべてが棒に20%の差を3倍にし、すべてのラベルが正確である間、チャートは比率について嘘をつくので、40にそれを注ぐ。 小さな違いが重要でゼロであれば、ラインチャート、ドットプロット、またはデルタ・アgainst-target を使用して、バーのベースラインを移動しないという信号です。
::

::tip{icon="i-lucide-palette"}
**1つの色、1つの例外。** すべてのバーが異なる色がデザインされ、余計なものを伝えているバーチャート。 単一のニュートラルのバーチャート、アクセントの上のまたは下にあるバーチャート、読者がラベルを読んでいる前に発見を伝えます。
::
