# パート・オブ・ホール・チャート

コンポジションは、分析における最も過剰な比較です。 実際のダッシュボードのほとんどすべてのドーナツは、テーブルやソートバーとして優れています。

## なぜ角度が難しいのか

人々は比較します **長さ** よく、 **アングル** ひどく。 19%に23%のスライスは、目でコインフリップです。 単一の事実は家族全員を支配します。

::note{icon="i-lucide-pie-chart"}
**ドーナツは2枚または3枚のスライスで動作します。**シェイプそのものがメッセージを運ぶ「1つの商品から3分の収入が来る」。 過去4年、読者はラベルを読み、テーブルを読んでいると仕事が良くなり、スペースが少ない。
::

## テスト

::tip{icon="i-lucide-help-circle"}
**読者が答えで何をしているか尋ねて下さい。** アクションがランクとラフの比率を知ることに依存している場合 — 「私たちの収益のほとんどは企業です」 — チャートは右です。 数字自体に依存している場合 — 「エンタープライズは43.2%であり、ターゲットは45%です」 — 彼らは数を必要とし、チャートは彼らに言ったことができるものを推定します。
::

## 時間をかけて構成

2つの異なる質問、しばしば混乱:

- **「ミックスが変わるの?」** → 100%の積み重ね、または各共有の行のセット。 サイズは意図的に隠しました。
- **「各部分が成長するのか?」** → 別の行、または小さい複数。 意図的に隠されているミックス。

::warning{icon="i-lucide-layers"}
**積み重ねられた領域は、両方に答え、確実に答えようとします。** 一番下のバンドは下がるので、下が下がるので、そのセグメントは平らで成長しているように見えます。そのベースラインはバラになります。 Mid-Marketが成長しているかどうかを知りたい場合は、Mid-Marketに独自のラインを付与してください。
::

## アカデミーの作業例

6つのプロダクトを渡るプロダクトによる収益、3つの価格設定モデル。 6つのスライスのドーナツは、ほとんど何も通信しません。各バーの値を並べ替えられたバーが即座に「どの製品の問題」に答えます。そして、正直な構図の質問 - 「プリペイドプール - 教室の席日、バウチャー、コンサルティング時間 - 収益のより大きなシェアになる」 - は、合計で毎月100%積み重ねられた列です。 KPI その上にタイル。
