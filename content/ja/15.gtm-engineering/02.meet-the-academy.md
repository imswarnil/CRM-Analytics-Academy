# Namilio について

**ナミリオ** AIプロダクトの背後にある配管を売る:電話に答える声の代理店、メッセージング APILLMコピロットエンドポイント、電話確認、製品チームが連携するスタジオ。 およそ140人の顧客、数千の鉛、約$ 58Mは日付に閉まりました。

存在しません。 つまり、実際にGTM エンジニアを雇う企業からシェイプがコピーされ、そうしないと信頼するメトリックを破るので、それぞれのオッズディテールが存在します。

## キャスト

これらの人が常にフィルタリングするので、知る価値があります。

::field-table
---
dataset: "reps.csv"
grain: "one row per rep, 40 rows"
fields:
  - name: "AE"
    type: "14 reps"
    role: "dimension"
    note: "キャリー・クォータ。 セグメントを揃えるので、セグメント全体を比較することはデフォルトでは不公平です。"
  - name: "SDR / BDR"
    type: "13 reps"
    role: "dimension"
    note: "SDRはインバウンド、BDRはアウトバウンド動作します。 異なるジョブ、異なるメトリック。"
  - name: "SE"
    type: "6 reps"
    role: "dimension"
    note: "ソリューションエンジニア — POC を所有しています。これは、 POC の長さが測定可能である理由です。"
  - name: "CSM"
    type: "7 reps"
    role: "dimension"
    note: "設置された基盤を所有して下さい。 arr_snapshots に参加して、ビジネスの本を確認します。"
  - name: "RampStatus"
    type: "Ramping / Partial / Full"
    role: "dimension"
    note: "フェアネスフィルタ。 クォータチャート上の月2日の担当者は、チャート全体が嘘になります。"
---
::

::tip{icon="i-lucide-users"}
**使用条件 `RampStatus` 早くも頻繁に。** セールスチームの信頼を失う最速の方法は、3週間前に始めた担当者をランク付けするリーダーボードです。 1つのフィルターで、それについて考えた人です。
::
