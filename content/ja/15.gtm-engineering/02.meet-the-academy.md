# アカデミーについて

ここからのすべてのダッシュボードの会社が **CRM Analytics アカデミー** — このコースの背後にある事業は、会社としてモデル化しました。 この同じ4つのトレーニングを販売しています。認定を受けたい個々の学習者に、管理者とアナリストをアップグレードし、6つのトレーニングセンターの教室で、そしてむしろ構築したチームのための実装プロジェクトとして。 約 140 の顧客アカウント, 2,800 リード, $13.4M は、日付にクローズ, およそ $7.0M ARR によって 9 月 2026.

数値は合成です。 形状はそうではありません:それは本当のB2Bトレーニングビジネスの形であり、あなたがそうでなければ信頼するメトリックを破るので、各awkwardの細部は存在します。

## キャスト

これらの人が常にフィルタリングするので、知る価値があります。

::field-table
---
dataset: "reps.csv"
grain: "one row per rep, 40 rows"
fields:
  - name: "AE"
    type: "14 reps"
    role: "dimension"
    note: "キャリー・クォータ。 セグメントを揃えるので、セグメント全体を比較することはデフォルトでは不公平です。"
  - name: "SDR / BDR"
    type: "13 reps"
    role: "dimension"
    note: "SDRはインバウンド機能 — 無料のコース学習者と見積り依頼を行います。 BDRはLにアウトバウンド&Dリーダー 異なるジョブ、異なるメトリック。"
  - name: "SC"
    type: "6 reps"
    role: "dimension"
    note: "ソリューションコンサルタント — パイロットコホートとカリキュラムを設計し、パイロットの長さが測定可能である理由です。"
  - name: "CSM"
    type: "7 reps"
    role: "dimension"
    note: "設置された基盤を所有し、座席活発化を追います。 arr_snapshots に参加して、ビジネスの本を確認します。"
  - name: "RampStatus"
    type: "Ramping / Partial / Full"
    role: "dimension"
    note: "フェアネスフィルタ。 クォータチャート上の月2日の担当者は、チャート全体が嘘になります。"
---
::

::tip{icon="i-lucide-users"}
**使用条件 `RampStatus` 早くも頻繁に。** セールスチームの信頼を失う最速の方法は、3週間前に始めた担当者をランク付けするリーダーボードです。 1つのフィルターで、それについて考えた人です。
::
