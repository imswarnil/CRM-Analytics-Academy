# デプロイと書き込みバック

デプロイされたモデルがレコードをスコアし、結果をバックに書き込む Salesforce レコード — 解析を中止し、行動を影響する瞬間です。

## 仕事がどこにあるかを

::note{icon="i-lucide-map-pin"}
**書き込みバックに関する最も強いことは配置です。** ダッシュボードのスコアは、担当者が行くと見なければならないことです。彼らが既に開いている機会のスコアは、彼らが見逃せないものです。 これは組み込みと同じ引数です。 Einstein Discovery セクションでは、その人が何をするか、四半期ごとに賞賛され、毎日無視されるモデルの違いです。
::

## スコアで何の旅行

3つのこと、そして2つ目は落ちるものです:

  - title: "トップ要因、明白な言語で"
    description: "それを引き下げる3つのことは、人がそれらを言うだろうとフレーズした。 これは、対決ではなく、得点を対決リストにする部分であり、それは表面により多くの仕事であるため、最も頻繁に省略される部分です。"
  - title: "スコアされた日付"
    description: "予測が悪くないから2回移動した取引で6週間前からの予測。 スコアがステープルの場合、その場所が表示されるように言います。"

::

::warning{icon="i-lucide-bell-off"}
**1ヶ月以内に無視される理由のないスコア、そしてその後の不信。** シーケンスは予測可能である: 到着すると、人々はそれを見て、何をすべきかを彼らに伝えません、彼らは探して停止し、何人かの人が後でAI投資が何も変更しなかった理由を尋ねると、それが誰の行動を与えなかったということです。 要因をサーフすることはポーランド語ではありません。それは展開です。
::

## スコアリングアカデミー

レコード変更 意図的に、彼らは再scoredどのくらいの頻度を決定し、選択を目に見えるように:

- **リフレッシュ** — データセットのスケジュールに従うスコア。 シンプルで、この朝を移動した取引は、昨晩のスコアを運ぶ。
- **変更について** — 実際の時間と高価に近づいています。誰かがその日のスコアで行動するときにのみ価値があります。

どちらかが守れる。 守秘不可能とは、誰が場所にあるかを誰も知らないことです。なぜなら、誰も自分の目の前でレコードに不一致しているスコアを信頼する方法を知っているからです。

## 退職計画

::tip{icon="i-lucide-power-off"}
**デプロイメントで、それをオフにさせるものを決めます。** 指示されたしきい値の下の正確さは、トレーニングデータがもはやビジネスを記述しない、または単に四半期のためにそれを行動しない十分なポートフォリオ変更の大きい十分に変わります。 退職条件のないモデルが退任されず — 信じられないほど静かに止まり、それは権威を求めるレコードページに滞在しているためです。
::
