# テーブル、KPI、マイクロチャート

3人の家族が決定ダッシュボードでほとんどの仕事をしています。 チャートは教えられます。これらは使われます。

## KPI タイル

単一番号、目立つ。 単独の数字はほぼ無用です。比較と方向が必要です。

::lesson-kpis
---
columns: 4
items:
  - label: "ネット新規登録"
    value: "$1.42M"
    delta: "+8.3% vs plan"
    trend: "up"
    good: true
    hint: "Comparison and direction included"
    spark:
      - 820
      - 910
      - 1040
      - 980
      - 1180
      - 1310
      - 1420
  - label: "純収入保持"
    value: "112%"
    delta: "+3pt QoQ"
    trend: "up"
    good: true
    hint: "The single most predictive number"
    spark:
      - 104
      - 106
      - 105
      - 108
      - 109
      - 111
      - 112
  - label: "インフォメーション ペイバック"
    value: "14.2 mo"
    delta: "−1.1 mo"
    trend: "down"
    good: true
    hint: "Down is good here — set goodness per metric"
    spark:
      - 17.1

::note{icon="i-lucide-gauge"}
**3つの原料はタイルの実用的なようにします:** 数値、それにスケールを与える比較、および喜んで言う方向。 3番目のタイルを注意してください。CACのペイバックが落ちるのは良いニュースなので、下方矢印は緑色です。 グッドネスは、矢印の方向ではなく、メトリックのプロパティであり、その誤った取得は、赤の壁に良い四半期を回します。
::

## スパークライン

タイルの中の小さなチャート、最後の数の期間を示す。 「これは正常ですか?」と答えます。これは、単一の数字が常に証明され、決して答えられない問題です。

::tip{icon="i-lucide-activity"}
**スパークラインは2番目のチャートよりも価値があります** スペースがほとんどなく、注意を払わないため。 ツイート KPI 112%は少し意味します。; 7ヶ月のために着実に登ったラインの最後に112%は、かなり具体的です。 別のチャートを追加する前にスパークラインを追加します。
::

## テーブル

チャートは形状を表示します。 テーブルはアイデンティティを示します。 回答が「特定のアカウント」の場合、テーブルはフォールバックではなく、正しいウィジェットです。

::field-table
---
dataset: "when to use a table"
grain: "one row per case"
fields:
  - name: "Identity matters"
    type: "use a table"
    role: "key"
    note: "お問い合わせ リスクの10つのアカウントは、名前を必要とします。 10名のバーチャートは未読で、名前は全点です。"
  - name: "Several attributes per row"
    type: "use a table"
    role: "dimension"
    note: "アカウント、セグメント、ALR、利用、所有者。 チャートは2つを表示することができます。テーブルは5つすべてを表示し、読者のスキャンを許可します。"
  - name: "An exception list"
    type: "use a table"
    role: "measure"
    note: "構造で短く、物事がうまく行くと空に - 理想的な状態であり、誰もそれが壊れていると思うので、空のメッセージを必要とします。"
  - name: "Everything, all rows"
    type: "do NOT"
    role: "measure"
    note: "スクロールバー付きの140行は、ダッシュボードではなくエクスポートです。 人々が本物に完全なリストを必要とするならば、それらをダウンロードを与え、ダッシュボードをトップ10に保ちます。"
---
::

::warning{icon="i-lucide-scroll"}
**スクロールバーは指示です。** スクロールせずに誰も取ることができるテーブルはダッシュボードウィジェットであり、データデリバリーメカニズムになります。 それは正当な必要性である - ダッシュボードのデザインセクションは正しくダウンロードをカバー — しかし、それは毎晩6人がチェック画面を占有するべきではありません。
::

## 違いを作るフォーマット

- **整列番号** そのため、数字が並び、大きさが一目瞭然です。
- **一貫した小数** コラムで; 混合された精密は不注意として読み、比較を遅くします。
- **多数の数字を吸収** — $1.42 M ではなく $1,420,000 — タイルに, 誰がそれを必要とするテーブルで完全な精度を維持.
- **どんなことでもソート**ほとんどアルファベットではありません。
