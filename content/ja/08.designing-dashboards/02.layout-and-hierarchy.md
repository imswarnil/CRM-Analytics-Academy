# レイアウトと階層

ダッシュボードのレイアウトは、何が重要なのかについて議論します。 読者は、あなたが1つを作ることを意味しているかどうかそれをフォローします。

## 読書順序

左から右、最下まで、このコースはほとんどの言語で公開され、右から左にアラビアとウルドゥーで、このサイトはミラーリングによって処理されます。 重要な結果は定数です。 **左上隅は画面上の最も貴重な空間であり、見出しを保持する必要があります。**

::warning{icon="i-lucide-move"}
**最も一般的なレイアウトの間違いは、左上にあるフィルターを置くことです。** ビルダーが構成するのは最初のことです。なので、画面上で最初に終わると、ダッシュボードの最も価値のあるスペースは、誰も自分の2番目の訪問まで必要な制御に費やされます。 フィルターは、ストリップとしてトップエッジに沿って、または狭い左のレールに所属しています。現在、未従順であり、回答がすべきコーナーを占有していません。
::

## 近接とは関係を意味します

閉じるウィジェットは関連として読み込まれています。 グループ間のスペースは「これらは異なるものです」と言います。 これは自動的に起こります。そのため、問題は目的にのみ起こります。

## タイトルは、ウィジェットよりも多くの作業を行います

ウィジェットのタイトルは、利用可能な最も安い明快さであり、最も一般的に無駄です。

- **「ルビーヌ」** — どの収入、何期間も、何と比べて?
- **「クローズドウォン売上高、前年度26年度Q3、前年度同四半期」** — 曖昧さ、フォローアップの質問なし、チャートが何を示した会議はありませんでした。

::tip{icon="i-lucide-type"}
**期間、フィルタとタイトルの比較を置きます。** 限度額を含む「ARRによるアカウント数」ではなく「ARRによるトップ10アカウント」。 いくつかの単語を費やし、すべての誤読のクラスを除去する - 誰かが可視バーを要し、合計が間違っている報告を含みます。
::

## 空白のスペースは無駄ではないです

あらゆるエッジにパックされたものよりも、部屋を呼吸するダッシュボード。 スペースを埋める本能は、空のピクセルが未使用であるという感じから来ていますが、リーダーの注意はピクセルではなく、スカースリソースであり、すべての余分なウィジェットはそれの一部を費やしています。
