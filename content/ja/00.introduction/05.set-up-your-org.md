# Orgを設定する

ビルドするには、org が必要です。 このレッスンは、約半時間で作業中のデータセットに何もないし、待機できるすべての説明をスキップします。アクセスセクションは、ライセンス、インテグレーションユーザー、および行レベルのセキュリティを適切にカバーします。

::warning{icon="i-lucide-alert-triangle"}
**通常の開発者版のサインアップは使用しないでください。** 標準的な自由な開発者のorgはします **コメントはありません** 含まれるもの CRM Analytics, 設定からそれを切り替えることはできません — ライセンスは、オーガニではありません. 利用する CRM Analytics 開発者版のpromoの印の下の。 これは、最初の夕方が浪費される単一の最も一般的な方法です。
::

## 2つの権限セット、1つの段落

CRM Analytics アクセスは、プロフィールではなく、管理者ではなく、権限設定によって付与されます。 **CRM Analytics プラス管理者** アプリケーション、データセット、レシピ、ダッシュボード、およびプラットフォームを介してすべてのデータを表示する機能: 作成と管理権限を運ぶ。 **CRM Analytics プラスユーザー** 日帰り利用の許可が必要です。 実際のorgでは、これらは異なる人々に移動し、区別はアクセスセクションの主題全体です。 あなた自身の練習では、両方の、自分自身で、あなたがアクセスセクションがなぜ分割が存在するのかを説明するまで、それを忘れたいです。

::tip{icon="i-lucide-log-out"}
**もし、 Analytics Studio タイルは欠落しています** 許可セットを割り当てた後、ログアウトしてログアウトします。 パーミッションセットの割り当ては、App Launcherがそれらをピックアップする前に、新しいセッションを必要とする場合があります。 これは他の修正よりもはるかに頻繁に解決します。
::

## 「アプリ」とは、混乱しているから

ログイン **アプリケーション** お問い合わせ CRM Analytics 設定を共有するコンテナです。アプリケーションよりもフォルダーに近いです。 データセット、レンズ、ダッシュボードを1つにまとめました。 アプリを共有すると、それが何であるかを共有します。, コラボレーションの探求セクションは、ボタンではなく、アプリのデザインに関するほとんどレッスンです.

あなたのorgは既にサンプルアプリをから含んでいます Salesforceお問い合わせ それらを一人で残します。彼らは有用な参考資料であり、時々それらにレッスンポイントです。 お問い合わせ *お問い合わせ* ビルドは **ナミリオGTM**お問い合わせ

## ローディング CSV: 毎回チェックする

アップロードする CSV 10秒かかります。 2分かかります。ビルドを保存します。 周波数のこの順序で3つの事柄が間違っています:

::field-table
---
dataset: "the upload preview"
grain: "one row per thing to check"
fields:
  - name: "Date fields read as text"
    type: "most common"
    role: "date"
    note: "テキストとして入力された日付は、日付、月別にグループ化、または日付トグルで使用されます。 トレンドラインが必要な瞬間に生き残る理由は、テーブルで完全にうまく見えます。 修正すると、フィールド属性を編集し、ファイルをリロードすることを意味します。"
  - name: "IDs typed as measures"
    type: "common"
    role: "key"
    note: "数値表示識別子は測定として推論されるので、 CRM Analytics それをまとめるために陽気にオファーします - そして、誰かが、最終的に、意志。 アップロード時に寸法に強制します。 AccountId と CampaignId では、常に参加します。"
  - name: "Currency scale"
    type: "expensive when wrong"
    role: "measure"
    note: "任意の量で小数スケールを確認してください。 センチメートルに格納されている値が、数字全体として読み込まれる値は100×で、すべての下流番号はそれを継承し、何も警告しません。 1列の比較 CSV 移動前の目で。"
  - name: "Row count"
    type: "always"
    role: "measure"
    note: "データセット README は、すべてのファイルに対して真の行数をリストします。 ヘッダーの問題を抱えている 1 つで、あなたのものがオフの場合; 負荷が失敗しゼロである場合 Data Manager → モニターは理由を保持します。"
---
::
