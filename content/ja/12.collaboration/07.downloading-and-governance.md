# ダウンロードとガバナンス

作品が1年間生き残っているかどうかを決定する2つの無類のトピック。

## ダウンロード

人々は輸出します。 ダッシュボードが行わないことや、問題ではなく、エクスポートは通常信号です。

::lesson-steps
---
items:
  - title: "彼らがそれで何をするかを尋ねる"
    description: "通常は3つのことの1つです。ダッシュボードの計算は提供しません。リストは、他の人が要求する形式です。 それぞれに異なる修正があり、3つの2つは、ビルドできるものです。"
  - title: "彼らが回復しているものを作る"
    description: "いつも同じピボットが適用される週単位のエクスポートは、まだ構築されていないウィジェットです。 これは、本当に望んでいた機能の単一の最も信頼性の高いソースです。"
  - title: "リストを正しく与える"
    description: "必要性が行を通すことである場合、それは正当です。 ダッシュボードをトップ10に保ち、画面に140のスクロール行を置くのではなく、完全なダウンロードを提供します。"
  - title: "残りを受け入れる"
    description: "銀行、監査人、またはボードパックがファイルを必要とするため、いくつかのエクスポートが存在します。 つまり、目標はゼロエクスポートではなく、ダッシュボードを再作成するゼロエクスポートです。"
---
::

::warning{icon="i-lucide-file-spreadsheet"}
**競争の激しい問題は実質の危険です。** エクスポートされたスプレッドシートは、更新されず、編集され、共有されず、6週間後に修正されたダッシュボードに対して引用されるスナップショットです。 誰が悪い信仰で行動し、両方の数字は実証されています - これは、単純なエラーよりも解決するためにはるかに難しくなります。 ダウンロードは敵ではありません。 誰かの永続的な作業コピーになるダウンロードはあります。
::

Rowレベルのセキュリティは、それがクエリに関係するので、エクスポートに適用されます: 人々は彼らが見ることができるものをダウンロード. それは正しいことであり、それは同じウィジェットをエクスポートする2人が異なるファイル、合法的に生成することができることを意味します。

## ガバナンス、最も小さい有用な形で

小さな組織のガバナンスは、委員会を必要としません。 それは4つの事柄と責任ある人を必要とします。

::field-table
---
dataset: "the minimum that actually works"
grain: "one row per artefact"
fields:
  - name: "An owner per dashboard"
    type: "a name"
    role: "key"
    note: "質問に答える人、定義を維持し、変更を決定します。 このダッシュボードが無事に劣化させることなく、スケジュールのドリフト、上流を意味するフィールド変更、そして誰かがチケットをファイルする前に信頼が長くなります。"
  - name: "Metric definitions"
    type: "one page"
    role: "key"
    note: "フォーミュラ, 穀物, ソース, 既知のトラップ — このコースを通して使用されるメトリックスペック形状. 誰が尋ねる最初の質問である「私の番号とは違う」と答えます。"
  - name: "The security note"
    type: "four lines"
    role: "dimension"
    note: "どのデータセットが述語を運ぶか、それぞれが英語で言うもの、免除されている人、フォールバックが何であるか。 設定としてセキュリティ設定は未読です。"
  - name: "A deprecation habit"
    type: "quarterly"
    role: "measure"
    note: "ダッシュボードを削除またはアーカイブする 誰も開かずに。 わずかに異なる定義を持つ4つのパイプラインダッシュボードは、1つよりも悪くなります。そのため、補正量が解決しない引数を保証します。"
---
::

::tip{icon="i-lucide-trash-2"}
**削除は、ガバナンス活動です。** 未使用のダッシュボードは、将来の引数、メンテナンスコスト、誰かが間違った瞬間に見つけ、信頼するものです。 誰が開いたのかを確認し、それを取り除くことは無類であり、それは誰にとっても最高レベルのガバナンスであり、新しい作業のための承認プロセスよりもはるかに多くなります。
::

## 所有権文

::note{icon="i-lucide-user-check"}
**「このダッシュボードはXによって所有され、定義はここにあり、それは3時00分に毎晩更新されます。」** その文章は、ダッシュボードに添付され、ほとんどのガバナンスです。 誰が実際に持っている唯一の3つの質問である、数字が何を意味するのか、そしてどのように電流であるかを尋ねる答えです。
::
