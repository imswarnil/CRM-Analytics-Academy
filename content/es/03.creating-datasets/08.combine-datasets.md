# Combine Datasets en un Dataset final

Ahora has construido el mismo conjunto de datos de oportunidades de dos maneras, y subiste un externo CSV antes. Tiempo para el movimiento que va a hacer constantemente en proyectos reales: **mezcla dos conjuntos de datos en uno** — Salesforce datos enriquecidos con datos externos y producir un conjunto de datos final y listo para el panel.

Aquí es donde la distinción "baseline vs final dataset" paga. Su conjunto de datos de oportunidades y su CSV son **Base de referencia** bloques de construcción. Ahora los combinamos en un **final** Dataset un dashboard realmente lee.

::tip{icon="i-lucide-recycle"}
No siempre necesitas una receta nueva. Si ya tiene una receta que produce el conjunto de datos de oportunidades, a menudo puede añadir otro nodo sobre ella en lugar de mantener una receta separada. A medida que escala, busque activamente formas de **reducir el número de recetas** mantienes vivo — menos partes móviles, menos cosas para programar y depurar.
::

## Producto del conjunto de datos final

La misma regla que antes: los lazos no hacen nada hasta que usted **añadir un nodo de salida**.

- Haga clic en el plus después de la unión y añadir un **Producto** nodo: este es el conjunto de datos terminado (por ejemplo. *Oportunidades con Cantidad Externa*).
- **Aplicar**Entonces **Guardar y correr**. La receta ejecuta y materializa el conjunto de datos combinados.

Eso es. Te has unido al interior Salesforce datos con datos externos CSV datos en un conjunto de datos enriquecido. Desde aquí se puede capar en transformaciones — columnas computadas, agregaciones, filtros— pero incluso esta mezcla simple es suficiente para alimentar un tablero o una historia.

Programarlos en esa secuencia, o su conjunto de datos "final" servirá silenciosamente los datos de ayer.

## Lo que puedes hacer ahora

Puede crear conjuntos de datos de tres maneras: CSV, Dataset Builder, y recetas - y combinarlas en conjuntos de datos terminados, listos para análisis. Esa es la fundación todo lo demás en CRM Analytics sigue adelante.
