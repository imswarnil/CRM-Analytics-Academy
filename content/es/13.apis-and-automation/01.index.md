## Lo que esta sección cubrirá

Todo en CRM Analytics es accesible sobre un API — lo que hace posible, los cuatro trabajos valen la pena automatizar, y los que deben permanecer manuales.

## Enseñanzas planificadas

- **Por qué automatizar** - Todo en CRM Analytics es accesible sobre un API — lo que hace posible, los cuatro trabajos valen la pena automatizar, y los que deben permanecer manuales.
- **El REST API** — Authenticating, las familias de endpoint que importan para el análisis, la versión y los límites que vale la pena diseñar alrededor antes de escribir cualquier cosa.
- **SAQL desde el código** — Enviar una consulta sobre API y leer lo que vuelve — más las cuatro razones legítimas un número de un script difiere del mismo número en el panel de control.
- **Cargando datos** - Los datos externos API: declarar, subir en partes, completar la señal — el patrón de tres pasos, el archivo de metadatos que decide sus tipos de campo, y el fracaso que todo el mundo golpea una vez.
- **Python end** — Un camino trabajado en Python: autenticar, declarar una carga, empujar los datos de la Academia en partes, completar la señal, verificar el recuento de filas y consultar el resultado.
- **Automatización & despliegue** — Programación, credenciales, manejo de fallas y uso de metadatos exportados para dar a los paneles el historial de cambio que el producto no proporciona.
- **Preguntas de entrevista** - El API y preguntas de automatización, con respuestas modelo, y el juicio operativo que realmente están probando.
- **Gráficos** — Ocho preguntas sobre autenticación, la consulta y las API de datos externos, operaciones de carga, programación y cambio de historia.
