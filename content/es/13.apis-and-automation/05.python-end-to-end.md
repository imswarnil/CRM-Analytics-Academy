# Python End to End

La forma de un cargador real, en el orden que usted lo escribiría. La biblioteca específica importa menos que la secuencia - las mismas cinco etapas aplican si usted utiliza una Salesforce SDK, un cliente REST, o solicitudes simples.

## Las cinco etapas

::lesson-steps
---
items:
  - title: "Autentizar como usuario de integración"
    description: "Credenciales de variables ambientales, nunca del archivo. Obtenga un token, y envuelva la llamada para que un refrigerio de funcionamiento medio en lugar de morir."
  - title: "Lea y prepare los datos"
    description: "Cargar la fuente —la web_sessions.csv de la Academia, o una consulta de almacén— y configurarla para que coincida con los metadatos que está a punto de declarar. Nombres de columna, tipos y orden establecidos aquí, no improvisados durante la carga."
  - title: "Declarar el trabajo"
    description: "Nombre, operación y metadatos de campo. Este es el archivo que decide si sus fechas son fechas; mantenerlo en el repositorio junto al script por lo que es revisable."
  - title: "Subir en partes numeradas y completar la señal"
    description: "Recoge las filas, envía cada parte con su número, y luego establece el trabajo para completar. La señal de terminación es el paso que se olvida, y olvidar que no produce ningún error y ningún conjunto de datos."
  - title: "Verificar, luego reportar"
    description: "Lea el recuento de la fila del dataset y compártelo con lo que envió. Arregla ambos. Un cargador que no verifica es un cargador que falla en silencio."
---
::

## El esqueleto

```python
import os, csv, json, math, requests

BASE   = os.environ["SF_INSTANCE_URL"]        # from the secret store
TOKEN  = get_access_token()                    # refreshable
HEAD   = {"Authorization": f"Bearer {TOKEN}"}
CHUNK  = 10_000                                # rows per part

def declare(dataset, operation, metadata):
    """Create the upload job. Nothing is sent yet."""
    body = {"Format": "Csv", "EdgemartAlias": dataset,
            "Operation": operation, "Action": "None",
            "MetadataJson": metadata}
    r = requests.post(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData",
                      headers=HEAD, json=body, timeout=60)
    r.raise_for_status()
    return r.json()["id"]

def upload_parts(job_id, rows, header):
    """Send the rows as numbered parts. Part numbers start at 1."""
    for i in range(0, len(rows), CHUNK):
        part = i // CHUNK + 1
        payload = encode_csv(header, rows[i:i + CHUNK])
        post_part(job_id, part, payload)

def complete(job_id):
    """The step that is forgotten. Until this runs, nothing is processed."""
    requests.patch(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData/{job_id}",
                   headers=HEAD, json={"Action": "Process"}, timeout=60).raise_for_status()
```

::note{icon="i-lucide-code"}
**Los caminos de punto final y el esquema de metadatos exacto cambian entre liberaciones** — compruebe la documentación actual para su API versión en lugar de copiar un camino de cualquier blog, incluyendo este. Lo que no cambia es la secuencia: declarar, partes, completar, verificar. Aprende la forma y busca los detalles.
::

## La verificación es la parte que gana su mantenimiento

```python
expected = len(rows)
actual   = dataset_row_count(dataset)          # read back from metadata
if actual != expected:
    raise SystemExit(f"load mismatch: sent {expected}, dataset holds {actual}")
```

::tip{icon="i-lucide-shield-check"}
**Fail fuerte en un desajuste en lugar de registrar una advertencia.** Un trabajo que sale de cero después de cargar el 80% de las filas produce un dashboard que es silenciosamente equivocado durante todo el tiempo que lleva a alguien a darse cuenta - que, en un número que nadie tiene antes, puede ser meses. Un código de salida es leído por el agendador; una advertencia en un registro es leída por nadie.
::

## Querying the result back

El mismo período de sesiones puede celebrarse SAQL, lo que hace que un paso de reconciliación sea natural al final de una carga: tire del total del conjunto de datos ahora reporta y compare contra la propia figura del sistema fuente. Ese es el hábito de respuesta clave de la sección API automatizada — y es la cosa más valiosa que un cargador puede hacer más allá de la carga.

## Corriendo.

Lo que sea que lo ejecute — cron, un programa de CI, un orquestador— necesita tres cosas: el horario, las credenciales de una tienda secreta, y en algún lugar el fracaso es *visto*. Un trabajo que falla en un directorio de registros que nadie abre es un trabajo que no está funcionando, y te enteras semanas después.
