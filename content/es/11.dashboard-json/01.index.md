## Lo que esta sección cubrirá

Cada panel es un JSON documento debajo. Lo que te compra — ediciones a granel, diffs, revisión, reutilización— y las cuatro situaciones en las que la apertura es el movimiento correcto en lugar de mostrar.

## Enseñanzas planificadas

- **Cuándo abrirla** - Cada panel es un JSON documento debajo. Lo que te compra — ediciones a granel, diffs, revisión, reutilización— y las cuatro situaciones en las que la apertura es el movimiento correcto en lugar de mostrar.
- **Anatomía** — Las cuatro partes de alto nivel de un documento de dashboard — estado, pasos, widgets y diseños — cómo se refieren entre sí, y cómo encontrar algo en un archivo que no escribió.
- **Pasos & consultas** — La capa de datos de un documento dashboard: qué paso contiene, la diferencia entre una consulta clicada y cruda SAQL, pasos estáticos y consolidando consultas para el tiempo de carga.
- **Widgets & diseños** — Lo que se dibuja contra donde se sienta — por qué existe la separación, los diseños sensibles que causan la mayoría de las sorpresas, y las propiedades widget que vale la pena editar como texto.
- **Edición segura** — Backups, validation, the round-trip test and diff-based review — how to make dashboard changes reversible and reviewable in a product that has no real version control.
- **Preguntas de entrevista** — Lo que un entrevistador está comprobando cuando preguntan si usted ha trabajado con dashboard JSON - con respuestas modelo.
- **Gráficos** — Ocho preguntas sobre la estructura de documentos, pasos, diseños, ediciones a granel y edición segura.
