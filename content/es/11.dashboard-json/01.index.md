# Cuándo abrir el JSON

A CRM Analytics El tablero es un JSON documento: widgets, diseños, consultas y vinculantes, todo como texto. El constructor lo escribe para usted, y ocasionalmente el texto es la mejor herramienta.

::note{icon="i-lucide-file-json"}
**Este no es el nivel avanzado del edificio de dashboard.** La mayoría de los tableros nunca deben tener sus JSON abierto, y alcanzar para que haga algo que el constructor hace perfectamente bien es una manera de producir un dashboard que nadie más puede mantener. Gana su lugar para el trabajo a granel, para revisión, y para el puñado de cosas que la interfaz no expone.
::

## Las cuatro buenas razones

  - name: "Review and diff"

  - name: "Reuse and templating"

    type: "occasional"

## Las dos malas razones

::warning{icon="i-lucide-hand"}
**No uso JSON hacer el trabajo ordinario más rápido, y no utilizarlo para ser inteligente.** Un dashboard de mano-editado en una configuración que el constructor no puede ida y vuelta es un dashboard sólo usted puede cambiar, que es el mismo fracaso que un over-bound. Si el constructor puede expresarlo, que el constructor lo exprese — el JSON es por lo que el constructor no puede hacer, y por ver lo que hizo.
::
