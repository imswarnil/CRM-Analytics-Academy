No. Solicita autenticar como usuario y que los permisos del usuario, compartir y nivel de fila de seguridad se aplican exactamente como en la interfaz. Vale la pena decir claramente porque 'usar API' ocasionalmente se ofrece como una solución para un problema de acceso, y no es uno. También es la primera cosa que comprobé cuando el número de un script difiere de un dashboard: generalmente se ejecutan como diferentes usuarios y ambos números son correctos.
