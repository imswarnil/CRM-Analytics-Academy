# 共享盘

那个 **份额** 动作坐落在每一个仪表板的右上角,这是大多数人首先发现的特征——通常因为他们想要向管理者发送截图. 它的作用远不止于此。

## 准许进入

共享对话框的第一个标签是关于 **谁能打开仪表板**。 。 。 你选一个用户,组,或角色, 并给他们一个水平的访问—— 典型的 **查看器** 为商业观众, **编辑器** 或 **经理** 对于需要改变或重新分享它的人。

值得记住:仪表板访问是 *没有* 和数据访问一样 共享仪表盘让某人打开页面;他们所看到的仍然受数据集共享遗产和任何设定的安全前提的支配. 两个人可以一样打开 URL 并合法地看到不同的数字。

::tip{icon="i-lucide-shield-check"}
如果同事报告共享的仪表板是"空的",在检查共享设置前先检查行级安全. 空的仪表板通常是指访问页面但不访问行.
::

## 贴给聊天者

共享对话框可以将仪表板直接推向一个 **闲聊** feed——你自己的,同事的,或者一个团体的. 你输入一个消息,选择目的地,并张贴。

这确实有用,而且真正没有得到充分利用。 在销售-ops Chatter 集团中宣布的带有上下文句子的仪表板("新管道健康仪表板,晚上6点刷新")被打开. 一个被作为无上下文链接的电子邮件是没有的 。

## 那个 URL 还有为什么它比看起来聪明

共享对话框给出了一个 **URL** 你可以拷贝。 重要的细节是 URL 不只是指向仪表板——它编码 **您目前所看到的状态**。 。 。 。

这解决了分析对话中最常见的摩擦:"看Q3中的西部地区"变成三个后续信息,关于哪个过滤器可以点击. 代为送州.

## 下载为图像

那个 **图像** 选项使仪表板成为您可以掉入甲板、文档或电子邮件的图片。 它捕捉到目前过滤过的仪表板,因此同样的"先设置状态"习惯适用.

这是一个快照,虽然——当你输出它的时候,它就不再是直播了。 对于任何反复出现,a **订阅** (后来在本节)是一个比每个星期一的手工图像更好的答案.

## 打印

**打印** 是人们错过的选项。 它不只是在屏幕布局上点燃浏览器的打印对话框—— CRM Analytics 首先把仪表板重排成一个方便打印的安排, 所以部件不剪在页面边框上, 整件事在纸上很贴切。

从那里选择 **另存为 PDF** 在浏览器的打印对话框中,您有一个可共享的文档。 对于希望每月PDF在收件箱中的高管,这是订阅自动化的手动版本.

::tip{icon="i-lucide-lightbulb"}
如果你知道你的仪表板会被打印, 设计时会考虑打印:非常宽的网格和高高的滚动表翻译不好。 一页紧凑 KPI 瓷砖和几张图表印得很漂亮
::
