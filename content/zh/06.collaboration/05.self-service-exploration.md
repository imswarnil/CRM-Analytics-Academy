# 自我服务探索

这是每个仪表板设计师都知道的场景 你运送一个仪表板。 在一周内,你收到电子邮件: *“这太棒了——你能添加一个按产品而不是地区细分的版本吗?”* 你加起来。 下礼拜: *"... 一个主人?"*

**探索** 是结束队列的特性。

## 探索会做什么

每个部件的动作菜单包括 **探索**。 。 。 选择它需要部件的查询——并应用仪表板的当前过滤器和选择,然后以一个 **镜头**: 完整的探索界面,与分组,度量,和图表类型的控制被曝光.

从那里,用户不再看别人设计的图片. 他们正在等待询问。

::lesson-steps
---
items:
  - title: "打开部件上的探索"
    description: "部件的当前查询和仪表板的活性滤波器也随之而来,所以起点正是他们所看到的."
  - title: "换个问题"
    description: "将分组从区域换到产品,增加第二个分组,切换度量,改变图表类型——所有点击镜头."
  - title: "读一下答案"
    description: "他们寄给你的这个问题 在30秒内就被他们回答了"
  - title: "留着作为自己的镜头"
    description: "如果这是他们想要的切片, 他们保存在自己的应用程序中的镜头。 它成为他们的, 不碰你的仪表板。"
---
::

最后一步是安静的胜利。 仪表板继续专注于你设计的故事;一次性的变体作为属于需要的人的个人镜头进行直播. 你的仪表板不会慢慢膨胀成40张图 因为有40人要求一张

::tip{icon="i-lucide-users"}
探索(Explore)是在用户培训课中演示的最高杠杆功能. 大多数商业用户不知道他们的执照让他们自己建立分析——他们假设每个新观点都是一张请求票. 向他们展示这个动作会改变他们使用平台的方式.
::

## 当你应该关闭它

探索并不总是正确的选择。 禁用它的合理理由 :

::lesson-cards
---
columns: 2
items:
  - title: "管理仪表板"
    icon: "i-lucide-crown"
    description: "一个板级仪表板 每一个数字都是故意设定的 让一个观众重新组合,这会引起对衡量标准的错误解释,而衡量标准仅仅是指在上下文中的含义。"
  - title: "嵌入和移动表面"
    icon: "i-lucide-smartphone"
    description: "嵌入在闪电唱片页面或为移动而紧凑的仪表板——将一个用户扔到一个完整的镜头界面中,那里有罐头,并且经常在视觉上断裂."
---
::

请注意,取舍是真正的取舍。 关闭 Explore 保护叙述, 但也让你回到那些邮件的接收端。 除非有原因 否则你无法打开它

## 如何关掉

两个开关都是部件 **属性**,设置在带有所选部件的仪表板编辑器中:

::lesson-cards
---
columns: 2
items:
  - title: "显示部件动作"
    icon: "i-lucide-list-x"
    description: "主开关. 取消检查, 部件的整个动作菜单就会消失—— 没有探索, 没有共享, 没有设定通知, 没有注释 。"
  - title: "显示探索动作"
    icon: "i-lucide-search-x"
    description: "目标开关。 将动作菜单留在原位,但删除探索选项,因此用户在无法重新组合查询的情况下继续共享和下载."
---
::

达到 **显示探索动作** 先说 关闭部件动作完全是一个钝器——它同时带走通知,说明,下载,用户很少将缺失的菜单与有意的设计决定联系起来. 他们只是假设仪表板坏了

探索让用户自行构建数据剪切. 接下来的教训包括他们如何保持和分享 *您的电话* 仪表板,完全没有留下它: **视图**。 。 。 。
