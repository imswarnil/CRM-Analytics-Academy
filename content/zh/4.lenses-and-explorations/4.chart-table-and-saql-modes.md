## 图表模式

点击图表类型图标即可获取 **图表拾取器**: 栏,列,叠,线,时间线,甜甜圈,漏斗,散,热图,地理图,还有不少. picker grays 输出您当前查询不能支持的类型——一个甜甜圈需要一个分组,一个散点需要两个度量,这是关于您询问缺失的有用提示.

旁边是 **格式化/ 属性面板**也值得实时投入 这就是你设定:

- **轴标签和范围** ——包括强迫一个轴从零开始,这阻止了一个条形图对一个差的大小进行躺着.
- **图例** 位置,或当图表不言自明时关闭。
- **值标签** 在栏杆上,所以读者不必盯着轴线看。
- **数字格式** ——简称(1.2M),小数位,前缀.
- **排序顺序**, (中文). **颜色**和参考线。

::tip{icon="i-lucide-lightbulb"}
格式化应用在镜头中随它而行。 把图表找对了 *这里*在你把它剪到仪表盘之前, 否则你会在使用它的每一条仪表盘内重做同样的格式。
::

## 表格模式

切换到表格图标,你得到三种不同的表格类型。 它们是真正不同的工具,而不是一个主题上的变化。

### 数值表

那个 **数值表** 显示 **原始行数** ——完全没有汇总. 这是您进入数字背后实际记录的窗口,是产品中唯一最有用的调试工具. 总的外观翻了一番? 打开一个值表,过滤到一个账户,然后数行。 你通常会立刻发现粉丝的加入

开着一套 **默认列** 从数据集的元数据中选择(您可以改变这个数据——这是下一个课). 从左边的字段列表中添加或删除列。

### 比较表格

那个 **比较表** 是合并的、电子表格式的视图:左边的组合,横跨顶部的计量。 它的超级力量是 **公式编辑器** -你可以加一个 **导出列** 从表中其他各栏计算。

这就是你如何构建的东西 单凭询问不会给你:

- **赢率** ——按总金额除以赢金额,格式为百分比.
- **与目标的差异** 实际减配额。
- **占总数的百分比** ——一栏对总计值.
- **每组平均数** ——一种措施除以另一种措施.

每个派生的列获得自己的公式,自己的数字格式,本身也可以被后面的列引用. 比较表是透镜停止作为图表开始进行分析的地方.

### 关键表格

那个 **枢轴表** 跨越两个维度——一个在行下,一个在列上——在单元格中标量. 沿边向下, 上方为四分之一, 中间为总和。 这是经典的跨塔布,每当有人说"我想要它像Excel"时,就是正确的答案.

## 高级( A)SAQL模式

最后一个图标打开 **高级编辑器**,显示 **SAQL** 镜头一直在产生。 它的读法大致是这样:

```sql
q = load "Opportunities";
q = filter q by 'StageName' == "Closed Won";
q = group q by 'Industry';
q = foreach q generate 'Industry' as 'Industry', sum('Amount') as 'sum_Amount';
q = order q by 'sum_Amount' desc;
q = limit q 10;
```

每个段落映射到您点击的东西: `filter` 你的过滤棒, `group` 你的酒吧/组合, `foreach ... generate` 你的措施, `order` 和 `limit` 是您的类型和查询限制。

你可以直接编辑和运行. 解锁点点点点点点点点点点点点点点无法表达的事物 ——多步骤查询, `cogroup` 合并来自同一数据集的两个流,用于运行总计和排序的窗口函数, `case` 用于自定义桶的语句和计算 `foreach`。 。 。 。

::tip{icon="i-lucide-triangle-alert"}
编辑 SAQL 是一个 **单向门** 那个镜头 一旦你亲手编辑了查询,视觉探险家就再也回不来了,你继续工作 SAQL 从此而起. 先点击,尽量靠近, *接下来* 倒进编辑室最后一英里。
::
