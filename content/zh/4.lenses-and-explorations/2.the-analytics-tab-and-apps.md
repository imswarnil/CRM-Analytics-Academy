# 分析标签和应用程序

在你能探索任何东西之前 两件家务报酬十倍以上: **使用户进入 Analytics Studio 没有摩擦**,以及 **把你的工作放在一个可以分享的地方**。 。 。 。

亦无光泽. 两者都是分析项目的人使用与静静死亡的区别.

## 让用户进入 Analytics Studio

从盒子里出来,唯一可靠的方法 Analytics Studio 这是 **应用程序启动器** ——点击华夫饼,键入"分析",打开 Analytics Studio。 。 。 这有效,但是它让用户 退出了他们工作的闪电应用。 销售代表生活在销售软件中并不想离开它,大多数不会去打猎.

固定在水面上 **分析** 作为他们已经使用的应用程序内的标签。

点击它 Analytics Studio 负载 **内部** 闪电体验 — 相同的主页, 相同的创建按钮, 一切相同 。 用户从不离开应用程序.

::tip{icon="i-lucide-info"}
这是一个应用程序 **导航** 更改,而不是权限更改。 添加标签不会让任何人访问分析。 用户仍然需要适当的 CRM Analytics 他们仍然只能看到与他们共享的应用程序和资产。
::

## Apps:你建造的一切的容器

内部 Analytics Studio,一个 **应用** 是文件夹。 它拥有仪表板、镜片、数据集和 Einstein Discovery 故事 故事 故事 故事 每一个你创造生命的资产 在一个完全的应用程序。

默认情况下,你的工作在 **我的私人应用程序** 一个没人能看见的私人空间 甚至一个管理员 都不假冒你 这是一个很好的原型地点,但当你想要另一个人看到你的作品时,你需要一个真正的应用.

## 共享:为什么应用软件很重要

这是人们低估的部分。 **App访问是访问模式.** 你不能单独共享一个仪表盘、一个镜头或一个数据集。 **应用** 它包含它们, 和赠款流向所有内部。

打开应用程序并单击 **份额**。 。 。 。 您可以授权访问:

::lesson-cards

  - title: "用户"

  - title: "组"
    icon: "i-lucide-users"
    description: "Salesforce 公共团体。 实用的默认:在Setup管理一次会员资格,每个应用程序都尊重它."
  - title: "角色"
    icon: "i-lucide-network"
    description: "Salesforce 角色,可选地包括下属——在访问时应该遵循您所在的汇报层级."

每个接受者都得到三个等级中的一个: **查看器** (可以打开和互动), **编辑器** (可以创建和改变资产),或 **经理** (也可以分享应用并删除).

::tip{icon="i-lucide-shield"}
应用共享控制 *用户可以打开的资产*。 。 。 。 没错 **没有** 控制 *在数据集内看到哪个行* ——这是行级安全,通过分享遗产或数据集上的安全前提单独处理. 两个不同的问题,两个不同的工具。 不要依赖应用程序共享来隐藏敏感记录.
::

实用习惯:创建应用程序 **在此之前** 你开始建设,而不是之后。 从开始将一个仪表板保存到正确的应用程序就是一击. 稍后把一堆资产从你的私人应用程序中搬走 并且重新定位所有东西 是一个下午
