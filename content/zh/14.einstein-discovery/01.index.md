# 预测及其原因

Einstein Discovery 使用数据集和结果列,查找与结果相关的内容,并可以将结果作为模型进行部署,将分数记录和写回 Salesforce。 。 。 。

::note{icon="i-lucide-split"}
**一个故事就是调查;一个模型就是承诺.** 一个故事告诉你什么与赢得交易有关,在什么方向和多么强烈——它本身有用,并且没有产生分数。 一个模型拿了这个并得分了现场记录,这意味着它开始影响人们的行为. 运行一个故事和部署一个模型之间的空隙是大多数判断所生存的地方.
::

## 决定通过的规则

::warning{icon="i-lucide-scale"}
**一个没有理由的分数在一个月内就会被忽视.** "这个机会有23%的可能关闭"告诉一个代表,他们无法采取行动,所以他们不再寻找. " ... 和三个因素拉下来 没有经济买家确定, 从上次活动47天, 折扣超过30%"是一个待办事项列表。 Einstein Discovery 产生两者。 只部署人数是这种能力抵达的最常见方式,受到不信任,被悄悄关闭。
::
