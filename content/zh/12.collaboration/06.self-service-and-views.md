# 自我服务和视图

自助服务不是您所允许的功能。 这是一套数据集拥有或没有的财产,几乎完全由早在有人探索任何东西之前所做的工作决定。

  - name: "Sensible default aggregations"

## 已保存视图

页:1 **视图** 记得一个仪表板的状态——过滤器,选择器,日期范围——所以一位区域主任返回他们的地区,而不每天早上重新点击.

::tip{icon="i-lucide-bookmark"}
**观点是本节静静的胜利.** 每天早上三点是人们默默付出的代价,慢慢地怨恨. 保存的视图可以移除它,不花费任何费用,在物质上可以提高一个仪表板的打开频率. 当你把一个仪表盘交给一个 切片总是一样的人时,你明确建议一个—— 大多数人不会自己发现这个特征。
::

## 诚实的限制

    subtitle: "New questions needing new data"
    icon: "i-lucide-x"
    pros:
      - "Nothing — this is a build request wearing a self-service costume"
    cons:
      - "The data is not in the dataset, so no amount of clicking finds it"
      - "Promising otherwise sets people up to fail and then blame themselves"
    verdict: "Say plainly that it needs a build."

::warning{icon="i-lucide-message-square-x"}
**别把它卖过头了** "你可以自己回答任何问题"是不真实的,20分钟没有找到一个从未同步的球场的人得出结论,他们在工具上表现不好. 说出数据集所覆盖的和它所没有的——人们对于一个已说明的边界是完全合理的,并且被一个未说明的边界所压抑.
::
