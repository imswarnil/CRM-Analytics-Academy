# 弹夹和宾宁

桶将连续的计量转换成类别:交易大小变为小、中、大;使用变为 处于危险、健康及超龄状态;保有权进入群体。 这是一个小的变形节点,也是分歧的一大根源。

## 边界是商业决定

::note{icon="i-lucide-ruler"}
**范围甚至有三分之一是算术上假装是判断.** 乐队界限应该是某人行为不同的地方. 学院使用率低于55%的波段是存在的,因为这就是一个CSM接听电话的地方;超105%的波段是存在的,因为这是更新对话改变形状的地方. 两者都来自企业的运作方式,而不是将范围分成三个,两者都写在衡量定义旁边。
::

如果没有人能告诉你边界在哪里,那就是信息:该措施可能还不能执行,而用桶装意味着不存在的确定性。

## 有一次,在食谱里

::warning{icon="i-lucide-copy"}
**每个仪表板上定义的桶在一年内成为若干定义.** "Large deal"是指销售仪表板上超过100k,财务版上超过250k,两者都是可辩驳的,分歧的浮出在会议而非审查中. 食谱中的变形节点产生一个每个仪表板继承的带状柱——当业务改变一个阈值时,它会在一个地方变化.
::

例外的是,一个乐队真正属于一个屏幕——一个探索性的分裂者正在尝试。 这可以生活在一个询问中,它不应该生存到共同的东西中。

## 引起争论的边缘案例

::field-table
---
dataset: "bucketing decisions to write down"
grain: "one row per decision"
fields:
  - name: "Which side is the boundary on?"
    type: "inclusive or exclusive"
    role: "key"
    note: "55%的人处于危险之中还是健康? 最终有人会降落在边界上问,通常是在别人面前问. 决定,把它写在定义中, 和一致的每个带。"
  - name: "Where do nulls go?"
    type: "the fourth band"
    role: "dimension"
    note: "无值的记录不是零,也不是平均值. 给它一个明确的\"未知的\"乐队,而不是让它掉进公式恰好产生的哪个乐队. 它经常是最有趣的乐队。"
  - name: "Are the bands stable over time?"
    type: "fixed vs relative"
    role: "date"
    note: "固定边界可以比较时间段。 以夸蒂尔为基础的乐队总是每个四分之一,因此乐队可以生长或收缩,而没有任何真正的变化——这使得时间比较变得毫无意义. 除非你是故意要亲戚,否则最好修好"
  - name: "Do they cover everything?"
    type: "no gaps"
    role: "measure"
    note: "105分时停放的乐队 将每个账户都放在上面 上下带应该开放,否则图表会悄悄地失去行."

## 命名乐队

地名的读数远多于边界。 "冒险"告诉别人该怎么做;"一号班"让他们寻找他们找不到的定义.

::tip{icon="i-lucide-tag"}
**动作名称,并在定义中保留数字.** "消费不足(<55%)"在传说中是理想的:名字带有意义,括号带有精度,没有人可以问出门槛是什么. 唯一要避免的就是一个隐含着数据不支持的判断力的名称——"Faling"而不是"under-clusing"会引来关于账户的争论,而不是数字.
::

## 排序带宽列

一个带宽的栏目是文字,因此默认情况下它按字母排序——它只在"过度"之前将"处于危险中"置于"健康"之前,并且完全用"10-20"和"100+"等数字名称打破.

::note{icon="i-lucide-arrow-down-up"}
**在食谱中给乐队排序**,通常为数字伴行。 否则,在它们身上建造的每一个图都需要手定的顺序,其中之一最终将不会是——产生一个其带按字母顺序排列的分布图,其读法为噪音而不是形状.
::
