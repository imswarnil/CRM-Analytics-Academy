# 缺少值

无效手段 *我们不知道*。 。 。 。 一个零表示 *我们知道,它不是*。 。 。 每一次汇总都对他们有不同的对待,混淆它们是产生错误数字最安静的方法之一.

## 每个集合都做什么

::field-table
---
dataset: "nulls in aggregation"
grain: "one row per function"
fields:
  - name: "Sum"
    type: "skips them"
    role: "measure"
    note: "返回有值的行总数。 超过40%的柱子是空的,总计占数据总数的60%,无话可说."
  - name: "Average"
    type: "skips them in both parts"
    role: "measure"
    note: "具有价值的行的平均值——通常是你想要的,很少是检查的. 如果你打算将空白数计为零,那么与所有行的平均值有实质上的不同。"
  - name: "Count"
    type: "depends which count"
    role: "key"
    note: "行数包括空白;列的单独数不包含。 在一个稀疏的领域,两者差别很大,两者都不对。"
  - name: "Grouping"
    type: "makes a null bucket"
    role: "dimension"
    note: "诚实,经常是图上最有趣的桶。 标签它\"未知\"而不是隐藏它——\"未签名\"是一个真正的类别,通常是一个工作项目."
---
::

## 填补空白是索赔

::warning{icon="i-lucide-pencil"}
**每个填满都填满了** 没有。 平均数为典型。 先前的价值没有变化。 在某些情况下,每个都是合理的,每个都是你代表数据所做的陈述,因此它属于参数定义,而不是埋在一个公式节点中. 问题在于: *如果这个填满是错的,什么休息?* 用零来填充缺失的金额会拖动每个平均值;用"恶"来填充会发明一个从未存在的交易.
::

## 当填充合法时

::compare-cols
---
items:
  - title: "填充"
    subtitle: "The gap has a known meaning"
    icon: "i-lucide-check"
    pros:
      - "A month with no rows for a product that existed: zero is the true value"
      - "A carried-forward status in a snapshot, where no change genuinely means unchanged"
      - "A default that the source system would have applied anyway"
    cons:
      - "Needs writing down, or the next person cannot tell filled from real"
    verdict: "Fine, documented, and preferably in a flagged column."
  - title: "不填满"
    subtitle: "The gap is genuine ignorance"
    icon: "i-lucide-x"
    pros:
      - "Nulls propagate honestly — the number excludes what you do not know"
    cons:
      - "Charts show gaps, which look like defects and generate questions"
      - "Somebody downstream may fill it anyway, worse"
    verdict: "Leave it null and label the gap on the chart."
---
::

::tip{icon="i-lucide-flag"}
**当你填满时,请保留一个旗柱 说你做到了。** 布尔 `AmountWasImputed` 成本不高,意味着任何人都可以把填充的行排除在不应包括这些行的分析之外,而且一年后可以知道哪些行是真实的。 没有旗帜的填充会破坏它曾经缺失的信息.
::

## 预测性填充

从其他栏中估计缺失价值——从片段和产品中推断的数额,从舞台和年龄中推断的接近日期——有时是合理的,而且总是比常数更大的索赔要求。

::warning{icon="i-lucide-brain"}
**如果你预测一个值,然后分析它,你会发现你预测的模式。** 片段的减值,然后按片段报告收入,你看到的片段差异部分是你自己对你的回顾的推算. 继续从任何分析中推断出价值 并标注它们,以便其他人也能。
::

## 作为信号的缺失

有时空白是数据集中信息最丰富的一栏.

::note{icon="i-lucide-lightbulb"}
**在纳米利奥, `EconomicBuyerIdentified` 空白与损失相关** 这并不是因为空白会造成损失,而是因为没有参与的代表不填字。 这使得“它是空白的”真正具有预测性和完全不可诉性:让一个代表填充这个领域不会造成一个经济买家。 这是最常见的方法之一 一个好的模型 产生的建议 没有改变什么, Einstein Discovery 区域返回它。
::

## 反应率案例

纳米利奥的CSAT覆盖了大约42%的结案案件. 平均数字是准确的,回答的问题比其标签上的说法要窄:它描述了选择回应的人,对高兴和愤怒的人的反应。

修行非妄说. 它除了评分之外,还在公布答复率——没有评分的满意数字是广告而不是衡量。
