# 公式和计算字段

两个问题决定一个计算存在的地方: **是每行还是合并后**,以及 **属于公司还是这个屏幕**。 。 。 。

## 每行,或汇总后

公式节点计算 **每行数**在任何组合之前。 对于从同一行的数值中算出的任何数字,都是正确的:

- `NetAmount = ListAmount - DiscountAmount`
- `DaysToClose = CloseDate - CreatedDate`
- `IsEnterprise = Segment == "Enterprise"`

任何首先需要总数的东西都是错的。 分析中最常见的错误答案 完全就在这里:

::warning{icon="i-lucide-divide"}
**比率平均数不是总数比率。** 纳米利奥的报价每笔交易都带有折扣. 与2000美元交易额完全相同 所以少数打低价的小交易 将"平均折扣"拖到公司从未真正打折扣的地方 人们想要的数是总折扣除以总清单值——计算 *之后* 汇总,从不作为每行列的平均值.
::

同样的陷阱还穿其他衣服:代表的平均换算率、各阶层的平均赢率、帐户的平均使用率。 每个单位默默地给予每个单位同等的权重,当业务几乎总是意味着按大小加权.

## 击球

一个将连续的节点桶转换成命名的频段:处理大小变为小/中/大,使用到消耗不足/健康/在超龄时,使用权变为组别.

::tip{icon="i-lucide-ruler"}
**一次,在食谱, 并命名带 在数据集。** 如果每个仪表板桶都用自己的方法,那么一个"大"交易就意味着销售仪表板上的一个东西,另一个则意味着财务上的一个东西,分歧的出现是在一个会议而不是在审查中. 连带界限是一个值得在衡量定义之外写下来的商业决定 — — 包括尴尬的界限,比如使用百分之五十五是否处于危险之中或健康。
::

## 神经病,为什么它们比看起来更重要

无效不是零。 这是"我们不知道", 两者的行为在每一个汇总:

- **总和** 忽略无效。 超过40%的栏数等于超过60%的数据,未作评论。
- **平均数** 忽略分母中的无值,所以平均值是有值的行的平均值——这通常是你想要的,很少是检查的.
- **计数** 区分行数和非null值数,混淆它们是一个常见的静态错误.

::warning{icon="i-lucide-circle-slash"}
**纳米利奥的CSAT调查就是实例。** 只有大约42%的结案案件进行了调查。 因此,平均CSAT描述的是: *选择响应*而不是顾客 和被调查者 向快乐和愤怒的。 号码没有错;它回答的问题比它的标签要求更窄. 第10节用旁边永久显示的答复率来构建它,因为没有答复率的满意分是广告而不是衡量。
::
