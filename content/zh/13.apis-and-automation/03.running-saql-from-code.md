## 阅读回复

结果是回来 JSON:一组记录,每个列名图到值. 有两件事要处理 而不是假设:

- **列名来自查询 `generate` 别名**,所以将一个别名重新命名为响应中的密钥并打破任何消耗它的东西. 刻意把名字固定下来,保持稳定
- **类型是数据集所说的。** 日期到达数据集的表示,而不是作为您语言的日期对象,数字可能会作为字符串到达,取决于客户端. 明确分析而不是信任形状。

::tip{icon="i-lucide-copy"}
**从仪表板本身的查询开始,而不是从头写一个.** 复制 SAQL ,然后添加所选择的过滤器。 调和两个独立写的查询比改编一个困难得多,而且大多数时候这种差异是无人记得的过滤器.
::

## 和解的决定因素

::warning{icon="i-lucide-calendar-clock"}
**和解工作必须确定日期。** 将滚动窗口与源系统进行比较,每一次时钟移动都会产生差异,你会花一个下午时间来调查一个完全属于两个查询运行时的异象. 绝对开始和结束,一次在工作的顶端计算,用于双方.
::

## 将查询保存在仓库中

运行在时间表上的查询是代码 。 保留在寄存器中与工作,不粘贴在排程器的文本框中,不能对其进行审查,散发或解释——当它产生的数字被质疑时,没有人会找到它.
