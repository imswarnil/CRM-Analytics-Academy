## 本节将涵盖

里面的东西 CRM Analytics 可达于 API ——这可以做到的,是四个值得自动化的工作,以及应该保持手动的工作.

## 计划的经验教训

- **为什么要自动化** - 所有东西都在里面 CRM Analytics 可达于 API ——这可以做到的,是四个值得自动化的工作,以及应该保持手动的工作.
- **那个 REST API** —— 验证,那些对分析,版本化很重要的终点家庭,以及你写东西之前值得设计的极限.
- **SAQL 从代码** 发送查询 API 并且读到回来的东西——加上一个脚本上的数字与仪表板上的数字有区别的四种合理的理由.
- **正在装入数据** ——外部数据. API:宣布,上传部分,信号完成——三步图案,决定您字段类型的元数据文件,以及每个人一次点击的失败.
- **Python 到结束** ——Python的一条工作路径:认证,申报一个负载,将学院的数据按部分推,信号完成,验证行数,并查询结果返回.
- **自动化 & 部署** ——排程,资质,故障处理,利用元数据导出给出产品不提供的更改历史仪表板.
- **面谈问题** - 这个 API 和自动化问题,有模范答案—— 以及他们真正研究的操作判断。
- **分级考试** ——关于认证,查询和外部数据API,加载操作,调度和更改历史的八个问题.
