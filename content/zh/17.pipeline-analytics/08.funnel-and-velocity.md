# 构建:漏斗转换和销售速度

机会管理问"什么交易". 这问到"机器工作如何,制约在哪里".

::note{icon="i-lucide-gauge"}
**反直觉的发现,你应该期待。** 转换率最差的阶段 通常不是你收入最高的阶段 昂贵的舞台是最糟糕的转换 *和* 只有价值加权的漏斗能证明这一点。
::

::tip{icon="i-lucide-calendar-x"}
**不完整的陷阱。** 两个月前成立的企业集团不能关闭——周期为97天。 包括它和晚期转换似乎崩溃了。 灰度或排除一个周期长度以下的组别 **每部分**,因为SMB的28天和战略的186天是完全不同的窗口。
::

## 盖起来

::lesson-steps
---
items:
  - title: "构建计数漏斗"
    description: "对于一个创造的-加速, 计算曾经达到每个阶段的机会。 注意\"从未达到\"——现在的谈判协议通过\"发现\"(Discovery),只计算目前阶段每早期都低报."
  - title: "在它旁边建一个值漏斗"
    description: "同一组人,总和是数量而不是数量。 比较两个形状. 失去30%交易但价值只有10%的阶段正在失去小交易,这也许很好。"
  - title: "每阶段中间天数"
    description: "对于封闭的交易,从进入每个阶段到下一个阶段的时间. 中度,不是说意思——一个400天的交易扭曲了平均水平,隐藏了一个健康的过程."
  - title: "每段计算速度"
    description: "每部分每季度提供4个投入。 在结果旁显示组件, 以便读取器看到哪个杠杆被移动 。"
  - title: "最后一个热图"
    description: "阶段×段,通过转换涂色. 这就是你发现Entertainments在Business Case中输掉交易,而SMB在Discovery中输掉交易——两个不同的问题,一个漏斗平均混合成一个毫无意义的数字."
---
::

::note{icon="i-lucide-lightbulb"}
**发现与 商业案例是教训。** 发现会损失最多的交易,而"商业案"损失最多的是钱,因为到达"商业案"的交易规模更大,条件更好. 一个优化发现小组正在处理数量问题;一个优化商业案例小组正在处理收入问题。 价值漏斗是唯一区分它们的图表,大多数公司从未建造过漏斗.
::
