## 本节将涵盖

每个仪表板都是 JSON 下方文档。 买你买的东西——批量编辑、diffs、审查、再利用——以及打开是正确动作而不是炫耀的四种情况。

## 计划的经验教训

- **什么时候打开** - 每一个仪表板都是 JSON 下方文档。 买你买的东西——批量编辑、diffs、审查、再利用——以及打开是正确动作而不是炫耀的四种情况。
- **解剖学** ——仪表板文档的四个顶级部分——状态,步骤,部件和布局——它们如何相互参照,以及如何在您没有写的文件中找到任何东西.
- **步骤 & 查询** ——仪表板文档的数据层:步骤包含什么,点击的查询与原始的区别 SAQL,静态步骤,并合并加载时间的查询。
- **部件 & 布局** ——画什么与它坐在哪里 ——为什么分离存在,引起最大惊喜的响应性布局,以及值得编辑作为文本的部件属性.
- **安全编辑** ——备份,验证,圆通测试和diff基审查——如何使一个没有真实版本控制的产品中的仪表板更改可逆和可审查.
- **面谈问题** 当他们问及你是否使用过仪表盘时, 采访者到底在检查什么? JSON ——有模范答案.
- **分级考试** ——关于文档结构,步骤,布局,批量编辑和安全编辑的八个问题.
