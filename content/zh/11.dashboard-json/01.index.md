# 何时打开 JSON

页:1 CRM Analytics 仪表板是一个 JSON 文档:部件、版式、查询和绑定,均作为文本。 构建者为您写作,偶尔文本是更好的工具.

::note{icon="i-lucide-file-json"}
**这不是高级仪表板大楼** 大多数仪表板都不应该有 JSON 并且为了让它做一些 建造者做得非常好的事 是制作一个无人能维护的仪表板的方法 它为批量工作、审查、以及界面不暴露的少数事情赢得了地位。
::

## 四个好理由

  - name: "Reuse and templating"

  - name: "Reaching something the UI does not expose"
    type: "occasional"
    role: "measure"
    note: "格式中存在的属性,但在构建器中没有控制. 真实的,不寻常的, 和人们首先打开文件的原因-- 然后他们发现了另外三个并留下。"

::

## 两个坏原因

::warning{icon="i-lucide-hand"}
**不使用 JSON 做普通工作更快, 不要用它来聪明。** 一个仪表板手动编辑成一个配置,而建造者无法往返是一个只有你才能改变的仪表板,这和超限的一样失败. 如果建造者能表达出来,则让建造者表达出来—— JSON 是为建造者所不能做的事情,也为观察它的所作所为。
::
