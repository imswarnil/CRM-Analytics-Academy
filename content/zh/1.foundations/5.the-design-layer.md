# 设计层 : Lenses盘子 & 应用程序

在最后一课中,我们把原始数据塑造成快速、优化的数据集。 但是,一个数据集本身对于商业用户来说是看不见的——它需要一张脸. 这是你的工作 **设计层**,其中数据集成为人们实际观察和探索的东西: **镜片**, (中文). **仪表板**,以及 **应用程序**。 。 。 。 这三种概念是日常词汇 CRM Analytics让他们成为第二大自然

## Lenses:快速、自我服务探索

页:1 **镜头** 这是最快的方式 *听着* 在一个数据集。 打开一个数据集,然后你被扔到一个镜头中:一个轻量级的探索表面,在那里你可以按一个字段分组,改变测量,切换图表类型,以及过滤器——都用几下点击.

把镜头当成一个简单的问题:

- "我们有多少机会在舞台上?"
- "本季度按地区划分的总收入是多少?".

你没有制造任何抛光物;你在探索。 Lenses 内在的 **自助服务** ——好奇的用户可以在不等待开发者的情况下回答自己的问题.

::tip{icon="i-lucide-search"}
需要镜头时伸手 *一个数据集的快速回答*。 。 。 。 它相当于快速草图的分析。
::

## 盘片: 卷轴、多翼分析

当一组问题足够重要,可以一次又一次地回答——对于一个团队,一个会议,一个角色——你从一个镜头毕业到一个镜头. **仪表板**。 。 。 。

仪表板是 **编译部件集**:多张图表、表格、过滤器、切换、数字瓦和文本,在画布上刻意排列。 与单镜不同,仪表板可以:

- 从这里拉 **多个数据集** 马上
- 将几种视觉融合为一个连贯的故事.
- 提议 **互动** ——过滤和选择,将整个页面一起更新.

仪表板是 *设计*。 。 。 有人决定观众所关心的问题, 挑选正确的图表, 并把它们列出来, 所以答案是显而易见的一看。 (好的仪表板设计本身就是一种技巧——我们稍后在课程中覆盖它).

## Apps:分组,关键是分享

所以,你有镜头和仪表板。 他们住在哪里,谁可以见到他们? 输入 **应用**。 。 。 。

一个 **应用** 基本上是一个 **文件夹** 相关组别 CRM Analytics 资产组合 :

- 电线板
- Lenses
- 数据集
- 故事

但应用不仅仅是一个干净的容器。 它也是 **获取和分享**。 。 。 您通常不会一个一个地共享每个仪表板; 您共享 **应用**,而里面的一切 继承了这种访问。

::note{icon="i-lucide-folder-lock"}
设计层的安保在 **应用** 级别。 允许用户访问销售应用程序,他们可以看到它持有的仪表板,镜头,和数据集——不再,也不减少.
::

因此,各组织按功能创建专用应用程序:

- 页:1 **销售应用** 与销售团队共享。
- 一个 **HR 应用程序** 人口统计和自然减员,只与人力资源分享。
- 页:1 **财务应用** 收入和利润,仅限于融资。

Apps 可以是(Apps ) **私营** ——只向创作者可见,而仪表板是正在进行的作品——或 **共享** 与特定用户,角色,或团体,一旦准备好. 这种灵活性可以让你安全地在私人中建立起来,然后公布给正确的受众。
