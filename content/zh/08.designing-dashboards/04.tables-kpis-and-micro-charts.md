# 表格、 KPI 和微图

三个家庭主要做决定仪表板的工作。 图表被传授;这些被使用。

单数,显著。 数字本身几乎是无用的——它需要一个比较和方向:

::note{icon="i-lucide-gauge"}
**三种成分使瓷砖可操作:** 数字,一个比较, 给出它的规模, 和指示是否高兴的方向。 注意第三块瓷砖——CAC回扣是好消息,所以它的下箭是绿色的. 善良是度量衡的属性,而不是箭头的方向,而使这个错误把一个好的季度变成了一堵红色的墙.
::

## 闪光线

砖块内部的一个细小的图表,显示了过去几个时期. 它回答"这是正常的吗?"——这个问题是一个单一数字总是挑起的问题,永远无法回答.

::tip{icon="i-lucide-activity"}
**一个火花比第二个图值多** 因为它几乎没有空间和注意力。 页:1 KPI 112%意味着很少;112%在7个月来稳步攀升的线末,意味着相当具体。 在添加另一个图表之前添加闪光线。
::

## 表格

图表显示形状。 表格显示身份。 当答案是“哪个账户”时,一个表格不是一个倒数——它是正确的部件:

::field-table
---
dataset: "when to use a table"
grain: "one row per case"
fields:
  - name: "Identity matters"
    type: "use a table"
    role: "key"
    note: "' 10个账户处于危险中 需要名字 条形图十个帐号名称是不可读的,名称是整个点."
  - name: "Several attributes per row"
    type: "use a table"
    role: "dimension"
    note: "账户,分部,ARR,使用,所有者。 一个图表可以显示其中的两个;一个表格可以显示所有五个,让读者扫描."
  - name: "An exception list"
    type: "use a table"
    role: "measure"
    note: "简而言之,当事情进展顺利时是空的——这是理想的状态,需要空的状态信息,所以没有人认为它破裂了."
  - name: "Everything, all rows"
    type: "do NOT"
    role: "measure"
    note: "带有卷轴栏的140行是导出,而不是仪表板. 如果人们真的需要完整的名单,就给他们一个下载,并将仪表盘保存在前十名."
---
::

::warning{icon="i-lucide-scroll"}
**卷轴条是告诉。** 一个没有卷轴就无人能及的表格不再是一个仪表板部件,而成为一个数据传送机制。 这是合理的需要——仪表板设计部分涵盖适当的下载——但它不应每天早上占用六人检查的屏幕。
::

## 格式化使变化

- **右对齐编号** 所以数字排列起来 尺寸可以比较
- **一致的小数** 在栏中; 混合精度读作粗心大意,并慢了比较。
- **缩写大数** - 1.142美元) M而不是1 420 000美元——在瓷砖上,在桌子上对需要的人保持完全精确。
- **按什么来排序**,这几乎从来没有字母。
