# 链接板 一起来

一个仪表板不能回答一切 试试看,你得到一个卷轴怪物 没有人读。 更好的规律是 **设定** 焦点仪表板——一个摘要,一个管道细节,一个活动视图——连接起来,使用户在它们之间移动,而从未触及导航菜单.

那个 **链接** 部件是你如何构建的, 它做远不止打开一个 URL。 。 。 。

## 联系可以指什么

将链接部件拖放到画布上, 其属性请求目的地 。 你有三个选择:

您也可以控制目标是在同一标签中打开,还是新的标签中打开 。 对属于流量一部分的钻入的标签相同;对参考材料的新标签,用户会从中返回.

## 横跨过滤器

这是让联系真正强大的环境, 和大多数人离开关闭 因为他们从来没有注意到它。

启用 **应用选择 / 应用过滤器** 链接和用户的 **当前仪表板状态与他们一起旅行**。 。 。 如果他们已经过滤到EMEA,Q3和闭元,他们降落在目标仪表板上已经过滤到EMEA,Q3和闭元.

没有它,旅程就是:小心过滤,点击通过,重新应用所有相同的过滤器,失去你的思维列. 有了它,两个仪表板感觉就像一个应用,有两个视图.

::tip{icon="i-lucide-triangle-alert"}
过滤器只在 **目标仪表板有兼容的过滤器** 的数据集。 在一个完全不同的数据集上将输油管仪表板与辅助仪表板连接起来,选择没有捆绑. 设计连接的仪表板作为一个家族从一开始, 在共享的数据集和共享的字段命名上, 这只是工作。
::

## 将链接设置为标签

链接部件接受与其它部件相同的样式——背景颜色,字体,边框半径,垫装. 在仪表板的顶部放置一排, 给他们一个满满的背景和一个圆形的顶端, 并且你有一些东西,用户读得清晰 **选项卡**。 。 。 。

突出当前一个(更强的背景,或品牌颜色)和灰色其他,一套四个仪表板的行为类似四塔布应用程序. 它完全是化妆品——下面没有真正的标签组件——但用户不知道,也不需要. 它是现有型号影响最大的位点之一,因为导航是大多数仪表板落地的地方.

## 集装箱上的透明链接

现在的诡计值得偷。 链接部件作为文本制作, 有时您想要 **可点击图像** 相反——一种产品瓦片,团队照片,一个打开相关仪表板的品牌卡片.

没有图像按钮部件 。 你装的很有说服力

::lesson-steps
---
items:
  - title: "丢弃容器部件"
    description: "在画布上放置一个容器,并按您想要的瓷砖大小。"
  - title: "给它一个背景图像"
    description: "在容器的属性中,设置一个背景图像,并选择它适合的方式——封面通常看起来最好."
  - title: "覆盖链接部件"
    description: "将链接部件拖放在容器上方, 这样它就覆盖了同一个区域 。"
  - title: "使链接隐形"
    description: "将链接的背景颜色设置为完全透明,其字体颜色也设置为完全透明。"
  - title: "指着目的地"
    description: "设定目标仪表板并启用应用选择,然后测试整个瓦片点击通过."
---
::

结果是用户点击的图像. 链接仍然在那里,在做它的工作,带着它的过滤器——它只是没有什么可以看得到的。 两个背景 *和* 字体颜色需要透明; 文本不透明, 图片上会浮出一个偏移的字。

::tip{icon="i-lucide-lightbulb"}
因为隐形链接不会给出徘徊的反馈,所以自己加入负担:容器上一个细微的边框,下面一个标题,或者链接上的一个工具提示来解释它去向. 一个可以点击的图像是一个不错的惊喜;这个图像 *看着* 可点击,而且是一个很好的设计。
::

用于登陆页——图像瓦片网格,每块打开业务的不同区域. 它每瓷砖需要两个部件,它让一个分析应用程序感觉像一个产品而不是一个报告文件夹.
