# 表格和枢轴表格

分析中评分最低的部件 最常用的部件

## 图表显示形状; 表格显示身份

一个图表回答"多少"和"更大". 一张桌子回答"哪张,准确的,我还知道什么"

::note{icon="i-lucide-list"}
**当答案是人们将要采取行动的事物列表时,就是一张桌子。** "这十个账户有消费风险"需要名字,ARR,使用,趋势和一个所有者——每行5个属性. 一个图表可以编码其中两个。 表格不是这里的倒置;它是正确的部件,将数据装扮成十个账户名称的条形图,使得使用起来更加困难。
::

## 滚动条测试

::warning{icon="i-lucide-scroll"}
**如果一个表格需要滚动, 它不再是一个仪表板部件 。** 查看一个仪表板;通过出口。 两者都是合理的需要,它们不是同一个目标。 将部件保留在合适的位置上——十行,五列,并为完整列表提供旁边的下载. 仪表盘上一个140卷的滚动表无人使用:扫描时间太长,太尴尬无法工作.
::

## 决定可读性的格式

::lesson-steps
---
items:
  - title: "右对齐数字, 十进制一致"
    description: "数字排成一行,数量变得可比而不读. 一栏中的混合精度读作粗心大意,并慢了每次比较."
  - title: "按什么顺序排序,下降"
    description: "几乎从来没有字母顺序。 就风险清单而言,按受威胁的ARR排序,而不是按百分比有多差来排序——否则,名单是根据比率的严重程度来排序的,而这很少是任何人应该工作的顺序。"
  - title: "只给例外颜色"
    description: "40个表格中的3个红细胞可立即读取。 40个彩色细胞是一个装饰的表,其中没有留下信号."
  - title: "标出标题中的限制"
    description: "10账户处于风险,而不是\"账户处于风险\"。 否则有人把栏目加起来,报告总数是错的。"
  - title: "给它一个空的状态"
    description: "当事情进展顺利时,一个例外的表格是空的——这是理想的状态,它看起来像一个断开的部件,没有一条文字这样说。"
---
::

## 中枢表,当它们停止工作时

一个枢轴器充其量是一个小矩阵:五个部分半年,或五个区域四个产品。 在大约8个栏目之外,读者正在横向滚动,并进行远距离比较,这恰恰是图表能做的更好。

::tip{icon="i-lucide-shrink"}
**如果一个枢轴太宽,你问两个问题。** 拆分它:一个用于时间趋势的部件,一个用于按类别细分的部件。 两个可读部件击败一个完整的部件,拆分通常会揭示两个问题中只有一个真正重要.
::
