# 数字、高地和火花线

大部分仪表板都以单一值打开. 多数单一的数值是不可操作的,而固定则没有代价。

## 单是数字就意味着很少

"网易新ARR:1.42M"——好么?. 读者不能知道,所以他们要么问你,要么假设。 三种成分可以修补:

::lesson-kpis
---
columns: 3
items:
  - label: "空数"
    value: "$1.42M"
    hint: "Cannot be acted on — no scale, no direction"
  - label: "比较一下"
    value: "$1.42M"
    delta: "+8.3% vs plan"
    trend: "up"
    good: true
    hint: "Now it has a verdict attached"
  - label: "还有火花"
    value: "$1.42M"
    delta: "+8.3% vs plan"
    trend: "up"
    good: true
    hint: "And now the reader knows whether it is normal"
    spark:
      - 820
      - 910
      - 1040
      - 980
      - 1180
      - 1310
      - 1420
---
::

::note{icon="i-lucide-gauge"}
**数字,比较,方向。** 这一比较给出了比额表——相对于上一个时期的计划,相对于去年同期。 方向给出了判决。 请在标签上说明是哪一个:“上8%”与三个不同的引用给出了三个不同的答案,他们常常在签名上持不同意见。
::

## 善良属于衡量标准

::warning{icon="i-lucide-arrow-down"}
**向下不总是坏的。** 楚恩跌落,CAC还本付息缩短,时间到接近下降,过去SLA下降的案件,贴现率下降——都是好消息. 一种默认的调色板,将每个减少的红色涂上,将坚固的四分之一变成警示墙,并教读者忽略颜色. 设定每个公尺的善良方向,并通过问: *如果这个数目减半,我会高兴吗?*
::

## 闪光线

砖块内部的一个细小的图表,显示了过去几个时期. 它回答"这是正常的吗?",这就是一个单数总是挑起并且永远无法回答的问题.

::tip{icon="i-lucide-activity"}
**在添加另一个图表之前添加闪光线。** 几乎没有空间,没有注意, 他们转换每一个 KPI 从一瞬间变成一种趋势。 112%的NRR意味着很小;112%的线末,已经攀升了7个直月,意味着具体的东西——同样112%的线末,从121%下降,意味着紧迫的东西。
::

## 高盖斯

测量表显示一个值对一个尺度,通常带有彩色带. 它在一种情况下会获得自己的空间: **一个真正的固定目标 在哪里"我们有多近"是问题**。 。 。 。

::compare-cols
---
items:
  - title: "不错的测量"
    subtitle: "A real target exists"
    icon: "i-lucide-target"
    pros:
      - "Pipeline coverage against 3x — the target is the point"
      - "SLA attainment against a contractual 95%"
      - "Bands come from the business, not from thirds of the range"
    cons:
      - "Uses much more space than the number plus a delta"
    verdict: "One per dashboard at most."
  - title: "计数器故障"
    subtitle: "A number wearing a dial"
    icon: "i-lucide-circle-slash"
    pros:
      - "Looks like a cockpit"
    cons:
      - "No meaningful maximum, so the scale is invented"
      - "Bands split evenly into thirds, which is arithmetic pretending to be judgement"
      - "Occupies four times the space of the KPI tile it replaced"
    verdict: "Use a number with a comparison."
---
::

## 数字本身格式化

::field-table
---
dataset: "number formatting"

    role: "measure"
    note: "没有人决定标题的最后四个数字。 在下面的桌子上保持完全精确 任何需要它的人。"

    role: "dimension"
    note: "单位数字,所以一列数字在小数点上行,大小可以一目之间比较."

    type: "in the label"
    role: "date"
    note: "\"Net New ARR——Aug FY26, vs plan\". 仪表板最常见的误读时间是头条封面的哪个时期,可以自由预防."
