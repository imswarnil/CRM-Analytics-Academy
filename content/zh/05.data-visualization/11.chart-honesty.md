# 图表诚实

每个数字都正确,结论是错误的。 这个教训是关于做这些决定的少数格式化和捕捉这些决定的核对表。

::note{icon="i-lucide-eye"}
**测试不是“如此准确”,而是“在四秒钟内有人会得出什么结论,这是真的吗?”** 准确性是容易的部分,几乎总是好的。 结论是仪表板失效的地方,故障是足够系统的,可以检查.
::

## 合计也是索赔

同一列的总数、平均数、中数和明显数回答四个不同的问题,部件标题通常不表示。

::warning{icon="i-lucide-sigma"}
**"Average deals size"(Average deals size)含义模糊,两种读物差异很大.** 平均值由少数企业交易拉高;中值描述典型交易。 学院有36 000美元平价企业方案费和数百 240美元学院Pro订阅费,因此,平均和中位数讲述真正不同的故事——两者都是正确的。 将该功能放在标签中:"中间交易大小",而非"平均".
::

## 时间是比较出错的地方

- **哪个日期?** 创建,关闭,最后修改,阶段条目. 由不同日期分组的相同数据讲述了不同的故事,图表无法显示您选择的。
- **什么比较?** 上月,上年同月,或计划增加12%——三个答案经常在签名上出现分歧.
- **部分期间。** 本月总是下调,因为它还没有结束。 要么把它排除在外,遮盖,要么贴上标签——一个显示一个不完整月的仪表板,除了完整的仪表板之外,每个月都生产一个下降。

::tip{icon="i-lucide-shield-check"}
**这并不涉及谨慎到无用的程度。** 拒绝说明问题的图表是其自身的失败。 目标是它提出的点是数据支持的点——这通常意味着标题中再加一句,并减少一个聪明的编码.
::
