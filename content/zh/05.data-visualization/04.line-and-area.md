# 线条和区域图

时间变化图. 它的失败比条形图的安静,这使得它们更持久.

## 线条用于连续变化

一条线意味着,各点之间的数值是有意义的,即测量是连续存在的,你对此进行了抽样。 ARR、使用、误差率和输油管价值都是如此。 "每月关闭交易"不是事实,这是一系列独立的事件。

::note{icon="i-lucide-spline"}
**对已计数的事件使用列,对一个关卡使用行。** 3月结束的交易是一个只存在于月颗粒度的计数;将其画成一条线意味着在3月中旬7.5个交易结束时有一刻。 没有人对此真正感到困惑,但栏目版本读得更快,因为它与数字相符.
::

**当很多系列真正存在时, 灰化它们并突出一个。** 所有部分都用轻中性, 正在用重音讨论。 读者获得上下文和要点,图存后被截成文档.
::

## 差距意味着什么

一个月无行是模糊的:值是零,还是未知?

::warning{icon="i-lucide-unlink"}
**直截了当地跨越了一个缺口,声称这一措施顺利通过。** 对于一个真正为0的计数, 阴谋0。 对于数据缺失的时期——同步失败,产品尚不存在——断线. 输油管下线一个月的连续线是数据不能支持的主张,这是一张图表无任何错误的最常见的方式。
::

Namilio的数据就是这个: `VOICE-AGENT` 2025年2月推出,所以前几个月没有排行. 加入一月至三月的一线意味着一种存在且一无所获的产品. 休息说它不存在。

## 基线问题

对于线条来说,与条不同,非零基线常常是合法的. 编码是 *倾斜*,而不是离轴的距离, 并且强迫0 的度量 活度在94%到112%之间 平整每一个重要的运动。

## 双轴

两个尺度,两个尺度,一个图表。 这是唯一一个最误导的部件。

::warning{icon="i-lucide-x"}
**两行交叉的点是一个格式化的决定.** 移动任意一轴,十字路口随之移动,但读者将一个十字路口解释为一个事件——"收入在6月超过成本". 没有什么能超越任何东西;这两项措施在不同单位,完全无法比较。 如果关系是问题,则使用散块图;如果两种趋势都重要,则使用两张共享x轴的堆叠图,读者可以在此看到每个形状而无需被邀请来比较高度.
::

一个可辩解的双轴是两个单位的同样措施——收入和按计划计算的收入百分比——这些轴真正相互锁定。

## 区域图

一个区域与它所填充的区域一致。 填充索赔 *曲线下的数量* 具有意义——累积量,消费总量.

- **一个系列,有意义的积累:** 合法且可读。
- **相关部件的堆叠区域,合计:** 合法,有与堆叠条相同的警告——只有底带有稳定的基线.
- **一些不相关的系列以透明方式覆盖:** 装饰。 使用线条.
