# 图表为参数

图表不是数字的中性容器。 在有人读到一个值之前, *形状* 已经提出一个要求:这些东西是可比较的,这个更大,这个上升,这是其中的一部分。

::note{icon="i-lucide-message-square-quote"}
**从比较中选择图表,而不是数据类型.** "我有一个度量和维度,所以——条形图"是大多数图表是如何被选择的,这就是为什么这么多的仪表板是条形的墙. 问题是读者应该作什么比较: *军衔*, (中文). *趋势*, (中文). *组成*, (中文). *分发*, (中文). *关系*,或 *对一个目标的单一值*。 。 。 。 每一个都有一个正确的答案,几个错误的答案。
::

## 真实的数字是怎样的

本节中没有任何内容是让图表更漂亮。 这是关于正确数字被误读的具体方式:

::field-table
---
dataset: "common misreadings"
grain: "one row per failure"
fields:
  - name: "A bar chart sorted alphabetically"
    type: "hides the ranking"
    role: "dimension"
    note: "读者假设栏杆是按尺寸排列的. 如果不是的话,眼睛会读第一条酒吧是最大的, 没有人重复检查。"
  - name: "A line chart with a non-zero baseline"
    type: "exaggerates change"
    role: "measure"
    note: "当读者假定为零时, 说说你在轴标签上做了什么"
  - name: "A donut with nine slices"
    type: "shows nothing"
    role: "dimension"
    note: "人类对比的角度 糟糕过大约四片。 九片是一张穿圆的桌子."
  - name: "An average with no distribution"
    type: "hides the shape"
    role: "measure"
    note: "学院88%的公司平均占30%,占140%。 两者都需要行动,方向相反,平均结果也没有。"
  - name: "A dual axis"
    type: "invents a relationship"
    role: "key"
    note: "在两个尺度上的两个度量衡在选择放置斧头的地方交叉. 过境点是一种格式化的决定,读者将它解释为一种发现。"
---
::

::tip{icon="i-lucide-eye"}
**整个区都有一个习惯** 在建立任何图表后,请问: *4秒钟后有人会得出什么结论 而这个结论是真的吗?* 不是"数字正确"——数字几乎总是正确. 结论是错的。
::
