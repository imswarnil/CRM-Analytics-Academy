# 整体图

组成是分析学中最过度的比较. 几乎每个甜甜圈 在一个真正的仪表板 将更好作为一个桌子或排序棒。

## 为什么角度很硬

人比较 **长度** 还有 **角度** 惨了 两倍长的酒吧显然是两倍长的;一个23%的切片对19%的其中一个是硬币逐眼翻转. 这个事实支配着整个家庭。

::note{icon="i-lucide-pie-chart"}
**甜甜圈用两三个切片**,其中形状本身带有信息——"大约三分之一的收入来自一种产品". 阅读者正在阅读标签,
::

## 测试

::tip{icon="i-lucide-help-circle"}
**问读者如何是答.** 如果动作取决于对级别和粗略比例的了解——"我们收入的大部分是企业"——则图表是正确的. 如果它取决于数字本身——"企业是43.2%,目标是45%"——他们需要数字,一个图表让他们估计一些你可以告诉他们的东西.
::

## 随时间演变的组成

两个截然不同的问题,经常被混淆:

- **"混音变了吗?"** ——100%堆叠,或每股一组行. 大小刻意隐藏.
- **"每个部分都有成长吗?"** → 单行,或小倍数. 混合故意隐藏。

::warning{icon="i-lucide-layers"}
**随着时间的推移,一个堆积的区域试图回答两个问题,而可靠的答案也一样。** 底部上方的每一个波段都因为下面的东西而移动,因此一个段段可以看起来像在平坦的同时在增长——它的基线上升. 如果有人需要知道中市是否增长,就给中市公司自己的线路.
::

## 学院的榜样

6种产品按产品分列的收入,3种定价模式. 六块甜甜圈几乎什么也没有沟通;每个条上值的分类栏立即回答“哪些产品很重要”;诚实的构成问题——“是预付的池子——教室座位日、凭单、咨询时间——成为收入的更大份额?” KPI 旁边的瓷砖。
