# 地图

当 **在地球上的位置是信息的一部分**。 。 。 每当地理只是一种标签时,它就是错误的——无论如何,它是被选择的。

## 测试

::note{icon="i-lucide-map-pin"}
**如果重新贴上A、B、C的标签,读者的结论是否会改变?** 如果有,地理正在真正发挥作用:辅助性、距离、地域界限、旅行、覆盖差距。 如果没有,地理只是一个分类名称,一个排序的条形图对这些分类的排序要精确得多,远比任何颜色尺度都要精确得多。
::

纳米利奥有四个地区:AMER,EMEA,APAC,LATAM. 四类. 一个排序的条形图确切地回答"哪个地区最大,多少". 一张地图让读者比较两个蓝色的遮荫在大小迥异的形状上,需要4倍的空间才能做到更糟.

## 人口问题

::warning{icon="i-lucide-users"}
**任何原始总数中的一种和弦大多是人口图.** 给美国、德国和印度带来颜色 以收入和最大的经济体为单位 在打开仪表板前你就知道 几乎每个商业地图都需要正常化:每个账户的收入、对可解决市场的渗透、增长率而不是水平。 不合常理的版本没有错——它只是回答一个没有人问的问题.
::

同样的问题有第二个更安静的版本: **区域不是值**。 。 。 人口稀少的大片区域占据的像素比小的密集区域要多得多,所以无论颜色如何,眼睛都更重.

::tip{icon="i-lucide-bar-chart-3"}
**区域商业数据的诚实默认是一个排序的条形图.** 当有人需要看到时,请联系地图 *地点*,而不是当维度恰好有 地名在里面。 这是为数不多的图表决定之一,其中更令人印象深刻的选择通常是最差的选择。
::
