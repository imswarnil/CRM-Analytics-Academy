# 以 Dataset Builder

现在我们造了一个真正的 Salesforce 数据集。 **Dataset Builder** 是原始的导引工具: 它走对象关系 *给你的*,然后将其指示写成 **数据流**。 。 。 这是建立基线数据集最友好的方法, 正因为如此,我仍然把它交给人们学习平台。

记住谷类课的计划: 这个数据集是 **关于机会**,所以我们从机会开始看 *上来* 转到账户和用户。

::tip{icon="i-lucide-plug"}
Dataset Builder 从 **连接/同步层**,不是从 Salesforce 直接来 所以,不像一个 CSV 上传,同步必须先到位. 如果一个对象没有同步, 您将无法选择它 。
::

## 踢开它

从 Analytics Studio编号 : **创建 — 数据集 — Salesforce 数据**。 。 。 这是中间选项——你没有上传一个 CSV,而你并没有在现有的数据集之上构建(这条路径导致食谱).

你会被问到要使用哪一个数据流。 每艘有 **默认 Salesforce 数据流**,可以添加或创建自己的. 在生产中,你通常会有少量的 命名的,有计划的数据流, 你会确切知道每个集合点是什么。 暂时使用默认值. 单击 **下一个** 和 Dataset Builder 打开 Data Manager 选项卡。

## 从最小对象开始

Dataset Builder 现在显示它能够到达的每个对象。 我们三个是 **机会**, (中文). **账户**,以及 **用户**。 。 。 。

::lesson-steps

items:
  - title: "先选择机会"
    description: "这是核心对象和谷物。 从这里开始, 您可以联系到账户和用户 。 从账号开始,你就会被卡住——它无处可寻。"
  - title: "通过关系添加账户"
    description: "跳过机会节点,单击加号,打开关系,并选择账户. 这是一种检查——它在每个机会上都附加了帐号字段."
  - title: "添加用户( 所有者)"
    description: "从机会的关系,加入用户表来带来机会的主人. 现在你有三个连接的节点。"
---
::

谷物持有: **每行都是独一无二的机会**,用它所属的账户和拥有该账户的用户丰富。 任何机会都不计算两次。

::tip{icon="i-lucide-wand-2"}
注意点 *没有* 不得不这么做: 你从来没有告诉过它的机会 `AccountId` 等于账户 `Id`。 。 。 。 Dataset Builder 直接读取关系 Salesforce 计程车和窃听钥匙给你。 那个自动的钥匙检测是它最方便初学者的原因
::

## 选田

随着关系的存在,加入每个对象需要的字段. 在走道上,大概是:

::lesson-cards

items:

::

::tip{icon="i-lucide-triangle-alert"}
**一旦点击"Next",你就不能回到这个屏幕了.** 忘记一个字段,你将不得不编辑数据流的消化节点代替(更多关于下一节课). 因此,在继续前进之前,需要的每个字段都会被选中。 两次测量,点击一次
::

设置您的字段时, 请选择一个应用( 学习时私有应用程序是好的) 并单击 **创建数据集**。 。 。 。 Dataset Builder 把这些都推到数据流中 然后把它踢下来 在接下来的课中,我们将看它运行——并处理新训练兽人喜欢的首次抛出的错误.
