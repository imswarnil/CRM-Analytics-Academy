# 设计 : CRM Analytics

您可以构建一个功能 CRM Analytics 仪表板大约十分钟。 拖动几个图表, 连接过滤器, 保存 。 它的工作原理。 它看起来也像其他的仪表板 在矿石, 没有人打开两次。

本节是关于 **其他90%** 将工作仪表板变成一个执行官的部件 一直被困住 一点都不难 这主要是要知道哪块地产板 拥有你想要的环境 并且曾经看过这个把戏

## 这里"设计"是什么意思?

设计在 CRM Analytics 不是选更漂亮的颜色 是关于 **缩短问答之间的距离**。 。 。 。 本节中的每一个技术都做三件事之一:

## 前面这节是什么

我们将通过部件属性来工作, 顺序你自然 到达他们,同时擦亮一个真正的仪表板:

::lesson-steps
---
items:
  - title: "有条件的格式"
    description: "在图表、表格和数字部件上按照阈值——宾、标签、梯度——对一个度量。"
  - title: "日期切换和面对面"
    description: "在日期部分上构建干净的切换过滤器, 并控制面部, 这样选项不会随着用户点击而消失 。"
  - title: "表格、图像和主题"
    description: "值表、默认列、间隔、暗部件主题和渲染 URL 字段为真实图像。"
  - title: "工具提示和图表标记"
    description: "自定义徘徊显示的内容,添加插件自定义文本,以及特定数据点的标注。"
  - title: "KPI 微图"
    description: "构建最上行的指标——时间表、预测线、极度测量和格式化的数字部件。"
  - title: "连接仪表板"
    description: "带用户过滤器穿过的链接部件,加上透明链接的图像瓦片伎俩."
---
::
