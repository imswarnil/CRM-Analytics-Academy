# 为什么 SAQL 已存在

每个镜头,每个部件和每个仪表板查询都是 SAQL 从下面 单击生成它;仅在点击界面耗尽时才会写入它.

::note{icon="i-lucide-waves"}
**SAQL 是流变换,而不是声明式查询。** 每个语句都取上一个语句的结果并进行转换,重新分配同一个流变量. 没有选择者重排你的工作,所以 **您写入语句的顺序是运行中的计划** ——分组后过滤真的做了你即将丢弃的集合行. 这是唯一的结构差异 抓住的人谁知道 SQL 不错
::

## 形状

```
q = load "Academy_Opportunities";
q = filter q by 'StageName' == "Closed Won";
q = group q by 'Segment';
q = foreach q generate 'Segment' as 'Segment', sum('Amount') as 'Revenue';
q = order q by 'Revenue' desc;
q = limit q 10;
```

装入,窄,组,计算,顺序,限制. 六个语句,每个重分配 `q`,每个消耗 上一个生产。

::warning{icon="i-lucide-eye-off"}
**什麽? SAQL 不应用于:界定商业衡量标准。** 任何读取数据集、食谱或文档的人都看不到写入一个部件查询的定义。 几个月后,有人将重新发现这两个仪表板,找出两个仪表板有什么不同之处,而且也不会出错。 形状查询在 SAQL;在食谱中定义衡量标准。
::
