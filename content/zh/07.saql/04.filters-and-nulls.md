## 不平等陷阱

::warning{icon="i-lucide-ban"}
**页:1 `!=` 对比值与您排除的值一起下降。** `'Stage' != "Closed Lost"` 删除已关闭- 丢失的交易 *和* 每个交易的阶段都是空白的,最有可能是值得注意的数据质量问题。 数字下降,没有错误, 和缺失的行正是 没有人在看。 当您的意思是"除了X,包括未知数之外的一切"时,明确写下: `'Stage' != "Closed Lost" || 'Stage' is null`。 。 。 。
::

这是 SAQL 版本的食谱滤波器警告来自数据准备部分,它是一个不同的地方同样的错误.

## 零号不明

无效的意思是"我们不知道" 零意味着"我们知道,它不是。" 他们的行为在每一个集合中都是不同的,他们经常被混淆:

::field-table
---
dataset: "null behaviour"
grain: "one row per function"
fields:
  - name: "sum"
    type: "skips nulls"
    role: "measure"
    note: "返回有值的行总数。 超过一个稀疏的栏目 这是一个子集,作为总数列出。"
  - name: "avg"
    type: "skips nulls in both parts"
    role: "measure"
    note: "有价值的行的平均值. 通常正确, 很少检查—— 并且与所有行的平均值有实质上的不同, 如果你打算将无值算为零。"
  - name: "count vs unique"
    type: "rows vs values"
    role: "key"
    note: "计数 () 计数行, 计数行; 唯一 () 计数不同的非数值 。 在一个稀少的栏目上,差别很大,也没有错。"
  - name: "Grouping by a nullable field"
    type: "produces a null bucket"
    role: "dimension"
    note: "这是诚实的,经常是图表上最有趣的桶子——“未签名”是一个真正的类别。 标注它而不是隐藏它。"
---
::

::note{icon="i-lucide-search"}
**在信任列之前检查无效密度 。** 一个查询——行数对照 `unique` 或计算非虚值——告诉你一个字段是空的5%还是空的60%. 学院的CSAT是一个长期的例子:只有大约44%的已结案案例进行一项调查,因此每个满意数字都描述了被调查者而不是客户. 这个数字没有错;它回答的问题比其标签要求要窄。
::

## 盘点盘中的过滤器与查询中的过滤器

三个不同的事物, 和混淆它们产生仪表板 一半的部件响应一个控制, 一半安静不:

- **查询过滤器** 是部件的一部分 SAQL ——总是应用的,是观众看不见的.
- **仪表板过滤器或侧面** 应用在顶端,每个交互,并且只达到连接到它的部件。
- **安全前提** 由平台应用,每个浏览器, 并且不能绕过任意一个。

::tip{icon="i-lucide-list-checks"}
**一个必须总是排除某些东西的部件应该在查询中排除它,而不是在过滤器中查看器可以清除.** "开放管道"不应该因为有人重置了过滤器而显示封闭的丢失交易. 任何结构属于查询;任何探索性属于过滤器.
::
