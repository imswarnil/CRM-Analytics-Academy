# 从这里开始

这是一个免费的,开源课程 **Salesforce CRM Analytics** ——分析平台前身为: Einstein Analytics波浪,还有 Tableau CRM。 。 。 它被写成要通过而不是看, 它结束于某个特定的地方: 用16个仪表板, 你自己建在一个数据集上,足以争论。

::note{icon="i-lucide-target"}
**承诺** 完成这个之后,你可以把公司原始的上市数据——线索,网络会话,营销支出,机会,引用,使用,支持案例——变成其高管实际使用的少量仪表板. 不是"你会知道什么是镜头。" 这是手段,不是重点。
::

## 是什么使这与文档不同

Salesforce自己的文件很好,你应该看看 它有一个结构性的局限性:它由下列组织: **特性**因为它必须是。 每页都回答"这个按钮是做什么的". 没有任何页面回答"我们有四个需求数据来源,两个团队对合格领先是什么有分歧——现在是什么".

## 一条规矩

**建 it. 不要读它。**

每一次实践课大约15分钟就能读到,大约45分钟就能建成. 45分钟就是学习的地方 阅读一个有关粉丝出局问题的课会产生一个能够定义粉丝出局的人;构建一个将学院的61M机会变成204M的联赛,凝视它,然后修复它,产生一个检查每个联赛的粒子的人,供他们剩下的职业生涯使用.

::warning{icon="i-lucide-hand"}
**此课程的失败模式是逆向设计的 。** 看着路过的尽头 感觉就像你学到了一样 你没有,你学会了认识它。 识别崩溃时,您自己的数据有重复的密钥。 因此,每个课都提到故意打破的东西,然后检查的东西。
::

## 这不是什么

- **不是认证卡** 恰巧涵盖了大部分 *CRM Analytics 和 Einstein Discovery 顾问* 考试考试,每个科都以面试问题结束. 但组织它是为了让你可以就业,而不是让你通过, 如果两者有分歧,它选择第一个。
- **不是每个菜单的巡演** 实际中没有人用过的特征得到句子和链接. 每天使用的特色都得到了完整的教训。
- **不是中立的,也不是粉碎的** 何处 CRM Analytics 比Tableau或Looker或Plain还糟糕 SQL通常因为安全模型已经建好 并且你的数据已经输入 Salesforce。 。 。 。
- **没有证明** 你带着仪表板和它们背后的推理离开 在一次采访中,这是更好的动画。
