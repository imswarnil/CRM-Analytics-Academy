## कंकाल

```python
import os, csv, json, math, requests

BASE   = os.environ["SF_INSTANCE_URL"]        # from the secret store
TOKEN  = get_access_token()                    # refreshable
HEAD   = {"Authorization": f"Bearer {TOKEN}"}
CHUNK  = 10_000                                # rows per part

def declare(dataset, operation, metadata):
    """Create the upload job. Nothing is sent yet."""
    body = {"Format": "Csv", "EdgemartAlias": dataset,
            "Operation": operation, "Action": "None",
            "MetadataJson": metadata}
    r = requests.post(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData",
                      headers=HEAD, json=body, timeout=60)
    r.raise_for_status()
    return r.json()["id"]

def upload_parts(job_id, rows, header):
    """Send the rows as numbered parts. Part numbers start at 1."""
    for i in range(0, len(rows), CHUNK):
        part = i // CHUNK + 1
        payload = encode_csv(header, rows[i:i + CHUNK])
        post_part(job_id, part, payload)

def complete(job_id):
    """The step that is forgotten. Until this runs, nothing is processed."""
    requests.patch(f"{BASE}/services/data/v62.0/sobjects/InsightsExternalData/{job_id}",
                   headers=HEAD, json={"Action": "Process"}, timeout=60).raise_for_status()
```

::note{icon="i-lucide-code"}
**समापन बिंदु पथ और रिहाई के बीच सटीक मेटाडाटा स्कीमा परिवर्तन** - अपने लिए वर्तमान दस्तावेज़ीकरण की जांच करें API इसके बजाय किसी भी ब्लॉग पोस्ट से एक पथ की प्रतिलिपि बनाने के बजाय, इसमें शामिल है। क्या बदलना नहीं है अनुक्रम: घोषणा, भागों, पूर्ण, सत्यापित करें। आकार जानें और विवरण देखें।
::

## वेरिफिकेशन वह हिस्सा है जो अपने रहने को कमाता है

```python
expected = len(rows)
actual   = dataset_row_count(dataset)          # read back from metadata
if actual != expected:
    raise SystemExit(f"load mismatch: sent {expected}, dataset holds {actual}")
```

::tip{icon="i-lucide-shield-check"}
**एक चेतावनी लॉग करने के बजाय एक गलतफहमी पर जोर से विफल रहता है।** एक ऐसा काम जो 80% पंक्तियों को लोड करने के बाद शून्य से बाहर निकलता है, एक डैशबोर्ड उत्पन्न करता है जो चुपचाप गलत हो जाता है जब तक कि यह किसी को नोटिस करने के लिए लेता है - जिसके लिए, नंबर पर किसी के पास पहले नहीं है, महीने हो सकता है। एक एग्जिट कोड शेड्यूलर द्वारा पढ़ा जाता है; लॉग में एक चेतावनी किसी के द्वारा पढ़ा जाता है।
::

## परिणाम वापस क्वेरी

उसी सत्र को चलाया जा सकता है SAQL, जो लोड के अंत में एक सामंजस्य कदम प्राकृतिक बनाता है: कुल डेटासेट को अब रिपोर्ट करता है और इसे सोर्स सिस्टम के अपने आंकड़े के खिलाफ तुलना करता है। यही कारण है कि एपीआई अनुभाग स्वचालित से उत्तर कुंजी आदत है - और यह एकल सबसे मूल्यवान चीज है जो लोडर लोडिंग से परे कर सकता है।

## इसे चलाना

जो भी इसे चलाता है - क्रोन, एक CI अनुसूची, एक ऑर्केस्ट्रेटर - तीन चीजों की जरूरत है: अनुसूची, एक गुप्त स्टोर से क्रेडेंशियल, और कहीं विफलता है *देखा*। एक नौकरी जो लॉग डाइरेक्टरी में विफल हो जाती है, कोई भी खुलता है वह काम है जो नहीं चल रहा है, और आपको सप्ताह बाद पता चलता है।
