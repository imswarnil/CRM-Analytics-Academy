# एक चार्ट चुनना

वाक्य से प्रारंभ करें पाठक को चार सेकंड के बाद कहने में सक्षम होना चाहिए। चार्ट का प्रकार लगभग यंत्रवत् होता है।

## डिफ़ॉल्ट जो अक्सर सही है

**एक क्षैतिज बार चार्ट, क्रमबद्ध अवरोही, शीर्ष दस तक सीमित, शीर्षक में सीमा के साथ।**

::tip{icon="i-lucide-bar-chart-3"}
**यदि आप तय नहीं कर सकते हैं, तो वह निर्माण कर सकते हैं।** यह सबसे आम सवाल (जो सबसे बड़ा है) का उत्तर देता है, यह किसी भी आकार में पढ़ा जा सकता है, यह ग्रेस्केल और एक प्रोजेक्टर से बच जाता है, और यह बहुत मुश्किल है। जब आपके पास एक कारण होता है तो कुछ और तक पहुंचें - एक प्रवृत्ति, एक संबंध, एक रचना - क्योंकि डैशबोर्ड में उस पर कई बार हैं। बार का एक डैशबोर्ड जो प्रत्येक वास्तविक प्रश्न का उत्तर देता है, एक विविध को हरा देता है जहां दृश्य रुचि के लिए तीन विजेट मौजूद हैं।
::

## क्या CRM Analytics आपको देना

चार्ट सूची लंबी है, और उपयोगी सबसेट छोटा है। अभ्यास में, इस खंड में परिवार अनिवार्य रूप से सभी उत्पादन डैशबोर्ड को कवर करते हैं:

::field-table
---
dataset: "the working set"
grain: "one row per family"
fields:
  - name: "Bar / column"
    type: "rank, and discrete time"
    role: "dimension"
    note: "सबसे अधिक उपयोग किया जाता है, और एक जिसका क्रमबद्ध क्रम अक्सर गलत होता है।"
  - name: "Line / area"
    type: "trend"
    role: "date"
    note: "समय के साथ सतत परिवर्तन। केवल तभी जब भरा मात्रा सार्थक है - असंबंधित श्रृंखला का एक स्टैक्ड क्षेत्र सजावट है।"
  - name: "Donut / stacked / treemap"
    type: "composition"
    role: "dimension"
    note: "केवल भागों की छोटी संख्या। पिछले चार, एक तालिका या एक छँटाई बार का उपयोग करें।"
  - name: "Scatter / bubble"
    type: "relationship"
    role: "measure"
    note: "दो उपाय, और बबल के आकार के रूप में तीसरा। इसके विपरीत यह कितना प्रकट होता है।"
  - name: "Number / gauge"
    type: "against a target"
    role: "measure"
    note: "अधिकांश डैशबोर्डों की हेडलाइन। कुछ भी करने के लिए तुलना की आवश्यकता है।"
  - name: "Table / pivot"
    type: "identity and exact values"
    role: "key"

  - name: "Map"
    type: "geography, when geography matters"
    role: "dimension"
    note: "केवल जब पृथ्वी पर स्थिति लेबल के बजाय बिंदु है।"
  - name: "Funnel / waterfall"
    type: "process and bridge"
    role: "measure"
    note: "अनुक्रमिक चरणों, या परिवर्धन और घटाव कुल तक पहुंचते हैं।"
