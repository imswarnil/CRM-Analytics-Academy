# जब खोलने के लिए JSON

A CRM Analytics डैशबोर्ड एक है JSON दस्तावेज़: विजेट, लेआउट, प्रश्नों और बाइंडिंग, सभी पाठ के रूप में। बिल्डर इसे आपके लिए लिखते हैं, और कभी-कभी पाठ बेहतर उपकरण है।

::note{icon="i-lucide-file-json"}
**यह डैशबोर्ड इमारत का उन्नत स्तर नहीं है।** अधिकांश डैशबोर्ड कभी नहीं होना चाहिए JSON खोला गया, और इसके लिए कुछ ऐसा करने के लिए पहुंच गया जो बिल्डर पूरी तरह से अच्छी तरह से करता है, एक डैशबोर्ड का उत्पादन करने का एक तरीका है, कोई और रख सकता है। यह थोक काम के लिए अपनी जगह कमाता है, समीक्षा के लिए, और उन चीजों के लिए जो इंटरफ़ेस को उजागर नहीं करता है।
::

## दो बुरा कारण

::warning{icon="i-lucide-hand"}
**उपयोग न करें JSON सामान्य कार्य को तेज़ी से करने के लिए और इसे चालाक होने के लिए उपयोग नहीं करते।** एक डैशबोर्ड हाथ से संपादित एक विन्यास में है कि बिल्डर राउंड-ट्रिप नहीं कर सकता केवल एक डैशबोर्ड है जिसे आप बदल सकते हैं। यदि बिल्डर इसे व्यक्त कर सकता है, तो बिल्डर को इसे व्यक्त करने दें - JSON क्या यह है कि बिल्डर क्या नहीं कर सकता है, और यह देखने के लिए कि यह क्या है।
::
