# খোলার সময় JSON

একটিও নয় CRM Analytics ড্যাশবোর্ড একটি JSON ডকুমেন্ট: উইজেট, বিন্যাস, প্রশ্ন এবং বাইন্ডিং, যেমন টেক্সট হিসাবে । নির্মাতা আপনার জন্য এটা লিখেছে, আর মাঝে মাঝে টেক্সটের অর্থ হচ্ছে ভাল হাতিয়ার।

::note{icon="i-lucide-file-json"}
**এটা ড্যাশবোর্ড ভবনের আধুনিক টাইগার নয়.** বেশীরভাগ ড্যাশবোর্ড তাদের করা উচিত নয় JSON ( খ) কীভাবে আমরা জানি যে, যিহোবা আমাদের প্রার্থনার উত্তর দেন? এর জন্য প্রচুর কাজ, পর্যালোচনার জন্য এবং ইন্টারফেসের কয়েকটি জিনিস প্রকাশ করা হয় না।
::

## দুটো খারাপ কারণ

::warning{icon="i-lucide-hand"}
**ব্যবহার করা হবে না JSON সাধারণ কাজ দ্রুত করা, আর চালাকের সাথে এটা ব্যবহার করবেন না।** একটি ড্যাশবোর্ড-আউট-এর কনফিগারেশন সহ-বিভাগ করা হয়েছে যা নির্মাতাকে রাউন্ড-ট্রাপ করতে দেওয়া যাবে না... ...শুধুমাত্র আপনি পরিবর্তন করতে পারেন, যা একটি বাঁ দিকে সমান। নির্মাতা যদি তা প্রকাশ করতে পারেন, তাহলে নির্মাতাকে তা প্রকাশ করতে দিন — JSON নির্মাতা যা করতে পারে না, আর এটা দেখার জন্য।
::
