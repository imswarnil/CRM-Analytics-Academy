# কেন SAQL আগে থেকেই আছে

প্রত্যেক লেন্স, প্রতি উইজেট এবং প্রতি ড্যাশবোর্ড অনুসন্ধান SAQL নিচে. ক্লিক করা হলে স্বয়ংক্রিয়ভাবে সঞ্চালিত হবে।

::note{icon="i-lucide-waves"}
**SAQL একটি স্ট্রিম রূপান্তর, কোন decliz রূপান্তর নয়।** প্রতিটি বক্তব্য আগের বক্তব্যকে পরিবর্তন করে এবং পরিবর্তন করে, একই স্ট্রিমের পরিবর্তন। তোমার কাজের কোন উন্নতি নেই, তাই **যে আদেশ আপনাকে বিবৃতি দিতে হবে যে পরিকল্পনাটি পরিচালনা করবে** — গ্রুপিং-এর ফিল্টার আসলে একটি arking সারি আপনি বর্জন করতে যাচ্ছেন। এই একক কাঠামোগত পার্থক্য মানুষকে ধরতে পারে যারা জানে SQL ভাল.
::

## আকৃতি

```
q = load "Namilio_Opportunities";
q = filter q by 'StageName' == "Closed Won";
q = group q by 'Segment';
q = foreach q generate 'Segment' as 'Segment', sum('Amount') as 'Revenue';
q = order q by 'Revenue' desc;
q = limit q 10;
```

লোড, সংকীর্ণ, গ্রুপ, গণনা, সীমা, সীমা। ৬টা বিবৃতি, প্রতিটি নিয়োগ `q`...যে যা শেষ হয়েছিল তা প্রত্যেকেই গ্রাস করে।

## এই বিভাগ কি কভার
