# Selection Bindings

Take what the user picked, put it anywhere.

## Anatomy

```text
{{ cell(region_1.selection, 0, "Region").asString() }}
     └──── source ────┘  └shape┘            └format┘
```

| Shape | Returns |
|---|---|
| `cell(step.selection, row, "col")` | One value |
| `column(step.selection, ["col"])` | A list |

## Patterns

```sql
-- one value
q = filter q by 'Region' == {{cell(region_1.selection, 0, "Region").asString()}};
-- many, and all when nothing is picked
q = filter q by 'Region' in {{coalesce(column(region_1.selection, ["Region"]), column(region_1.result, ["Region"])).asObject()}};
-- switch the grouping with a static toggle
q = group q by {{column(groupby_1.selection, ["value"]).asGrouping()}};
```

::tip
The dashboard inspector shows each query after bindings are replaced. Read that, not the template.
::
