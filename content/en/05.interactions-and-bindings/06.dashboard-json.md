# Dashboard JSON

Every dashboard is one document. Learn to read it.

::lesson-hero{figure="dashboard"}
---
points:
  - "Open and back up the JSON"
  - "Read steps, widgets and layouts"
  - "Know the safe and dangerous edits"
  - "Map bindings on an inherited dashboard"
---
::

```json
{
  "steps":   { "won_by_region": { "type": "saql", "query": "q = load …" } },
  "widgets": { "chart_1": { "type": "chart", "parameters": { "step": "won_by_region" } } },
  "gridLayouts": [ { "pages": [ { "widgets": [ { "name": "chart_1", "row": 0, "column": 0 } ] } ] } ]
}
```

| Safe | Dangerous |
|---|---|
| Titles, labels, colours, formats | Renaming a step |
| Widget positions | Renaming output columns |
| A step's SAQL text | Deleting a step still in use |

::tip
Search the JSON for `{{` to list every binding. Retrieve dashboards into git so every change has a diff.
::
