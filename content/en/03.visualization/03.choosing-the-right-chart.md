# Choosing the Right Chart

Pick the chart from the question.

::lesson-hero{figure="dashboard"}
---
points:
  - "Match six questions to six charts"
  - "Sort bars, start them at zero"
  - "Know the four charts to avoid"
---
::

| Question | Chart |
|---|---|
| Which is bigger? | Bar, sorted |
| How did it change? | Line |
| What share? | Stacked bar (donut ≤ 4 parts) |
| How spread out? | Histogram, box plot |
| Do two things move together? | Scatter |
| How do things flow? | Funnel, Sankey |
| One headline number | Number widget + comparison |

## Avoid

- **3D**: distorts size
- **Dual axis**: fakes relationships
- **Gauges**: lots of ink, one number
- **Truncated bar axes**: bars start at zero
