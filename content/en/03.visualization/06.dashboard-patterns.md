# Dashboard Patterns

Five layouts cover almost every dashboard.

::lesson-hero{figure="dashboard"}
---
points:
  - "Recognise the five patterns"
  - "Know the widgets each one needs"
  - "Build one pattern per page"
---
::

| Pattern | Answers | Widgets |
|---|---|---|
| **KPI board** | Are we OK? | 4–6 numbers + comparisons + sparklines |
| **Trend page** | Which way are we going? | Line by snapshot date, split line, biggest movers |
| **Funnel** | Where do we leak? | Stage counts, conversion, split by source |
| **Action list** | What do I do today? | Filter bar + values table with record links |
| **Drill-down** | Why? | Summary → detail → rows, linked by faceting or bindings |
