## What this section will cover

Everything in CRM Analytics is reachable over an API — what that makes possible, the four jobs worth automating, and the ones that should stay manual.

## Planned lessons

- **Why automate** — Everything in CRM Analytics is reachable over an API — what that makes possible, the four jobs worth automating, and the ones that should stay manual.
- **The REST API** — Authenticating, the endpoint families that matter for analytics, versioning, and the limits worth designing around before you write anything.
- **SAQL from code** — Sending a query over the API and reading what comes back — plus the four legitimate reasons a number from a script differs from the same number on the dashboard.
- **Loading data** — The external data API: declare, upload in parts, signal completion — the three-step pattern, the metadata file that decides your field types, and the failure everybody hits once.
- **Python end to end** — A worked path in Python: authenticate, declare a load, push the Academy's data in parts, signal completion, verify the row count, and query the result back.
- **Automation & deployment** — Scheduling, credentials, failure handling, and using metadata export to give dashboards the change history the product does not provide.
- **Interview questions** — The API and automation questions, with model answers — and the operational judgement they are really probing for.
- **Graded quiz** — Eight questions on authentication, the query and external data APIs, load operations, scheduling and change history.
