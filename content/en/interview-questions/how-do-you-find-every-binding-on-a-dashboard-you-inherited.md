Search the JSON for the binding syntax. Bindings are invisible in the interface — they live in individual configuration panels — so in the builder finding them all means opening every widget. In the file they are greppable, and ten seconds gives you the dependency map that would otherwise take an afternoon. Then I write that map into the dashboard description so the next person does not repeat the exercise.
