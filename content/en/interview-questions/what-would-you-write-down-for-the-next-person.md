Four lines: which datasets carry predicates, what each says in plain English, who is exempt and why, and what the fallback is. Security configuration is unreadable as configuration — the next person inherits a set of screens with no statement of intent, and reasonably refuses to change anything. That note is the most useful artefact in the project after the metric definitions.
