Ask whether the identity of each row matters — which account, which deal — because then a table is the correct widget rather than a fallback. What I avoid is a table that needs scrolling: at that point it has stopped being a dashboard widget and become a data export. Both are legitimate needs and they are not the same object, so the widget shows the top ten and a download sits beside it.
