# Cogroup: Joining in a Query

Group and join in one statement, at query time.

::lesson-hero{figure="data-model"}
---
points:
  - "Cogroup two datasets on a key"
  - "Prefix fields by stream"
  - "Choose inner or left"
  - "Compare one dataset under two filters"
---
::

## Two datasets

```sql
a = load "academy_opportunities";
b = load "academy_accounts";
c = cogroup a by 'AccountId' left, b by 'AccountId';
c = foreach c generate a.'AccountId' as 'AccountId',
      first(b.'Industry') as 'Industry',
      sum(a.'Amount') as 'Amount';
```

## One dataset, two filters

```sql
tq = load "academy_opportunities";
tq = filter tq by date('CloseDate_Year','CloseDate_Month','CloseDate_Day') in ["current fiscal_quarter".."current fiscal_quarter"];
lq = load "academy_opportunities";
lq = filter lq by date('CloseDate_Year','CloseDate_Month','CloseDate_Day') in ["1 fiscal_quarter ago".."1 fiscal_quarter ago"];
q = cogroup tq by 'Region', lq by 'Region';
q = foreach q generate tq.'Region' as 'Region',
      sum(tq.'Amount') as 'This', sum(lq.'Amount') as 'Last';
```

::tip
Used by many widgets? Join once in a recipe. Cogroup is for one widget.
::
