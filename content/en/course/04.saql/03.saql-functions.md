# SAQL Functions

The tools you use inside `foreach` and `filter`.

| Family | Functions | Example |
|---|---|---|
| **Aggregate** | `sum` `avg` `min` `max` `count()` `unique` `median` | `unique('AccountId')` |
| **String** | `upper` `lower` `substr` `len` `trim` `replace`, `matches` | `'AccountName' matches "Bank"` |
| **Math** | `round` `abs` `floor` `ceil` `power` `sqrt` | `round(x * 100, 1)` |
| **Date** | `toDate` `now` `date_diff` | `date_diff("day", toDate('CloseDate_sec_epoch'), now())` |
| **Logic** | `case when … end`, `coalesce` | `coalesce('Competitor', "None")` |

```sql
q = load "academy_opportunities";
q = group q by 'Region';
q = foreach q generate 'Region' as 'Region',
      count() as 'Deals',
      unique('AccountId') as 'Accounts',
      round(avg('Amount'), 0) as 'AvgDeal',
      case when sum('Amount') > 100000 then "Big" else "Small" end as 'Size';
```
