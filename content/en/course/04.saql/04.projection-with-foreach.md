# Projection with Foreach

Choose and calculate your columns, once or twice.

::lesson-hero{figure="dashboard"}
---
points:
  - "Project columns row by row"
  - "Know what's allowed after group"
  - "Chain foreach for ratios"
  - "Count conditionally with case"
---
::

```sql
q = load "academy_opportunities";
q = group q by 'Region';
q = foreach q generate 'Region' as 'Region',
      sum(case when 'IsWon' == "true" then 1 else 0 end) as 'Won',
      sum(case when 'IsClosed' == "true" then 1 else 0 end) as 'Closed';
q = foreach q generate 'Region' as 'Region', 'Won' as 'Won', 'Closed' as 'Closed',
      case when 'Closed' == 0 then null else round('Won' / 'Closed' * 100, 1) end as 'WinRate';
```

| foreach… | Sees | Output rows |
|---|---|---|
| Without group | Every field of each row | One per row |
| After group | Group fields + aggregates | One per group |
| After a foreach | The previous foreach's names | Same as input |

::warning
Widgets and bindings find columns by their `as` names. Keep them stable.
::
