    a: "A permission set licence plus a permission set for the user's role (viewer, builder, admin), app sharing with groups at Viewer, Editor or Manager, and row-level security on the datasets."

# Apps, Sharing and Licences

Three locks on the door, then security on the rows.

::lesson-hero{figure="dashboard"}
---
points:
  - "Assign licences and permission sets"
  - "Organise work into apps"
  - "Share with groups at the right level"
  - "Check the integration user for missing fields"
---
::

| Lock | Where |
|---|---|
| **Licence** | Setup → Users → Permission Set Licence Assignments |
| **Permission set** | Viewer, builder or admin set |
| **App sharing** | Analytics Studio → app → Share |

| App role | Can |
|---|---|
| **Viewer** | Open and explore |
| **Editor** | Save changes |
| **Manager** | Share onward |

::note
Sync reads as the **Analytics Integration User**. A field it can't see never reaches a dataset.
::
