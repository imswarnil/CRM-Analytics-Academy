# The CRM Analytics Data Layer

Dashboards don't query Salesforce. They read datasets, built by a chain you control.

## Four layers

| Layer | What it does | Where |
|---|---|---|
| **Connections** | Sources: your org, Snowflake, S3… | Data Manager → Connections |
| **Data Sync** | Scheduled copy of chosen objects and fields | Data Manager → Connections |
| **Recipes** | Join, clean, calculate | Data Manager → Recipes |
| **Datasets** | Indexed tables dashboards query | Analytics Studio → Browse |

## Freshness

```text
01:00 sync  →  01:20 recipe  →  dataset updated
09:00 a deal is saved  →  visible after tomorrow's 01:20 run
```

Put a **data as of** date on every dashboard.

::note
Dataflows are the older JSON version of recipes. Build new work as recipes.
::
