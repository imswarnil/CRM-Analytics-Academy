# Getting Data In

Clean dashboards start with clean loads. Three ways in, one rule that prevents duplicates.

## Three doors

| Tool | Who runs it | Volume | Objects |
|---|---|---|---|
| **Data Import Wizard** | A person, in the browser | Up to 50,000 | Accounts, Contacts, Leads, custom |
| **Data Loader** | A person or a schedule | Millions | Any |
| **REST / Bulk API** | Another system | Any | Any |

## External ID + upsert

Your other systems don't know Salesforce Ids. They know their own keys (`ACC-1066`). Store that key in a field marked **External ID** and **Unique**, then **upsert**:

- key exists → **update**
- key is new → **create**

```http
PATCH /services/data/v62.0/sobjects/Account/Academy_Id__c/ACC-1066
{ "Industry": "Retail" }
```

Run the same file twice: the second run creates nothing.

## Relating by key

In Data Loader, map an opportunity's account column to `Account:Academy_Id__c`. Each opportunity finds its account by the external key, with no Salesforce Ids anywhere.

::warning
Never match on names. "Aster Bank" and "Aster Bank Ltd" are one customer and two records, and the dashboard splits their revenue in half.
::
