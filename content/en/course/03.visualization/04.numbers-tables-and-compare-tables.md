## Compare table: win rate

| Column | Query |
|---|---|
| **A** | Count where `IsWon` = true |
| **B** | Count where `IsClosed` = true |
| **Win rate** | `A / B` |

## Quarter-over-quarter

| Column | Query |
|---|---|
| **A** | Sum `Amount`, close date = this quarter |
| **B** | Sum `Amount`, close date = last quarter |
| **Growth** | `(A - B) / B` |

::tip
Open the step in SAQL mode: the compare table wrote a `cogroup` and a `foreach` for you.
::
