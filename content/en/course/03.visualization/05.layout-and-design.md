## The layout

```text
┌──────────┬──────────┬──────────┐
│  Number  │  Number  │  Number  │   ← the answer
├──────────┴──────────┴──────────┤
│          Main chart            │   ← the why
├────────────────────────────────┤
│          Detail table          │   ← the what to do
└────────────────────────────────┘
```

## Rules

- **One question per page**
- **Grey + one accent** colour, the same colour per category everywhere
- **Same number format** everywhere, titles with measure and period
- **Data as of** on every page
- A **phone layout**: numbers, one chart, one list
