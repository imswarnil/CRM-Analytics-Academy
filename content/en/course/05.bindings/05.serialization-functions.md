# Serialization Functions

The last part of every binding decides what text lands in the query.

::lesson-hero{figure="dashboard"}
---
points:
  - "Pick the function from where the text lands"
  - "Write whole filters with asEquality and asRange"
  - "Switch grouping, measure and sort"
---
::

| Lands in | Function | Writes |
|---|---|---|
| A comparison | `asString()` | `"EMEA"` |
| After `in`, or a JSON property | `asObject()` | `["EMEA","APAC"]` |
| A whole filter | `asEquality('Region')` | `'Region' in ["EMEA"]` |
| A range filter | `asRange('Amount')` | `'Amount' >= 10000 && 'Amount' <= 50000` |
| A date filter | `asDateRange('CloseDate')` | the date range clause |
| `group by` | `asGrouping()` | `'Segment'` or `('Region','Segment')` |
| `foreach` | `asProjection()` | `sum('Amount') as 'Value'` |
| `order by` | `asOrder()` | `'Value' desc` |

```sql
q = load "academy_opportunities";
q = filter q by {{column(region_1.selection, ["Region"]).asEquality('Region')}};
q = group q by {{column(groupby_1.selection, ["value"]).asGrouping()}};
q = foreach q generate {{column(groupby_1.selection, ["value"]).asProjection()}},
      {{column(measure_1.selection, ["value"]).asProjection()}};
q = order q by {{column(sort_1.selection, ["value"]).asOrder()}};
```
