## The recipe

| # | Node | Setting |
|---|---|---|
| 1 | **Input** | `academy_opportunities` |
| 2 | **Filter** | `Type` = New Business |
| 3 | **Formula** | `DealSize` (below) |
| 4 | **Drop columns** | Everything no dashboard uses |
| 5 | **Output** | Dataset `academy_new_business` |

```sql
CASE
  WHEN Amount >= 50000 THEN 'Large'
  WHEN Amount >= 10000 THEN 'Mid'
  ELSE 'Small'
END
```

## Run it, then schedule it

Save → **Run Now** → watch **Jobs**. Then schedule it to run **after the data sync**.

::tip
When a run fails, the error names the node. Usual suspects: a deleted field, a null in a formula, a key that changed type.
::
