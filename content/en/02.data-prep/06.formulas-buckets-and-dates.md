## The functions

| Need | Function |
|---|---|
| Rules | `CASE WHEN … THEN … ELSE … END` |
| Missing values | `COALESCE(Competitor, 'None')` |
| Text | `UPPER`, `TRIM`, `CONCAT`, `SUBSTR` |
| Math | `ROUND`, `ABS`, `+ − × ÷` |
| Dates | `DATEDIFF`, `DATE_ADD`, `NOW` |

```sql
-- sales cycle in days, safe win rate
DATEDIFF(CloseDate, CreatedDate)
CASE WHEN Opps = 0 THEN NULL ELSE Won / Opps END
```

## Buckets

Transform → **Bucket**: draw ranges by hand. Readable, and one click to change.

## Dates

Each date becomes `_Year`, `_Quarter`, `_Month`, `_Day` and epoch fields. Set the **format** at load and the **fiscal year start** in the dataset settings.
