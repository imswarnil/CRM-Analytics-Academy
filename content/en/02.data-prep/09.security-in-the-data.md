# Security in the Data

Sharing a dashboard opens the door. Row-level security decides what's inside.

## Predicates

```text
'OwnerId' == "$User.Id"
'OwnerId' == "$User.Id" || 'OwnerPath' == "$User.Id"
```

Field names in **single** quotes, values in **double** quotes. `OwnerPath` comes from a **Flatten** of the user hierarchy.

## Sharing inheritance

Dataset → Edit → **Sharing Source** (for example Opportunity). Users see what they see in Salesforce. Always set a **backup predicate** for users who can see too many records.

## Test

| Log in as | Expect |
|---|---|
| A rep | Their deals only |
| A manager | Their team's deals |
| No records | Nothing, not everything |
