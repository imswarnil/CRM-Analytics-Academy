# Append and Aggregate

## Grain

| Dataset | One row is | Measures that belong |
|---|---|---|
| `opportunities` | an opportunity | `Amount`, `WeightedAmount` |
| `opportunity_products` | a product line | `ARR`, `CommittedUnits` |
| `marketing_spend` | channel × region × month | `Spend` |

## The two nodes

- **Append**: same columns, more rows. Rows out = rows A + rows B.
- **Aggregate**: group rows, sum or count measures. Optional **group columns** pivot values into columns; **hierarchical aggregation** rolls totals up a manager tree.

```text
opportunity_products (1,192 rows)
  → Aggregate by OpportunityId: SUM(ARR), COUNT() AS ProductCount
  → 608 rows → safe to join to opportunities
```
