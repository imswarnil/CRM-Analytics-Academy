# Time Series and Fill

Make missing dates real, then forecast.

::lesson-hero{figure="pipeline"}
---
points:
  - "Fill gaps in a date series"
  - "Forecast with timeseries"
  - "Add bands, seasonality and ignoreLast"
---
::

```sql
q = load "academy_opportunities";
q = filter q by 'IsWon' == "true";
q = group q by ('CloseDate_Year', 'CloseDate_Month');
q = foreach q generate 'CloseDate_Year' as 'CloseDate_Year',
      'CloseDate_Month' as 'CloseDate_Month', sum('Amount') as 'Amount';
q = fill q by (dateCols=('CloseDate_Year', 'CloseDate_Month', "Y-M"));
q = timeseries q generate 'Amount' as 'Forecast'
    with (length=6, dateCols=('CloseDate_Year', 'CloseDate_Month', "Y-M"),
          predictionInterval=95, seasonality=12, ignoreLast=true);
```

| Option | Does |
|---|---|
| `length` | Periods to forecast |
| `predictionInterval` | Adds high and low band columns |
| `seasonality` | Repeating cycle (12 for months in a year) |
| `ignoreLast` | Leaves out the unfinished period |

::warning
No row is not zero. Fill before windows and averages.
::
