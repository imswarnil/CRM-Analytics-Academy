# Windowing

Keep every row, and look at its neighbours.

::lesson-hero{figure="dashboard"}
---
points:
  - "Read the over / partition / order frame"
  - "Build running totals and moving averages"
  - "Rank and compute share of total"
  - "Compare with the previous period"
---
::

```sql
q = load "academy_opportunities";
q = filter q by 'IsWon' == "true";
q = group q by ('CloseDate_Year', 'CloseDate_Month');
q = foreach q generate 'CloseDate_Year' + "-" + 'CloseDate_Month' as 'Month',
      sum('Amount') as 'Won',
      sum(sum('Amount')) over ([..0] partition by all order by ('CloseDate_Year', 'CloseDate_Month')) as 'Running',
      avg(sum('Amount')) over ([-2..0] partition by all order by ('CloseDate_Year', 'CloseDate_Month')) as 'Avg3M',
      sum('Amount') - sum(sum('Amount')) over ([-1..-1] partition by all order by ('CloseDate_Year', 'CloseDate_Month')) as 'Change';
```

| Range | Means |
|---|---|
| `[..0]` | Start → this row (running) |
| `[-2..0]` | Two before + this (moving) |
| `[-1..-1]` | Previous row only |
| `[..]` | Every row (share of total) |

`rank() over ([..] partition by all order by sum('Amount') desc)` ranks groups.
