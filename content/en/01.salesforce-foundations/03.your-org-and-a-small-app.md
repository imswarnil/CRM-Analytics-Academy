# Your Org and a Small App

Every lesson after this one points at an org. This is the one-time setup: a free org, CRM Analytics switched on, the Academy data loaded, and one small app you built yourself.

::lesson-hero{figure="data-model"}
---

  - "Load the Academy sample data as datasets"
  - "Build a custom object with a lookup"
  - "Stop bad data with a validation rule"
---

## 1. Get the org

| Step | Where |
|---|---|
| Sign up for the CRM Analytics Developer Edition | developer.salesforce.com |
| Enable CRM Analytics | Setup → Analytics → Getting Started |
| Assign **CRM Analytics Plus Admin** to yourself | Setup → Users → your user → Permission Set Assignments |
| Open **Analytics Studio** | App Launcher |

If Analytics Studio is missing from the App Launcher, the permission set is missing. That is the cause nine times out of ten.

## 2. Load the Academy data

Download the CSVs from [/sample-data/academy/](/sample-data/academy/opportunities.csv). In Analytics Studio: **Create → Dataset → CSV File**. Start with `opportunities.csv`, `accounts.csv`, `leads.csv` and `opportunity_products.csv`.

Before you upload, check the field types:

| Field | Type |
|---|---|
| `Amount`, `ARR`, `Probability` | Measure |
| `CloseDate`, `CreatedDate` | Date, `yyyy-MM-dd` |
| `Stage`, `Region`, `Segment` | Dimension |

A number loaded as text cannot be summed. Fix it here, not later.

## 3. Build the Enrollment object

The Academy sells classroom batches; learners enroll in them. Create a custom object **Enrollment** (`Enrollment__c`, auto number `E-{0000}`) with:

- **Account**: Lookup(Account). This is what lets a dashboard show revenue by industry.
- **Status**: picklist (Enrolled, Attended, Completed, Cancelled)
- **Price Paid**: currency
- **Start Date**: date

Then a page layout with those four fields at the top, and an **All Enrollments** list view.

## 4. Stop bad data at the door

```text
ISPICKVAL(Status__c, "Completed") && ISBLANK(Price_Paid__c)
```

Error: *A completed enrollment needs the price paid.* Every record this rule stops is a dashboard number you never have to defend.

::warning
You can see every field because you are the admin. Other users need field access through a permission set. This is why dashboards can be full for you and blank for them.
::
