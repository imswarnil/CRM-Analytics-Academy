## Deploy

| Metadata type | What |
|---|---|
| `WaveApplication` | The app |
| `WaveDataset` | Dataset definition (no rows) |
| `WaveRecipe` | Recipes |
| `WaveDashboard`, `WaveLens` | Visuals |

```bash
sf project retrieve start -m WaveApplication WaveDashboard WaveRecipe WaveDataset WaveLens
sf project deploy start -o production
```

Order: datasets and recipes → **run recipes** → dashboards.

## Speed

1. **Pre-aggregate** in the recipe
2. **Fewer steps** per page
3. **Short** results-binding chains
4. **Limit** table rows
5. **Narrow** datasets
